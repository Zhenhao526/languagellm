# v0.5 环境与信息界限独立审查

日期：2026-09-15。本文记录训练前的可解性审查，不报告学习结果。独立脚本 `bounds_audit.py` 不导入训练环境，只枚举有限决策问题；它验证数学定义，不替代随后对实际环境和消息路由的检查。

## 1. 第一阶段采用的最小环境

- 两名主体在独立样本或任务段之间交换侦察者和采集者职责，段内职责固定。这是实验指定的信息分工，不是自发职业分化。
- 四个有固定空间身份的地点中，恰有一个食物点和一个水点，位置不同，另两个地点为空。12种有序地图等概率。单轮任务每个样本重新独立生成地图，旧经验不能预测下一地图。
- 侦察者观察四地点的资源照片及存在掩码。空间身份由规定观察接口提供；不能解释为DINO自动学会地图。仿真器资源类别只用于生成环境与计分，不通过照片之外的类别编号交给策略。
- 采集者看到本轮私有需求、四地点行动菜单与规定自身状态，看不到资源分布。需求是食物或水各一半，通过任务状态中的二维需求量表示；这属于提供的非语言任务接口，不等于模型从照片自行推断饥饿。
- 行动菜单每次随机排列，采集者知道按钮与地点的对应关系。两种目标条件均不向侦察者显示菜单排列。唯一处理变量是侦察者是否看到当前需求。
- 发信发生在行动之前，侦察者没有移动、采集或其他可观察的环境动作。采集者选一个地点，取得所需资源记1，否则0。

这一版本先保留清楚的信息缺口，三轮库存与地点持续性另成一阶段。两食两水的替代地图会使无通信上界变为1/2，而且少数条件动作方案即可完成任务，表达需求较弱。

## 2. 单轮精确上界

单轮无通信时，无论当前需求是什么，每个地点恰好含所需资源的概率都是1/4。固定地点分工、固定按钮、独立菜单排列、历史和与当前地图独立的共同随机数都不能提高期望成绩。全信息策略可达到1。

接收函数可以表示为一个二元组 `(食物需求时选的地点, 水需求时选的地点)`。共有16种确定接收函数。私有菜单排列只是地点动作的重标记，并不增加世界信息；最优物理地点选择不需要依赖这个独立随机排列。随机发信和随机接收也不会提高最优期望：给定其他策略，总存在不更差的确定最优响应。

独立脚本枚举全部65,535个非空接收函数子集。已知目标时，发送者可以为两种目标分别选择消息；未知目标时，每张地图必须选择同一个消息服务于两种目标。

| 可区分消息数 | 目标可见上界 | 目标隐藏上界 |
| --- | ---: | ---: |
| 1，即无通道 | 1/4 | 1/4 |
| 2 | 1/2 | 1/2 |
| 3 | 3/4 | 5/8 |
| 4 | 1 | 2/3 |
| 5 | 1 | 17/24≈70.83% |
| 12及以上 | 1 | 1 |

目标可见时，四个地点指示码即可完成任务，接收者不必使用需求来解码。目标隐藏时，每个非退化接收函数只能对一张有序地图同时满足两个目标；其他地图至多满足其中一个目标。因此5个消息最多使5张地图两个目标都正确，另7张地图最多各一个正确，总上界为 `(5×2+7)/24=17/24`。脚本找到达到此界的接收函数集合，故该界可达。

目标隐藏、要求全部地图和两个目标都正确时，需要至少12种消息。两个五选一符号和一个二十五选一符号都容许12张地图完整查表，因此两者高分均不能单独证明成分复用。单次大词表是容量对照，也不能仅凭接口形式断言其一定使用整体编码。

这些都是指定均匀分布下的**期望成绩界限**，并非每个有限测试集的逐例限制。四张组合留出图上的五消息上界可以为1；不能拿17/24直接评判该子分布。若改变地图频率、目标概率、额外观察或允许行动通信，须重新计算。

## 3. 三轮持续版本的精确定义

三轮版本沿用12种初始地图，每个现存资源点只有一份可采资源。初始库存为食物0、水0，两类容量各2。

1. 每轮需求独立等概率生成，与地图及全部过去历史独立。采集者知道需求；目标可见条件的侦察者也知道。需求不是公开库存的确定函数。
2. 同一侦察者观察当轮完整资源图并发信，同一采集者选择地点，三轮内不交换职责。若交换且允许完整记忆，昨日侦察过的地图将成为另一种信息来源，当前上界不再适用。
3. 所选地点为空，则没有采集，世界两资源位置都不变。否则实际采走该资源，即使对应库存已满，仍采走并丢弃超出容量的部分。
4. 首次审计采用“入库时截断到2，再消耗本轮需求的一份”。有库存可消费即奖励1，否则0；未消耗资源保留。
5. 下一轮开始前，刚采走的资源在除另一现存资源位置之外的三个地点中等概率补充，其中包括自己的旧地点。另一资源位置保持不变。采集者不直接观察补充发生的位置。
6. 采集者可记住自己的地点选择、实际取得的食物/水/空、历史需求和库存。侦察者没有发信以外的环境行动。公开库存不额外暴露侦察者的独立观察。

“先消费再将剩余库存截断到2”是另一种规则：库存已满又采集同类并消费时，会产生不同终点库存。本次初始空库存、三轮时程的奖励上界不受这个末轮差异影响，但实际轨迹和更长时程会受影响。实现必须固定顺序，并与审计匹配。

## 4. 三轮可解性结果与独立重算

无通信策略的最优值通过有限信念状态动态规划精确求得。信念是在12张地图上的有理数概率；采集者根据实际采集结果更新信念，再将被采资源的三种补充位置边缘化。Bellman状态还包含库存和剩余回合。优化允许完整个人历史和最优探索，不局限于固定地点或贪心补货。

| 段长 | 无通信最优总奖励 | 无通信平均每轮 | 全信息平均每轮 |
| --- | ---: | ---: | ---: |
| 1轮 | 1/4 | 25.00% | 100% |
| 2轮 | 2/3 | 33.33% | 100% |
| 3轮 | 265/216 | 265/648≈40.8951% | 100% |

全信息策略每轮采集本轮需要的资源，即可逐轮满足需求，因此均值1可达。无通信主体可以利用过去采集结果、未移动资源的位置线索和库存，故其三轮平均上界高于单轮25%。这种改善是合法的非语言能力，必须保留。

脚本另用一套不归一化的联合概率历史树重新求解三轮问题。它不调用信念转移、库存转移、世界转移或原Bellman函数，得到同一个265/216；并核查全部48个世界—行动基本随机转移。结果使用精确分数，没有蒙特卡洛近似。

首次输出保存在 `bounds_audit_result.json`，加入独立历史树的验证输出保存在 `bounds_audit_verified.json`，原结果没有覆盖。复现命令：

```sh
.venv/bin/python redesign_v0.5/bounds_audit.py --output redesign_v0.5/bounds_audit_verified.json
```

40.8951%针对允许上述完整观察历史、且能正确识别采集结果的理想无通信策略。有限记忆或视觉识别不完美的学习主体未必达到它。若侦察者只在段首看图、后续没有新观察，全信息1也不能直接作为该受限条件可达上界。

## 5. 训练与解释前还须逐项核查

- 已知/未知目标条件共享世界、目标、菜单分布和预算；发送者菜单权限相同。若另一条件同时暴露菜单，无法将差异单独归于目标可见性。
- 动态环境中无通道训练仍获得合法的实际采集结果及个人历史。终点遮蔽消息只测现有策略的依赖性，不代表从头训练的无通道能力。
- 重排消息时保留同一世界、目标、菜单、库存与合法历史；动态闭环替换若改变动作，会使后续状态合法地分岔，不能强行沿用原轨迹并称为真实闭环回报。
- 评价同时分列两个需求、两人职责、地图及每个回合，防止只服务某一需求的高平均分掩盖不完整协议。
- 消息长度、发信时机、角色和共享时钟不能成为未计入信道。当前固定长度及固定时机可减少这些渠道。
- 两符号序列允许12张地图查表；结构判断仍需保留上下文的单成分干预、跨目标使用与平衡组合留出。未见组合成功不能单独证明组合性；失败也可能来自学习与视觉接口。
- 所有数学界限都假设DINO接口已经能区分需要的视觉信息。冻结DINO并不等于冻结完整行为函数；独立的资源识别/行动准备仍应单列验收。

## 6. 实际 runner 的独立审查

审查对象：`camp.py` 与 `run_stages.py` 的首轮实现及主代理随后修正的C阶段来源。审查过程中没有修改这两个文件。

最先发现的阻断问题是C阶段起点预算不一致：最初无通道条件直接从个体准备开始，其余条件先有A阶段训练；已知目标条件还来自不同A阶段协议。主代理已经修正：

- `persistent_communication`、`persistent_channel_removed`、`persistent_known`、`persistent_delayed` 均继承同一 `A/hidden_sequence` 终点，重建Adam，各自接受相同C预算。
- `persistent_blocked` 继承 `A/hidden_blocked`，A和C均阻断通道，总更新预算与其他路线一致；它是完整无通道训练路线，历史不同于撤去已有通道的路线。

这样，前四组可以比较从同一起点迁移后的干预；第五组提供从第一阶段开始无通道的基准。两种无通道结果不可合并为一个条件。建议配置中同时保存A来源路径及检查点哈希；目前初始参数哈希可以核对同一起点，但不直接表明来源。

已核对实际 `collect` 为先截断容量再消费，与精确审计一致；采满仍采走并补充、空点不补充、未采资源位置不动、跨轮资源照片只随补充改变。接收者的14维历史是此前两次实际地点选择、实际所得资源或空；三轮内足以保留全部相关采集事件，没有加入侦察者隐观测。过去需求未显式保存，但当前库存与全部采集事件对本任务的地图信念和剩余库存决策已经足够；未来需求独立同分布。

记忆条件有两个必须准确描述的性质：

- `delay_replay` 直接重做 `GRU(seen, zero)`，所以与 `immediate_continue` 的前向结果及梯度完全相同。相同起点、输入和随机流下，应得到相同的训练轨迹和终点参数。这是流程正控，不是另一种独立的记忆机制。
- `delay_reset` 把发送状态全部归零。单轮隐藏目标、空库存条件下，发送者已经没有关于地图的信息；25%的上界是信息移除的结果。它不能用来证明无记忆主体不具备语言能力。

C的消息重排是在各自合法闭环中执行。第一轮后，动作变化会导致世界与库存分岔，因此全段正常—重排差值测量的是破坏通道对动态策略的影响，不是逐一固定相同世界和历史的局部消息效应。后者需要另外读取原始轨迹，在固定接收者上下文下替换消息并检查即时动作。

四地点准备门槛调用旧 `Agent.actor` 并屏蔽空点。它证明准备后的视觉投影仍支持区分资源并选择对应的可见对象，不能表述为新 `CampAgent` 的GRU和行动接口已经通过90%独立行动验收；这些新增接口在A开始时仍为随机参数。

独立测试文件 `test_camp_independent.py` 已运行通过12项测试，总用时0.587秒：

- 穷举2,592个世界、库存、需求、行动与补充组合，独立计算所有输出并核对输入不被修改。
- 满库存仍采走并补充、空点不补充但可以消费旧库存，以及库存守恒。
- 单轮容量上界、两套独立三轮信息界限与留出地图的因子平衡。
- 阻断消息时，改变全部私有地图仍不改变同条件下的采集动作。
- 真实个人历史、段内角色隔离、菜单重排仅重标记按钮。
- 25种序列均可进入整数信道，接收者损失不反传发送者，投影冻结且参数无共享。
- replay与immediate逐值逐梯度一致，reset完全移除场景，重排保持需求/库存条件分组。

复现测试：

```sh
redesign_v0.3/deployment/.venv/bin/python -m unittest discover -s redesign_v0.5 -p test_camp_independent.py -v
```

这些检查没有训练模型，不构成正式实验结果，也不证明优化过程必然达到数学上界。C起点问题修正后，当前检查范围内未发现阻止开始探索试验的剩余环境或消息路由错误。
