# v0.5 信息路由与模型隔离审查

2026-09-15。检查 `camp.py`、`run_stages.py` 及继承的 `ImageBank`、`individual_practice`。未改这些源码。本审查包括静态阅读和小批量内存探针，不把开发 smoke 或阳性诊断写成主实验结果。主代理在审查期间增补了阶段 C 来源对照及阶段 A 课程调度；以下按增补后的行为说明。

## 已核对的关键约束

1. **主体参数与梯度隔离。** 两名 CampAgent 通过 deepcopy 得到各自 project；初始化还检查所有参数存储地址不重复。消息是 detached 的整数，经 NumPy 复制后才进入另一主体的接收嵌入。个人 loss 只遍历归属于此人的发送／采集项，自己的 value 也只读本人规定输入。一个主体的 loss 反向传播不会给另一主体参数产生梯度。共享的是环境标量后果，不是可微隐藏状态或共享优化器。
2. **空点正确掩蔽。** `scene_visual` 在 project 后分配四个全零槽位，再填入两处照片表征；没有将原始零向量经过有 bias 的 project 当成空点。另四维存在标志指出已观察的空／非空。本阶段提供者每轮知道四地点的当前情况；存在标志不是未访问地点的合法替代观察。
3. **prepared 冻结。** project 全部 `requires_grad=False`，投影缓存也在 no_grad 中生成并 detach；训练优化器只收可训练参数。训练终点重新投影全部 60 张照片并校验缓存哈希。准备结束后的新通信、记忆、接收行动与 value 接口独立初始化。
4. **目标可见性。** A 的同信道 known/hidden 两组使用相同架构、同种子初态及世界流；区别仅在 sender 的二维目标输入是否置零。receiver 在两组均得到当前目标。当前目标逐轮独立抽样，公开库存不直接等于当前目标。发送者看不到 collector 的随机菜单顺序。
5. **角色和菜单。** 每个 batch 分成相等的两个方向，整段 episode 内角色固定；两个人各以提供者和采集者身份学习自己的头。四地点编号是外加的公共空间坐标，菜单顺序仅采集者可知。初审版本 actor 对菜单中的地点 one-hot 逐项评分，随后版本由 context 输出四地点 logits、按菜单 gather；两版都最终用 `menu[row, sampled_action]` 还原真实地点。菜单置换只置换评分，不改变对应地点的评分含义。这是实验指定的角色交换，不是自发分工。
6. **照片及地图留出。** 社会训练显式 `split='train'`，评估默认为 `test`；ImageBank 的中心与尺度只由训练 44 张拟合。holdout 条件训练池排除四种指定地图；课程传入 map_pool 时还会与 TRAIN_MAPS 求交。评估不受课程池限制，使用全部 12 张地图。照片ID、地图真值和正确位置用于环境／记录，不进入接收策略。旧 16 张测试照片仍是开发留出，不能算新的确认资料。
7. **阻断条件。** sender 仍抽样符号并保留自己的 REINFORCE 项，但传递消息始终覆盖为零；从训练起阻断的 normal/stochastic 评估也不解禁。阶段 C 的 persistent_blocked 延续 A hidden_blocked，persistent_channel_removed 则从 A hidden_sequence 后移除通道，区分了两种学习历史。

内存探针使用旧开发准备文件 `smoke_001/prepared_99001.pt`，不更新参数或保存训练结果。12 项通过：同种子初始化相同、project 禁梯度、另一主体无梯度、project 无梯度、投影后空点全零、训练照片池正确、地图留出正确、测试照片池正确、菜单置换等变、阻断输入为零、A known/hidden/blocked 世界流匹配，以及主体自己的可训练参数确有梯度。128 个训练情境只出现地图编号 `[1,2,3,5,6,7,10,11]`。A 三组世界哈希均为 `a27851b91cdec006e430fc10dddad5f81ac9e0b6ebe75d65389af02c22204f84`。

## 需要保持的证据边界

**准备门槛只检验了旧动作接口。** `evaluate_prepared_four_sites` 延伸旧 ResourceAgent.actor 至四候选，并显式屏蔽空点；CampAgent 只继承 project，接收 actor 是新的。因此不能称新 CampAgent 已通过四地点行动准备。主代理已接受这一限制，并授权独立 `diagnostic_receiver_control.py`：用明确标记的外部 oracle 地图／目标位置编号，单独检查新接收接口的行动映射可学性。该控制不是语言形成，权重不得回灌主实验；其结果另行保存，不能提前写成通过。

**当前记忆测试范围较窄。** 每次采集前 `observe` 都从零状态读取当前四地点照片。delay_memory 只是观察后连续三次全零输入的 GRU 递推，世界在这段计算间隔内不改变；不是离开现场后跨采集回合保持旧地图。collector 的 14 维输入另保存本人最近两次地点及采集结果，属于研究者提供的事件接口。两种记忆来源必须分开描述。

**delay_replay 与 immediate_continue 在当前实现中数学等价。** replay 最终重新计算 `memory(seen, zero)`，丢弃此前延迟递推；没有 dropout 等随机层。相同初态、世界流和预算应产生相同的输出与梯度。它可检查恢复合法观察是否恢复行为，不是独立发现一种优越的记忆机制。reset 完全移除私有地图，属于信息损失边界控制。

**持续任务的打乱是整段干预。** shuffle 在方向、当前目标和库存内交换完整消息，保留这几项消息边际，但未条件化 collector 的事件历史。当前消息被打乱后动作会改变库存、地图及以后经历。因此 C 的 normal−shuffle 是持续通道扰乱造成的总表现变化，不能自动等同于固定同一当前历史时某条消息的即时因果效应。要检验后者，应另在相同已保存前缀上分叉当前消息干预。world 哈希包含内生地图与照片，C 的正常和扰乱轨迹不同属预期；不能把哈希不同误判为外生随机流不一致。

**学习历史对照不要混淆。** C 通信与 persistent_channel_removed 使用相同 A hidden_sequence 终点，可研究移除通道后继续学习；C persistent_blocked 使用从开始就阻断的 A 终点，比较的是整段通道可用性。persistent_known 当前也从 A hidden_sequence 开始，因而 C 的目标开放比较有相同起点，不能称它继承了 A known 协议。

**课程与混排要按实际匹配层级命名。** 本次初见实现对 course/mixed 固定了各难度级别的更新次数，但每次实际世界仍按更新编号抽样，故不是完全相同场景多重集仅改变次序。已向主代理提示：若仅保持该版本，应称“匹配难度更新数的混排”；若随后将 world seed 与难度条目共同打乱，可再核对严格匹配。各容量条件还存在参数量及策略随机数抽样次数差异，25 个原子码与两位五符号码只匹配可区分码数，不能称架构和优化完全等价。

**非符号信息通道需要披露。** 公开二维库存和采集者本人收到的食物／水结果是明确编码的身体／行动后果反馈。它们不泄露未采地点类别，但不能把主体描述成“除照片和符号外没有任何结构化资源信息”。固定地点 one-hot、二维需求、整段角色安排也都是研究者提供的非语言能力。

评估的 n 是 episode 数；C 每段三步会产生 3n 条步骤记录，这些不是额外独立训练种子。形成和结构结论仍以独立种子为统计单位。本次探索规模用于检查可学习性、失败模式和后续设计，不承担人类语言起源、一般世界理解或新照片确认的结论。

## 审查结论

在已检查版本中，未发现阻塞阶段 A 探索的信息泄漏、跨主体梯度、空点投影或 train/test 混入问题。上述能力门槛、记忆含义和持续干预范围需在执行方案及结果中明确。正式运行前应保存实际源码快照、准备来源和条件起点；若改动调度或路由，应基于对应快照重新核查，不把此审查自动外推到未来版本。

## 同日开发变更后的追加核查

主代理随后将 mixed 改为连同 batch identity 一起置换；地图池、可达地点和世界 seed 都随 identity 变化。对 1800 更新预算核查所有 identity 一一对应，course/mixed 都含 400 次两地点、400 次三地点和 1000 次四地点任务。又抽取跨阶段 8 个 identity 核对两组 world 哈希完全一致。此版本已补齐相同训练世界批次多重集的顺序比较，不再受上文初见调度限制。

新课程每 batch 随机抽取可达地点子集，并在采集动作 logits 上屏蔽不可达地点；地图也只把资源放在此子集。这个物理可达性约束在资源类别抽样之前确定，不直接给类别答案；它会提供关于候选位置的合法非符号信息，使早期任务较容易。应在观察／动作权限表中披露，而不是把早期两地点阶段的无通信基线当作完整四地点任务的基线。提供者输入仍是其合法地图照片，没有接收者私有菜单顺序。

新 flat actor 的菜单 gather 等变、实际动作始终处于 allowed_sites，以及上述 batch 配对均通过内存探针。这轮核对源码哈希为：camp.py `703106a0096adc8803cdc97f34f68b6eb6f7c4e4a5e4eda610eafb29509faa63`；run_stages.py `c3a50b92c1c775da8aad84c6678b4d959695b480f357324454124ad4cf3ddda4`。仅对此快照负责。

两次外部代码阳性诊断已另行完成、未回灌主实验。旧逐候选评分器在完整地图代码及目标地点代码下均达到两人 100%。同 seed 的 flat actor 在目标地点代码下仍 100%，完整地图代码仅 75.00%／75.28%；每人有 6 个地图仍不能按不同目标改变地点选择。旧、新非社会 prepared 参数逐 tensor 相同，因架构变化，接收头初态不能视为跨架构完全相同。两个诊断内的地图／目标位置条件初态均匹配。此反差提示优化参数化的作用，不能把主实验中的不足自动归结为四地点行动容量不足，也不能预先假定新头更好。详见各自目录内 diagnostic_report.md。
