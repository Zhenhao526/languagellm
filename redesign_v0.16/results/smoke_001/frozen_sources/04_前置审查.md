# v0.16 分支幅度干预的独立审查

本轮新增 policy_only_scale（10）和 value_only_scale（01），复用 v0.14 reset（00）及 v0.15 reset_scaled（11）。这是看到两个端点后设计的同来源机制实验；新增 24 个运行并不增加独立来源数。在尚未开始任何开发或正式训练时，讨论后将唯一主要终点固定为 sealed 自然 N 的路径差 `Y10−Y01`，先在每个来源内平均三分区和两方向，再报告四来源配对差及均值。四个简单效应、交互 `Y11−Y10−Y01+Y00`、old/added 与 AUC 为辅助，不据结果更换主比较；未设等效界，不能把小交互或不显著解释为可加性或等效。

## 缩放位置与语义

observe 保留 v0.14 reset 的未经缩放 h。两个固定 float32 buffer 为 `send_context.h_scale` 和 `send_value.h_scale`，只在对应网络第一层之前乘 local 的前 96 维；后 4 维目标及库存不缩放。不得先乘再除恢复 h，也不得把记录用的 policy_h/value_h 再送入 send 造成双重缩放。原参数名称、对象、初始化、requires_grad 与优化器参数顺序必须保持，两个 buffer 均不进入优化器。

该接口安排同时覆盖正常 send 和协议 make_context 直接调用 send_context 的路径。记录中的 h 与 raw_h 应相同；policy_h/value_h 分别是两个实际分支所消费的 96 维向量。00 的 raw_h 对齐旧 reset 的 h；11 的 policy_h 和 value_h 对齐旧 reset_scaled 的有效 h。不得因层级语义改变而忽略 h 的跨版本核对。

价值支路既通过有限批次的 `(target−value).detach()` 改变策略梯度权重，又通过发送端共同梯度裁剪影响策略更新。两分支没有可训练的共享视觉上游，但不是彼此独立的学习系统。交互的符号还依赖成功率尺度及其上下界，不能将它直接命名为语言能力之间的协同或必要性。state-only 基线在理想未裁剪完整期望下的恒等式不等于当前有限批次、裁剪及 Adam 过程没有价值支路效应。

## 来源、校准与预算

完全复用 v0.15 已封存的每人 alpha，不重新校准、不扫描倍率。来源仍为 31101–31104 与三分区，原照片、原准备、同一 reset 社会初态；新增两臂同为 2400×512 通信，只 old18 获得反馈，added/sealed 无反馈。随机身份不加入臂名，所有世界及外生策略均匀数与 00/11 匹配；实际消息、行动、价值和梯度允许不同。四臂效应不能直接解释为新增世界信息：alpha 本身利用了既有 retained 训练支持上的统计量。

审计应绑定 reset、reset_scaled 两批完成 manifest、v0.15 校准完整记录与实际消费文件；既有 v0.15 对校准前向/支持/范数的独立审计作为明确继承证据，不把未改变的校准再称本轮新独立科学结果。需确认新源没有更改旧冻结文件或历史参考，也未引入新私人训练。

## 独立执行核验

审计器只复用旧的独立抽样/损失/概率测量数学，不导入被审 branch_interface。自行建立保持原参数的前 96 维缩放网络，实现两个 buffer，再重放训练、价值与协议路径。

开发短批同时包含 00、11、10、01，各 2 更新；00 对齐旧 v0.14 reset 两步，11 对齐旧 v0.15 两步。长批为 10、01、11 各 2101 更新，11 对齐旧 v0.15 smoke002 全轨迹；覆盖 2101 熵关闭。原张量、原 Adam、行为、价值损失、消息 logits 与协议均需逐位重放；只剔除明确新增 buffer，并按 raw/effective 语义对齐 h。容器类型或记录哈希差异与真实数值差异分开，失败源和 receipt 保留。

正式后核验全部 24 新运行、每一步预算/世界哈希/零留出反馈、每个检查点视觉冻结及两标量不变。尤其两个新 buffer 虽以 send_ 开头也必须单独冻结检查，不能被发送参数前缀过滤掉。首步和 2101 步独立重建原生采样、双方角色损失、分角色 norm2 裁剪和 Adam 参数/矩状态；所有终点五模式及八个检查点的完整 49 码原生分布、逐符号贪心消息和接收表独立重算。原生参照仍限于各自政策和同一支持，不能跨政策减 N 或拼接子组最优表。

不追加梯度因素、基线替换、学习率扫描或新的认知解释。若实验显示支路依赖，只支持当前接口和有限训练算法下的作用；它不替代新图片/新来源确认，也不证明人类语言起源的条件。
