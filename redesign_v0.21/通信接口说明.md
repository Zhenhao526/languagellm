# v0.21 通信接口

本模块只实现新通信政策与损失，不加载私人行动头，不训练视觉或时间接口。调用者先恢复 v0.20 的 `full` 视觉参数，再调用 `reset_communication(agent, seed)`。观察仍使用 v0.20 两帧函数及末端无仿射 LayerNorm；本文件不额外规范化或缩放 `h`。

`reset_communication` 接受显式 63 位非负整数种子，在局部 Torch RNG 内原位重新初始化 `send_context/send_embedding/send_recur/send_out/receive_embedding/actor/send_value/receive_value`，保留参数对象与名称。全部参数先冻结，再开启发送 43,319 参数（9 张量）与接收 6,364 参数（5 张量）；两个价值网络虽重新初始化，但冻结且不进入任何前向或损失。所有历史梯度槽清空；优化器必须由运行器新建。同一配对比较应使用相同通信初始化种子，不同个体的种子派生与记录由运行器负责。

## API

- `trainable_groups(agent)` 返回 `{'sender': list[Parameter], 'receiver': list[Parameter]}`，自身不改变参数或标志。
- `message_log_probs(agent,h)` 返回有计算图的 float32 `[B,49]` 完整消息对数概率，行内码序为 `7*t0+t1`。对每个首符号前缀分别运行同一个 `[B,...]` 自回归计算。
- `greedy_messages(agent,h)` 返回 int64 `[B,2]`，先选首符号，再条件选择次符号。它不等于 49 码联合最大概率解码；并列取首索引。
- `receive_messages(agent,messages)` 返回 float32 `[B,2,6]` 行动 logits。只接受 int64 `[B,2]` 消息，库存和历史固定全零；两个目标分支均不见对方行动或反馈。
- `receiver_logits(agent)` 枚举相同序号的所有 49 码，返回 `[49,2,6]`。
- `direction_loss(sender,receiver,h,uniforms,positions,entropy_weight)` 返回 `(sender_loss, receiver_loss, trace)`。`h` 必须是无梯度 CPU float32 `[B,96]`，接收方没有获得 `h` 的路径。

`uniforms` 必须由调用者提供 NumPy float32 `[B,4]`，依次控制两个符号和食物、水两次行动；函数内部不产生随机数。`positions` 是整数 `[B,2]` 终态位置真值，仅在完成离散消息和两行动之后计算回报，不作为任一网络输入。两个角色必须是参数对象不共享的个体。

`trace` 含 NumPy 数组 `h/uniforms/messages/first_logits/second_logits/token_probabilities/action_logits/action_probabilities/actions/positions/success/reward/advantage/sender_logp/receiver_logp/sender_entropy/receiver_entropy`，以及标量 `sender_loss/receiver_loss/entropy_weight/baseline`。第二符号概率对应实际抽中的首符号。默认返回完整轨迹，保存频率由运行器决定。

## 损失和解释范围

一次场景发一条消息，两需求各独立抽一次行动。设两成功指示为 `rF,rW`：

`R = .25*(rF+rW) + .5*rF*rW`，取值为 `0/.25/1`；常数优势为 `R-.5`，没有旧实验的 `R-1` 平移或学习型价值基线。

每个返回的角色损失已经对 B 个场景取均值：发送 log probability 是两符号之和，接收 log probability 是两目标之和，分别乘同一个常数基线优势；再减去给定系数乘该角色的两项熵之和。发送第二项熵只在实际采样到的首符号前缀计算，沿用原采样前缀政策损失，并非额外计算全序列边缘熵。

本模块不除以 2。运行器按预定的两个角色平均再除以 2，进行独立反向、角色参数裁剪和 Adam 更新；不得在外部再次对本模块的 B 场景重复平均。发送者损失不会通过接收者反向，接收者损失不会通过离散消息反向到发送者。双方只能通过离散符号和共享标量反馈共同适应。

这构建的是任务中的双目标离散通信政策。沿用需求分支、地点布局及两个符号的架构，不预设任一符号的资源意义；通信成功本身不等于成分性、语法或人类语言起源。

自检命令：`redesign_v0.3/deployment/.venv/bin/python redesign_v0.21/social_model.py --self-test`。自检使用合成主体，不进行训练；检查新初始化、冻结保留、梯度隔离、真值路由、49 码归一与采样概率一致、逐符号贪心、常数基线及未调用价值网络。
