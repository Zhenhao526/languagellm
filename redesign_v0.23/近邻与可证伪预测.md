# v0.23：私人经验范围与通信迁移的近邻及可证伪预测

2026-09-16。只读固定方案、前置科学审查及原始论文相关方法；未读取本轮开发或正式成绩，不改执行方案、主指标或验收门槛。

本轮能增加的证据是：**在固定预算和接口下，私人阶段接触过某个状态组合，是否足以帮助新协议表达通信训练未见的该组合。** 这比笼统比较“认知较强/较弱”更具体。表征预训练影响通信、视觉任务成功不保证通信泛化、发送信息与共同适应需要分开，均已有直接工作；三臂设计与本项目 v13–19 不同，并不构成领域首次性的证据。

## 这三个条件实际识别什么

| 条件 | 私人准备支持 | 新通信训练支持 | 对 new12 的准确称呼 |
|---|---|---|---|
| A | old18 | old18 | 两个本轮拟合阶段均未接触的布局 |
| B | all30 | old18 | 私人训练已接触、通信训练未接触的布局 |
| C | 与 B 同一 all30 私人终点 | all30 | 两阶段都已接触的布局；通信可学习性的辅助对照 |

按固定方案，主量为终点 new12、两 mask 等权的自然贪心双目标 J 的 **B−A**，先来源内平均，再列四个来源差。B/C 共享私人终点，A/B 共享社会训练世界和通信参数初值，因而比把不同历史的既有结果拼在一起更容易解释。C−B 是同一私人接口下改变通信经验的辅助比较，不是通信泛化成绩的直接竞争。

仍有三个必须保留的限制：

- 固定总预算下，all30 组每张旧图的平均曝光约为 old18 组的 60%；局部视野下隐藏地点候选也由训练支持中的 3 个变为 5 个。因此操纵的是**经验分配的总作用**，同时涉及覆盖、复习频次和私人任务难度，不是只增加知识量。
- B 的 new12 不是主体全阶段未见的组合，C 更不是通信留出。沿用的 test 照片可检查实例迁移，但不能把这次结果叫独立新图库确认。DINO 和此前资源准备的经验也不随 A/B 改变。
- 私人原头成功只证明该头和接口可以完成规定行动；丢弃私人头后，新消息头能否读出这些信息仍是学习问题。若 A/B 私人准确率均高，仍可分析经验分配效应，但不能宣称制造了清楚的私人行动能力差。

## 结果前的反驳条件

工作预测是：若私人全支持确实消除了相关状态的不熟悉，B 应在通信未见 new12 上优于 A。它是待检验的方向预测，不追加显著性门槛；均值和四个来源差均须完整报告。全私人组原定八个来源×mask 平均条件均达 80% 的能力验收，不能由通信成绩或事后挑选个人替代。

| 预定结果模式 | 可改变的判断 | 不能顺势推断 |
|---|---|---|
| B 私人验收通过，B−A 通信 J 为正且各来源较一致 | 支持本预算下私人状态经验有助于通信阶段未见组合的表达；下一问题是经验改变了哪种可读结构。 | 不能证明符号已组合化。49 条完整码足够记忆 30 布局，私人 all30 也可能形成整体状态表征。 |
| B 私人验收通过，但 B 仍弱；C 明显较好 | 反驳“只要私人行动熟悉，当前协议学习就自然迁移”的充分性预期；直接通信经验在此设置中仍有贡献。 | 不能定位为发送器、接收器、表征或优化中的某一环，更不能证明主体普遍缺乏组合表达能力。 |
| B−A 约零、负向或来源间反向 | 削弱私人经验扩展会稳定帮助协议迁移的预测；应保留可能的任务难度、曝光分配或表征几何解释。 | 四来源结果不足以宣称统计等效、经验完全无效或普适负效应。 |
| B 私人验收失败，或 C 通信也弱 | 前者使“私人已会却不会表达”的前提不成立；后者使当前协议接口与预算的可学习性解释仍未排除。 | 不追加训练到满意，不换主量，也不以失败证明语言能力的必要条件。 |

自然 J、原生概率 Q、常码和整码重编码参照各有口径。Q 上升而 J 不升可提示策略确定性/决策差异；它不能改写预先主结果。重编码参照或消息变化也不单独证明语法。两 mask 分项用于检查效应是否仅来自一类当前可见资源，不能把最好的 mask 替代等权主量。

## 最小贡献表述与检索边界

若结果有辨别力，合适的表述是：“在同一自监督视觉底座和冻结接口条件下，区分私人状态熟悉度与通信状态熟悉度，并量化私人行动经验对新协议表达迁移的贡献或不足。”它不是新语言学习算法，不识别人类语言起源的必要条件，也不识别 DINO 世界知识的必要性。是否足以成为论文贡献，仍取决于结果、机制证据、直接方法比较与独立材料复核；这次有界检索不能认证 ICLR 级新颖性。
