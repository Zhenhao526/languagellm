# v0.11 预定协议测量

在正式36臂训练开始前固定。主功能比较按固定执行方案和测量细则执行；这里的指标是机制诊断，不代替主AUC或独立确认。全部训练完成后才执行探针。

来源为12个base终点和36臂各300、600检查点，共84对模型、168方向。使用沿v0.10固定的每图16个验证照片对，30图共480例，每方向old18分母288、added6分母96、sealed6分母96。每份保存逐例自然消息、第一位与每种首位下第二位logits、49码×两资源×六地点的接收logits。逐位贪心不能替换为整码概率最大。枚举菜单排列核对动作物理地点等价。

保留每个图组的自然贪心N、原贪心接收可达U、完整分类政策解析联合成功Q、知道地图的分析者为固定随机接收者选整码的最佳概率B、子集单独最优重新赋义C_S。概率从保存的float32 logits用float64稳定softmax计算，不作为有限随机数实现的逐比特模拟。只保证N≤U、N≤C_S、Q≤B，不能跨随机/贪心口径任意作上下界。sealed从不进入兼容前沿的优化。

兼容诊断固定旧发送者S0在old18上的自然贪心码频数o(m,z)，而新增频数a(m,z)来自当前发送者Sθ在added6上的自然贪心消息。接收者Rθ为当前同阶段版本。分别报告：

1. 当前Sθ→当前Rθ在added6的自然J，旧S0→当前Rθ在old18的真实正确数Tθ；当前Sθ→旧R0在old18的J及当前伙伴旧J另列。
2. 对每码选择解为旧地图或新增地图的整数动态规划。在旧正确数至少为Tθ时求新增最大正确数，原当前Rθ的新增成绩须不超过该界。另以原S0→R0的旧正确数T0作固定门槛；当Tθ<T0时明示模型不符合该约束，不能把其成绩超界叫突破上界。
3. 逐例保持旧S0全部旧照片例两动作（包括原有错误）的新增界；新增单独C_S与达到它所需最小旧正确数损失。保存49码动作表见证并由原例重算。
4. 当前发送者旧图消息相对S0的变化比例，新增消息使用旧S0在旧图已用过完整码的比例。这些描述有限照片上的自然码使用，不代表随机政策全部支持或稳定词义。

动态规划允许分析者读取真地图，任意重新赋义完整码，限定确定性完整码→联合动作。它不受神经参数化与学习预算约束，不保证可学习。若改为随机动作及期望旧正确数约束，整数DP不是该更宽类别的普适界。两个端点的可行域不同，不能用起点上界限制两端共同学习的全程。每个阶段都用同一旧S0统计参照，当前新增码重新测量；不是将供体码冻结到起点后冒充实际新消息。

汇总先在四种子各自平均三划分及两方向，再列均值与四种子结果。anchor/release在300点的完整logits与消息应一致。该协议探针不新增片段替换、拼接、语法阳性、模型训练或新图采样；不能从高C_S或某个界改善直接宣布组合语言。正式源码、依赖和本方案哈希见protocol_fixed_manifest.json。
