# v0.11 旧伙伴锚定：事前测量与解释边界

2026年9月15日。依据已讨论的三臂方案固定测量口径；本文件不启动训练，不修改v0.10数据。具体字段待运行器接口落实后对齐，若有差异，应在正式批次前记录。分析脚本为 `analyze_anchoring.py`。

## 目标、重复单位与支持集

问题是：当双方都有相同可塑性时，继续满足旧伙伴的约定是否限制新用途学习；在固定中点解除要求，能否恢复学习？这次干预操纵伙伴版本及其带来的学习压力，不直接操纵理想解码的数学可行域。

继承v0.10的全部12个形成终点，不按成绩、冲突程度或概率上界筛选。三个条件为当前伙伴、持续锚定、锚定后解除，各600更新，共36次继续学习。独立单位是原四个主体对种子29101–29104；每种子内先平均三个分区和两个方向。36运行、72方向和重复评价世界都不能当成独立主体数，也不能称四个新的确认种子。

old18、added6、sealed6标签保留v0.10分区。旧与新增图参与本轮训练，sealed始终不训练。新增图结果是适应；只有sealed成绩涉及未训练组合表达。沿用的照片和任务仍属于开发数据。

所有正式运行完成固定预算后统一读取与汇总结果；不根据sealed曲线调整训练。分析入口先检查全36个结果文件集是否齐备，缺失时只返回文件清单，不读取或输出部分成绩。

## 三种评价连接

各时间点在同一预定世界集合、照片、目标查询和物理动作口径下，分别测量：

| 连接 | 含义 | 主报告范围 |
| --- | --- | --- |
| `Sθ → Rθ` | 当前伙伴之间完成任务 | old、added、sealed各自的自然贪心双目标成功J、单目标准确率及收益 |
| `Sθ → R₀` | 当前表达能否被旧接收者使用 | old图J，单独保留两个方向 |
| `S₀ → Rθ` | 当前接收者能否使用旧表达 | old图J，单独保留两个方向 |

两条跨旧伙伴连接各自汇总，不能只报告它们的平均值。跨旧伙伴J低可以来自整条行为函数的不兼容，不应称为纯词义距离。旧任务在当前伙伴间保持，也不保证原有消息含义或逐照片两动作保持；仅凭J总数不证明没有具体旧例退化。

`S₀,R₀`必须来自对应方向的形成终点，始终冻结。`Sθ,Rθ`使用同一检查点的当前权重；不在一次评价中更新参数。同一来源的三臂共用评价世界。三种连接在零步应完全相同，因为当前权重等于旧版本。每种子每指标先平均六个分区×方向单元，再在四种子之间求均值。

## 主指标与比较

检查点固定为0、25、50、100、200、300、325、350、400、500、600。完成第300次更新后解除锚定，第一次使用当前伙伴的更新是301。解除时不重置Adam，不改变学习率、探索系数、奖励、地图支持或批量。

**唯一主比较为“解除−持续锚定”的新增图当前伙伴J在300–600步的归一化AUC。** 只使用300、325、350、400、500、600六个固定点：

`AUC = Σ [(J(t_i)+J(t_{i+1}))/2 × (t_{i+1}−t_i)] / 300`。

它是这300步内平均成功水平，不是不加权的六点均值，也不单独等于学习斜率。300点仍属于共同锚定结束的状态。解除与持续锚定在0–300必须有相同世界、权重和优化器状态，且贪心评价相同；否则先作为执行问题核查，不能把已有分叉解释为解除效果。共同300起点使AUC差与减去共同起点后的AUC差相同，不重复算作两项证据。

**预定次比较为“当前伙伴−持续锚定”的新增图600步终点J。** 同时完整保留解除臂终点、所有新增曲线、三个条件下两种旧跨伙伴J，以及当前伙伴old/added/sealed J。old相对零步的变化、跨旧伙伴相对零步的变化应并列展示。600步终点、AUC、变化量和不同方向是相互关联的结果，不能当成多次独立确认。

每项比较列出按种子配对的四个差值、均值和范围，不以照片数构造主体总体的二项置信区间，也不把三个分区当成12个独立形成种子。本批不追加bootstrap或显著性筛选。小效应或符号混合需原样报告，不能因为不显著就证明效应为零。

## 事前预测及否证边界

候选机制得到支持需要多项观察共同成立，而非单个新增图高分：

1. 持续锚定确实维持两种旧跨伙伴互通；如果只保持一条连接，应报告方向性，不能说整体约定保持。
2. 相对当前伙伴，锚定使新增图学习受限，而当前伙伴旧任务没有同步普遍崩溃。若使用“旧任务相近”这种判断，应列出连续差值；本细则不事后引入任意近似等价门槛。
3. 从完全相同300步状态出发，解除相对持续锚定提高后半程新增图AUC；同时展示旧跨伙伴兼容是否改变。兼容下降与新增提高并存可支持约定变化的解释，单纯相关不识别中介。

不要求“当前≥解除≥锚定”的必然排名。解除保留了前300步历史，可能稳定学习，也可能形成难以摆脱的约定，因此它并非当前伙伴条件的短预算复制。

| 结果模式 | 合理解释 | 不成立的解释 |
| --- | --- | --- |
| 锚定未维持跨旧伙伴J | 操作未实现预期的行为兼容，或兼容学习本身困难 | 新增学习低就是维持旧用途的特定代价 |
| 锚定使新增与当前伙伴旧图都普遍下降 | 总体训练或适应困难仍是替代解释 | 已定位到旧码冲突这一机制 |
| 锚定与当前伙伴相近，或锚定更好 | 未观察到预期约束，旧伙伴也可能提供稳定反馈 | 隐藏的兼容约束必然存在且是主瓶颈 |
| 解除后的主AUC不提高或种子方向混合 | 本预算下缺乏稳定解除效应；精度有限 | 证明所有历史约定约束都无效 |
| 解除提高新增图，sealed仍弱 | 已暴露新用途的学习改善 | 获得可靠零样本组合表达 |
| 旧任务总分保持，旧跨伙伴J下降 | 当前任务保留与旧伙伴互通不同 | 所有具体旧行为未改变 |
| oracle可行空间宽而实际J低 | 可实现的查表重赋义不等于可学的神经策略 | 已经证明主体缺少某种纯语言认知能力 |

锚定同时改变伙伴非平稳性、收益分布、信用分配以及共同调整的机会。因此即使主预测成立，结论仍是旧伙伴要求的总效应，不能直接把DP冲突称为已确认的因果中介。旧副本是实验者保留的历史行为，不是新人、代际传承或自发制度。全49码仍足够逐图约定，任务高分与符号片段结构必须分开。

## 分析产物及必要核查

计划输出机器可读结果、中文功能分析草稿和三组PNG/PDF科学图：新增学习与解除后主配对差；当前旧任务及两条旧跨伙伴曲线；当前伙伴旧／新增／sealed终点。纵轴及任何展开尺度均标明，所有四个种子保留。

结果读取后核查：36组完整范围、继承来源哈希、三臂公共起点、同来源评价世界、锚定／解除0–300相同状态与曲线、所有检查点的支持计数与方向计数、旧副本冻结、sealed训练暴露为零。正式运行审计负责独立核对查询次数、损失路由、优化器和实际世界；功能分析不将这些实现检查数量当成科学样本。

此前v0.10事后兼容性结果用于提出本候选，不是本轮先验之外的新确认。若另行加入动态码计数或其他探针，应在正式结果前明确范围和真值oracle边界；本功能分析不默认执行片段替换、拼接、重编码或新模型推理。
