# v0.31 固定伙伴与轮换伙伴

本轮把伙伴关系从评价条件推进为训练条件：四个主体在同一多伙伴资源任务中，比较始终使用同一伙伴与在两个伙伴之间轮换。目标图、训练图、冻结视觉输入、消息容量和优化预算完全配对。

24组正式训练已经完成。轮换伙伴的目标12终点 J 高于固定伙伴，且同私有类型主体的消息一致率大幅提高；多伙伴同时正确率仍低，因此结果支持“伙伴轮换促进协议复用”的有限机制结论，不等于已经产生了人类语言。
