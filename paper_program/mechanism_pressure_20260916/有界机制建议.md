# 社会共现支持如何改变未训练配对的表达

建议新增两个通信条件，保持现有 DINO、私人 all 终点、h96 接口、两枚七选一符号、接收者、奖励及优化规则不变。唯一环境操作是改变社会训练中的18个资源位置配对。优先采用下述两个连通图，暂不采用 K3,3 与三棱柱比较。

本次只有有限整数枚举，没有模型训练、推理、图像访问或网络查询。具体列表与完整80个候选见 [support_enumeration.json](support_enumeration.json)，可由 [enumerate_supports.py](enumerate_supports.py) 重现。这里是设计建议，最终执行以另行冻结的方案为准。

## 精确可行的两个支持

把食物位置和水位置分作二部图的两侧：训练过布局 `(i,j)` 就有一条边。令共同测试配对

`P = (1,0,3,2,5,4)`。

先排除6个同址布局，再排除6个 P 配对和另一个置换 Q 的6个配对，保留18个训练布局：

`A[i,j] = 1 当且仅当 i≠j，j≠P[i]，j≠Q[i]`。

| 数学性质 | target_paths3 | target_paths2 |
| --- | --- | --- |
| Q | (2,3,4,5,0,1) | (2,4,5,1,3,0) |
| 训练布局 | 18 | 18 |
| 每种资源在每位置的出现次数 | 3 | 3 |
| 二部图连通分量 | 1 | 1 |
| 双向有序训练边数 | 12 | 12 |
| Q 的循环长度 | 3+3 | 3+3 |
| 共享物理地点图的有向三角数 | 8 | 8 |
| 二部四循环数 | 3 | 6 |
| 每个 P 目标的训练三步路径数 | 3 | 2 |
| 15对食物位置的共同水情境数分布 | 12对共享1个、3对共享2个 | 3对不共享、6对共享1个、6对共享2个 |

水位置一侧的共同情境数分布相同。每个共同目标 `(i,P[i])` 的三步路径由三个已训练布局 `(i,b)、(c,b)、(c,P[i])` 组成，计数为 `(A Aᵀ A)[i,P[i]]`。它是训练支持的可检查性质，不是主体确实使用了三步推理的证据。两臂对每个未训练目标均有3个食物匹配供体和3个水匹配供体，直接双供体组合数都为9；差别在这些供体之间是否存在已训练的连接。

两个图均连通，四循环数不同，因此不可能仅由共同地点改名变成对方，即使允许两种资源各自独立改名也不可能同构。后者不是本环境允许的真实位置变换，只是更强的不等价检查。

所有训练分布均匀时，`H(F)=H(W)=ln6`、`H(F,W)=ln18`、`H(W|F)=ln3`、`I(F;W)=ln2` 完全相同。无消息的最优单资源成功率均为1/6、双成功均为1/18、当前混合收益均为1/9。49个完整码足以单独记住18个训练布局，也足以记住全部30布局；没有强迫主体采用组合编码的容量瓶颈。

## 主要比较与最小矩阵

建议沿用四个 v28 来源的私人 all 终点，三个 p 各作为配对坐标重复；每格两个条件，共24次新社会训练，不重训私人能力或选择成功来源。三组共同测试 P 分别对应已有三个 matching，具体共同地点置换已写进 JSON 的 `panels`。各格私人接口与通信初始参数、照片/策略随机流身份完全配对；使用全新通信学习，不能继承已形成的协议。四个来源是外层重复单位，三个坐标重复和两个方向不增加独立 n。

根方案提出每批126个基础世界，每个训练布局恰7次，再展开两种末帧遮挡，得到每方向252条消息。这使每资源每位置每批恰21次、每种遮挡各21次，优于仅在期望上平衡。两臂都使用相同2400更新及同样新批大小；相较此前256消息属于本轮共同变化，不与旧 B 的结果作单因素因果比较。照片可同流抽取，但不能据此声称每个照片类别也逐批精确平衡。

唯一建议主量：2400步，共同 P6 的自然逐符号贪心双目标成功率，`target_paths3 − target_paths2`；两种遮挡、方向及三个坐标重复先在来源内平均，再报告四个来源差与均值。预期方向是路径3较好，但零差或反向都必须保留，不据结果改图、换目标或增加预算。

两臂共享13个训练布局，实际共同未训练7个布局：P6之外还有1个。预先只以 P6 为主要测试，是为保持其位置边际均匀；额外1个应另外列出，不能写成共同未见恰6个。各自其余6个留出集合不同，不能直接把两套各自 held12 分数差当作同目标因果效应。辅助报告共享训练13、各自训练18、各自 held12、全30以及曲线/AUC，足够识别一般学习困难，不需再扩奖励或架构矩阵。

可反驳的窄预测是：在相同私人能力和训练边际下，支持中较多连接共同未见目标的训练路径提高这些目标的自主任务表达。若只有训练分数提高而 P6 不变，或四来源方向不一致，本批没有支持稳定的新配对迁移收益。若 P6 提高而训练也提高，仍不能排除一般协议学习难度；若任务迁移提高但片段干预无证据，应写整条消息的泛化改善，不能写组合结构出现。

## 必须保留的解释限制

1. P6 是完美匹配。在这个子集里，知道任意一种资源的位置就能确定另一资源的位置。因此 P6 的 J 只能测这些未训练配对上的任务迁移，不能单独证明消息独立描述了两种资源。每个布局中的图片仍是测试图片，但私人 all 曾以其他训练照片体验全部30布局；“未见”仅限通信经验。
2. 四循环数、共同情境覆盖和目标三步路径数一起变化，不能称本设计只识别四循环的独立作用。建议沿明确的 `target_paths3/2` 命名，避免把四循环更多泛称为“复用压力更强”。固定两图也不代表全部图族。
3. 在6地点共30布局、训练恰18布局的条件下，如果还要求完全相同的12个未训练目标，训练支持就被其补集唯一确定，无法做上述操纵。共同且严格均匀的非空测试支持只能取6或12个；取6又必然形成一一配对。当前任务的这项识别限制不能靠更多统计检查消除。
4. 有限片段干预可辅助：只取训练供体、同图片与遮挡，两个 token→资源槽位方向都预先列出；不能按 P6 成绩选择方向。人工拼接不等于主体自然发出消息。若要说槽位复用超出任意整码标签，仍需保持完整消息行为的随机双射参照；没有该参照时仅报告原始拼接分数。这里不新增模型训练或直接指定符号词义。
5. 私人接口冻结减少了能力准备差异，但不同训练图必然呈现不同组合的 h；这也改变函数拟合问题，不能把结果唯一定位为人类式类比推理或语言起源条件。仍只有四个已使用的开发来源和小图像池。

## 与已有轮次的区别

独立枚举确认 v23/v28 三组 old18 在共同地点改名下都等价于无向三棱柱，不是三种共现拓扑；更早 v7/v8 是24训练/6匹配留出，分别改变视觉槽局部性、回报互补程度。v13 改变私人空间等变训练，v24/v25 改变读取已学私人预测的发送架构。本候选保持接口、奖励和私人来源，首次在该本地程序内操纵均匀18布局的社会共现结构。它不据“本地未做过”宣称文献首创。

备选 K3,3 虽可与三棱柱保持对称支持、18布局和位置边际，但二部展开会分成两个组件，测试目标又不同；比较将同时包含分组捷径、连通性和目标变化。当前两连通图对照更收敛。若本轮不能给出稳定任务迁移及有约束的符号复用证据，下一步应重审任务识别力，不继续扫更多图或循环数量。
