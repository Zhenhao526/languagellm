## 文件入口

- [sampling_frame.json](sampling_frame.json)：全部分类候选、分页来源及固定 800 条请求顺序。
- [candidate_status_manifest.json](candidate_status_manifest.json)：800 条逐项状态；200 已取得，下一批10条遇限流，其余590条未请求。
- [manifest.json](manifest.json)：200 条完整文件元数据，包含作者原始 HTML、原作链接、原 SHA1、尺寸、时间、许可 URL、页面 revision 及 API 响应链。
- [license_chain.tsv](license_chain.tsv)：上述 200 条的便于核查的许可／署名／来源索引。它不是已批准发布的素材清单。
- [old_exclusion_registry.json](old_exclusion_registry.json)：全部 101 条旧候选及原数据文件哈希；[partial_author_groups.json](partial_author_groups.json)：未完成的作者／原作关联图。
- [requests.jsonl](requests.jsonl)与 [raw](raw)：逐次请求和原始响应。没有抓取任何图像 URL或缩略图。
- [status.json](status.json)：当前限制、待取数量、来源指纹和续取边界。

## 停止原因与修订记录

最初本地断言错误地要求 101 条标题在 casefold 后仍为 101 个键。已改为保留全部原记录、按原 SHA1 恢复旧原始作者元数据；旧排除范围没有缩小。[开发失败记录](collection_development_log.json)及失败源文件保留。

首批文件元数据请求将 `rvlimit=1` 与多个标题组合，官方 API 返回 `invalidparammix`。去除该参数、仍读取默认最新页面 revision 后继续；请求范围、顺序和配额没有改变。[参数修订记录](api_parameter_fix.json)及两份错误响应保留。

第 101–110 条请求曾遇一次 429，等待 30 秒重试后成功。第 201–210 条再次遇 429，等待后第二次仍为 429，达到本轮预定重试上限，因此停止。[最后限流响应](raw/0031_metadata_0200_a2.response)可核查。没有换网络、身份、代理或其他官方入口规避限制。

当前不足以预约 72 张最终照片。后续若在服务允许的节流安排下继续收集，必须保留同一抽样框、盐和候选顺序，复用成功响应，并另记等待时间和节流修订；不能立即反复重跑失败请求，也不能为了填水或橙子配额跳过前面的固定待取候选。完成全部元数据后再合并作者簇并预约集合。

## 复现与下一步边界

本轮执行入口是 [collect_metadata.py](collect_metadata.py)。它未调用图像下载或模型；当前限流状态下不应立即再次执行网络收集。只读完整性核查可直接运行：

```sh
.venv/bin/python paper_program/visual_confirmation_v1/audit_metadata.py
```

之后仍需：完成其余元数据；作者／许可链消歧；图像下载与全部旧 101 图的近重复筛查；盲化人眼资源与224裁剪验收；锁定最终像素和条件清单；最后才是冻结接口的确认测试。72 张只是预设目标配额，不能将这 172 条元数据候选计作合格图像。图像阶段属于已授权持续研究的后续工作，本次委派只执行元数据阶段；按既定采样与服务节流条件继续即可。

本项目共用工作区，没有声称技术上的权限密封。确认隔离目前是未向模型暴露、未作分割和未看成绩的流程约束；正式确认前还须固定数据保管、开发访问和一次揭盲程序。
