# 最近邻核查与论文贡献缺口

核查日期：2026-09-15。研究对象限定为非 LLM、预训练视觉表征之上的新符号约定及其扩展。本文件是选题审查，不是新实验预注册，也不表示已有结果达到 ICLR 接收标准。

**目前最值得继续的问题是：既有约定面对新增区分时，旧用途的兼容性约束怎样限制单端适应，何时需要发送与接收共同重组。** “双端可更新比单端冻结表现好”本身不足以成为论文核心；它同时增加可训练参数、可改变函数和优化自由度。贡献需要解释、预先预测并通过干预改变这种差异。

## 检索与阅读边界

先读本地文献库、[既有创新性审计](../../research_program/论文证据与创新性审计_2026-09-15.md)及 v0.9 的对称边界诊断。新雷达配置使用 emergent communication / symbol emergence / cooperative language acquisition 等主题，未使用默认 DFT。请求 24,000 小时、20 篇候选，分类 API 返回 HTTP 429，未形成雷达候选池；已知 ID 的第一次 packet 因空数据库失败。

随后从官方 arXiv 摘要页定向提取八篇近邻元数据，写入**新目录自己的数据库**，再使用未修改的 `radar.py packet`、`record-review`、`finalize`。这是明确披露的故障后备流程，不是一次成功的广泛收集。八篇均完成标题/摘要分诊；七篇核查全文中的方法、主要结果、局限和相关附录；Pitzer 的全文提取失败，保留低置信度摘要评审。另重新核查 Lee 和 CELEBI 的正式论文关键方法。全文核查不等于复现代码、逐式证明或全部图表审计。

记录见 [候选集](targeted_candidates.json)、[故障记录](collection_status.json)、[八篇分诊表](triage.md)、[逐篇验证评审](radar_ranked_review.md)、[证据表](citation_evidence.md)。OpenReview 部分状态页遇浏览器验证，未绕过验证，也未把作者稿“under review”当成接收。排名是本项目的阅读优先级，不能理解为论文质量总排名。检索不覆盖未公开稿件，也不能支持“首次”“唯一”或“尚无人研究”。

## 最接近的工作已经做到什么

1. **Rita 等，NeurIPS 2022**：分解信息损失和共适应损失，冻结发送者训练新听者，并控制听者收敛、重置与正则。它已把发收端负担和形成动力学作为核心问题。我们的 `C_S` 是有限样本、零一联合正确任务的最优解码参照；`C_R` 是原贪心接收表的可达范围，二者不能直接相加当作该文损失分解。[原文 §2.3–3.3、§5](https://papers.nips.cc/paper_files/paper/2022/file/093b08a7ad6e6dd8d34b9cc86bb5f07c-Paper-Conference.pdf)

2. **CtD，ICLR 2025**：通过概念分解课程和代码本得到未见概念合取表达，包含零样本成功。正式版本第34页明确承认 oracle 概念分组、给定消息长度和传递潜向量的限制。我们可以区分无概念组监督、整数信道与独立奖励学习，但这只是设置差异，须带来新机制证据。2026 是较晚的 arXiv 上传年。[正式原文](https://proceedings.iclr.cc/paper_files/paper/2025/file/fb9d01fb202e360b2f78510c47e0fa3e-Paper-Conference.pdf)

3. **Kaszyński，2026 预印本**：冻结 DINOv2/V-JEPA、因子组合留出、原子码对照、迭代听者、消息位置干预及冻结发送者的下游迁移，都与当前路线直接重叠。其发送接口继承有监督比较 oracle 的准备参数；通信通过接收任务损失反传，不能称作完全独立奖励学习。§3.2/4.6 的“agent”计数与带宽匹配说明有歧义，未复现前不照引其排除带宽的强归因。[作者稿](https://arxiv.org/abs/2604.03266)

4. **Ochiai 等，2026 预印本；Kouwenhoven 等，CMCL 2024**：前者已用冻结 DINO/MAE、随机初始化的文本模块和本地接受/学习形成离散共同序列；后者已用冻结 DINOv2 研究视觉交流，发现提高 TopSim 不等于提高严格视觉组合区分。故“具有视觉世界知识而未经语言预训练的主体产生符号”以及“指标结构与功能可分离”均有明确先例。[Ochiai 原文](https://arxiv.org/abs/2605.11695)、[Kouwenhoven 正式论文](https://aclanthology.org/2024.cmcl-1.5/)

5. **Lee，EMNLP 2024；CELEBI，NeurIPS 2025**：前者已有听者兴趣差异与全组正确奖励，后者已有逐符号重建及冻结旧接收者、让新发送者模仿行为结果。不能把联合收益影响结构、接收端塑造表达、行为保持而允许换码分别写成新意。[Lee 正式原文](https://aclanthology.org/2024.emnlp-main.1157.pdf)、[CELEBI 正式原文](https://proceedings.neurips.cc/paper_files/paper/2025/file/3310034c97fab48fdbcba18f90fd5364-Paper-Conference.pdf)

6. **ECTL，IJCAI 2024；Foraging Games，2025 预印本 v2**：社区加入、预先学环境技能再翻译协议，以及独立 PPO、局部感知、同步采集、人口和行为通信，均已有实验。前者的示范监督与后者的采集任务不能当成我们已复现的同等基线；但后续做新人或真实行动时必须面对它们。[ECTL](https://www.ijcai.org/proceedings/2024/5)、[Foraging Games](https://arxiv.org/abs/2505.12872)

## 当前结果留下的具体候选差异

v0.9 已显示：新增六图参与训练后，两端适应优于单端适应；旧图平均成绩变化较小，但个别来源仍下降。这是**既有约定的适应**，不是新增组合的零样本形成，也不是新词已经诞生。

只看新图的发送可区分性会高估低损伤扩展的空间。旧 mixed 来源的新图独立 `C_S` 约98.61%，但保持原旧图正确总数的最优重新解码参照约16.58%；两者允许的旧用途损失不同。该约束是分析者 oracle：知道地图标签，可改变具体旧例的成败，只保持总计数，不保证主体能学到它，也不代表逐例保义。[诊断与完整条件](../../redesign_v0.9/发送可区分性诊断.md)

由此产生的候选主张是：**导致旧通信失败的歧义、原接收者没有可用码，以及新旧用途争用同一码，是不同约束；约束之间的关系可预测扩展时需要改变哪一端，以及局部片段是否被自然用于新表达。** 这与只分解原任务训练损失、教授概念分解或提高统计组合性有所区别，但本次有限检索尚不能确认该完整命题无人研究。

查表最优解、逐码最大计数和整数动态规划本身都是标准决策分析工具。将它们用于此任务可形成严格诊断，不能单靠新命名包装成原创理论。论文需要一个有范围条件的结论，例如可计算的兼容性界及达到界的构造，再用独立实验验证它何时预测学习、何时预测失败；不能从“oracle 允许”直接推出“神经主体可学”。

## 最少需要的对照与它们排除什么

| 对照 | 作用 | 与既有方法的关系及边界 |
|---|---|---|
| 冻结双方、发送可学、接收可学、双方可学；加相同旧/新支持下从头训练 | 分清既有约定迁移与一般重新学习，并保留冻结零变化基线 | v0.9 三臂是起点。两端多自由度不自动构成协同机制 |
| 冻结发送者的完整表最优解与充分拟合的新接收者 | 区分消息碰撞、原接收策略限制与有限预算学习失败 | 必须比较 Rita 式探针；新接收者用哪些数据、是否看新图需明确 |
| 冻结原接收表的可达性，与无旧损伤/允许固定损伤的重新解码前沿 | 分开仅选码、修改解码以及新旧码冲突 | oracle 前沿是分析基准；同时报告逐例旧行为保持与旧收益，避免两者互换 |
| 同源初始化、同容量、同旧任务成绩的兼容性干预，预先预测后续适应 | 判断兼容性是否改变学习结果，而非事后与成功相关 | 需避免泄露新图正确消息；行为等价重编码可作不应改变整体功能的阴性控制 |
| 接收端正则/收敛控制；行为结果保持的适配器或蒸馏 | 排除普通过拟合及稳定性正则足以解释新方法优势 | 前者来自 Rita，后者与 CELEBI 接近；改造版须说明额外监督、参数和算力 |
| 概念分解/结构化 oracle 阳性，与同49码的原子码 | 确认任务能检出结构，并区分信息容量与因子结构 | CtD-inspired 是带明确额外信息的上界，不能同纯奖励法混称自然涌现 |

不是要求同时移植所有外部框架。论文主问题若是约定扩展，先完成前三项与一个真正改变兼容性的干预；CtD 是结构阳性，ECTL 留给社区加入，MHCG 留给感知异质性问题。应围绕一个因果链组织，避免把所有旧版本拼成“大而全 benchmark”。

## 可支撑较强投稿的证据门槛

- **预先可反驳的预测。** 在未用于选题的新来源上，用冻结指标预测哪一端受限、旧用途保持代价和适应顺序；失败也保留。不能事后只挑已有高结构来源。
- **干预后的机制变化。** 相同名义容量及信息条件下，改变可兼容解空间应按预测改变适应。若只有双方参数更多带来的普遍提分，则收窄成优化结果。
- **两类泛化分别证明。** 新照片和非同构因子关系检验机制外推；组合尚未训练时的自然消息成功检验组合泛化。训练过新图后的适应速度不能替代后者。
- **功能结构独立于指标。** 自然联合成功、原函数可达性、严格片段替换和研究者拼接分别报告；整体重编码基准保持成功，检验片段分数是否依赖序列坐标。人工拼接不算主体自主产出。
- **真正的独立重复与预算。** 三划分、两方向、数千照片不是独立主体种子。新的确认量应基于开发阶段效应和所需精度事先固定；十个种子只是可执行起点，不保证统计功效或接收。
- **控制提供的能力。** 地点框架、需求分支、对象存在位、采集反馈是给定接口。冻结 DINO 的存在不证明其必要性，更不意味着主体在社会学习前已理解全部世界或“无任何语言逻辑”。

本轮没有依据声称已找到 ICLR 级创新。较可信的方向是把语言形成问题转化为一个受控机制问题：**给定非语言表征与行动能力，既有符号约定的可扩展性由哪些共同学习约束决定。** 若兼容性不能预测独立适应、干预不能改变它，或效应完全由普通正则/预算解释，就应放弃该强主张，保留完整负结果与诊断工具。

## 最接近预印本的核查疑点

Kaszyński v1 的 §3.2 定义每个 sender 发送 K 位、字母表 V，则 N 个 sender 的联合空间为 V^(N K)。§4.6 同时出现“4个主体各2×5”与“单个4×5、625码匹配总容量”的描述，Table 7 还在单/双输入条件中混用计数。它可能源于把比较两侧和每个场景的 sender 数混写；本轮未检查执行代码，不能判定其实际对照错误。应列为复现前必须解决的问题，而非据此否定整篇研究。源页面的日期字段也与 arXiv 月份编号不一致，本表只写2026及版本，不据该字段建立先后优先权。

Pitzer 只核摘要和作者代码页；其微调互通结论尚未进行全文独立判断。Foraging 的 OpenReview 页面无法完成状态核验，按预印本 v2 引用。所有这些限制已进入逐篇评审，不能在主报告中删除后变成确定性证据。
