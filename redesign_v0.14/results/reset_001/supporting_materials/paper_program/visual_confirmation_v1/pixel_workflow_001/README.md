图片常见问题包括明显文字/水印、内容物不可见的不透明瓶子、混合食物、只有果皮或类别难辨。没有按模型分数排除困难图片，也没有改变候选顺序或追加来源。分歧和不确定一律保守排除；没有从评审中挑选较宽松意见。

评审是AI视觉判断，不是人类志愿者评审。B只看匿名全图和实际224裁剪；A兼任收集和调试，接触过少量URL/格式元信息，因此不能声称两者完全来源盲或本过程为双盲。两人均在查看对方意见前封存自己的判断。逐项结果及源文件SHA见[汇总状态](pixel_review_status.json)，原始独立意见保留于[首10图](review_round1/combined_review.json)、[A第二轮](review_round2/reviewer_a.json)与[B第二轮](review_round2/reviewer_b.json)。
