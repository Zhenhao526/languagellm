# v0.14 对论文证据的增量与解释边界

2026-09-16。只读取本目录固定方案、两份前置审查、`manipulation_002` 及已有空间能力近邻核查；没有读取运行中的 `results/reset_001` 成绩、图表或汇总。本文是正式结果未查看前的解释记录，不冒充正式运行前完成的预注册，不修改固定方案，也不认证首次性。

## 本轮增加的是哪一块证据

**v0.14 能补上“私人准备所得接口本身是否有迁移收益”这一缺失对照；仅有 retained/reset 仍不足以支撑一篇强机制论文。** v0.13 在已有私人准备上比较额外空间一致性压力，不能单独回答基线私人经验留下的参数变化是否重要。本轮直接撤销这些变化，再保持后续社会模块初值、外生世界、随机流和预算一致，比“私人分数较高且通信也较好”的相关叙述更有辨别力。[固定方案](固定执行方案.md)

准确的对象是 **memory 与 slot_phi 中私人训练留下的综合参数变化**。覆盖6个张量、145122参数，实际发生变化的是5个张量、117474参数；零状态单步路径中的循环权重没有变化。DINO、200×64资源后果实践所得 project、公共地点、需求、存在位及动作接口仍保留。memory 在这里不是跨轮时间记忆，reset 不是移除世界知识、随机像素或无空间能力主体。[前置科学审查](前置科学审查.md)

在当前实现和固定预算内，这个配对干预可以识别保留该接口的**总效应**；它没有隔离资源辨认、地点绑定、表示幅度、坐标几何、读出兼容性或优化条件。三分区和双方向仍嵌套于4个已用来源，不能增加独立样本数。复用来源 control 节约计算，但不是重新独立重复 control，也不是新照片确认。

## 7.25 对 1.39 留下的替代解释

较大 h 在同一个初始仿射读出中改变输入项相对偏置的作用，还可能改变下游非线性、消息熵、梯度大小及裁剪出现的频率。相同 Adam、学习率和 norm2 裁剪并不保证整个随机策略学习过程对表示尺度不变。因此，retained 若学得更快，可能部分受幅度与优化条件影响，不能立即解释为主体获得了更强的概念或空间推理。

这仍只是明确的替代解释，**尚未证明范数差造成任何社会收益**。平均范数不能给出各坐标分布、方向、各向异性或饱和比例；也不能断言“放大5倍就会得到一样的政策”。trained 与 reset 之间并非已证明只有缩放差异。h 范数、私人准确率或二者的相关性均不构成中介因果识别。

## 按预定主要终点解释正、负和异质结果

主要差值始终是 `retained − reset` 的2400步 sealed 自然双目标 N；必须先报告4个来源差及均值，再看预定辅助指标，不把更好看的 added、AUC 或协议指标改成主要结论。固定方案没有等效界，均值接近零不能直接宣称两者等效。

| 可能结果 | 可以改变的判断 | 仍不能声称 |
|---|---|---|
| sealed N 在各来源一致改善，旧图学习也明显更好/更快 | 私人准备接口在当前训练预算内有一般迁移收益，并伴随封存表现改善 | 唯一机制是组合结构，或封存收益独立于一般学习能力 |
| 旧图形成和终点近似，而 sealed N 有方向一致的差异 | 支持更有针对性的封存迁移表现差异；简单“只是旧图没学会”解释变弱 | 已排除尺度、可读性、训练轨迹和所有优化解释 |
| 只有旧图或形成 AUC 改善，sealed 终点无稳定收益 | 有限预算下的学习效率收益；不能据此支持可靠未见组合表达 | 非语言准备已经赋予组合语言能力 |
| common30 发送参照提高，或消息更规整，但自然 sealed N 未改善 | 学到的发送政策在分析者参照下可区分性不同，实际协作仍未兑现 | oracle 能力就是主体能力，或信息参照提高即形成共同组合符号 |
| retained/reset 差小或方向不稳定 | 当前4来源、旧图片和冻结路径下未观察到稳定净收益；需要缩小主张 | 所有私人经验无用，或者已完成总体等效/必要性检验 |
| reset 在来源间一致更好 | 该私人准备可能给后续固定社会接口带来负迁移；私人目标与社会目标的偏好可能不一致 | 学习世界知识普遍有害，或者随机主体“更有语言能力” |
| 来源间出现正负差 | 效果依赖起点或具体分区；整体均值不能代表普遍规律 | 挑选正向来源后称机制有效，或把三分区/双方向当独立重复提高把握度 |

共同30图 oracle 由各条件自身的原生发送政策产生，不是两臂共享的能力上界；原生 Q、原生发送配贪心接收 G、逐符号贪心 N 分开解释。不能用不同照片口径的协议分数减去9600世界主终点。保留 shuffle/blank 的作用是检查既有政策对消息的依赖，不能单凭成功下降证明人类式语义或组合性。

## 一个后续候选：仅检验全局幅度解释

**仅为下一份方案的候选，不加入当前矩阵、不执行，也不依据未读取的 reset 成绩调条件。** 相较同时再改奖励、容量或架构，最小的机制补充是一个 `reset_scaled` 条件：保持 reset 的冻结表示方向和全部网络不变，在所有原本合法消费 h 的社会路径前乘同一个固定正标量。

标量按每个来源/分区/个人分别校准：预先固定 old18 **训练照片**、完整平衡世界和顺序，仅前向计算两接口；取该校准集 retained 的平均 L2 范数除以 reset 的平均 L2 范数，之后全程固定。不得直接用本节含 added/sealed 的7.2473/1.3877作为倍率；不得逐世界匹配 retained 范数、用当前世界正确答案、或在封存评价后选倍率。若分母异常则报工程故障，不搜索另一倍率。

这样只提供一个训练支持上的全局校准常数，不增加每世界的类别/地点真值，不增加可训练参数；正标量在数学上可逆。保持原 S/R 初始化、预算、外生流、熵与裁剪，沿用原 retained/reset 作为参照；如果另行采用它，完整执行4来源×3分区的一种新增条件，不挑来源。无裁剪、逐样本归一化、LayerNorm或多个倍率扫描，否则比较的问题又变了。

可反驳的窄假设是：“观察到的准备收益仅凭这一个全局幅度差就足以解释。”未来应同时报告 `reset_scaled − reset` 和 `retained − reset_scaled` 的原定 sealed N 差，并保留旧图学习过程。若校准达到定义目标后仍留下稳定 retained 优势，单一全局幅度充分解释被削弱；若主要只补回旧图学习速度，仍不能解释封存组合迁移。若尺度校准补回大部分差距，则空间能力独占解释变弱，但不能据此断言私人准备毫无信息作用。接近零也仍须给出不确定性，不能用4来源均值直接作等效认证。

这个干预不匹配完整幅度分布、方向或非线性饱和，失败仅说明所定义的**单标量补偿**不足，不排除更一般的优化解释；成功也不构成一个新算法贡献。它的价值是让一个当前确有证据的替代解释可以受检验。

## 为什么 retained/reset 还不够支撑目标论文

预训练分类表征影响通信、视觉注意力影响组合性、冻结 DINO 与新消息模块、以及表征正则化的正负结果，都已有近邻。Garcia 2022、Ri 2023 和 Kouwenhoven 2024 已直接覆盖这些宽泛方向；Luna 2020 也说明感知条件改变结构指标并不保证未见组合改善。对学习所得编码器与随机起点作撤销比较，本身是一项必要消融，不能包装为首次发现“先有非语言能力才能有语言”。[已核查近邻与具体方法页码](../paper_program/literature_spatial_20260915/近邻方法与贡献边界.md)

当前还缺少一个能排除有竞争力替代解释的机制结论，以及在新来源/新图片上的预先固定检验。旧18/added6/sealed6 的同构地点任务、49码和两需求由研究者给定，不能单凭该任务反推人类语言的发生条件。DINO 的必要性、充分性及其与资源后果投影的各自贡献仍未识别。

因此本轮适合进入论文证据链，说明哪些私人准备参数具有、没有或不稳定地具有迁移作用；它可能帮助放弃一个过强解释，也可能为一个更窄机制提供下一步依据。强论文需要这个可反驳主张在严谨对照下成立或被有信息量地否定，而不是继续叠加更多成功率曲线。当前无需增加实验矩阵来掩盖证据边界。
