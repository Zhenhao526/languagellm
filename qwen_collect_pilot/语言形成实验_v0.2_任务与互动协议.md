# 语言形成实验 v0.2：河谷补给与协作搬运

状态：任务与互动方案已在 [qwen_language_v2](../qwen_language_v2/README.md) 实现，能力控制进行中，实际进度见[执行记录](../qwen_language_v2/执行记录.md)。旧两字符程序的结果只作为本机运行、上下文隔离与通信流程检查。本文先确定表达需求与互动机会，再确定信道预算；执行中的具体调整另记，不覆盖原方案。

## 1. 研究对象与第一项问题

主问题是：在持续合作、知识分散且情境不断变化的群体中，共同意义、可复用表达和表达新内容的能力怎样形成，哪些环境与社会条件改变这个过程？

首个可检验问题定为：**在相同任务和通信额度下，行动前的即时回应机会，是否促进伙伴能够理解并跨情境复用的表达形成？**

预测是即时回应可以帮助暴露和修复解释分歧，并可能改善后续新组合的理解。这是待检验预测。若它只提高当前任务得分或增加消息长度，却没有改善新组合理解、稳定对应或片段干预结果，就不能说它促进了语言结构形成。

成功率与语言性质分开报告。已有多主体实验中的高任务得分并不保证组合性：[Kottur等，2017](https://aclanthology.org/D17-1321/)。表达能力和可学习性的共同压力是另一条相关研究线索，但并不保证本方案会出现结构：[Kirby等，2015](https://doi.org/10.1016/j.cognition.2015.03.016)。

## 2. 一个足够具体的合作世界

保留三个主体。主体身份在群体内持续，物理场景按任务段重新布置，互动经历保留。这是持续互动的群体实验，不宣称重建完整原始社会。

| 要素 | 初版规定 |
|---|---|
| 地点 | 营地、林地、河滩，三处之间均有道路；通常一步到达相邻地点 |
| 主体 | 三人能力相同，每段起点和工具位置变化；不预设协调者、采集者等固定职业 |
| 物品 | 每段约8件可操作实体，含木材、纤维及斧具；资源有长/短、干/湿等属性，同类可重复出现 |
| 需求 | 任务板给出2项交付目标，资源属性、数量1或2、交付地点组合变化；板只在营地可读 |
| 木材规则 | 原木需持斧具加工才可交付；长木材需两人共同搬运，短木材可单人搬运 |
| 纤维规则 | 可单人取用，须匹配目标属性；物理规则固定，不把资源属性变成每段随机密码 |
| 携带与交接 | 每人有有限普通携带位；工具可在同地交接；共同负载由两人配合，不能单人带走 |
| 局部变化 | 部分任务段出现一次可观察变化，例如营地入口道路关闭或某批纤维被淋湿；只通知能够观察到它的主体 |
| 时间 | 每段最多12个物理动作步；在生成时验证变化发生后仍有合法完成计划 |

每人初始只看到所在地点、当地物品、自己的携带物，以及同地能够观察的主体状态。地图和物理操作规则公开；当前资源分布、需求板和远处变化不公开。

起点和资源配置轮换，使知道目标、找到工具、发现可用原料的人不同。第三人可以通过并行采集或信息更新改善合作，但不人为规定三人每段都必须各完成一种指定职业。

场景生成器保存至少一条可执行的完成计划，并用环境规则重放验证。该计划仅供实验者检查可解性，不提供给主体，也不冒称最优计划。没有符号通信时仍允许探索、行动和合作；其表现必须实测，不能继续套用旧任务的25%基线。

## 3. 表达内容必须有实际后果

| 合作中的问题 | 希望观察的表达现象 | 对应检查 |
|---|---|---|
| 同地有不同属性的同类资源，需求数量也变化 | 对象指称、属性和数量的区分 | 调换资源排列、属性组合和数量，检查理解是否随意义变化 |
| 资源、工具和交付点分离 | 表达当前看不见的对象及地点 | 把同类资源放到新地点，保持其他因素可比 |
| 工具可能由不同伙伴持有，重物需要两人 | 人物、接收者及合作关系的表达 | 交换持工具者、搭档和任务安排，不改变人物身份本身 |
| 先取工具和加工，才能交付木材 | 顺序与行动依赖 | 使用熟悉操作的新对象—参与者组合，检查计划是否适用 |
| 已经商定的通道后来关闭 | 旧信息更新、撤回或修正 | 保存变化前后对话，检验表达是否使伙伴改变具体行动 |
| 某条消息让伙伴选错对象或误解安排 | 澄清和纠正是否形成 | 检查后续交流是否选择性修复该误解，而不是靠反复试动作成功 |

这些是需要表达的意义和待观察的功能，不是提供给主体的通信字段。程序不规定词、句子、分隔符、语序，也不提供“请求”“确认”“否定”等消息动作按钮。不提示主体必须创造语法、采用组合表达或长句。

动作接口仍需表达移动、取物、加工、交接、共同搬运和交付等操作。例如共同搬运包含对象、搭档和下一地点。这个接口提供了对象与关系的结构先验；以后出现相应表达，不能说这些概念完全由主体创造。

## 4. 一段可以实际完成的过程

例子初始条件：A在营地知道需要一件干燥长木材和一束干燥长纤维；B在林地看见合适原木；C在河滩看见斧具和目标纤维。每人只能执行一个物理动作；两人共同搬运必须分别提交相互匹配的对象、搭档和目的地。

下表的中文是给研究者看的过程说明，**不是给主体的示范对话或语言模板**。实际主体只获得自己的观察并交换自发的符号序列。它们也可以选择其他合法计划。

| 动作步 | A | B | C | 交流可能发挥的作用 |
|---|---|---|---|---|
| 1 | 营地→河滩 | 留在林地 | 拿取斧具 | 汇集分散的目标、原料与工具信息 |
| 2 | 拿取目标纤维 | 留在林地 | 携斧具到林地 | 自行安排谁取纤维、谁带工具、谁协助 |
| 3 | 带纤维回营地 | 留在目标木材旁 | 加工目标原木 | 指定加工对象，使后续共同搬运可行 |
| 4 | 交付纤维 | 与C共同搬木材到河滩 | 与B共同搬木材到河滩 | 根据A报告的新情况调整返程路线 |
| 5 | 留在营地 | 与C共同搬木材到营地 | 与B共同搬木材到营地 | 两人对对象、搭档和下一地点保持一致 |
| 6 | 留在营地 | 与C共同卸下并交付 | 与B共同卸下并交付 | 完成交付 |

例子中，在第3步结算后，营地—林地直达通道的营地侧入口关闭。A在第4步观察阶段看到变化；B、C在林地看不到该入口，直到被告知或尝试通行才知道。营地—河滩、河滩—林地仍开放。通信发生在第4步行动之前，因此A有机会使伙伴及时绕行。

目标属性、数量、交付地点、持工具者和起点都应变化。这段六步计划不能成为所有任务通用的脚本。道路变化只是部分任务的条件，不是每段固定发生在第3步的可预测暗号。

## 5. 互动协议

每个物理动作步按以下顺序进行：

1. 环境给三人各自的局部观察。此后在通信阶段暂停物理变化。
2. 开放第一个同步通信窗口。三人各自生成一条消息或空串；全部生成完后同时公布。
3. 同样进行第二、第三、第四个窗口。每人只看见此前已公布的对话，不能看见同一窗口中尚未送达的消息。
4. 三人根据自己的信息和已收到的对话独立提交物理动作，全部提交后同时结算。
5. 各人获得自己可观察到的动作结果和局部变化，进入下一动作步。

四个窗口让发起、回应、进一步澄清和再次回应成为可能，但不指定哪个窗口必须做什么。第一个窗口也可以沉默、后续才发起话题。即使三人都沉默，窗口仍按计划走完，不能通过抢先结束通信阶段改变物理行动时机。

主条件用公共频道：所有人可发言和旁听。接口只公开发送者身份、消息边界、窗口次序和符号内容，不提供私聊接收者参数。发送者身份和消息次序是给定的社会与时序条件，必须纳入解释；不能把依赖身份、沉默或轮次的协调都归功于字符串内部结构。

不显示模型生成耗时、工具调用顺序、其他人的私有分析或尚未执行的动作。公开行动结果和同地可见行为仍可能传达信息，应作为环境中的非言语渠道记录；移除符号频道对照保留这些相同的观察规则。

## 6. 在上述表达需求下确定信道预算

初版采用以下参考配置。它是可调整的探索起点，不是语言的定义或已验证的充分条件。

| 项目 | 初版配置 |
|---|---|
| 原子符号 | `@#%&*+=~`，8种 |
| 单条消息 | 0—32个符号，主体自行决定长度 |
| 每人每个动作步总额度 | 最多64个符号，分配到4个窗口；每窗口仍不超过32 |
| 三人每步最大显式符号量 | 192个符号，不含给定的发送者身份和边界 |
| 消息形式 | 任意合法符号串或空串；不预设词界、字段和语法 |
| 私有分析 | 与旧运行一样原生thinking关闭；每次决策可作最多256 token的私有分析，温度0，不转发 |
| 保存的经历 | 自己的观察、动作与可见结果，以及已经收到的对话；不生成实验者维护的共享词典 |

32个符号的选择，是为一次表达同时涉及对象及属性、地点、参与者和行动关系留出余量；64个符号的分步总额则给后续回应和修复留出空间。不按这些意义单位分配字符位置，也不假定它们一定发展出六种“词类”。

所列8个字符已在本地Qwen分词器中验证为可原样解码的单token，编号分别为31、2、4、5、9、10、28、93。它们在预训练中并非真正无意义，不能把字符限制等同于消除语言经验。

主任务就绪后，可以比较单条上限16/32/64，保持4个窗口和每人总额64相同；这比较的是单次表达及分段限制，仍不是完全独立于信息容量的纯语法操纵。第一批先不以长度扫描代替互动机制研究。记录实际长度、触顶和因额度不足截断的情况；模型只发两字符时，不强制补长。

词元屏蔽应从源头限制正式输出，不依靠事后删除非法文本。预算耗尽时仍保留通信窗口，但正式输出只能为空。私有分析与正式输出的预算分别记账。

## 7. 首个主对照：即时回应与延迟共享

两条件均保留三人、相同环境序列、每步4个内部决策时点、单条上限32、每人总额64，以及相同的私有计算上限。物理行动都发生在第四个时点之后。

| 条件 | 消息何时对其他人可见 | 行动前具有的机会 |
|---|---|---|
| 即时交互 | 每个窗口结束就公开该窗口消息 | 后续窗口能回应伙伴、澄清或修正 |
| 延迟共享 | 四个窗口的消息生成完毕后，一次性按原次序公开 | 行动前仍能读到全部消息，但本步内不能根据伙伴消息再次发言 |

延迟条件的主体仍可查看自己的先前输出和过去动作步的共同记录，并得到同样的私有计算机会。这个对照检验的是**同一次物理行动之前的相互回应机会**；它不是绝对没有互动，因为下一个物理动作步仍能回应过去信息。

两条件最大符号额度相同，实际用量、思考token和消息分段仍可能不同，均需报告。同一随机种子下使用相同初始场景和外生事件；行为差异导致后续观察不同是闭环实验的结果，不应强行播放与行为不一致的固定轨迹。

主模型参数固定，群体之间的私有历史独立。基于规则的词典、完整信息或自然语言控制使用独立上下文，不能把控制条件的计划和解释复制进主实验。

## 8. 怎样获得语言形成的证据

以下六项同时覆盖过程与结果，不合成为一个“语言诞生分数”。

1. **共同意义及稳定性。** 记录表达和伙伴行为的对应如何出现、竞争、变化；测试资源排列和角色变化后是否仍可理解。编码者能区分情境与接收者能理解它必须分别计量。
2. **新组合的首次理解。** 保留熟悉对象、属性、地点和人物关系的新组合；在未获得该测试情境的反馈或澄清前检查理解。另列允许对话后的适应成绩，不把现场重新协商当作零样本理解。
3. **片段的可复用功能。** 先在开发记录中提出候选片段解释，再在独立确认情境中替换或重组已出现的片段，检验是否选择性改变对象、地点或参与者的选择。控制长度、熟悉度与上下文，不能只用陌生乱码造成的失败认定语义。
4. **关系敏感性。** 对“同一对象由不同人送给不同伙伴”“同一工具由不同人持有”等成对情境，检查行动是否正确改变；完整情境编号仍是竞争解释。
5. **误解修复。** 保存有可观察解释分歧的片段及后续回应；从同一状态和历史副本干预该回应，判断它是否解决特定分歧。话轮多、出现问号式字符、主体自称在澄清，都不够作证。
6. **实际合作作用。** 报告截止时目标完成比例、同完成度下用时和失败动作；从匹配状态移除或替换消息，检验符号频道的贡献。该任务没有预先给定的25%无通信上限。

理解检查不能把每条消息都当作报告一个目标的陈述。主体也可能在提问、建议或表达不确定；对话功能要结合前后情境和行为确认。首轮后的行动表现衡量无需进一步协商时的使用能力，不能单独判定某一条消息“有无意义”，也不能只凭模型对自己意图的自然语言解释赋义。

训练与测试的组合分割在正式运行前固定。两类资源、各属性和地点等基本要素在训练中都出现，但部分配对或角色绑定组合留给测试；避免把没学过操作规则误写成组合泛化失败。具体分割清单由任务生成器保存，主体不能看到模板编号、全局对象ID或随机种子。

在起始及预定任务段结束处保留完整的三份私有历史快照。每个测试案例从各自快照的独立副本开始，不把测试经验写回训练群体。允许对话的测试可临时保存该案例内的消息，以便真正回应，但不能把它再带到下一个测试案例。

正式确认前记录全部群体，包括没有形成稳定表达的群体。独立样本是群体，不能把数千条消息当成数千个独立实验。

## 9. 能力、先验与其他混淆

**任务能力。** 先通过环境执行器验证可解计划，再用完整信息规划和自然语言通信的独立控制检查主体是否理解动作、合作和变化规则。自然语言控制是能力参照，不是带宽匹配的语言形成对照；需在接近主实验的提示复杂度和历史长度下检查，不能重复旧实验只在短提示中通过校准的问题。

**直接序列化与共同先验。** 局部物体使用各主体独立的操作句柄；其他主体不能直接照抄该句柄选择同一对象。等价观察的字段与物品顺序独立变化。仍要检查零互动时是否已经能靠既有约定机械转码，不能把复杂字符串自动叫语言。后续可用实验期间稳定、主体之间不同的字形置换检查共同字符联想；它增加学习负担，并非完美去除预训练。

**反馈与动作渠道。** 不返回其他主体未公开的意图、目标或失败动作参数。自己尝试搬运未成功，可得到该动作没有发生的结果；不能借错误提示获知伙伴实际选了哪个隐藏目标。交付是否被接受由现场主体知道，任务段结束再给群体完成度；不提供全局正确计划。可见的移动、交接和共同搬运仍是非言语互动条件，需要如实分析。

**记忆与计算。** 各群体保留相同范围的自身经历和收到的消息，短期私有分析不转给伙伴。先导期不由实验者总结符号含义或维护共享计划。若完整历史超出资源预算，应在正式组启动前统一确定截取规则或缩短任务段数，不能按组内表现临时调整。记录截断、实际token和推理耗时。

**奖励。** 主目标是期限内满足交付需求，同等完成度下尽快完成。已交付单位不重复计数，错误操作消耗物理动作机会。初版不因消息更长、更短、更像自然语言、出现片段复用而额外奖励。

**结论边界。** Qwen已具有自然语言知识，这条线研究已有语言经验的主体如何形成新的共享表达系统，以及环境怎样影响其结构与使用。任务提供了物体、属性、人物和动作关系，不能据此声称重现人类首次获得这些概念或从无语言认知产生语言。新成员学习和代际变化留作后续独立条件。

## 10. 实施顺序与本轮定案

先实现并重放普通任务和局部变化任务，验证局部观察、同时交付消息、同时结算动作及合法完成计划。随后测量一个完整任务段的本地耗时与历史增长，并检查独立能力控制；此阶段不评价语言是否形成。

研究先导拟用即时交互/延迟共享两条件，各3个独立群体，每群体连续6个任务段。6段只是初步观察和预算估计，不足以假定稳定文化或语言结构一定形成。实际启动前根据整段实测锁定统一预算；若需要缩减，必须在看到条件差异前统一确定。社会传递、通信成本和环境关系复杂度的操纵后置。

本轮明确的设计选择为：**持续的三主体群体、分段变化的采集世界、轮换的信息与行动角色、4次同步公共交流、随后同步行动、8种符号、单条最多32符号、每人每步合计64符号。** 下一步需要实现新的环境与对话调度器；现有两字符运行器不具备这套任务，不能仅修改长度参数就当作新版实验。
