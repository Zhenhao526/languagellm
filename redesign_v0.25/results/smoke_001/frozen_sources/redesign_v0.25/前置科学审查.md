# v25 有序联合读入：前置科学审查

2026-09-16。根据根任务提出的单臂设计，已只读核对v24发送代码及已封存结论；尚未读取v25成绩、运行模型或修改生产代码。**无阻断性设计问题，可以作为固定预算的熟悉支持学习诊断。** 本轮问题由已知v24结果触发，是新的开发实验，不回写v24的主量，也不是独立材料确认。

## 能检验什么

继承v24 mean每个来源的初始参数、私人预测缓存、接收器与外生世界流，仅把单key下任务梯度为零的双线性矩阵换成零初始化的对比读出。编码后的有序向量记为zF、zW，定义m=(zF+zW)/2，d=(zF−zW)/2；本轮在原融合层的Tanh之前加入Wd。

把原fusion拆成Fq、Fm及偏置b后，融合输入为：

`Fq·q + Fm·m + W·d + b = Fq·q + (Fm+W)·zF/2 + (Fm−W)·zW/2 + b`。

因此这是让两个有序预测获得可独立学习的仿射融合权重；不需要由query动态选择key。W=0包含原mean函数，W可学习则扩大了原融合函数族。它可以检验：**从相同初始通信函数出发，开放这条对比读入路径，是否改善本预算下熟悉布局的通信学习。** 它不是只删除注意力后的完全等容量比较，也不证明mean已经丢掉特定信息。

和、差在实数算术下等价于保留两个原向量，但实际融合仍进入96维瓶颈，float32运算也不应宣称逐位可逆。宜称“保留有序预测的联合读入”，不称“最终无损表示”。这是静态读入权重；发送者的query与符号生成仍然自回归，不能把它称为完全非动态模型。

## 尚未匹配的因素

移除9,216个无效双线性参数、加入同数量有效对比参数，可保持发送者存储参数数为73,191，但有效自由度、梯度和优化几何不同。其合理目标是检验原mean读入限制的一个可修正条件，不是分离“容量”与“信息结构”的纯因果份额。

W零初始化只约束初始函数，不保证首次更新仍相同：W在第一步即可有非零梯度。数学上此时对旧编码器的附加路径梯度为零，但同一sender组的clip范数包含新梯度；若裁剪激活，旧参数也会当步受到不同缩放。随后输入、消息、奖励和接收器学习会共同改变。应按实际日志报告，不因此前批次裁剪未激活就默认本轮也未激活。

私人头、角色标记和位置概率维度均沿用。差向量依赖研究者给定的资源顺序，但没有规定第几枚token必须表达哪种资源；正确地点仍只作环境反馈与评价。相对v23 h96的比较继续只是历史参照，不能把联合读入的结果解释成无任务语义的纯视觉能力。

接受本轮唯一主量为**2400步old18自然贪心双目标J，joint减v24 mean**。这是熟悉布局上的留出测试照片表现，不是训练样本上的准确率。new12、Q、曲线及供体重组均为辅助；若new12较好而old主量不支持，不得临时换主量宣称实验成功。v24 attention只作辅助对照，本轮不再新增该臂。

四个来源33101–33104各自先平均三分区和两方向，再给出四个配对差及均值。12次新训练与12个历史mean结果构成来源内比较，不是24个独立来源。历史mean必须绑定来源和完整记录；开发重放用于检查迁移实现，不能包装成新增独立重复。两遮挡、所有来源和固定2400步预算全部保留。

若old主量改善，可支持该对比路径帮助当前接口学习熟悉布局；不能将全部变化归于恢复了丢失信息。若old改善而new12仍低，则熟悉布局学习与私人熟悉、通信未见布局的表达迁移继续分离。即使两者都改善，也仍需实际结构证据和独立材料确认，不能单凭J或人工拼接称语言能力增强。若old主量没有一致改善，应保留失败或不稳定结果并停止沿此配置追加调参，不能反推私人知识不存在。
