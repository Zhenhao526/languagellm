# v0.24 直接近邻基线：原方法与任务内改编

2026-09-16。有界方法核查，不读取本轮实验成绩，不运行或修改训练。核查对象为 Feng 等 AAAI 2024 正式论文及其 arXiv 附录、Ri 等 CogSci 2023 的本地 arXiv 全文。执行了 3 次定向主源检索；**未定位到可验证的两篇论文作者实现仓库，因此代码文件路径与 commit 均未核实**。以下只把原文明示的操作称为已核实，不把自行补齐的实现细节称为作者代码。

结论：选择 **Ri 式发送者双线性软注意力 AT 对照恒定焦点 NoAT**，作为 v23 全支持私人主体上的任务内改编。Feng 的主通信模型没有这里需要的注意力模块，不能命名为“Feng attention”。两篇原方法都没有与当前任务完全相同的接收者输入和监督，故本轮不能称忠实复现原论文实验。

## Feng 等：实际是 CNN—LSTM 指称游戏

正式论文第 3 页“Agent Architecture”“Optimization”写明：发送者 CNN 将图像编码为单向量，经 projector 初始化 LSTM 隐状态；输入开始符号后，逐步抽样符号并把其 one-hot 送回 LSTM，测试时逐 token 贪心。接收者用另一 CNN 编码各候选图像，用 LSTM 编码消息，再分别投影，以余弦相似度选择候选。**不是逐 token 查询多个视觉 key 的注意力发送者。** [AAAI 正式论文](https://ojs.aaai.org/index.php/AAAI/article/view/29685)

输入为两形状及其空间关系的生成图像。随机图像条件让两个主体看到同一语义组合的不同实例；接收者有候选图像，使用正确候选位置的交叉熵监督。发送者使用游戏奖励的 REINFORCE 加熵项。离散消息不提供跨主体可微通道；主实验的 CNN 随各自学习更新，不能与后面的冻结 SimCLR 诊断混为一谈。

正式论文第 5 页的 SimCLR 实验先以**同一训练组合**生成正样本图像对，再冻结所得视觉编码器学习通信。该正样本构造利用生成器的组合身份；它不是纯靠私人采集行动的标量后果。原文讨论的是预训练编码器与通信泛化，不是引入注意力。

arXiv v1 附录 A 补充了 reduced AlexNet、发送 LSTM、接收 LSTM 和投影结构；附录 C 的 Object Placement 接收者还能得到两对象的坐标及形状编号。其后续行动任务也不能作为“接收者仅消息＋自身需求”的同信息对照。[作者 arXiv 全文及附录](https://arxiv.org/html/2302.08084v1)

## Ri 等：原文确定了什么

Ri、Ueda、Naradowsky 的 *Emergent Communication with Attention* 收录于 CogSci 2023。这里读的是 arXiv v1；正式会议记录及论文检索结果可核实发表身份，不把预印本自身当成评审认证。[arXiv](https://arxiv.org/abs/2305.10920)；[会议记录](https://escholarship.org/uc/item/7dg8r8zk)

|---|---|---|
| 视觉输入 | 预训练 ConvNeXt-tiny 提取的 7×7×768 patch 特征；主体各自作 Linear＋GELU。实验是两个 Fashion-MNIST 类别组成图像，45 种类型分 30/15，两个主体看到不同实例和位置。 | 这是多 patch 输入；不是 v23 的单一终态 h，也不是私人行动头的两个预测向量。文中按特征输入描述，未从代码独立核验 CNN 的冻结标志或缓存流程。 |
| LSTM 发送者 AT | 前一 token embedding 经 LSTM 得到当前 query (q_t)；分数 (s_{ti}=q_t^T W_b z_i)，softmax 后对**原 key-value 向量** (z_i) 求加权和；query 与 attention context 经 post-processing 后预测 token。 | 没有明确规定本轮 LSTMCell 的具体状态更新或融合层；本轮零 h、c 初态是本地明确选择，不是已核实作者设置，不能用相似名称替代披露。 |
| 发送者 NoAT | 先将向量均值化成单向量，保留同一模块，对这个单 key 作 source-target attention；焦点恒定。作者声明两者模块及参数数目相同。 | 不是在完整多 key 输入上仅关闭一项正则；均值压缩与动态选择一起改变。 |
| 接收者 | 看候选图像。LSTM 版本用双向 LSTM 编码消息；NoAT 用平均消息向量与平均对象向量匹配；AT 用每个消息向量查询对象多向量，再平均符号—对象匹配分数。 | 给当前接收者增加图像、候选地图或私人预测会改变信息权限；不能原样搬入。 |
| 学习信号 | 发送者为离散抽样 REINFORCE，加熵和 EMA 发送政策的 KL 项；接收者使用正确候选位置的交叉熵。没有自然语言 token 标签，但有目标候选监督。 | 本项目两端独立标量混合收益学习、原有优化器及熵日程均是任务内替换；保留这些设置不等于复现原优化。 |

论文第 4 页还说明搜索熵系数，并按泛化得分选择每设置前十个主体报告。此选择程序不移植到本项目：固定来源全部保留，不能看到 new12 成绩后挑主体或调配置。

### LSTM 初始化、融合和 input feeding：明确的未核实项

- **初态：**原文没有写清 LSTM 的 (h_0,c_0) 是零、学习参数还是视觉投影。不能套用 Feng 的视觉初始化后说是 Ri 原实现。
- **attention 的顺序：**明确先 contextualization，再 attention，再 post-processing。双线性公式与加权原向量明确；但 post-processing 只概述 concat、addition、transformation，并指向 Luong/Vaswani 原方法，未给本实现逐层配置。
- **input feeding：**未明确说是否把前一步 attended/context 向量与下一 token embedding 拼接后再次送入 LSTM。引用 Luong 不足以证明启用了该选项。
- **pooling 次序：**第 2 页 Object Encoder 明确描述逐向量 Linear＋GELU 后求均值；第 4 页 Input Representation 又概述 NoAT 将 patch 特征平均成 768 维。没有作者代码，无法排除两段在具体次序上的歧义。本轮采用前者，必须固定说明，不能称已核实的代码顺序。
- **代码证据：**没有取得作者仓库、配置或 commit；不能声称核验过上述实现。当前可做的是按已给公式实现最小版本，并在固定方案明确本地选择，例如本轮 LSTMCell 的零 h、c 初态、是否额外更新一次状态、context/query 的融合公式以及是否 input feeding。不得把这些选择藏在“Ri decoder”这个名称下。

## 对根任务已选方案的判断

采用根任务拟定的输入：从同一个 v23 全支持私人终点，冻结原私人行动头，对两种合法需求分别得到六地点概率；每个概率向量拼接两个需求角色位，形成两个 8 维预测概念向量。AT/NoAT 都经过同一形式的 Linear＋GELU 编码、保留同一原无图像接收者，区别为多个 key 的软选择或平均单 key 的恒定焦点。

这可以忠实保留 **Ri 的 AT/NoAT 核心操作**，并做到两臂原始输入、已训练私人来源和反馈权限匹配。必须同时披露：

1. **从 patch 到预测概念。** 原输入换成学得的私人行动概率，提供了需求分解和坐标明确的中间读出；不是原始像素，也不是主体自发发现了两个概念槽。角色位是实验提供的需求身份，不能称完全没有类别/结构信息。它们不是每个新地图的正确地点标签，也不是预先指定消息 token 的含义。
2. **重用私人头是一条新读出路径。** v23 社会阶段丢弃私人头、只读 h；本轮重新利用私人头的学习成果。两臂彼此可比，但相对旧 v23 成绩的改善同时包含这条路径，不能全归因于 attention。原私人接口、头和概率计算应在两臂完全一致且冻结。
3. **只改发送者。** 接收者继续仅接收离散消息与自身需求，不加入候选图像，也不加入原论文的候选 CE。本轮发送 LSTMCell（零 h、c 初态）、两枚七选一 token、混合团队收益、固定预算等均逐项标成任务内改编。EMA KL 若不采用，也明确列为与原方法不同。
4. **不规定 token 对应哪个需求。** 两个概率向量有角色身份，不要求 token 0 表达食物、token 1 表达水；逐 token query 决定选择。不能用资源真值或人工正确消息训练 attention 或消息头。
5. **平均控制的范围。** NoAT 的单 key softmax 恒为 1，因此双线性 (W_b) 若无其他用途，其任务梯度为零，这是该控制的数学性质。相同存储参数数目不等于相同有效自由度、表达能力或实际计算量。AT−NoAT 识别的是保留两个向量并动态读取，相对均值压缩的总作用；不能单独证明一个抽象“注意能力”是原因。角色位须在两臂的相同非线性编码前加入，否则线性均值可能丢失角色与位置的对应；即使加入，也不能先验断言平均编码无损。

**建议名称：**“Ri 等（2023）双线性发送注意力的预测概念改编”，配对“同输入恒定焦点控制”。可以说“按原文公式改编并独立验证本地实现”，不能说“运行作者代码”“复现 Ri 原始分数”或“Feng attention 基线”。若另外保留全部预测信息的非注意力控制，它回答均值压缩之外的机制问题；不要事后把该自设控制写成 Ri 原始实验的一部分。

主要可反驳解释是：已提供私人预测概念后，动态选择是否比恒定均值更有利于通信未见组合的自然表达。若没有一致提升，保留注意力没有帮助的结果；若提升，也需区分平均压缩、学习便利性和实际协议结构，不能仅凭更清晰的 attention 热图证明组合符号或人类式共同注意。
