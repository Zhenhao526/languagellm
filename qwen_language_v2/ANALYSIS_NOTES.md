# v0.2 先导实验的分析边界与报告要求

本文件规定这次小规模先导怎样报告结果，不预先认定符号系统已经成为语言。主比较是同一次物理行动之前的即时回应机会，而非“有互动/完全无互动”。延迟条件仍能在下一个动作步回应此前消息。

## 必须先报告的流程证据

- 实际完成的条件、独立群体数、任务段数、每段动作步数与停止原因；失败群体不能删除。
- 场景可解性回放、独立能力控制结果及上下文长度。能力控制不能使用主实验的训练历史或把自然语言计划传入主实验。
- 每步4个窗口、12次通信调用中的可见性审计：即时条件不能看到同窗消息；延迟条件只能看到自己在本步此前发出的消息，直到统一发布；动作前两条件均收到全部正式消息。
- 非法输出、生成上限、余额耗尽、历史截取、实际私有思考token和耗时。达到输出上限不能自动认定存在更多未说出的语义内容。
- 分别报告每条长度、每人每步总符号数、空消息比例、达到单条32符号上限的比例、达到当前余额上限的比例，以及余额为零的窗口数。不要将这些量合成“语言复杂度”。

协议从源头限制正式输出长度。调度器不会把33字符悄悄裁成32字符；非法输出导致显式失败。研究者应保留失败记录，修复后另记运行版本。窗口和私有计算机会不会因沉默或额度用尽提前结束。

## 本次可直接获得的结果

**合作行为。** 逐群体报告每段截止时交付目标的完成比例、全部完成与否、实际动作步数及失败动作。各段任务量不同时同时保留分子/分母；没有全部完成的段不能拿较短用时当作效率优势。无通信成绩需要实际测量，本任务没有旧版25%的解析基线。

**通信使用。** 描述消息长度分布、空串比例、窗口间变化和同群体内表达复现。它们能说明主体使用了哪些通信机会，不能独自证明共享意义、句法或组合性。接收者即使获得信息，也可能因动作执行失败而未完成目标；应区分解释与执行。

**即时/延迟差异。** 使用配对的初始场景及外生事件种子，逐群体展示两条件结果和差值。后续局部观察因行为变化而不同是闭环结果，不宜强行匹配成不合法轨迹。若只有少量群体，优先报告完整个体结果、原始计数和范围，避免把每条消息或每个动作当作独立样本。差异只能说明这次运行中的表现；不据此宣布即时回应普遍促进语言诞生。

## 六种语言证据在小规模先导中的状态

| 维度 | 本次可做的诚实报告 | 还需要的确认 |
|---|---|---|
| 共同意义 | 对候选表达列出上下文、发送者与伙伴后续行为，包括反例 | 独立情境中重复理解，区分表达者编码与接收者理解 |
| 新组合理解 | 只报告事先固定且基本要素已在经历中出现的留出组合；列明测试时是否允许澄清 | 从冻结历史副本首次测试，测试经验不回流 |
| 片段复用 | 重复子串只能标为候选模式 | 先开发后确认，以熟悉片段的替换/重组检验选择性行为变化 |
| 关系表达 | 展示同对象而参与者或关系变化的对比案例 | 多个独立配对情境，排除整场景编号与角色捷径 |
| 误解修复 | 描述可观察分歧及后续纠正；私有分析仅辅助研究者定位，不作意义真值 | 从同一历史/环境状态分叉，移除或替换回应，检查特定误解是否恢复 |
| 合作作用 | 展示成绩及消息出现前后的行动 | 匹配状态中的移除/替换消息干预；完整无通信条件需保留相同非言语观察 |

若本轮未实施某项测试，应明确标为“未测试”，不能用任务得分、消息长度或模型自述替代。少量任务段内未见稳定表达，也不能证明这些环境条件不足以产生语言。

## 对照与解释中保留的混淆

- 即时和延迟条件的最大预算一致，实际符号数、生成长度及计算消耗可能不同。即时回应改变了可用信息的时间，可能通过规划或纠错直接提高合作成绩，尚不能推断形成了更强的语言结构。
- 固定的发送者身份、窗口边界和沉默可能参与约定；动作和同地可见行为也是非言语渠道。不能把所有协调归因于字符串内部结构。
- 8个字符及自然语言任务说明均有预训练先验；独立上下文不是互相没有语言经验。固定权重实验观察的是新共享表达的形成和使用，不是从无语言认知重现人类起源。
- 观察与动作接口已经提供对象、属性和关系结构。环境中的随机句柄、顺序扰动与留出组合检查只能缓解部分机械序列化捷径。
- 不能从同一小批日志先选出好看的片段，再把同一批数据当作组合性确认。须明确区分探索案例、事先固定指标和独立验证。

第一份结果表建议包含：条件、群体、任务段、交付单位/所需单位、全完成、动作步数、失败动作、总符号、空消息比例、上限触及比例、私有思考token、运行耗时。另保留候选表达案例表及其反例，不输出单一“语言诞生分数”。
