# v24：私人行动预测上的动态读取与共同通信

状态：正式训练前固定。承接 v23 已封存结果；本轮新增两个发送者条件，不扩展环境难度。问题是：在私人资源定位能力已具备时，保留分开的任务预测并在每枚符号生成时读取，能否改善社会学习未见组合的共同通信？它补足结构基线，不视为新算法。

## 来源与信息权限

使用 v23 experience_001 的四个来源 33101–33104，每源三个分区、每区两个主体的 private_all 终点，共24个冻结私人主体。它们经历所有30种资源位置组合的私人奖励学习，在既有有限测试集两种遮挡下均达到100%联合定位；不筛选来源。官方冻结 DINOv2 ViT-L/14（304,368,640参数）图片特征、继承视觉投影、两帧时间表征和私人行动头均保持冻结。本轮无新图片、无新DINO推理、无私人梯度更新，不启动其他暂停路线。

主体看到两帧：第一帧含两种资源；第二帧只显示食物或水，地图不移动。两帧表征 h96 经自身冻结私人头得到[2,6]位置概率，附加两位角色one-hot，构成[2,8]输入。概率来自模型，禁止替换为标签、argmax或真实地点；角色位显式保留已有需求分支语义。环境真值仅在采样完接收行动后计算收益。接收者只获得两枚整数符号，使用既有两需求行动分支；不读取图像、私人预测、遮挡标识或另一需求行动。

任务仍是有限资源定位与分工的抽象，尚无真实原始社会生存、工具生产、资源消耗或自由形成分工。私人见过30种、社会只见old18，因此new12指社会未见组合，而非整个主体从未经历的世界。旧图片测试仍来自同一小图像池，不能替代独立图像确认。

## 两个条件与网络

共同部分：共享Linear(8,96)逐向量编码后GELU；Embedding(8,16)，0–6为实际符号、7为SOS；LSTMCell(16,96)，每世界h/c均为零。每步先将上一枚符号嵌入送入LSTM，再由h查询key；无前步context input feeding，仅持续原LSTM h/c。分数为Linear_no_bias(h)与key的内积，即按实际参数记作 hᵀWᵀkey；softmax后加权原key作为context。concat(h,context)经Linear(192,96)、Tanh、Linear(96,7)生成logits。

- mean：对编码后的两个向量先取均值，仅留下一个key，再执行相同注意力模块。
- attention：保留两个key，每步动态计算两个权重。

不规定哪枚符号负责哪种资源。两枚符号自回归生成，词表7、长度2，共49码；测试逐token贪心，不以完整消息联合argmax替代。另枚举全部49码计算概率指标Q。

新sender有73,191参数，receiver有6,364参数，每人训练79,555参数；旧sender/value均冻结且不调用。mean单key的softmax为1，bilinear任务梯度为零，存储参数数目一致不等于有效容量或计算量一致。输出effective_attention在mean记为对两个原始预测的等效[.5,.5]，它不同于单key实际权重[1]。

方法依据 Ri等2023 Emergent Communication with Attention（arXiv:2305.10920v1）的AT/NoAT发送结构，属任务内改编：用私人预测替代原ConvNeXt图像patch，不搬入候选图像接收器、CE或EMA KL；零初态、融合层、无input feeding是明确的本地选择。作者代码未核实。Feng等2024不具有本拟议注意力结构。详见近邻核查。

## 配对训练预算

四来源×三分区×两臂，共24次双主体社会训练，每次2400更新。接收器按原v23 SeedSequence([23023,seed,p,d,1])生成的63位seed顺序重置；新sender用SeedSequence([24024,seed,p,d,0])生成63位seed，模式不进入随机种子。两臂初始参数逐位相同。

每方向每次128基础世界，成对展开两种遮挡成256消息，每消息服务两需求；双向每次512消息、1024行动。沿用v23 world.fixture的old社会世界与外部随机流，两个条件及历史B使用相同流。训练表29040行，测试960行（30地图×16照片对×2遮挡）。缓存可含全部组合，但训练索引只许old18。

收益R=.25(cF+cW)+.5cFcW，advantage=R−.5。REINFORCE，sender两token logp/熵之和、receiver两行动logp/熵之和；每主体(sender loss+receiver loss)/2。Adam lr=.0007，每角色独立clip2；前2100更新熵系数.02，之后0。总57,600对更新、29,491,200消息、58,982,400行动。记录0/100/600/1200/2100/2400，预算不因结果调整。

开发仅源99523、分区1，继承v23 smoke_001的私人all终点（私人只训练40步，因此不代表正式能力）。两个条件各40社会步，验证流程、不能用于效果调参。正式前要求代码/合成信息流审查、完整开发运行，独立终点与关键更新重放最终通过后才解释正式结果；如正式启动时独立开发审计尚未完成，需明确记录pending，不能补写为预先通过。

## 指标和结构检查

主指标：第2400步new12逐token贪心消息的两行动同时正确率J，attention−mean。每来源先平均3分区×2通信方向×2遮挡，再报告4来源配对值和均值，不把世界或方向作为独立来源。old18、两资源单项、两遮挡、共同30、Q（49消息×两个正确行动概率求和）、学习曲线和梯形归一AUC为辅助。提供固定空码与完整消息随机错配的精确有限期望。仅4个继承来源，显著性/独立复现/总体外推有限。

v23 all_old的new12 J=15.8963%仅作历史参考：与新臂相比同时改变私人头读出和发送架构，差值不能归于注意力或单一非语言能力。

另预先固定有限符号供体重组检查：对每目标，匹配相同遮挡与照片对，仅从old18选择供体。一供体匹配目标食物且水不同，另一匹配目标水且食物不同；均匀枚举所有供体配对，目标内先均值，再目标等权。分别报告第0/1槽对应食物/水及水/食物两种排列，不根据new12选择方向。old每目标4配对，new每目标9配对。从供体消息取对应槽的符号拼接，查已保存接收器贪心动作。

以seed2402401固定200个全49码双射：先整体重编码每个供体消息，再拆位重组，再逆映射查询原接收器。自然完整消息行为在重编码下严格不变，但字符结构会改变。所有来源/条件共用同组双射；原始200个结果在方向/分区/来源聚合后再取分位数。它只测人工构造消息是否具有相对任意整码重命名可复用的槽结构；不证明自然生成遵循该规则，更不等于语法或人类语言起源。49码仍足以记忆30地图；attention权重本身也不是因果解释。
