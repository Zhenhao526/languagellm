# v22：末帧可见对象反转的近邻与解释边界

2026-09-16，结果前短评。**本轮是固定 v20 私人接口与 v21 协议的离线行为诊断，检验已有协议的优势究竟随哪项输入条件变化；没有新的符号学习，不宜称为新的语言形成机制。** v20 能力差门槛未通过的结论保持不变。

**感知条件近邻。** Diana Rodríguez Luna、Edoardo Maria Ponti、Dieuwke Hupkes、Elia Bruni（2020），*Internal and external pressures on language emergence: least effort, object constancy and frequency*，Findings of EMNLP，4428–4437，DOI 10.18653/v1/2020.findings-emnlp.397。本次核实[官方记录](https://aclanthology.org/2020.findings-emnlp.397/)，复读既有原文 §4.2–4.4（PDF 第4页）及相关方法：分别改变发送/接收图像的位置、亮度及物体分布，考察通信内容和泛化。它已直接研究感知条件和暴露频率如何改变协议，但不是当前可见对象与记忆对象的固定协议反转；其“对象恒常性”也不能当作本任务跨帧保存地点的同义词。[既有 PDF](/Users/xia/Documents/ChatGPT/语言/paper_program/literature_spatial_20260915/primary/2020_RodriguezLuna_Object_Constancy_FindingsEMNLP.pdf)

**时间通信近邻。** Olaf Lipinski、Adam J. Sobey、Federico Cerutti、Timothy J. Norman（2026），*It’s About Time: Temporal References in Emergent Communication*，JAIR 86，Article 11，DOI 10.1613/jair.1.19795；[官方 v3 原文](https://arxiv.org/html/2310.06555v3)。沿用上轮 §2–5 方法核查，本次重读 §5.1、§6–7：顺序 LSTM 与重复目标环境产生历史相关消息，多数消息仍用于描述当前对象；时间相关消息的出现没有相应带来总体准确率提升。该实验中目标仍直接呈现给发送者，主要评价消息与过去目标重复的关系。它不能直接证明一般 RNN 具有何种近期偏向，也不是本轮资源可见性反转。时间信息进入消息、自然行动成功和组合结构须继续分开。

三个定向查询没有定位到可据以认定“同一已训视觉协议，完整初态→无移动 food-only/water-only 的精确反转诊断”已被原样执行的论文；这不是不存在先例的证明。没有增加 PDF 或继续扩库，其他搜索命中的 LLM 记忆研究不作为本项目机器通信证据。

本轮最清楚的判别是：如果食物末帧可见时食物占优、水末帧可见时水占优，便反对“优势只固定属于食物/水类别”的解释；没有移动事件，也说明这种优势不要求本次出现移动。**但可见对象同时是最近再次输入、且累计被呈现两次的对象，另一对象仅在初态出现一次。** 可见性、近期性和重复暴露仍共变；亮度、对比度或注意权重也没有被单独操作。因此结果宜称“固定协议对末帧可用信息的依赖”，不宜直接称感知显著性机制、纯记忆衰减或人类注意机制。

反转须比一个正交互更严格。令 `D_food-only = 食物准确率 − 水准确率`，`D_water-only` 同理；只有前者为正、后者为负才是对应方向的优势交叉。二者之差为正，也可能只是同一资源的优势变弱而没有反转。保留各主体来源的两个差及幅度，不能只报告宏均值交互。消息改变也不等于正确传递内容，仍以两需求的自然行动及其分项表现为准。

私人行动提供解释位置：若私人头与协议都随可见性反转，上游状态访问差异仍可能解释；若私人两资源均能正确行动、固定协议却优先表达末帧对象，则支持“该信息可以被私人头使用，但现有协议未同样有效使用”的较窄判断。后者依然不能区分消息头读出、共同约定、训练关联与表示几何，更不能凭一般 RNN 的常见印象给出确定机制。若没有反转，也不能立即证明固定类别偏好；无移动序列可能是相对既有训练历史的新输入条件，须保留分布转移的解释。

可增加的知识是对 v21 不对称现象做一次能反驳固定类别解释的定位。它可以成为研究中的机制诊断证据，不能独立充当创新算法、充分的论文贡献或“非语言记忆促成符号诞生”的证明。本短评不读取本轮结果，不改变实施计划，不提议追加训练矩阵。
