# R/S 短诊断执行设计审查

本文件审查已授权的 R/S 设计，不是实验结果。撰写时尚未审阅实现代码或本轮模型输出；不改变 v3 冻结核心和旧结果，不追加模型调用。默认 8 次正式选择，每次一次分析、一次正式输出，共 16 次后端调用；R 触发短规则卡时再加 4 次正式选择、8 次调用，最多 24 次。S 在 R 成败两种情况下都执行，不设置“试到成功”的重试。

目标是定位少量已知规则和状态使用疑点。R 是文字规则判断，S 是两个事后选定失败点的单人决策替换；两者都不能直接评估新语言形成，也不自动解锁符号主实验。

## 一、R 的对照实际检验什么

使用同一合成局部状态：A 空手，与干长、干短、湿长、湿短四种纤维同地。仅题目询问的目标长度在干长与干短之间变化；每种目标使用两个编号顺序，四题均从空上下文运行。完整 v3 规则下，两种目标的正确含义都是“可以单人拿取”。地面物品顺序、句柄、地点、周围主体及所有其他文本应保持一致；题中说明的目标与状态一致。

换序的两个选项须逐字相同，仅改变编号/位置，不能同时改写措辞。换序共享两阶段种子；目标长度对照也宜共享同一组种子，避免声称“只有长度不同”时另有随机条件差异。若使用不同种子，须在报告中列出，不能视作严格的单因素输入对照。即使温度为 0，也应保存实际种子和后端参数。

| 观察 | 最多支持什么 | 不能推出什么 |
| --- | --- | --- |
| 完整规则下四题正式输出均正确 | 在这四个固定输入中，选择了与纤维携带规则一致的含义，并经受了这两种顺序 | 四题答案含义相同，不能排除一贯选“可以单人拿取”的偏向；不证明理解长木材限制、完整规则掌握或能在物理任务中执行 |
| 换序后答案含义变化 | 这组输入对选项顺序敏感 | 不能据此单独诊断规则知识缺失、编号接口错误或模型整体能力不足 |
| 长短题的答案不同 | 在这两个长度提问下出现局部差异 | 一对状态、无独立重复，不能估计普遍的长度效应；更不能解释 v3 两场的成败，因为那两场改变了多个因素 |
| 短规则卡后改善 | 冻结的短规则呈现对这些题目有帮助 | 不能证明原错误只由提示长度导致；替换规则也改变内容范围、显著性和任务负担 |
| 分析说对，正式选择错 | 生成分析与正式编号/含义不一致 | 不能记作题目通过；分析文本不是内部真实原因的直接证据 |

短规则卡须在首次调用前固定，并明确是**替换完整 RULES**还是**追加在完整 RULES 后**；这两种不是同一干预。按原草案，建议替换为只包含纤维、短木材、长木材全部携带规则的卡片，不提供答案编号。两臂其他题目文本、状态、选项和种子均保持一致。先跑完原四题，再按冻结触发条件决定是否整组追加同四题；不要只重测错题，也不要看答案后修改卡片。

触发条件必须以正式输出映射后的含义定义。至少区分正确、语义错误、无法解析和后端执行错误，并预先规定哪些触发短卡。建议语义错误或无法解析视为原正式题未通过；后端异常另记执行失败，不能冒充规则错误。不能因分析截断但正式答对而擅自扩大短卡触发范围。

## 二、S 的边界与原动作重现标准

两个案例固定为 v3 首场 B 第 2 步、C 第 9 步，分别对应旧记录的分析/正式调用 **57/58、269/270**。它们来自已知失败，属于事后选例；原臂与空历史臂是诊断配对，不能用两点的结果计算无偏任务准确率或证明干预的一般有效性。

每臂当前完整信息观察、当前四窗广播、菜单、规则、人物身份、分析与正式参数、种子相同；只把“你自己的历史”保留或替换为 `[]`。B 第 2 步原历史有 1 条，C 第 9 步有 8 条；各有当前 12 条广播，空历史臂仍保留这些当步广播。不得删除当前 `last_result`、当前携带直读、当前任务板或当前消息中的旧计划；这样做会扩大干预。

若从旧轨迹重建历史，只按冻结 `remember` 逻辑加入原始观察、已送达广播、实际动作与反馈。不得添加私有分析、摘要、正确计划、另两人未执行动作或研究者目标标签。最终仍须与旧调用的实际输入逐字段及字节/hash 核对，不能仅凭“重建代码相同”宣布输入一致。

原臂重现至少分三层报告，不能合并成一个布尔值：

1. **输入重现**：原分析请求的完整 messages、序列顺序及序列化字节/hash 与旧 call 相同；模型版本、量化、模板、两阶段种子/温度/预算及后端代码也有对应记录。
2. **输出重现**：新分析文本是否与旧分析逐字相同；将本次新分析用于正式阶段后，正式完整输入是否与旧正式请求相同，正式原始输出是否相同。若分析不同，正式输入差异是实际发生的条件变化，须明示。
3. **动作重现**：正式编号解析为与旧记录相同的语义动作，并在冻结环境与另外两人旧动作共同结算时，复现反馈和后状态。只到这一层不能写“分析全过程精确重现”。

若原臂未重现旧动作，仍应保存预定两臂并执行已锁定流程，但将历史作用的解释降为“本次两输入配对的差异”；先报告复现缺口，不能把与旧轨迹的变化都归因于删历史。不要为恢复旧动作改种子或重复抽样。

空历史臂应独立重新生成自己的分析，再据该分析输出正式动作。不得将旧分析或原臂新分析复制进去，否则名义上删历史、实际上可能又引入由历史产生的信息。两臂正式输入除基础历史字段外，可能因各自分析不同而不同；这是本次两阶段决策流程的组成部分，应保存而非隐藏。

## 三、S 的一步结算不能仅看分数

结算使用两个互不影响的环境副本，只替换被测主体动作，另外两人的动作固定为原记录。固定动作不得进入主体提示。研究者因此测到的是“其他两人提交这些动作时，替换该人的一次决定会发生什么”；不是三人重新协商，也不是自然社会重新运行。

| 案例 | 可预存的诊断目标动作与观察 | 一步结算的解释边界 |
| --- | --- | --- |
| B，第 2 步 | 已持正确干长纤维；“前往营地”可将其带至目的地。按动作语义识别，不按固定编号 | 移动后仍须另一步交付，一步分数可能仍为 0；不能以分数不变称没有行动改善。其他合法选择也不能一概标成物理规则错误 |
| C，第 9 步 | 同地空手，A 的固定原动作是与 C 搬目标干长木材至营地；C 的匹配目标动作是与 A 搬同物至营地 | 配对成功后只是木材与两人到达营地，尚未交付。一方目标选择与固定搭档意向一致，不证明群体会自主再次形成相同协商结果 |

除分数外，至少报告所选语义动作、动作是否合法、该主体反馈、双方共同动作是否匹配、各人位置和携带物变化、交付量。诊断目标动作可以事先定义，但不要称它是任何合作规划中唯一正确动作。若需判断“目标进展”，预先指定是携目标物到达目的地或成功共同搬运，不在看到输出后临时扩展成功标准。

删除整个历史同时移除旧状态、旧消息和行动结果，并缩短输入；保留当前广播也意味着当前误导性说法仍在。两臂差异不能锁定到某一句旧广播、记忆污染或某种内部机制；两臂相同也不证明历史完全无影响。R 通过而 S 未选诊断目标，只能说明简单文字题表现没有在这两个完整输入中直接体现为目标动作，不能推成规则与规划的普遍分离。

## 四、最低执行检查

运行前冻结以下内容，并由程序断言关键条件：

- R 的四个题目、完整规则、短卡文本及替换/追加方式、选项顺序、目标真值和触发分支；S 的两源案例及旧 call、干预定义、诊断目标语义动作、固定伙伴动作与结算状态。不要把期待答案或固定伙伴动作放入模型消息。
- R 的同状态条件：四种纤维各一件、A 空手且同地；长度对照只改变预定询问字段，换序只改变两项顺序。两阶段种子配对关系与调用总预算可机械核对。
- S 原输入先与源调用核对；空历史输入与原输入的基础 payload 差异仅为历史字段。保留当前观察、直读、菜单和 12 条广播的原顺序与文本，确认没有预先给被测者另两人的动作。
- 每题、每臂有新上下文/缓存隔离，没有跨题历史、答案反馈或规则卡残留；S 不继承 R 的卡片或作答。两阶段各保存实际生成文本，不能悄悄复用原分析。
- 结果通过正式选项映射评分；动作选择用当时菜单解释。记录解析失败和截断，不能把 fallback 动作写成模型自主选中。遇执行异常保存实际已消耗调用，不以未授权重试补足漂亮结果。
- 冻结环境先重放两源步骤，确认原动作、反馈和后状态；每个反事实结算均从同一原 `state_before` 独立复制。只结算一步，不推进后续合作历史。
- 运行前后核对 v3 七个冻结核心及被引用旧记录的 SHA256；新输出仅写本轮目录，不修改旧结果或能力门槛。

## 五、应预先保存的字段

| 记录层 | 必需字段 |
| --- | --- |
| 本轮 manifest | 设计版本/时间、授权范围、默认与最大调用数、执行顺序、R 触发判据、模型仓库和 commit、量化/模板、运行库与后端版本、源码/完整规则/短卡 SHA256 |
| 每个测试定义 | 稳定 test_id、R/S、案例或目标长度、选项顺序及编号→含义映射、真值或诊断目标动作、独立上下文标识、配对种子、最大分析/正式 token、温度、规则臂 |
| 来源与重建 | 源 batch、episode/step/agent/call、源文件与所选行哈希、原观察/原菜单/原当前广播、原历史条数和完整内容、构建方法、与旧原输入的结构差异及字节/hash 比较 |
| 每次调用 | 阶段、完整 messages 与 prompt hash、实际种子/参数、原始输出、finish_reason、token 数、耗时、valid/解析状态、缓存是否新建、后端错误；分析与正式各自独立记录 |
| R 评分/分支 | 解析编号、对应含义、正式正确性、错误类型、原四题完成状态、短卡触发与原因、短卡是否真的运行；分析文本另列，不替代正式判分 |
| S 复现/干预 | 分析输入是否相同、分析输出是否相同、正式输入是否相同、正式输出/编号/语义动作是否相同；基础历史之外的输入差异；原/空臂各自状态快照 |
| S 一步结果 | 固定伙伴动作（研究者层）、被测选择与对应菜单项、联合动作、私人反馈、完整前后状态及哈希、位置/携带/匹配/交付/分数变化、诊断目标是否选择 |
| 结束与解释 | 实际调用数、异常/未完成题、条件分支、各题原始结果、复现层级、选择偏差与无泛化范围；不输出单一“语言能力分数”，不将本轮结果写入符号主体经验 |

上述字段用于使干预具体、可复核；不要求新增模型条件。凡未在执行前固定的指标，应在最终报告中标为事后描述。
