# 流程图片像素验收：执行前固定

2026-09-15。承接已冻结元数据框，仅处理已预约workflow的24张流程图片；本阶段不访问confirmation的48张图片，不运行视觉模型，不改变144簇预约与备用顺序。原元数据阶段的“不下载”是该阶段范围，本阶段在用户持续研究授权下推进图像验收。旧方案的人眼验收改为两名独立AI视觉评审，准确标注评审身份，不称人类志愿者评审。

先下载24张原图，核对SHA1、尺寸、文件格式与元数据快照。只使用已记录original_url；串行间隔至少10秒，60秒超时。429/503遵从Retry-After（大小写无关、秒或HTTP日期），缺失时30秒，最多一次重试；403或明确拒绝立即停止。不换入口规避限制。其他5xx/网络暂时故障最多一次5秒后重试。单文件读取上限50MiB；超出预算记失败不把难识别图片记为故障。记录每次请求头、状态、时间与原字节摘要。

冻结实现用Python3.12.14、Pillow12.3.0、NumPy1.26.4，运行时精确记录。EXIF校正、RGB，依旧数据方案缩至最长边640（LANCZOS，不放大），JPEG质量95；实际模型裁剪严格使用旧encode_images.preprocess的短边256 BICUBIC、居中224整数坐标流程，不做模型推理。完整原图保留、派生修改与许可署名链保留。RGB归一化之前的224 PNG供评审；预处理张量应与旧函数逐位相同。

固定64位pHash：EXIF/RGB后的派生640图转L、LANCZOS缩为32×32，正交DCT-II的左上8×8（包括DC），以64值中位数为阈值、严格大于为1，按行顺序打包。固定64位dHash：相同L图LANCZOS至9×8，右像素严格大于左像素为1，按行打包。pHash距离≤8或dHash≤6召回疑似近重复。此为本项目冻结的明确定义，不暗示所有第三方库位值一致。覆盖旧101张已存640派生图和全部新下载流程图；旧原始字节此前未全部保留，因此这是同处理尺寸的像素比对，不能声称原图全覆盖。跨确认集及备用的像素排查仍待未来阶段。

匿名ID为SHA256(旧盐+'|pixel-blind|'+candidate_id)前12位，按ID排序。评审材料只含匿名ID、全图（显示缩放）及实际224裁剪；隐藏来源标题、类别层、作者和集合分配。两名评审各自判断：真实照片、食物/透明容器水可辨、裁剪保留资源、明显文字/水印、混合食物或不明液体。每项记录是/否/不确定和原因。全部判为可用才通过，不确定与分歧保守排除。评审看到的可能是缩放全图；若细节不足则访问原图局部查看，不能凭标题推断。
