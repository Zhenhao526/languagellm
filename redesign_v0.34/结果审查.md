# v0.34 配对结果审查

本审查覆盖同一 34034 fixture 命名空间下的 rotating A/B 批次与 fixed-A control。两批次 source/input hash 相同；报告中的主要差值是配对的 seed×panel 结果，并在 seed 内对三个面板取平均。

## 已核查范围

- 核查同一命名空间下的 rotating A/B 批次和 fixed-A control，以及 source/input hash 绑定。
- 核查 native、已见 B、未见 C 的 grounded 分数、target/held-out 划分、终点曲线、agreement 和跨团队替换。
- 核查配对 seed×panel 差值、seed-level 聚合，以及 native 性能和 all-cross 兼容性的区别。
- 核查独立 NumPy 重算、fixed-control trace replay、完成哈希、终端回执和栅格图形 QA。
- 核查配对报告中的全部绝对本地链接。

## 核心发现

- fixed-A native A 目标 J 为 40.625%，rotating-A 为 29.109%；同命名空间 seed×panel 差值为 -11.516 个百分点。
- rotating-A 的 all-cross J 为 20.779%，fixed-A 为 6.037%；配对差值为 +14.742 个百分点，而 native within 差值为 -11.516 个百分点。
- 完整双 token 一致率从 fixed-A 的 12.708% 升至 rotating 的 43.125%，但 native grounded J 同步下降；形式一致和语义后果分离。
- rotating 的已见 B 目标 J 为 29.716%，未见 C 为 13.281%，说明拓扑覆盖仍有限。

## 审计与限制

- rotating 独立统计：344,368 checks、4,241,664 scalar comparisons，最大误差 0；边界审计 14,856 checks。
- fixed-A 独立统计：83,013 checks、34,944 scalar comparisons，最大误差 0；trace 审计 8,209 checks。
- rotating 36 组运行，fixed-A 12 组运行；两个批次没有新的私有接口拟合和视觉前向。

## 审查结论

结果可以进入研究记录和论文材料。更准确的表述是：伙伴轮换在同一命名空间下提高了跨团队 token 兼容性和形式一致率，但降低了 native grounded 性能，且未见拓扑仍有明显迁移损失；这是一种可测的社会迁移—任务性能权衡，不是已经产生群体共享语言的证据。下一步应先做 sender/receiver 身份留出。
