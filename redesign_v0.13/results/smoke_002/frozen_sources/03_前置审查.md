# v0.13 私人空间对应准备：独立前置审查

2026-09-15。此审查依据根线程的固定候选设计及既有 CampAgent 接口，先于新训练结果。新运行器和 private_preparation 模块仍需按最终源码及 smoke 独立核验；本文不表示正式执行已经通过，也不改变旧版本冻结数据。

## 研究问题与主要边界

两臂均有冻结 DINO 特征、同一私人 project 和相同初始 CampAgent、私人行动头。control 只通过个人资源行动的标量奖励学习；equivariant 在相同个人经历上增加空间置换对应的 JSD 约束。随后只传递 memory 和 slot_phi，丢弃私人行动头，用相同全新语言接口学习 old18 图的通信，视觉部分继续冻结。

这是“给定实验者提供的空间对应训练后，固定视觉表示如何影响新通信”的干预。JSD 使用已知置换 g 及其对行动坐标的作用，是明确额外提供的非语言结构监督；不能称两臂都只有标量奖励。它没有提供食物/水的类别真值或正确地点 CE，但不等于毫无先验。已有地点坐标、两种需求、存在位、目标分支和合法行动继续由实验者给定。

私人头的政策满足置换对应，并不自动证明被迁移的潜向量 h 按某种已定义表示变换等变。头与视觉模块共同准备，而头在社会阶段丢弃，因此只能把该政策指标作为所学准备的行为诊断；没有潜表示变换检验时，不应把低政策 JSD 直接命名为“潜表示已经等变”。同样，社会差异可能来自综合表示质量、优化条件或信息保持方式，不能直接等同某一种纯认知能力的独立作用。

## 数学支持与置换方向

定义 g 为旧地点到新地点的置换，资源地图 x=(F,W) 变为 gx=(g(F),g(W))，图片身份随资源移动、需求类别不变。行动分布的推前应为 `(g p)[j]=p[g⁻¹(j)]`，实现可用 `inverse_permutation` gather。直接用 g gather 通常是反向操作，不能用仅含自逆置换的测试验证。

每个分区 old18 对应 18 张有序地图。从 old18 × S6 中只保留 gx 也在 old18 的组合。任意给定源图 x 与目标图 y 都有 4!＝24 个满足 g(x)=y 的置换，因此合法三元组为18×18×24＝7,776。每张源图和目标图各出现432次。已用独立 NumPy 穷举验证三个分区均满足这些计数，并用非自逆六地点置换验证概率推前方向。

均匀抽取这7,776项，使 x 与 gx 的地图边际均匀，且二者在18×18图对上均匀；不是仅抽取 old18 支持的全局自同构。每对保留相同两张资源照片，这使对应学习不混入照片替换因素。所有 map ID、g、inverse g、照片行号及两侧私人目标规则均应明确保存。

`JSD(p(gx),g p(x))` 以两侧概率均值为中间分布，两个目标均参与，最后在512对×2目标上平均；两侧应同时接收梯度，不默认为教师端 stop-gradient。正确范围为[0,ln2]（nats）。均匀分布也能达到0，因此低JSD必须与行动准确率和预测熵一起读。稳定实现应从 log-softmax 和 logaddexp 求混合分布，不用先把极小概率截断来改变目标。

control 同样计算诊断 JSD，但其系数严格为0；equivariant 系数固定0.1。两臂初始可训练参数数量、样本、RNG身份、实际行动机会和更新次数相同，梯度与学习后的实际动作不必相同。增加JSD本来就会改变总梯度及裁剪触发，不能声称梯度预算或优化难度也被完全匹配。

## 预算与隔离

4个新种子31101–31104，三个分区、两个条件，共24个私人主体对准备和24个社会运行；统计独立单位仍为4个来源主体对。

- 每个私人主体各2,400次更新，每次512个成对场景＝1,024个实际单目标行动场景。两个场景的policy-gradient项按全部1,024次行动取均值，以reward−0.5为目标、不使用critic。熵前2,100步0.02，最后300步0；Adam lr0.0007，活动memory/slot_phi/head合并裁剪norm2。
- 全批私人阶段共58,982,400个场景对、117,964,800次实际单目标行动。监督JSD的两目标概率计算不能另计为额外实际行动。
- 社会阶段每主体对2,400×512次通信，全批29,491,200次通信、58,982,400次实际资源行动。两需求使用同一消息，接收两行动独立采样，无中间反馈；保持mixed回报0.5和原生/贪心口径。
- old18以外的added6与sealed6均不得进入私人准备或社会训练。最初project的200×64旧资源实践没有六地点地图支持；其来源与新种子仍需单独核查，不计成六地点泛化训练。
- 私人初末需保存完整agent、独立head及Adam。transfer应严格仅含准备后的memory/slot_phi，其他状态与私人初态逐位相同；社会阶段用独立固定初始化创建语言模块，再只复制允许模块。私人head、critic或优化器状态不能通过序列化或对象共享进入社会阶段。
- 社会project、input_transform、memory、slot_phi全部冻结，只有预定发收通信模块更新。两个条件在同一seed/partition的社会语言参数起点应逐位相同，不能受私人训练过程中全局Torch RNG消耗影响。私人和社会每步世界/RNG身份跨臂配对；实际策略产生不同消息或行动是干预结果。

## 预定能力指标与解释表

建议用预定测试照片前4×前4＝16对，在全部30图上保存私人头的两需求完整地点logits，共480个视觉上下文；只作评价，不改变训练、选择来源或调参。全部S6可由这些同照片政策表离线索引得到，无须额外模型训练。按源地图的old/added/sealed分组，另明确被比较的gx可以属于哪个支持；不能把“源在old”误写成“两侧均old”。

| 指标 | 作用和限制 |
| --- | --- |
| 私人贪心准确率、原生政策正确概率 | 分资源、分old/added/sealed；两者都报告，区分实际贪心表现与完整概率变化 |
| 政策JSD，按两目标平均 | 衡量同照片资源移动后的分布对应；联合报告两侧行动准确率，不将均匀政策视为能力成功 |
| 地点预测熵与贪心并列情况 | 识别低JSD是否主要来自不确定或退化输出；argmax对应会受并列规则影响 |
| 社会sealed自然N | 唯一主要能力迁移结果：逐符号贪心发信、贪心接收，同消息完成两个需求；仍没有新照片独立确认 |
| 社会共同30图发送信息参照 | 次结果，限定固定发送政策与共同支持；原生与逐符号贪心分别计算，子组oracle不拼成共同表 |

若JSD降低且old基本行动相近、社会sealed N也改善，可以支持这项空间对应准备在本任务中帮助后续自主表达；仍不能证明JSD是唯一中介或该能力对语言必要/充分。若私人行为改善而社会未改善，说明在当前接口和预算内的可迁移收益有限，不否定所有非语言能力作用。若两臂old行动能力明显不同，只能解释为综合准备效果，不能将社会差异全归因于等变性。若JSD降低但行动接近机会水平，应视为约束满足而非能力形成。

能力评价可在私有阶段结束时保存，但主运行器不得据added/sealed成绩筛来源、停止某臂、改预算或选择检查点。全部预定运行纳入四种子汇总，不因准备失败剔除。若事前另设工程完整性门槛，应只检测实现/数据合法性，不把测试成功率变成结果筛选条件。

## 独立审计待验收项

`audit_v13.py`将独立枚举合法三元组与边际、JSD推前方向和梯度、配对世界、原生两行动抽样、完整源权重、新种子准备、允许迁移字段与冻结范围。源码最终固定后，先用开发smoke检查首步参数/Adam及损失；正式后再核验所有预算、训练支持、checkpoint、保存政策、逐符号贪心与原生概率分离、四种子汇总。旧版本数据和冻结实现不变；通过审计不自动建立论文新颖性或接受门槛。
