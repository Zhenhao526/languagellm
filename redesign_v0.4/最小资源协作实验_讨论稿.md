# 最小资源协作实验：讨论稿 v0.4

2026-09-14。根据“完全不需要这么复杂，重新设计”的反馈，重新收缩第一步。下文保留当时的讨论稿。用户随后已授权按此思路尝试，实际实施选择官方视觉骨干加学习接口，并在训练前根据库存反例改为当轮资源即采即用。最新设置见[实施说明](./README.md)。

## 要回答的问题

先检验一个小问题：**两个具有预训练视觉表征、能通过后果学习的主体，在资源互补且各自信息不完整时，能否形成对彼此选择有实际作用的符号约定？**

这一轮检验一组能力的充分性实例。要判断哪项能力起作用，随后只改变一项能力；不能凭一个系统成功就列出语言产生的必要条件。

## 一个营地、两名采集者、两种资源

用回合制采集替代实时游戏操作。每次选择直接执行一次采集，产生实际的库存变化。环境保留资源后果、信息差和共同需求。

1. 两名主体维持同一营地，营地有食物和水两种储备。一个短回合序列中，储备持续消耗；缺少任一种就产生损失。
2. 每名主体每轮看到自己附近的两个可采集对象，以没有文字的照片呈现。可能是两份食物、食物与水、两份水。照片实例和左右位置变化。
3. 两人具有相同动作权限，各自选择一个对象采集。环境执行选择，将所得放入营地库存。主体不需要学习走路、转视角、开背包。
4. 选择之前，两人各有一次同时发信号的机会：四种离散符号或空白。收到伙伴的信号后再选择采集对象。符号没有预设词义。
5. 两人都能看到营地储备和自己的资源照片；看不到伙伴当前的资源照片。回报来自营地资源状况，不奖励说话、某个符号或固定职业。

例如，A 面前只有食物，B 面前有食物和水。如果 B 能根据 A 的信号选择水，这个信号就可能帮助避免共同缺水。接着要检查换照片、换供给情况后是否仍有效，不能从一个成功例子就解释出词义。

第一版让环境生成的资源机会足以支持补齐两种资源，以便把供给不足与协调失败分开。初始库存留有短暂缓冲，避免一次探索错误立即终止学习。营地回报和自动汇集资源是明确预设的合作条件，本轮不研究合作动机或分享行为如何产生。

同一个人可以在不同轮次获取不同资源；不指定“找水者”和“找食物者”。只有发现持续且可切换的专业化行为，才能讨论分工。这里的原始社会背景是机制抽象，不是历史复原。

## 主体边界必须说明白

现成自监督视觉模型可以提供已有视觉表征。候选是原始 **DINOv2 ViT-L/14** 视觉骨干，官方报告约 3 亿参数；不用分类标签头或 dino.txt 文本扩展。官方提供图像自监督预训练权重，但它输出视觉特征，本身没有采集策略或通信策略。[官方仓库](https://github.com/facebookresearch/dinov2)、[原论文](https://arxiv.org/abs/2304.07193)。

因此，两条路线有不同含义：

| 用户允许的范围 | 对应方案 |
| --- | --- |
| 允许现成视觉骨干加少量可学习接口 | 冻结官方视觉权重，分别学习选择与信号收发。实验对象准确称为“使用预训练视觉表征的学习主体”。 |
| 必须使用本来就能行动的完整预训练 agent | 不把 DINO 包装成完整 agent；继续从现成行动主体的原有动作与环境中收缩任务，重新核对迁移成本。 |

目前不把第一条当作已获接受的模型方案，也不据此启动实现。无论选哪条，双方都需要各自的学习状态；完全冻结又没有任何可保留学习机制，不能靠反复推理自动建立长期约定。

自监督视觉经历不等于理解饥饿、因果或伙伴意图，也不保证训练图像绝无文字。具体资源后果仍是本实验中新学的规则。

## 第一轮只比较两个条件

- **可以交流：**伙伴收到主体选出的离散符号。
- **没有有效消息内容：**相同任务、相同视觉输入和训练预算，接收端始终为空白。

先各做 3 次独立训练，只用于小规模可行性判断。照片特征可预先计算并缓存，以降低本地负担；这不改变主体各自的私人观察、状态和参数更新。用同一任务内的个体练习检查图像辨别和选择后果，不再建设独立的游戏能力验收系统。

通信仅传递离散编号，不传图片特征、梯度或隐藏状态。发送机会和动作执行时刻由环境固定，避免额外时间编码。共享营地库存是公开环境信息，会形成另外的行为线索；两组保持相同，评价显式消息带来的额外作用。

只记录三类结果：

1. **协调收益：**资源短缺是否减少，是否超过无有效消息条件。
2. **形成过程：**在固定训练检查点保存策略，观察消息与资源机会的关系以及接收行为怎样变化。
3. **消息的实际作用：**在相同状态下替换消息，是否系统地改变伙伴选择；在未见过的照片实例上是否仍成立。

消息打乱造成收益下降只是一部分证据，还要检查选择变化是否符合该消息在独立样本中的用途。分别检查两个交流方向；双方能互相配合，不自动意味着双方使用相同词义。第一轮不预设“达到某个成功率就是语言诞生”。

## 有效后只增加一个变化

环境实验优先改变**资源互补程度**：食物和水必须搭配，或二者可以相互替代。保持资源机会、总资源量、动作预算和信息条件一致，并校准回报尺度。检验更强互补是否改变约定建立的速度、稳定性和用途；任意资源都能完成任务的条件可能接近满分，应报告这种上限，而不是把它解释为“缺少交流能力”。

能力实验随后单独改变一项，例如可访问的私人经历长度，同时复测无通信时的资源选择能力。要识别视觉预训练本身的贡献，需要另设视觉表征对照并检查基本辨别差异；这一轮不能完成该归因。

从这里逐步发展论文问题：**同样的非语言主体，在何种资源与信息条件下形成何种约定，以及改变一项能力后，形成轨迹如何改变。**使用预训练视觉特征和奖励学习研究通信已有先例，本轮任务本身尚不能当作创新结论。[Lazaridou 等，Multi-Agent Cooperation and the Emergence of (Natural) Language](https://arxiv.org/abs/1612.07182)。
