## 共用环境与此前curriculum_001课程批次设置

- **视觉模型：**官方 DINOv2 ViT-L/14，原始视觉骨干，冻结全部权重。图像特征预先计算；主体仅接收自己看到的两张照片的特征。
- **学习接口：**每人独立的视觉投影、信号选择、行动选择及价值基线。接口从随机初始化学习，主体之间不共享可更新参数、梯度或隐藏状态。
- **资源：**食物与水，各需一份。每天同时采集，再消耗；余量不能留到次日。两人各看到两个本地对象，选择其中之一；当天同时取得两种资源得 1，否则得 0。
- **消息：**五个离散编号 0–4，每人每天先发送一次，接收后采集。编号没有预设词义，不采用文本 tokenizer。0 在通信训练中也可学到用途，不能视为天然中性的空白。
- **观察：**私人照片特征、公开库存和剩余天数，以及收到的离散编号。原图名称、类别 ID 和伙伴图片不进入策略。当前即时消耗条件下，每天起始库存都是零。
- **条件：**不加／加入基于自身消息概率的发信辅助，两组均可交流。三个配对种子 101、202、303；同种子两组使用相同个体练习结束权重、资源照片随机流和预算，各自重新学习。
- **预算：**复用个体资源后果练习每人 200×64 次选择后的权重；该批社会阶段每组 1,200×1,024 次双人互动。前 600 次使用一方受限的课程，601–900 次回到完整场景并渐撤发信辅助，901–1200 次只按资源回报学习。CPU 训练接口，复用此前 MPS 计算的视觉特征。
- **优化：**各自使用 REINFORCE 与私人价值基线。即时环境无跨轮行动效应，gamma=0；无词义或正确动作标签监督。两组前 900 次都有相同行动熵奖励；仅辅助组添加发信项，该项也更新本人的共用视觉投影。最后 300 次两项系数均为零。
- **评估：**按原始图片划分训练／测试；保存 12 个预定检查点，包含早期 20、50 次更新。最终每组在课程及完整任务各 8,192 次新组合上评估，报告消息重排、固定符号 0、随机策略采样及同观察消息替换。三个训练种子是重复单位。

## 为什么去掉跨日库存

原讨论稿的容量 4、初始各存 2 份规则，允许无消息主体“优先补较少资源”而永久满分。这个机制已通过有限状态穷举和独立模拟确认，详见[库存反例核查](./库存反例核查.json)。第一轮改为当日资源必须当日配齐，从而留下真实的协调收益空间；这项修改发生在模型训练之前。

在当前14种等概率、独立生成的资源机会中，单对随机选择的期望成功率为4/7，理想无当前消息策略的期望上界为5/7，全信息策略可达1。课程8场景中的无消息上界为1/2。有限测试样本可能略偏离这些期望。共有时钟或固定身份不会突破该单对无消息上界，因为资源机会逐日独立。最新形成确认已新增同课程、同预算、从第一步始终接收0的训练对照，其原生最大概率和概率采样评估都保持0；资源可替代条件单列原生恒满分与互补任务诊断。

该任务预设共同回报、自动汇集资源和通信通道。它检验在这些条件下形成的约定，不代表合作动机、分工制度、完整语言或人类语言历史起源已被重建。照片数据规模小，泛化仅限未用于接口训练的照片实例；不能保证这些照片不在 DINO 的预训练数据中。
