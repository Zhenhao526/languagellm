# 发送与接收可塑性实验：复现说明

该实验从固定伙伴形成的已有约定开始，允许伙伴轮换，比较发送函数与条件行动函数的可塑性。核心四条件均固定共享视觉投影；价值基线可以学习。`all_plastic` 额外允许视觉投影学习，作为单独参照。

| 条件 | 可学习模块 | 可变行为参数/主体 | 含价值基线的可训练参数/主体 |
|---|---|---:|---:|
| `behavior_frozen` | value | 0 | 4,417 |
| `sender_only` | sender、value | 4,677 | 9,094 |
| `listener_only` | actor、value | 8,833 | 13,250 |
| `both_learn` | sender、actor、value | 13,510 | 17,927 |
| `all_plastic` | project、sender、actor、value | 79,110 | 83,527 |

固定模块使用 `requires_grad=False`，每检查点核对权重逐位不变；固定发送函数和接收函数还核对全部概率漂移为零。冻结接收函数指在相同私人照片、公开时钟和收到编号下，条件行动概率保持不变。实际行动仍可能随收到的编号改变。行为固定组仍抽样行动，并更新不会改变策略的私人价值基线。

## 批次与固定预算

探索来源为 `partners_001` 的固定群体101、202、303。确认来源为新群体404、505、606、707、808、909、1001；各群体四个主体全部重新初始化。种子不按结果筛选。新来源先执行原来的200×64次个体资源正控，再执行固定伙伴的600次课程、300次完整任务含行动熵奖励、300次完整任务纯回报训练。

机制阶段每条件600次更新，每次四个主体各1,024次选择，学习率0.0003；全程完整资源任务，发信辅助和额外行动熵奖励均为零，继续按学到的概率抽样。每三次更新恰好完成三种完美匹配，每条边新增200次更新。所有条件共享私人输入、伙伴日程、世界、布局和各主体策略随机流。

四条件×十群体共40个新运行；七个新群体另做 `all_plastic`，合计47个机制运行。三个探索群体的全可变参照复用 `contact_001` 的FR结果，小步同流测试已验证新实现与原实现的参数、训练指标和NumPy随机状态逐位一致。七个新来源另计七个运行。

## 运行

以下命令在项目根目录运行。训练仅使用已有本地照片特征，旧实验目录保持保留。正式输出目录必须不存在；脚本拒绝覆盖已有批次。

```sh
redesign_v0.3/deployment/.venv/bin/python -m unittest discover -s redesign_v0.4 -v
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/run_mechanism.py origins
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/run_mechanism.py mechanism
```

只读分析与核查：

```sh
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/audit_mechanism_origins.py
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/audit_mechanism_execution.py
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/audit_mechanism_communication.py
redesign_v0.3/deployment/.venv/bin/python redesign_v0.4/audit_mechanism_bounds.py
.venv/bin/python redesign_v0.4/analyze_mechanism.py
```

源代码、模型起点、图片清单与特征、训练日志、检查点、终点轨迹、冻结标志、Adam和随机状态均保存。最终Adam只为实际参与梯度更新的参数保存状态；冻结参数应无梯度和Adam动量。`state_dict` 本身不保存冻结标志，恢复时必须先依据保存的 `trainability` 重建参数组；`restore_state` 返回模型、优化器、NumPy随机流以及包含Torch随机状态的原始保存对象。

## 统计与上界

主分析仅七个新群体，原三个探索群体和合并十个群体单独列示。群体是重复单位；bootstrap使用10,000次群体重抽样和固定种子6000914。同一个群体的条件差先配对计算，再重抽样。区间用于描述变异，不据此宣称一般语言机制或多重检验后的显著性。

固定函数上界枚举现有测试集每类八张图片的全部有放回有序图对与16个公开时钟，正常策略和按概率采样分别计算。单方受限的八种场景中，固定sender使用混合允许伙伴后的最优资源分类上界；固定actor使用对允许伙伴平均效果最好的输入编号。其余六种场景乐观计为全部成功。因此完整任务上界为 `3/7 + (4/7) × 单方受限上界`。

上界是有限图片分布下的期望值，不是随机抽取4,096个案例所得分数逐次都不能超过的边界。真实资源类别只供离线计算上界，未传入主体或训练。上界也不保证当前网络架构和600次预算能够达到。单侧条件表现差，可能包含冻结协议的信息冲突或行动兼容性限制，不能直接推断一般性的学习能力缺失。
