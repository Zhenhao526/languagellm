# 接收通路阳性对照

原 ResourceAgent 的接收与选择通路可以学习根据离散消息改变资源选择。此处人工规定符号含义，只用于定位流程问题，不是语言涌现结果。

## 固定配置

- 保留原 `ResourceAgent` 结构与 `act()` 通路，使用原冻结 DINOv2-L 的照片特征缓存、原训练集归一化及原训练/持出划分。
- 接收者每次看到一张食物照片和一张水照片，左右随机；公开库存固定 `[0,0]`，剩余回合随机取 1–16 后除以 16。
- 目标食物/水在每个 batch 中各占一半；人为规定消息 1 表示取食物、消息 2 表示取水。这是明确可解的人工词典。
- 只根据选择后是否满足目标给予 0/1 标量后果，用原 `draw()`、REINFORCE、固定基线 0.5、熵系数 0.01、梯度裁剪 2 更新。
- 种子 101/202/303，初始化分别为原 `prepared_s{seed}.pt` 中的主体 0 和同种子的随机接口；学习率为 1e-3 或 3e-4，共 12 组。
- 每组预先固定 500 次更新、每次 128 个场景。配置先落盘再执行，没有按成功延长训练或搜索种子。
- 每组在原持出照片上采样 4096 个场景评估，每 100 次更新记录一次。持出集仅评分，没有用于梯度更新。

## 结果

| 指标 | 12 组结果范围 |
|---|---:|
| 贪心选择目标资源的准确率 | 100% |
| 同一照片与公开状态下，仅交换消息 1/2 后的资源选择翻转率 | 100% |
| 交换消息后仍取原目标的比例 | 0% |
| 将消息替换为 0 后取原目标的比例 | 48.68%–50.88% |
| 原目标动作的平均概率 | 82.72%–99.17% |
| 消息替换导致的动作分布平均总变差 | 0.655–0.983 |

全部组在第 100–300 次更新的已记录检查点达到至少 90% 持出准确率。因为主对照已经成功，没有启动预先限定的备选交叉熵容量对照。12 组训练循环与评估合计约 4.90 秒，不包括解释器启动与特征加载。

## 能排除和不能排除的解释

这一结果排除了“原结构无论如何也无法让消息改变选择”这一解释；也证明原照片特征、消息 one-hot 输入、动作采样、梯度及持出评估能在这个接收问题上联通。

原 actor 对两个候选使用共享评分网络，消息先作为共同上下文进入 tanh 隐层，只有非线性交互才能让消息改变候选排序。这不是严格的表达能力障碍，但仍可能影响两个未约定主体一起学习时的优化难度。

本对照没有学习发送者，也没有复现原双主体联合信用分配。人工消息已经携带正确目标，故其成功不能证明主体会自己发明约定，不能并入 pilot_001 的主实验成功率。
