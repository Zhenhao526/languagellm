# v0.18 固定政策梯度诊断：独立前置审查

2026年9月16日，开发计时及正式诊断之前。此轮不训练政策、不新增数据，不修改v0.17已固定的主比较或既有源文件。科学动机来自已经完成的基线置换实验：其主终点未显示一致损伤，因此直接检验一个范围更窄的方差解释。

## 固定对象与测量量

读取v0.15 reset_scaled的四来源31101–31104、三个分区、两个人及检查点0、100、600，共72个人政策检查点。每人固定本分区old18地图，各配最小训练food特征行与最小训练water特征行。只枚举这18个世界、49个完整消息及固定伙伴的接收行动分布；不读取added/sealed标签选择输入，不换照片或挑来源。18个世界是本诊断支持，不是原每人256世界训练批次的重放或完整训练照片分布。独立统计单位仍为四个继承来源。

完整消息score对应原发送策略的9个参数张量：send_context的Linear权重/偏置、send_embedding、send_recur的四个GRU张量、send_out权重/偏置，共43,319个标量。send_value、接收模块及冻结视觉上游均不属score；原visual_scale只改变固定输入，不变成可训练坐标。必须从实际加载模型的命名参数核实该清单，不按宽泛send_前缀误纳独立价值网络。

当前确定的数值定义是：保持原float32参数及模块前向；第一符号与七个前缀的后继各用batch1，logits转float64后做log_softmax并相加，得到同一解析π下完整logjoint的梯度，梯度仍落在原float32参数坐标，矩用float64累加。这不是原训练float32 log_softmax梯度的逐位复制，也不是PRNG浮点分箱概率的精确重建。须保存概率/score零均值残差及dtype，按明示容差核验；不得把不同数学政策或求和精度混用。

## 核心等式及必要条件

令两目标正确概率为pF、pW，给定完整消息及固定世界后，两次接收抽样独立且无反馈。奖励R=.25(F+W)+.5FW，T=R−1，因此T为−1、−.75或0：

- E[T|x,m]=.25(pF+pW)+.5pF pW−1。
- E[T²|x,m]=1−(7/16)(pF+pW)−(1/8)pF pW。

独立审计应再枚举6×6接收动作核验上述一、二阶矩，不能只重用生产公式或以E[T]²替代E[T²]。菜单使用空间坐标的映射须明确；接收目标、库存与历史固定为原合法上下文，不能把食物/水查询顺序当作额外消息。

完整score是两符号logprob梯度之和，必须在相同参数坐标上先相加、再求范数平方。共享send_out、context及GRU路径产生的交叉项不能删除，也不能假设两个token的梯度正交。

对每世界定义A=E||z||²、B=E[T||z||²]、C=E[T²||z||²]和μ=E[Tz]。原基线b只由该世界和固定政策确定，不依赖本次消息/动作。解析E[z]=0，所以平均reward-score梯度不随b变化。原生消息分布须使用全部49码；argmax消息或贪心接收不能替代。

固定世界列表长度n=18时：

Vmatch=Σ(C−2bB+b²A−||μ||²)/n²。

均匀排列期望为Vperm=Σ(C−2 mean(b)B+mean(b²)A−||μ||²)/n²。排列不放回并不要求各个b独立；各世界score均值为零、且各世界的条件平均梯度不随排列改变，使跨世界协方差项抵消。应在小型合成分布中完整枚举排列和消息/接收结果验证，不能把一张打乱后的表当作均匀排列的解析期望。

b*=B/A仅在A>0时定义。须记录A=0或近退化项，验证最优参照不高于给定b，以及超额方差ΣA(b−b*)²/n²。T∈[−1,0]使非退化b*落在该范围，不能把普通E[T]当成方差最优基线。不得用钳位隐藏明显负方差、score残差或除零错误。

上述量是未乘角色权重的reward-score批均值梯度协方差迹。实际发送角色在总损失中乘1/2，所以该项的方差再乘1/4；损失的负号不改变方差。报告应同时写清所用尺度，不把n²遗漏、改成n，或将18世界结果按256例训练曲线作未经定义的换算。

## 独立审计的实现路线

审计器仅新建于本目录，不调用被审`gradient_moments.measure_world`或`aggregate_support`来证明其正确性。旧模型加载和已有来源核查工具可以复用，但实际score与矩必须另行构造。

1. **来源与支持。** 核对v0.15原检查点、prepared及旧图像特征/manifest、校准标量与完成清单的SHA；参数只读、无optimizer、无权重回灌。独立枚举old18和训练照片最小行，记录真正消费的行ID与SHA，不声称新照片或新独立模型。
2. **前向。** 独立按Linear、Tanh、embedding及GRU门公式重建发送logjoint；GRU候选门必须保持PyTorch的reset作用位置与两组bias语义。用同一原权重的float64算术作为核验参考，不把该参考当成实际测量模型。接收侧独立按actor两需求分支恢复6动作概率，遍历36对动作求ET/ET²。
3. **score。** 开发源99513固定小样本上，对独立手写网络使用Jacobian，并用预定参数坐标的中心有限差分交叉检查；比较生产样本完整score向量，除整体误差外覆盖所有9张量。验证两token之和、共享参数交叉项、非policy参数未进入score和未被更新。不能只比较某一层或重新调用同一个生产导数函数。
4. **数学。** 合成小支持完整枚举消息、两行动和全部排列；核对平均梯度、二阶矩、batch协方差迹、1/n²和角色1/4。涵盖无信息、确定接收、非均匀消息、非恒定基线和A=0退化，不将可疑负值默默截断。
5. **正式数据。** 在全部预定政策诊断完成后，一次检查72份结果及1296世界的来源、参数清单、概率、ET/ET²、A/B/C/μ范数、零score均值残差与聚合公式。正式不保存全部大梯度矩阵时，核对事先约定的score样本；保留所验证的明确范围，不声称逐元素重算全部63,504个消息梯度。
6. **开发预算。** 开发只用于测时、内存、数学和实现验证，不按正式效应裁减检查点或换来源。容差应由定义和数值精度设定并在正式前固定；发现错误保留原代码和失败记录，修正后重新验证。计时前不承诺运行分钟数。成功gate及其审计源须可按SHA恢复。

## 解释边界

这只测同一固定双方政策、同一18世界列表上的消息/接收行动随机性，不含世界/照片抽样、价值回归、采样熵项及其交叉协方差、裁剪或Adam。后继符号熵依赖已采样前缀，其梯度不必是常数；主动排除它是测量定义，不是证明训练中无作用。

欧氏参数梯度方差依赖参数化。本轮同一政策/同一坐标内的matched与解析perm比较有定义；不能跨倍率、不同编码器或不同终点政策直接称内在语言性变化。局部方差下降不等于sealed收益的因果中介；没有下降也只限制预定政策、时点和小支持上的解释。经典最优基线和控制变量等式不是新的语言起源理论，完整审计不替代新颖性、独立数据确认或任务适用范围证据。
