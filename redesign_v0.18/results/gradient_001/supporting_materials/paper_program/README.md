此前v0.17完成12个发送基线批内置换新运行，复用12个matched参考。sealed自然N为匹配13.63%、置换14.39%；唯一主差matched−shuffled为−0.76个百分点，四来源−5.92/+13.59/+3.66/−14.38个百分点，两正两负。sealed AUC差+0.19个百分点也无一致方向；old匹配92.44%、置换93.50%。置换改变99.60%的基线值，合并RMS0.236367；两臂全程无非单位裁剪。本批未支持对应关系带来稳定收益，也不证明等效或全局基线机制。778,759项执行核验、23,424个原始标量、34,824项统计及2,278项诊断比较通过。见[完整报告](../redesign_v0.17/results/baseline_001/发送基线与场景对应关系的通信形成研究报告.md)、[复现索引](../redesign_v0.17/README.md)。该后续固定策略方差诊断现已在v0.18完成；本批主比较保持不变。
