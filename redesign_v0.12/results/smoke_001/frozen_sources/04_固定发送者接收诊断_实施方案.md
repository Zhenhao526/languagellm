# 固定发送者的接收诊断：实施方案 v1

2026-09-15。**这是可供下一轮实现的规格，尚未运行，不是 Rita 等论文的已完成复现。** 方法根据正式论文及当前任务接口确定，不依赖 v0.11 成绩选择来源、目标或超参数。执行前须统一冻结实现、照片 ID、来源权重、种子与评价清单。

## 目的与最近邻依据

给定已经形成的视觉发送者，检验：消息本身还留下多少地图歧义；当前接收者在自己的任务目标下距最佳完整码决策多远；直接获得监督标签的新／旧接收者能利用多少已有信息。**重新训练一个接收者不是创新本身，监督探针成功也不是主体自行创造了更好的语言。**

| 正式论文方法 | 本任务的对应与差别 |
|---|---|
| §2.1，PDF第3页：发送者按政策采样消息；接收者以原对象为目标做监督重建 | 保留冻结发送者的原生随机消息。接收者的监督目标改为食物、水的两个地点；这是明确增加的任务真值监督 |
| §2.2–2.3，第3–4页：最优后验、信息项与共适应项的分解 | 本任务仅49完整码，可以按固定照片分布枚举消息概率；必须处理两分支接收器的因子化限制，不能直接把其 NLL 等同完整地图条件熵 |
| §3.1、图1及脚注2，第5页：冻结原发收主体，另训新接收探针；训练分布与全分布的探针不同 | 同时保留只看旧+加入24图的接收探针，以及看全30图的特权信息诊断。后者明确失去“封存图未训练”的资格 |
| §3.3，第6页与 §4.2，第7页：接收学习程度、开发选择和探针泛化 | 本批固定相同预算，记录开发 NLL 选择的补充结果；未达到解析参考时只报告“预算内未达”，不能自行延长到得到阳性 |

## 来源、冻结范围与最小矩阵

固定来源为 v0.10 全部形成终点：`redesign_v0.10/results/generalization_001/s{29101,29102,29103,29104}_p{1,2,3}_base/final.pt`。每个来源分别诊断两个方向，共24个固定发送函数。所有来源都纳入，不按基线高低筛选。4个主体对才是外层独立单位，三个分区和两个方向是其内部重复。

每个方向新跑以下四项，共 **96个单方向接收拟合**；可将同源两个方向合并为一个作业，但统计口径不变。

| 条件 ID | 接收起点 | 拟合地图支持 | 实际学习信息 | 作用 |
|---|---|---|---|---|
| `warm_rl24` | 原接收者 | 旧18+加入6，均匀24图 | 实际采样行动后的 λ=.5 标量收益，独立策略梯度 | 本任务匹配的奖励控制，必须新跑 |
| `warm_ce24` | 同一个原接收者 | 同24图 | 每条消息对应的正确食物地点与水地点，直接 CE | 控制接收起点，测量增加监督后的解码改进 |
| `fresh_ce24` | 同架构新初始化 | 同24图 | 同上 | 排除继承旧接收初始化对监督拟合的影响 |
| `fresh_ce30` | 与 `fresh_ce24` 完全相同的新初始化 | 全30图 | 包括原封存6图的正确地点标签 | 全地图支持的信息探针，仅作特权诊断 |

另外只读评价原接收者 `R₀`，无需训练。不能直接用旧 v0.10 `expand_receiver` 充当 `warm_rl24`：本方案改变了接收拟合的照片划分、预算、单角色损失归一化与评价方法，必须有真正匹配的重新运行。

保留原冻结 DINO、旧训练归一化、私人 `project`、`input_transform`、`slot_phi`、`memory`、`send_context`、`send_embedding`、`send_recur`、`send_out`，以及所有其他发送状态；不更新发送价值头。固定发送不只是冻结最后一个输出层。拟合前后对完整发送路径的参数、buffer、规定输入上的首符号／条件第二符号 logits 和逐位置贪心消息逐项核验。

监督条件仅更新原架构 `receive_embedding` 与 `actor`，两需求分支、6地点动作及历史维度不改。新初始化只重置这些接收模块，不动视觉／发送路径。监督条件的接收 critic 不参与目标；奖励条件另拟合原有 `receive_value`。比较的是相同的行为策略架构，但训练信号和辅助 critic 的用途不同，不能宣称所有损失或训练参数数量完全相同。

所有新接收器都只看到两位整数消息、自身需求、零库存和18维零历史。它们不接收照片、文件名、地图ID或类名作为推理输入。CE 的正确地点通过**训练标签**进入损失，必须在主文写明这一额外监督。

## 照片与地图支持的固定划分

使用旧数据做方法诊断，不占用正在准备的新 Commons 确认材料。按正式 [旧 manifest](../../redesign_v0.4/data/manifest.json)中的资源类别分别处理22张原训练图：以 `SHA256('receiver-baseline|2026-09-15|photo-split|' + image_sha256)` 升序，前16张为 `probe_fit`、后6张为 `probe_dev`。原测试8张为 `probe_evaluation`，三者图片ID互斥。

- 拟合照片：16食物×16水，共256对；24图条件共6,144视觉上下文，全30图条件7,680。
- 开发照片：6×6，共36对；相应地图支持为864或1,080上下文。
- 评价照片：8×8，共64对；全30图每方向1,920上下文，旧／加入／封存分别1,152／384／384。所有条件共用。

不使用跨 fit/dev 的混合照片对。发送者在原形成期已经见过这22张图，因此此划分只是**接收探针拟合标签与开发选择**的分离，不是发送者的全新视觉留出。原测试照片也已经用于多个旧实验，最终结果仍属于开发证据，不能称为新的独立照片确认。

`fresh_ce30` 的开发选择可以用其全30图开发照片；其他三条件的开发选择只用24图，不使用封存图标签。所有条件的全30图评价在权重和选择规则锁定后完成。封存一词对前三条件仍表示该接收拟合未训练；对 `fresh_ce30` 必须改标“已监督暴露”。

## 原生采样与贪心政策不得合并

**主拟合统一采用冻结发送者的原生随机政策 π。** 每个训练世界只采样一次两符号自回归消息，同一条消息用于两个需求；第二符号按实际第一符号条件分布抽样。原生采样使用实际发送实现及独立 RNG，发送端不接收梯度。不用消息联合概率 argmax，也不把每图最常见消息作为训练样本替代。

三项24图条件共用世界／照片／实际发信序列；只有奖励条件另采样接收行动。消息 RNG 与接收行动 RNG 分开，避免某条件的额外抽样改变后续世界。全30图条件由于训练支持不同，仅配对初始化与预算，不能声称训练世界完全一样。

评价分别保存：

1. **π发送、随机接收**：49码解析求和得到 J 的期望 Q、单目标成功及混合收益。
2. **π发送、贪心接收**：仍对发送分布求和，接收各需求取自己的最大概率地点。
3. **逐符号贪心发送、贪心接收**：与旧 N/J 的功能口径相接，但本批评价照片是64对，不能直接减去旧16对探针数值。

原生消息概率由原生 float32 logits 以 float64 稳定 softmax 构成数学分类政策，解析评价不是有限 PRNG 分箱的逐比特重现。原有 v0.9/v0.10 DP 自然码上界只适用于对应固定**贪心**消息与照片分布，绝不是原生随机训练的上界。若将来要比较贪心发信拟合，必须另列新条件，不能静默替换主采样政策。

## 三种不同目标各用自己的解析参照

记地图目标 `Y=(F,W)`，照片为 `I`，接收器不观察 `I`。在预定支持与照片分布下，将冻结发送概率汇总为 `c(m,f,w)=P(M=m,F=f,W=w)`；其边缘为 `c_F(m,f)`、`c_W(m,w)`。这里只要求传递资源地点，不要求编码照片ID；不能把照片外观熵错误地算作任务信息损失。

### A. 分支 CE／NLL

报告每世界两分支 NLL 之和：

`L_branch = E[-log r_F(F|M) - log r_W(W|M)]`。

其无限制边缘拟合下界为 `H(F|M)+H(W|M)`，不是一般情况下的 `H(F,W|M)`。两者差为 `I(F;W|M)`。严格地：

`L_branch = H(F,W|M) + I(F;W|M) + E_M[KL(p_F||r_F)+KL(p_W||r_W)]`。

因此，训练 NLL 相对分支熵下界的剩余项反映接收边缘拟合差距；它仍可能包含神经函数类限制和有限预算优化问题。评价照片上的剩余项还包含消息分布迁移。不能把它相对完整地图熵的全部差都命名为共适应或优化失败。

### B. 双目标准确率

最佳完整码 MAP 决策为每码选择 `argmax_(a,b) p(F=a,W=b|m)`，其准确率上界为：

`C_joint = Σ_m max_(a,b) c(m,a,b)`。

分支 CE 的两项边缘最大值不一定构成联合 MAP。即使 CE 完全拟合边缘，贪心双目标准确率也可能低于此界。必须计算“精确 CE 最优边缘所产生的贪心 J”作为另一个目标参照，不能要求 CE 必然达到 `C_joint`。

### C. 本项目 λ=.5 混合收益

给定消息 m，行动对 `(a,b)` 的期望收益为：

`u(a,b|m)=0.25[p(F=a|m)+p(W=b|m)]+0.5p(F=a,W=b|m)`。

最佳混合收益决策按此式取最大值，整体参考为 `Σ_m max_(a,b){0.25[c_F(m,a)+c_W(m,b)]+0.5c(m,a,b)}`。必须枚举 **36个行动对**，包括 `a=b`；虽然真实地图只有30种不同地点的组合，主体合法行动并没有禁止两需求选同一地点。

混合收益最佳、联合 MAP 最佳和分支 CE 最佳可以不同。奖励法主要距它自己的混合收益参考有多远，而不是被要求优化 CE 或联合准确率。监督法的额外标签和不同目标都可能改变 J；任何单一参照的差不能统称“优化失败”。

上述参照分别按原生 π 与贪心消息重算；按旧／加入／封存单独最优的决策也可以不同，不能将三个独立分组的最优值同时当作一张可部署接收表。另给拟合支持的共同最优表和全30图共同表，但后者只作分析者参照。所有表使用真值标签，是诊断 oracle，不回灌主体。

## 固定预算、种子与选择规则

- 每拟合运行2,400次更新，每次512个世界；保留第0、100、300、600、1,200、1,800、2,400次权重与曲线。原生消息和接收动作采样分别记流种子。
- Adam 学习率 `7e-4`、默认 β、无权重衰减、梯度范数裁剪2，四条件固定。它们是本任务的预设预算，不声称等于原论文所有超参数。
- 奖励条件继承 λ=.5、接收两行动 log-prob **求和**的策略梯度及 critic 目标 `R−1`；作为独立接收诊断，不能再混入一个冻结发送损失后取双角色均值。接收熵系数前2,100次为 `.02`，后300次为0。监督条件直接最小化两需求 CE 之和，不加入奖励、消息模仿或 critic 梯度。
- 每个来源／分区／方向一个固定新接收初始化，不筛选最佳随机重启。`fresh_ce24` 与 `fresh_ce30` 共用其初始化。派生 seed 为 SHA256 字符串 `receiver-baseline|2026-09-15|source_seed|partition|direction|stream_kind|step` 的前8字节大端整数；消息流不包含24图条件ID以实现配对，接收行动另命名。正式 config 保存完整字符串与数值。
- **主要报告固定2,400次终点，600次用于短预算比较。** 监督条件额外报告最低开发 NLL 的已保存检查点，平局取最早；不使用评价照片或封存图选择24图条件。它是 Rita-inspired 开发选择补充，不替代固定预算主表。全部运行仍完成相同更新预算，不能选到好结果即停止。
- 相对解析分支训练下界的残差≤`1e-3` nats/世界可标为接近该参照；只出现训练曲线平稳但残差较大，标记“预算内平台期”，不叫已收敛到信息极限。该阈值是诊断精度，不是低分时追加训练的开关。

## 主要比较、反证与证据边界

主表按四个来源主体对汇总，每种子内平均三个分区和两个方向；保留四个配对差与全部失败。96个拟合不是96个独立形成实验。

1. `warm_ce24 − warm_rl24`：同消息、同接收起点下，加入地点监督并改变损失后能获得多少额外解码表现。同时报告 J、混合收益和分支 NLL，不把全部改进归因于训练时长或 REINFORCE 的单一缺点。
2. `fresh_ce24 − warm_ce24`：在相同监督下，旧初始化是帮助还是妨碍。若差异小，不支持“旧接收初始化本身形成明显优化障碍”。
3. `fresh_ce30` 相对各自训练解析参考：检查完整地图标签支持下的函数拟合能力。若仍未接近分支下界，不能把这个有限探针当作最优接收者，也不能把剩余误差全部归给发送信息。
4. `fresh_ce24` 的封存表现与其在已训练加入图的表现分列。若只有全30监督探针改善封存，则证明额外解码教学能利用信息，不是未见组合泛化。

所有条件同时给旧图变化；新图单独可区分并不保证维持旧约定时能实现。旧兼容性前沿仍是单独分析，不能由一个不受旧约束的 CE30 高分替代。[旧约束诊断](../../redesign_v0.10/results/generalization_001/compatibility_exploratory_002/兼容性诊断.md)

若相应信息上界已经低，说明固定消息在该分布上有任务歧义；若上界高、监督拟合也达到相应目标而原奖励接收者差，则支持“当前接收学习仍有可利用空间”，但该空间借助了额外监督。若监督探针未达其参照，则保留“函数类／优化／照片分布迁移尚不能区分”，不因结果不理想改方法。

## 实现与验收清单

建议输出 `config.json`（来源与照片哈希、支持、监督类型、目标、全部RNG）、`training.jsonl`、`curve.json`、`final.pt`、固定评价表与 `diagnostic_summary.json`。冻结原发送者的完整概率表、两分支接收 logits、每行地图／照片 ID 和对应权重，足以用 NumPy 独立重算三个目标及原生／贪心参照。

正式拟合前用人工构造的小计数表核对：概率和、零概率项、原生与贪心分离；分支熵下界及 KL 恒等式；边缘最大、联合 MAP、混合收益最优不必相同；36行动对枚举；旧／加入／封存及 fit/dev/evaluation 零交叉；两需求同消息且无中间反馈；发送路径哈希不变；消息世界流跨24图条件完全一致。

一个固定校准例是常量消息、全30地图均匀先验：完整地图熵为 `ln(30)`，分支熵之和为 `ln(36)`，最佳联合准确率为 `1/30`，最佳混合收益为 `1/10`。这与均匀独立随机动作的联合成功 `1/36`、混合收益 `7/72` 不同；实现不得共用一条所谓“机会水平”。

不向原社会主体回灌任何探针权重、MAP表、最佳混合收益动作或正确消息标签。监督探针不是新人通过互动自然习得的主体，也不代表人类语言能力。主文名称使用“Rita-inspired 固定发送者接收诊断”，并明确本项目与正式论文的监督、架构、对象分布及预算差别。
