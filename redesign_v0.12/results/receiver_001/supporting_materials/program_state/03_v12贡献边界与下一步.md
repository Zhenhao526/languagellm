# v0.12 对论文主张的影响与下一步

2026-09-15。独立只读审查：核对 v0.12 已保存汇总、分析稿、正式审计状态，以及本地 Rita 2022 全文和最近邻审查；本次未运行模型、未修改训练或旧报告。下述实验是**候选方案，尚未冻结或执行**。

**v0.12 排除了一个有吸引力但不成立的主叙事：固定发送者之后，当前奖励接收者并不存在由大 NLL 缺口证明的巨大任务收益优化空间。下一步应直接操纵一种可测量的非语言能力，观察它是否改变发送约定的可扩展性。继续增加接收训练、重置或变换解码目标，优先级低于这个问题。**

## 一、实际证据支持什么

数值取自 [独立直接重算](../redesign_v0.12/results/receiver_001/independent_summary.json) 的 `means[arm].evaluation[group]`、`differences`，并与[正式分析](../redesign_v0.12/results/receiver_001/receiver_analysis.json)和[分析稿](../redesign_v0.12/results/receiver_001/接收诊断分析草稿.md)交叉核对。96 次拟合均完成；四个继承主体对是统计单位，三分区、两方向在种子内平均。以下为 2400 步、8×8 评价照片对；这些照片是已使用过的开发资料。

Q 是原生随机发送 π 和随机接收的双目标成功期望；G 是 π 发送加贪心接收；N 是逐符号贪心发送加贪心接收。三者不能混称同一成功率。

| 同一共同24图支持 | Warm RL24 | Warm CE24 | Fresh CE24 |
|---|---:|---:|---:|
| Q | 72.0425% | 67.1886% | 67.1362% |
| G | 72.0682% | 72.6486% | 72.6199% |
| N | 72.0595% | 73.0740% | 73.0333% |
| π 随机混合收益 | 0.784058 | 0.744943 | 0.744558 |
| 两分支 NLL，nats/世界 | 3.817449 | 0.651617 | 0.644196 |

在相同评价分布、相同 π 下，共同24图联合 MAP 参照为 **73.2591%**，混合收益参照为 **0.792825**。Warm RL 的两个差距分别为 **1.2165 个百分点**和 **0.008767 收益单位**。这是有限、任务特定的接近，不是所有来源都已达到最优，也不是训练已被证明完全收敛。它足以否定“观察到很大 CE 残差，所以原奖励任务还有很大可利用收益空间”的推断。

Warm CE 相对 Warm RL 的 Q 差在四种子依次为 **−5.4695、−5.6496、−3.8245、−4.4721 个百分点**。NLL 改善和随机执行收益改善不是同一件事；CE 拟合较软的条件边缘，而奖励学习可偏向收益较高的确定决策。CE 的 G/N 并未同幅下降，因此不能把 Q 下降简单描述成“CE 学坏了语言”或“消息信息减少”：发送者完全未变。上述解释不等于已经单独识别所有随机性和决策目标的因果贡献。

Warm/Fresh CE24 的 Q 均值仅差 **−0.0524 个百分点**，两者 fit KL 残差分别为 0.004572、0.004863。没有一个方向达到事前 `1e−3` 精度标记；不能写“已精确达到信息下界”。但结果也不支持旧接收初始化造成明显、持久的监督优化锁定；均值接近不是统计等效检验。

完整监督所有30图的 Fresh CE30 得到 all30 **Q=51.9899%、G=59.3643%、N=59.8134%**；其相同 π 的共同30图联合 MAP 参照为 **60.5396%**。N 接近这个数值不能用于计算“距 π 上界差多少”，因为 N 改变了发信政策；同政策应比较 G 或 Q。全支持 CE30 已监督原封存图，任何相关改善都不是未训练组合泛化。

旧18图、加入6图、封存6图的单组 π 联合参照分别为 **93.4165%、89.7090%、89.7464%**，而共同30图只有60.5396%。这些单组最优解会为同一码安排互不兼容的动作。尤其不能将三个约90%的分数拼成“完整消息已经包含足够信息，剩下全是接收者问题”。正式分析另保存 fit24/fit30 求表后、保持共同动作表不变用于各评价组的结果；它是使用拟合标签的分析者参照，不是主体会学到的约定。

执行审计记录 [audit_execution.json](../redesign_v0.12/results/receiver_001/audit_execution.json) 为 passed、1,444,323 项；[分析独立审计](../redesign_v0.12/results/receiver_001/audit_analysis_independent.json)为 passed、728,963 项。本审查读取并核对这些状态，没有重新运行全套审计。独立汇总读取时 SHA256：`b0b1cced93e5a9f9a314fa7c3ffd307366ed7f4ea7bc611789ea84ee50efa586`。

## 二、哪些解释应放弃，哪些仍待检验

| 旧解释或候选主张 | v0.12 后应采用的判断 |
|---|---|
| 接收者训练不足是未见组合低分的主要原因 | 共同24图的奖励法已经接近相应收益参照，不能保留这个概括。个别来源、不同支持或不同任务仍可能有学习差距 |
| 旧初始化锁死了新接收者 | Warm/Fresh CE 差很小，本批不支持；也没有证明所有预算或架构下不存在此效应 |
| 新图单独可区分，所以接收端应能同时保住旧图并学会新图 | 单组参照不共享决策表；共同支持和旧用途约束必须同时计算。此前贪心 DP 还不能直接约束本批 π 训练 |
| 大 NLL/KL 缺口就是奖励法优化失败 | 目标不匹配，不能这样命名。分支 CE、联合 MAP、混合收益是三个不同决策问题 |
| CE 改善加入图说明形成了更好的组合语言 | 它获得了正确地点标签，且旧图 Q 同时降低；封存迁移仍低。只能描述额外监督如何重分配固定码的用途 |
| 强旧伙伴兼容压力已经被实验证明是主要瓶颈 | v0.11 干预效应有限；v0.12 是无强保持约束的接收诊断，不能替 v0.11 补出强因果效应。约定冲突可测量，不等于它决定学习动力学的强命题已成立 |
| 冻结 DINO 的世界知识已经足以产生可泛化结构 | 未识别。已有个体诊断训练过完整30图，且只证明对应副本的行动能力；它不能证明原社会主体在形成前已具备未见关系重组能力，更不能分离 DINO 与地点框架、需求分支、适配层的贡献 |

目前较稳妥的项目结论是：在给定视觉、地点与需求接口下，主体可以形成有任务用途的有限约定；已训练新图的适应、自然未见组合产出、额外监督解码和研究者拼接是不同能力。已有结果反复显示它们分离。它们尚未共同构成一个独立的新理论或高水平会议论文的充分证据。

## 三、与既有工作的关系

Rita、Tallec、Michel、Grill、Pietquin、Dupoux、Strub 的 **Emergent Communication: Generalization and Overfitting in Lewis Games**，NeurIPS 2022，已经在 §2.2–2.3（PDF第3–4页）讨论最优后验与信息／共适应分解，在 §3.1 和图1（第5页）冻结发送者、训练新的监督接收探针，并明确区分训练支持与全分布的探针；第5页脚注2反对只在测试子集拟合后将其当成一般信息估计。§3.3（第6页）已有重置、部分训练和开发早停接收者。[正式论文](https://papers.nips.cc/paper_files/paper/2022/file/093b08a7ad6e6dd8d34b9cc86bb5f07c-Paper-Conference.pdf)；[本地带页码全文](literature_20260915/primary/2022_Rita_Generalization_and_Overfitting_in_Lewis_Games_NeurIPS2022.pages.txt)。

因此 v0.12 应定位为 **Rita-inspired 方法核对与本任务的目标校准**。本任务具有两需求分支、独立标量奖励、视觉发送输入和可完整枚举49码，这些差别使精确诊断方便，也揭示照搬 CE 解释的风险；这些设置差异本身不构成方法首创。条件熵、KL、MAP、逐码最优收益以及有限表决策都是标准工具，不能换名当贡献。

[最近邻审查](literature_20260915/novelty_gap.md)已核实：Kouwenhoven 等 CMCL 2024、Ochiai 等2026预印本、Kaszyński 2026预印本都直接涉及冻结视觉预训练模型与通信；CtD（ICLR 2025）已有概念分解和组合泛化，CELEBI（NeurIPS 2025）已有接收端塑造表达和行为保持式学习。这些工作禁止我们把“非LLM视觉主体”“冻结一端”“有片段结构”“符号组合优于查表”写成空白。v0.12 更适合作为排除伪解释的证据段，而非独立论文主贡献。

## 四、最值得尝试的单一机制比较

**候选问题：在相同视觉模型、消息容量和社会收益下，预先具备更强的非语言空间重组能力，是否使主体自然形成对未训练资源组合更可用的约定？**

这里的能力具体指：物体整体搬到其他地点时，主体能把自己的采集行动相应搬过去，并在没有练过的两资源组合上做到这一点。它不是会说话、会用两符号语法，也不要求已经知道“食物词／水词”各占哪个槽。比起再调接收训练目标，这项操作更接近最初提出的“哪些非语言能力支持共同符号及结构”。

### 只改变非语言准备中的空间对应约束

保留冻结 DINO、六地点、旧照片、两位七选一消息、λ=.5、旧18／加入6／封存6划分。两臂使用同架构、同初始化、同私人行动头、同地图与照片、同训练预算。社会阶段奖励、消息长度、参数量、课程均不扫描。

1. **私人行动准备的匹配控制。** 每批给同一主体两个真实可行动世界 x 和 gx：保持两张照片身份，按已知地点置换 g 移动物体。两世界都必须属于本分区旧18图；世界和 g 在采样前完整枚举，以保证两侧旧地图边际相同。主体仅按自己的需求行动，以原有个人标量采集反馈学习；无通信。两臂看到完全相同的成对世界和反馈规则。
2. **空间对应条件。** 在同一私人行动目标上，额外要求 `p(a|gx,z)` 接近将 `p(a|x,z)` 按 g 重排的分布，其中 z 为自身需求。可用按两个需求平均的 Jensen–Shannon 距离，系数固定一次，例如0.1；控制臂计算同一项但系数为0。两边前向世界数和更新数相同。JSD 是标准一致性正则，绝不作为创新命名。
3. **额外信息必须明示。** g 是环境提供的“同一物体被搬到哪里”的非语言对应关系，确实增加了训练约束。它不是资源类别、最佳消息或地图到码的标签。将菜单输出转回物理地点后再约束，不能把菜单次序误当空间。不要给错误配对关系充当所谓困难控制。
4. **仅传递准备后的视觉接口。** 沿用已有私人行动准备代码的 `slot_phi`、`memory` 路径；在两臂中都冻结这部分用于社会形成。DINO继续冻结。私人行动头丢弃，消息与接收模块从两臂完全相同的新初始化学习，不能把行动概率、正确地点或 oracle 表直接送入信道。这使非语言准备的效果不依赖更多社会可训练参数。
5. **主实验只做形成，不再叠加适应扫描。** 用旧18图训练社会主体，固定2400×512预算；加入6与封存6均不参与私人准备或社会反馈。主指标为预定封存6的自然 N，加入6只作第二个预定未训练组，不选择其中更好的作为主结果。所有输入、损失、变换和暴露计数须在运行前冻结。

上述约束需要新跑匹配控制；v0.10/v0.12 的旧运行不冻结同一准备接口，也没有成对非语言准备，不能充当配对控制。旧结果可复用为动机、代码验收和测量工具，不可复用成实验重复。最小开发规模为4个新主体对×3预定分区×2条件=24个社会运行；两人的私人准备分别配对。建议私人准备同样固定2400×512预算，成对世界总量按两臂一致记录。这个规模可在本机开展探索，不足以预先保证论文效应精度。

### 在看社会结果之前确定预测与失败条件

首先测量准备结束时的非语言能力：旧18图私人行动准确率、未训练组私人双目标准确率、物体搬移前后的行动分布一致性。既有全30图训练的100%诊断不能代替这个门槛。

预期空间对应条件在旧图仍达到事先行动门槛的同时，改善未训练组的私人行动重组；随后提高自然封存 N，并提高**共同30图**的发送联合可区分性。第三项必须使用一个共同解码表，而非三个组分别重拟合。这个方向性预测应在新运行前写入固定方案；不能先观察哪些种子有高片段分数再挑来源。

| 观察 | 对机制的判断 |
|---|---|
| 对应条件没有改善所测非语言重组，或明显破坏旧图行动 | 能力操纵未成立；不能把社会零效应说成能力不重要，也不能靠换系数继续到获得正结果。保留所有主体，不按门槛挑选种子 |
| 非语言重组改善，但共同30图发送参照及自然封存 N 不变 | 该能力在这个接口与预算下不足以促成可扩展符号；反驳“有这项能力即可自然得到组合表达”的强预测 |
| 共同30图发送参照改善，但自然 N 不改善 | 信息进入消息与共同解码仍分离；不能称已经形成可用组合语言 |
| 自然 N 改善，但共同发送参照不变，只有单组 oracle 或人工拼接改善 | 支持功能改善，却不支持所预测的共同发送可区分性机制；不能用单组或拼接分数补足这个机制环节 |
| 能力、共同发送参照、自然 N 均按预测改善，且消息打乱破坏收益 | 支持这项非语言准备在本环境中的总因果作用。三个量共同变化仍不是严格的中介效应识别，也不能自动归因于“关系绑定”这一唯一心理机制 |

必要基线限于上述匹配私人准备控制、每端个人行动检查、相同世界的消息打乱／空白干预，以及现有整体码与片段测量的正确参照。严格片段与人工拼接最多作结构补充；若只有这两项提高而自然封存 N 不提高，仍算主要预测失败。无需同时再训练原子码、改变奖励、加新人或增加消息容量。

## 五、这个方向仍不能宣称什么

这是对“可迁移空间行动能力是否支持可扩展约定”的检验，不是证明 DINO 预训练本身必要或充分。即使阳性，也只能说 **DINO加给定地点／需求接口及所测非语言准备**在限定环境下支持了某种表现；要分离 DINO 的贡献仍需后续独立视觉控制，不能把它悄悄塞入这一轮形成多因素扫描。

空间一致性训练、数据增强、目标等变性和具身非语言预训练都有广泛先例。现有最近邻审查尚未证明“将这一准备与共同码冲突、自然未见组合产出联系”的组合命题无人研究。它值得做是因为能回答一个更贴近原问题、可能被否定的因果问题；**不是因为换成这个表述就已拥有 ICLR 级新意**。若对照只重现常规增强改善泛化，则应承认这一点，不把标准方法重新命名。

独立 Commons 元数据框已完成800候选，但图像尚未验收。后续可用于冻结后验证视觉外推；当前不能把它记作已完成独立数据确认。新图确认也不能弥补缺失的机制对照。论文下一步的优先顺序是：先确认所操纵的非语言能力确实不同，再检验它能否改变自然约定的形成，最后用独立材料核验范围。
