# 固定发送者接收诊断：独立前置审查

## 设计判断与统计边界

拟定矩阵可以区分冻结发送函数下的任务信息歧义、接收目标差异及预算内拟合差距。四个条件为 warm_rl24、warm_ce24、fresh_ce24、fresh_ce30；每个 v0.10 base 的两个方向分别拟合，共 12 来源 × 2 方向 × 4 条件 = 96 次单方向拟合，各 2,400 × 512 世界。外层仍只有四个继承来源种子；三个分区、两个方向和多个检查点不是新的独立形成样本。

CE 给定正确地点标签，同时改变损失；监督与奖励之差不能单独归因于优化器或 REINFORCE。fresh_ce30 对全部地图接受直接监督，原 sealed6 已暴露。它可诊断信息和拟合能力，不能作为社会学习或零样本泛化。固定发送者的有监督接收拟合已有直接文献近邻，本批应称 Rita-inspired 任务内诊断，不称原论文精确复现或新方法。

## 最容易破坏比较的实现环节

1. **方向与完整冻结。** 方向 `who` 指 `agents[who]` 发送、`agents[1-who]` 接收。所有发送路径、project、input_transform 及其余未选中参数/buffer 都应逐位不变；发送 value 同样冻结。CE 仅更新接收 embedding 与 actor，RL 另外更新 receive_value。fresh 只重置这两个接收行为模块，不误重置发送路径；两个 fresh 条件逐参数共享新初值，warm 两条件完整共享来源初值。

2. **一次原生发信、两次独立动作。** 训练调用原生 send，第二符号依实际首符号递归；不能用 49 码联合 argmax 或常见消息替代。每世界只生成一条消息，F/W 两查询收到同一消息，互不看到另一行动或反馈。RL 的动作 RNG 与消息 RNG 分开，两需求连续独立抽样而非复用同一个均匀数。

3. **目标与梯度缩放。** RL 两行动 log-prob 和熵分别求和，以两个目标 value 的均值为不依赖行动的 baseline，目标为 R−1，策略项加 .5 MSE 与规定熵项；不再加入冻结发送损失后做双角色均值。CE 每世界两需求损失求和，不混入 critic 或奖励。活动参数集合分别裁剪 norm 2，fresh Adam 无历史状态，预算和学习率各臂固定。

4. **真正配对的部分。** 三项 24 图条件逐步世界、照片、消息流及实际消息完全相同；RL 多抽动作不会影响另外两个流。fresh_ce30 仅配对初值、照片规则和预算，不要求不同地图支持下世界相同。每步保存可重建的 seed 身份字符串、世界/消息 SHA 和支持计数，所有 24 图训练的 sealed 暴露须为 0。

5. **选择规则。** 第 0 步属于已保存候选，CE 最低 dev NLL 平局取最早；24 条件 dev 只含 24 图，CE30 可含 30 图。固定 2,400 终点是主结果，600 为短预算次结果，dev 最佳只是补充。选择不得读取 evaluation、24 条件 sealed 标签或未保存权重，不用结果驱动续训。

6. **合法的缓存与固定菜单。** 根线程拟缓存完全冻结 observe 的 float32 h，每步仍调用原生 send；只要缓存与相同源权重/照片直接重建的 h 和首/条件二符号 logits 一致，这是等价计算。固定 identity menu 与 F→W 查询顺序对四条件一致，且接收器无跨调用状态；actor 原本输出物理地点，再按 menu gather，不增加信息。贪心并列时固定菜单取最小物理地点，旧随机菜单的并列处理未必逐例相同，应作为本轮实现补充说明，不能宣称精确回放旧轨迹。

## 数学验收必须独立实现

原生政策以原 float32 首符号 logits 与全部七种首符号下的第二符号 logits，经 float64 稳定归一化构成联合 49 码概率；逐符号贪心消息单独保存，两者不合并。完整期望评价不是有限 PRNG 分箱的逐比特复现。

独立审计器不调用主指标模块的公式函数，使用 NumPy 从原始表重算：

- 每世界分支 NLL，`H(F,W|M)`、`H(F|M)+H(W|M)` 与条件互信息/边缘 KL 恒等式。
- 36 个合法物理行动对（含同地点）的完整码 MAP 与混合收益最大值；分支 CE 边缘最优的贪心 J 单独给出。
- 原生发送/随机接收、原生发送/贪心接收、逐符号贪心发送/贪心接收，及旧/加入/封存分组。不同子组单独最优表不能拼成一张可同时实现的接收表。
- 常量消息均匀 30 图、完美码、零消息概率、并列最大、边缘最优不等于联合最优的人工例。常量消息的 Hjoint=ln30、Hbranch=ln36、joint 最佳1/30、混合收益最佳1/10；均匀独立动作对应1/36和7/72。

训练和开发参照的残差只能解释对应分布；evaluation 残差还可包含照片诱导的消息分布迁移。有限神经参数化和预算未达参考不能全部归为信息不足。旧静态 DP 只约束原固定贪心消息分布，不是原生随机采样训练的普遍上界。

## 预检与正式审计的证据

待 runner schema 固定后，预检应覆盖：完整来源与冻结分区、四条件初值关系、照片分区、首步源消息/动作和损失复算、24 条件配对流、模型/Adam 更新预算、菜单映射、全部数学人工例和开发选择。只在这些检查通过且源 SHA 固定后签发正式 gate。

正式审计检查全部 96 个拟合、230,400 次更新、117,964,800 训练世界；原生通信次数与世界数一致，RL 实际采样接收行动 58,982,400 次，CE 的两个监督需求须与实际随机行动计数分开。检查每个保存 checkpoint 的冻结状态、初末 Adam、所有训练世界与消息配对、原始概率表的独立指标复算、固定终点与 dev 选择及四种子汇总。保存首步和 2,101 步原生轨迹及对应更新前权重，有利于独立复核熵切换前后；全预算审计不等于逐步重新优化所有模型。

通过审计只说明实现与记录相符；不能将监督高分当成自然语言诞生、更不能承诺投稿结果。训练主体与原社会主体、所有分析者 oracle、开发选择和特权 full30 监督保持明确边界。
