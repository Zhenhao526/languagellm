# v0.14 私人视觉记忆重置：独立前置审查

2026-09-15。依据已完成的 v0.13 与根线程的新候选设计；尚未读取新运行器或生成本轮效应。本文不表示预检已经通过，也不修改 v0.13 冻结实验。

## 本轮可识别的问题

在相同 DINO 特征、资源投影、社会接口、世界、优化规则和预算下，比较保留私人标量行动训练后的 memory/slot_phi，与恢复这两模块私人训练前初值的差异。原 control 已在 v0.13 完整执行；新增 reset 臂与其逐来源配对。该比较是在看到 v0.13 结果后提出的机制扩展，不是独立新种子或新图片确认。独立统计单位仍为原4个来源，三个划分和两个方向嵌套其内。

重置仍保留冻结 DINO、最初200×64资源后果实践得到的 project、地点/需求/存在位与社会动作接口。随机冻结的 memory/slot_phi 也可能保留可用场景信息。因此条件不能命名为“没有世界知识”“无空间能力”或“抹掉视觉信息”。它检验保留私人准备所得模块的总效应，不单独识别空间等变性、行动能力、表示可读性或优化难度。

## 必须逐位满足的起点与冻结条件

对每个来源seed/partition及两个人，先取 v0.13 control 的社会 step0 完整 state。只把 `memory.` 和 `slot_phi.` 前缀下的值替换为该来源 control 私人 `initial.pt` 的 `agents[who]` 对应值。不能用私人 final、equivariant、重新随机初始化、旧优化器或一个不对应来源的通用随机矩阵代替。

重置后的其余参数和所有 buffer 必须逐位等于原 control 社会 step0；尤其包括 project、input_transform、send_value、receive_value 以及全部发收通信接口。随后 project、input_transform、memory、slot_phi 都冻结，只有原社会发收参数训练。两主体参数对象不能共享。新 Adam 与原 control 的社会 optimizer0000 完全相同、状态为空；不存在私人头或私人 Adam 的迁移。

来源证据应至少绑定私人 initial.pt、原 control 社会 initial.pt/checkpoint0000、原 control 的训练配置、日志、曲线和终点，以及已通过的 v0.13 执行审计。可另外归档进入 reset 的完整初态与前后模块指纹。新运行不得改写原来源文件；旧 control 成绩也不能因新比较而重新选点。

## 配对、公平性与观察口径

保持原社会2400×512通信预算（每条消息两次资源行动）、旧18图支持、学习率0.0007、Adam设置、两角色loss各占1/2、分角色norm2裁剪、前2100步熵0.02后300步0，以及同一批数据与全部固定评价时刻。新条件名称不进入世界或策略随机种子。

v0.13 世界命名空间为13014，训练purpose1、评价purpose90；策略命名空间11011，训练stream11/12、评价91/92、打乱93。应逐步证明 reset 与来源 control 的世界/hash相同，使用相同外生均匀随机数身份。由于视觉编码不同，第一步的发送分布、消息、奖励和梯度也可以不同；不能误要求两臂参数更新或实际行为逐位相同。

训练仍只使用 old18。added6和sealed6均不进入训练反馈。主要比较继续固定为2400步sealed自然N；旧图、added、形成过程与AUC为辅助，不选择较好留出组或最佳检查点。正常消息、shuffle、blank、stochastic、erase_memory保留，明确这些是已学策略干预。原生49码概率、逐符号贪心N、原生发送+贪心接收G、双方原生Q保持分离；共同30图信息参照不能由子组最优解拼接。

## 预检与正式执行审计

新运行器和方案落盘后，先审来源路径、模块替换、参数标记、随机流、支持与预算，再对短 smoke 独立重放首步采样、损失、梯度和 Adam。精确重放须保持冻结参数的 requires_grad 标记及已知浮点计算图次序；若独立等价实现产生舍入差，保留失败证据、定位原因，不直接放宽门槛。

正式后仅审新增社会臂与其对应来源关系，不重复 v0.13 全私人训练。核对全部训练世界、每个checkpoint的冻结部分与Adam步数、1/2101取证政策及梯度、终点五模式全部原始行为、所有协议原生logits与概率指标。原 control 的同源数据和既有审计必须保留并绑定。能力或表达结果不影响是否纳入来源，不因结果弱而改预算或增加权重扫描。

若保留准备优于重置，只支持这套准备模块在当前任务和预算内具有迁移作用。若重置相近，只表明在本样本和预算内未见明确额外收益；均值相近不足以建立等效性，也不能判断空间能力是否必要或所有非语言准备是否无用。若重置更优，应区分私人目标与社会目标的表示偏好、冻结后的可读性和优化条件，不直接宣布学习私人能力有害。
