# 两个可替代搭档 × 显式中性动作实验

本包是独立新种子确认实验：每个世界有两个使用不同搭档对的合法完整方案；策略用独立的 neutral/engage 意图头和 16 类地点—目的地—搭档提案头。比较固定主体需求对应与每世界随机重配，以及 live/silent 通信。

预注册主量是物理执行后目标搭档选择率的 rematched × communication 差中差中心化时间 AUC。执行、参与、提案内容和完整方案成功率分开报告。详细冻结方案见 plan.md。

模型为本地 CPU NumPy tanh MLP，消息仍是离散无意义符号；本包不调用 LLM/API，也不把任务协调结果称为语言起源证据。
