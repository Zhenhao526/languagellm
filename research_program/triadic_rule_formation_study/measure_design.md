# 规则与通信形成轨迹：固定测量口径

本文固定本轮的统计汇总和有限消息描述。16 个新初始化区组为 60101–60116，每区组四个独立优化政策：strict／reciprocal × PL_live／PL_silent。推断单位是 16 个配对初始化，不是 64 项政策、需求世界、需求边或消息位置。主问题是规则如何改变通信支持的需求响应学习；Q 和以下消息面板都不是语言形成程度的直接度量。

## 唯一主量

完整双留出分区使用全部 53,568 世界、36 个布局×归属背景。更新时点固定为 `0,100,500,1500,3000,6000`。每点沿用原需求边 Q 的定义和九层等权，主量使用各政策自身训练规则的实际结算结果，即 native Q。相同提议再按 reciprocal 结算的 Q 是另一个预定辅助，不替换 native 主量。

对每个初始化 k，在每个 t 先算两条通信差：

`C_S,k(t)=Q_strict,live,k(t)−Q_strict,silent,k(t)`；

`C_R,k(t)=Q_reciprocal,live,k(t)−Q_reciprocal,silent,k(t)`。

再算 `D_k(t)=C_R,k(t)−C_S,k(t)` 和 `D*_k(t)=D_k(t)−D_k(0)`。主社会读数为按更新数的归一化梯形积分：

`A_k = Σ_j (t_(j+1)−t_j) [D*_k(t_j)+D*_k(t_(j+1))] /(2×6000)`。

唯一总体主量是 16 个 A_k 的等权均值。程序先在各社会内配对、扣除该社会自身初始化，再积分，不以群体平均初始化替代各社会初始化。Q 的 DiD 可以在 ±2 内，扣初始化后可以达到 ±4；不得把差或区间裁剪到 ±1。

时间积分不是六个时点简单平均，也不使用对数时间。原六点梯形权重为 `1/120,1/24,7/60,5/24,3/8,1/4`。主量归一化后仍是概率差，展示为百分点时乘 100。它反映学习预算内的累计响应差，不能精确定位语言首次出现的时刻。

每社会完整保留四条件的原 Q／Q_excess 六点、两条通信差、DiD 与扣初始 DiD、未扣初始 AUC、扣初始 AUC、初始化 DiD、末点 DiD 及末点相对初始变化。以上同时对 native Q、native Q_excess、共同 reciprocal Q、共同 reciprocal Q_excess 计算。只有 native Q 的扣初始 AUC 为主，其余均为预定辅助。Q_excess 也不命名为语义。

## 社会层面的近似区间

报告 16 个 A_k、均值、样本标准差 `sd(ddof=1)`、标准误 `sd/√16`，及 `mean ± t_(15,.975)×SE`。不计算世界层面 p 值，不用海量边缩小区间，不用区间是否跨零决定追加社会或延训。这是 16 个配对初始化均值的 Student-t **近似区间**；它依赖有限社会抽样下的近似，不能被解释为等价性证明或人类群体的不确定性。

本地绘图虚拟环境没有 SciPy，本实现未增加依赖。NIST 官方表核对了自由度 15、累积概率 .975 的临界值四舍五入为 2.131。[NIST Student-t 临界值表](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3672.htm)

额外精度由标准库独立数学计算得到并在结果读取前固定为 **2.1314495455597715**：以 `x=√15 tan θ` 把 t15 累积密度化成 `cos(θ)^14` 的积分，用偶次幂递推计算，再二分求 .975 分位数。系数为 `Γ(8)/(√π Γ(7.5))`；纯测试重新计算此常数的 CDF，得到 .975。运行期只使用已固定常数，不加载统计库或重新估计自由度。官方表只支持其给出的三位小数，更高精度来自上述本地数学核验。

## 有限的消息面板

只使用完整双留出的六点自然消息，每项 shape 为 `[53568,2窗口,3主体,4符号位置]`，符号为 0–7。静默与开放同样保留自身自然消息，都计算面板；静默中的局部离散计算不因此变成主体间语言。其他分区不新增这套面板。六个“主体×窗口”分别报告，不再合成总语言分数。

同一主体、同一窗口的四位置消息视为一个包，按 8 进制编码为 0–4095；这个编码仅用于计数。接收端、解码器、奖励和正确行动都不进入这些描述指标。全部位置与时点保留，不挑差异大、成绩好或有变化的包。

### 每时点：条件包熵和有效包数

按原 need-major、layout、owner 顺序，将某面板的完整包向量 reshape 为 `[1488需求世界,36公开背景]`。对每个背景 b 的全部 1488 世界统计经验包概率，并计算 Shannon 熵 `H_b=−Σ_m p_b(m)log₂p_b(m)`，单位 bits。

保存 36 个背景各自的 H_b、`2^H_b`、实际出现包数和常量标志。总体条件熵为 36 背景等权的 `H(M|B)=mean_b H_b`；总体条件有效包数定义为 **`2^(mean_b H_b)`**，即背景有效包数的几何平均，不是它们的算术平均，也不是原始不同包数量。全域出现包数另作范围描述。即便每个背景对应不同常量包，条件熵仍为 0、条件有效包数仍为 1。

### 五对相邻时点：原包变化和分区稳定性

仅计算相邻 `0→100→500→1500→3000→6000` 的五对，不扩成与初始化比较的矩阵。比较始终对齐同一个原世界、主体和窗口：

- **原包相等率**：四个位置全部一致的世界比例。
- **字符 Hamming 比例**：发生变化的原始符号位置数／全部世界×4，不先重命名或对齐符号。
- **全域 ARI**：以“包相等”形成世界分区，比较相邻时点分区的 adjusted Rand index。
- **背景内 ARI**：在每个公开背景的 1488 世界内计算相同分区指标，保存全部 36 个值，再背景等权平均。

ARI 对包标签的一一重命名不变；即使这种包重命名无法分解成逐字符重命名，它仍只看相等关系。因此 ARI 不表示词义一致，也不表示符号串结构一致。全域 ARI 可能主要反映公共布局形成的分组，背景内 ARI 比较的是固定背景下的包分区，两者均为描述。

ARI 使用稀疏联合标签计数，内存随观察到的包和联合包增长，不创建 4096² 矩阵。令 T 为世界对总数，A、B 为两个分区各自同簇世界对数，C 为同时同簇数，则按等价整数表达计算 `2(TC−AB)/[T(A+B)−2AB]`。不裁掉负 ARI。

边界固定为：两个常量分区的 ARI=1，哪怕所有符号都换了；两个全单例分区的 ARI 也为 1；一个常量、一个非恒定分区的 ARI=0。只有一个观察时两分区必相同，返回 1。空数组拒绝。每条 transition 直接保留全域／背景常量标志、包数及前后条件熵，各背景也保存前后熵，**常量 ARI=1 必须与熵 0 一起呈现**，不作为丰富约定或语义稳定的证据。

## 接口、验证与范围

`primary(runs)` 接收 64 个运行记录，以 `seed/rule/live` 识别四格。各 `trajectory` 必须具有按顺序的六个 `update`，读取 `evaluation.need_response.native/common_reciprocal` 中的 Q 和 Q_excess。输出顶层 `statistics` 与 `mean_centered_AUC` 为唯一主量，`by_seed` 保留所有原曲线和配对量，`auxiliary_statistics` 保留全部预定统计。记录顺序不影响社会配对，缺格、重复格或缺点拒绝。

`message_snapshot(messages,spec)` 和 `message_transition(before,after,spec)` 均返回 JSON，`panels` 按主体先、窗口后排列，共六项。函数验证完整数组形状、符号范围和原笛卡尔规格；仅靠消息内容不能验证来源世界顺序，调用方必须先按冻结的状态／索引及消息文件哈希绑定原序。transition 不自行决定时间对，runner 只传五对相邻自然转录。

纯测试覆盖解析线性轨迹、非等距权重、中心化差可超过 1、16 社会 t15 统计、无效输入，以及稀疏 ARI 与直接世界对参考的 256 组小例、常量／全单例／重命名边界、背景驱动分组、熵和有效包数的不同聚合。代码只做确定性数组计算，不读取模型、未完成结果或政策 NPZ，不训练或调用神经网络。预检及源哈希见 `metrics_preflight_001.json`。
