# 执行规则与通信机会的形成轨迹

在保留对象／材料、长短、搭档和目的地的合作任务中，比较“第三人必须等待”和“互选即可执行”两种规则，以及开放通信和从头静默两种条件。16个配对初始化各运行四种条件，共64次训练；每次固定6000次更新。没有加工前置步骤或道路事件，没有新增Qwen调用。

本轮使用9个小型独立MLP。两个同步消息窗口各允许4个符号，字母表大小为8。通信形式和任务规则预先给定，学习过程可以形成编码及接收行为；不能据此认定模拟了人类语言最初的出现。

唯一主量衡量规则怎样改变通信支持的需求响应在训练期间的累计变化。消息的使用范围、原包变化及分区稳定性分别描述，不合成“语言分数”。静默主体保留自己的离散计算，其符号不能称为社会约定。
