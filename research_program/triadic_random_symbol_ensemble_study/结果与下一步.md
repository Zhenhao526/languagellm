# 随机符号双射集成对照：结果与下一步

## 问题与设计

前一轮只有一个固定符号双射。若只在这个实例上看到响应下降，仍可能是某个特殊排列、个别符号槽位或实现路径的偶然结果。本轮预先固定六个 8 符号随机双射：

| 模式 | 双射（输入符号 0–7 的输出） |
|---|---|
| perm_00 | (6, 7, 1, 0, 4, 5, 3, 2) |
| perm_01 | (4, 1, 3, 2, 6, 5, 7, 0) |
| perm_02 | (4, 3, 2, 6, 1, 5, 7, 0) |
| perm_03 | (2, 0, 4, 7, 3, 5, 1, 6) |
| perm_04 | (7, 2, 6, 4, 0, 5, 3, 1) |
| perm_05 | (2, 3, 1, 7, 0, 6, 5, 4) |

它们在任何策略输出读取前就写入静态映射。每个模式只替换指定发送者的首窗 W1 对外包，保留自身通道、四个对象/属性/搭档/目的地表达需求、包长度和位置；live 条件重算 W2 和全部行动头，silent 条件直接使用自然策略输出。数据来自已冻结的 `formation_001` 与 `triadic_content_response_study/content_001`，没有训练或新的 Qwen 调用。

六个模式各覆盖 16 个配对初始化、strict/reciprocal×live/silent 四条件和六个检查点，共 2304 条策略—时间记录。实时文件 1152 个，每个 27648 行；另有 1152 个静默自然别名。主执行新增 191,102,976 个模块前向样本，训练更新为 0。

主量是 6000 步时自然同组 live `M` 减置换 live `M`：先在每个种子内平均 strict 和 reciprocal，再在 16 个种子上计算均值和近似双侧 t15 区间。`M` 是四个研究者定义的候选接收动作中，供体端点目标概率减去其余三者最大概率，先在组—背景内均衡，再对 12 个层等权。它用于比较反事实响应，不是全 17 动作成功率。

## 结果

六个双射的规则平均选择性均为正，且 16/16 个种子区组都为正：

| 模式 | 均值（百分点） | 近似 95% 区间（百分点） |
|---|---:|---:|
| perm_00 | 10.9666 | [7.1941, 14.7392] |
| perm_01 | 10.4096 | [7.5580, 13.2613] |
| perm_02 | 10.2903 | [6.9504, 13.6302] |
| perm_03 | 12.1221 | [8.9773, 15.2668] |
| perm_04 | 12.6381 | [9.4101, 15.8661] |
| perm_05 | 13.9320 | [10.7603, 17.1037] |
| 六置换按种子平均 | **11.7265** | **[8.6680, 14.7849]** |

六置换平均的 strict 规则选择性为 13.1694 个百分点，reciprocal 为 10.2835 个百分点。6000 步端点的自然 live `M` 为 strict −1.1317、reciprocal −7.2238 个百分点；六置换平均后的 `M` 为 strict −14.3012、reciprocal −17.5073 个百分点。相应地，目标动作概率、四候选命中率和全 17 动作命中率都下降，而不是只出现一个边际指标的变化。

所有置换在 0 步与自然策略相同；随形成更新增加，strict 和 reciprocal 的置换响应均逐渐低于自然包。这个时间关系与固定双射结果一致，但本轮仍是冻结策略上的反事实重放，不是重新训练后形成新约定。

## 审计与边界

主执行一次完成，耗时约 105 秒。独立审计逐条重建路由、W2、行动概率和 `M`，覆盖 1152 个实时文件及 1152 个静默别名，共 191,102,976 个独立模块样本；概率、消息、动作、映射和指标的最大误差均为 0，主量由独立实现精确重建。汇总和图表不读取检查点或模型。

结果支持一个较窄的判断：在这组固定任务和策略中，对首窗包做符号身份的随机双射通常会破坏同组四端点响应，固定整包编码敏感性并非某一个置换的孤例。它不能区分查表、槽位触发、符号身份绑定或真正的组合规则，也不能证明符号对应对象、属性、搭档或目的地，更不能单独作为语言诞生证据。六个置换都把整包变成未训练的代码，因而“敏感”不等于“对任意重命名应不变”；本结果没有检验学习后的新双射适应或保持等式模式的局部替换。

下一步应把识别问题继续拆开：在相同冻结策略上加入保持包内等式模式的局部替换、随机单槽替换和已见/未见端点—属性组合；同时在新的独立训练群体中预先固定内容泛化检验。若要主张语言形成，还必须观察可迁移的功能成分、跨背景的新组合和代际或新伙伴传递，并设置全信息可解性与无通信参照。本轮不延长训练、不按正结果追加置换。
