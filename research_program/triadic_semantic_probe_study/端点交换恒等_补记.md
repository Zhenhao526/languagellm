# remote_both的端点交换恒等与统计冗余

这是看到完整汇总后新增的数学与保存数据核查，不能追称预设发现。不修改主方案、源码或结果；本核查没有加载模型参数、执行网络前向或重新结算。

结论是：**PI的remote_both中，opposite供体施加于端点b，与same供体施加于端点1−b，对两个非发送者给出完全相同的行动输入。** 因此两方向平均后，`opposite.counterfactual_apt = same.current_apt`，反向也成立。它是两个干预分支之间的端点交换，不是重现远背景供体的自然完整输入。

## 为什么相等

设当前案例的两个recipient端点为0和1，只有sender S的需求不同；物资布局、owner及另外两人的需求保持。两名非S的PI观察和自然第一窗消息完全相同。remote_same在端点1−b与remote_opposite在端点b，依据冻结索引恰好选中同一个远背景、同一需求端点的S两窗消息。

两分支都用这份相同的远背景S消息覆盖S向另外两人的第一窗出站payload。非S的自身观察、来自另一个非S的第一窗和被覆盖的S第一窗因此全同；重算后的两个非S第二窗也相同。第二窗中S的出站payload再次被同一远背景值覆盖，所以两个非S的完整第二窗收件箱及最终行动输入相同。

S自身需求和自生消息没有被覆盖，因此**S自己的最终输入／行动不受这个恒等保证；两支的recipient真实世界也不同，完整团队原R不受保证**。也不能将此结论直接套用到W1-only或W2-only：前者仍保留可能不同的S自生第二窗，后者仍保留可能不同的自然第一窗。

## 哪些统计重复

令A_b为recipient布局中、端点b需求下的听者全部满分行动投影，Y为其行动。逐案例逐方向有：

\[
Y_{\mathrm{opp},b}=Y_{\mathrm{same},1-b},\qquad
\pi_{\mathrm{opp},b}=\pi_{\mathrm{same},1-b}.
\]

因此current与counterfactual适切及其概率质量在交换方向后相等：

\[
\mathrm{target}_{\mathrm{opp},b}=\mathrm{current}_{\mathrm{same},1-b},\qquad
\mathrm{current}_{\mathrm{opp},b}=\mathrm{target}_{\mathrm{same},1-b}.
\]

本设计每个无序案例内部对两个方向等权，所以恒等在每轴、静态S/L与所需伙伴分层、以及三轴宏平均中继续成立。两个方向的数值是**交换对应**，不要求同一方向数值相等。四种子等权平均不会产生新的独立信息。

预定的辅助差可以重写为：

\[
\Delta=\overline{\mathrm{target}_{\mathrm{opp}}-\mathrm{target}_{\mathrm{same}}}
=\overline{\mathrm{current}_{\mathrm{same}}-\mathrm{target}_{\mathrm{same}}}.
\]

所以remote_both的四个绝对边际适切率只有两组独立数值；不能将上述相等作为另一项语义成功，也不能把两种写法当重复验证。概率质量有完全相同的代数关系。

## 为什么配对差仍有信息

该恒等不要求Δ为0。右式检验同需求远背景消息引发的听者行动，是否更适合其对应需求集合而非反需求集合。若听者在两种供体事实下完全不改变行动分布，两个方向的正负贡献会抵消，Δ为0。因此正差可表明冻结远背景映射下、经S整条出站消息及后继路径产生的定向适切作用。

这仍弱于每个案例两端都适切：部分案例或仅一个端点的适当响应就可能贡献正差。须保留自然两端适切、远背景same的绝对当前适切及其相对自然的损失、每轴与四种子值、完整团队R。正差不保证当前真实任务获益，不证明逐符号词义、组合结构、任意布局可迁移或独立确认。

## 保存数据核查

对全部四种子、PI_silent／PI_live、train／heldout的64份remote_same_both／remote_opposite_both方向文件作核查。读取保存的recipient状态、生成消息和donor出站包，独立重建PI编码与两窗路由；没有重新生成消息或行动。

- 32组模式／方向交换核对，合计276,480个案例世界对。
- 552,960个非S完整输入逐项相等；对应行动与17项保存概率逐项相等，最大概率误差0。
- 576个批次的完整行动输入SHA及两窗路由SHA均与主记录一致。
- 逐案例current／target指标的方向交换，以及三轴配平后的等式均通过。

PI_live、heldout recipient、四种子等权复算为：

| 指标 | 比例 |
|---|---:|
| same当前适切＝opposite反事实适切 | 0.12950102880658435 |
| same反事实适切＝opposite当前适切 | 0.06360918209876543 |
| 预定差＝same当前−same反事实 | 0.06589184670781892 |
| same当前概率质量＝opposite反事实概率质量 | 0.1296631115125927 |
| same反事实概率质量＝opposite当前概率质量 | 0.06351387441180231 |

以上恒等不改变原辅助差约+6.5892个百分点，但缩小了可以视为独立读数的集合。它也不是本地local_both重现自然对端的旧恒等：这里比较的是**同一recipient背景中需求端点交换后的两个远背景干预**，并未断言非S完整输入等于远背景自然供体。

核查脚本为 `audit_endpoint_exchange.py`；完整来源SHA、每个种子／分区的比较、逐批输入绑定和精确数值保存在 `results/content_001/endpoint_exchange_001/verification.json`。本核查只新增补记和收据，没有改写主分析。
