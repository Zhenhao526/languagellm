# Ternary attribute and message-capacity extension

This study expands the two binary private attributes to three-valued attributes and three object types. Each subtask contains a random permutation of all three object types, so every target is achievable without a fixed site-position shortcut.

`mono9` uses one nine-valued token; `tri3` uses two three-valued slots. Both have nine possible complete messages, but only `tri3` exposes a slot decomposition. The tasks are `factorized` (one target value per subtask) and `entangled` (the second target is the modular sum of the two private values). The protocol is either `simultaneous` or `staged`, and each condition has a paired live/silent channel.

The primary readouts are live−silent, staged−simultaneous, and the held-out slot-recombination gap for `tri3`. A live tri3 endpoint is composable when natural return is at least 0.60 and absolute recombined-minus-natural return is at most 0.02. This is a capacity-scaling and action-timing experiment, not a claim that a nine-symbol code is natural language.
