# 接收者角色交叉：新学习者适应结果与下一步

## 研究问题

前两轮在同一架构中比较了新接收者 A 与已训练的 B/C，但 A、B、C 的模块历史不同，因而不能把差异归因于“接收者角色”本身。本轮在同一已审计的 `altpair_001` 完整策略上分别替换 A、B、C：每个角色都插入同一个规则下生成的全新三模块学习者，另外六个模块逐参数冻结。这样比较的是被替换位置在同一任务协议中的适应结果。

本轮仍是任务协议实验。它测量新学习者能否利用现有跨主体包来提高任务表现，不测量词素、公共词典、组合语法或人类语言起源。

## 冻结设计与执行

- 8 个独立源种子（66701–66708）× 3 个被替换角色（A/B/C）× `static/rematched` × `live/silent`，共 96 次训练。
- 每个角色臂使用相同的源 checkpoint、相同的新三模块初始化、相同的 batch／世界／消息／重配随机流；`live` 与 `silent` 共享初始化和训练流。
- 只更新被替换角色的 `sender1`、`sender2` 和 `action` 模块；其他六个模块始终冻结。每次训练 6,000 步、batch 256，保存 0/100/500/1500/3000/6000 六个 checkpoint。
- 监测使用两个固定训练布局，终点使用六个留出布局。主要读数是按种子统计的 `live−silent` 团队 Q 率和监测 Q 中心化时间 AUC；static 与 rematched 先分开报告。
- 首次生产执行的 96 个 worker 输出全部完成，原失败只发生在最后的返回顺序检查。权威批次 `role_crossover_003` 从已完成输出恢复并按冻结的 run 顺序重新组装；没有修改 checkpoint 或训练日志，也没有重新训练。

独立审计不导入生产结果，重放了 576 个 checkpoint 评价和 96 个终点评价，共 10,782,720 个监测世界、5,391,360 个终点世界和 145,566,720 次模块前向；配对日志、冻结角色、跨角色随机流和源 checkpoint 绑定均通过，`max_abs_error=0`。训练预算另记录为 576,000 次优化更新和 2,654,208,000 次训练模块前向。

## 主要结果

单位为百分点；区间为 8 个独立源种子的 t(7) 区间。

| 被替换角色 | static Q AUC | rematched Q AUC | static 终点 Q | rematched 终点 Q |
|---|---:|---:|---:|---:|
| A | +26.493 [+20.105, +32.881] | +17.476 [+4.913, +30.040] | +26.097 [+19.436, +32.757] | +25.879 [+16.969, +34.789] |
| B | +17.976 [+9.202, +26.750] | +18.671 [+12.698, +24.643] | +24.231 [+15.428, +33.034] | +24.322 [+16.458, +32.187] |
| C | +19.769 [+15.767, +23.772] | +20.380 [+15.461, +25.299] | +22.121 [+16.817, +27.424] | +19.076 [+11.050, +27.102] |

六个角色×日程单元的 Q AUC 区间都高于零，说明在这个固定任务中，新学习者通常能从 live 包中获得额外的团队 Q。把每个 seed 的两个日程先平均后比较角色，B−A 的 Q AUC 为 **−3.662 pp**（t(7) CI [−12.065, +4.742]），C−A 为 **−1.910 pp**（[−10.207, +6.386]）；终点 Q 差分别为 **−1.711 pp**（[−14.830, +11.408]）和 **−5.389 pp**（[−13.966, +3.188]）。角色差异区间都跨零，当前没有稳定的角色特异性适应优势。

## 机制分解

live 优势主要来自物理执行率，而非执行之后的内容选择。静态日程下，A/B/C 的 Q AUC 分别为 +26.493/+17.976/+19.769 pp，物理执行 AUC 分别为 **+68.028/+48.766/+55.276 pp**，条件 Q AUC 分别为 **+9.075/−16.966/−6.437 pp**。三个角色的终点目标搭档率变化分别为 **−15.598/−12.761/−14.213 pp**；重配日程也保持负值（A/B/C 为 −15.619/−15.304/−12.916 pp）。因此 Q 的正增益不能解释为新学习者已经稳定恢复了目标搭档或方案内容。

这轮把上一轮 A 与 B/C 的差异收窄为角色历史问题：当初始化、父代、预算、世界和消息流被配平后，A、B、C 的 live 通道收益相近。它支持“现有包能帮助新主体学会更常执行某种可行行为”的任务性结论，但没有证明包中存在可跨情境复用的词义或组合语法。

## 解释边界

角色交叉只识别了当前 `altpair` 任务、当前 PL 观察和当前严格结算下的适应差异。它没有区分“没有形成约定”“接收路径没有使用约定”“训练目标没有奖励内容传递”以及“行动空间仍允许靠固定或偏置方案取得部分 Q”。`live−silent` 是通道收益，不是语言能力量尺；`target_pair_legal_rate` 的下降尤其说明不能用未条件化 Q 代替内容选择读数。

## 下一步

下一项做同一 96 个终点策略的角色分层 `aligned/placebo` 探针：沿 `kind`、`length`、`destination` 三条需求轴构造同背景源端消息移植，并在相同发送者×轴×背景层内循环错配 placebo。首要读数为每个角色的 `aligned−placebo` 计划转移及其 `rematched×communication` 交互，同时保留物理执行、条件 Q、搭档转移和动作改变率。只有当某个角色在独立方向、placebo 和至少一种消息重编码下仍有稳定的源端内容增量，才值得把训练目标改成显式内容协商，或再进入代际传递。
