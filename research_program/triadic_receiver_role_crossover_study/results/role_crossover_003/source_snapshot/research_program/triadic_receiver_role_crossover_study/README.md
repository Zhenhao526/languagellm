# Receiver-role crossover study

This study replaces A, B, or C in the same audited full-combination policy
with the same fresh three-module learner. The other six modules remain frozen.
Each role arm uses the same source checkpoint, fresh initialization, world
streams, message streams, and rematching assignments, paired across live and
silent channels. The final result will compare adaptation by receiver role;
it does not claim lexical meaning or language origin.
