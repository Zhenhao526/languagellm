# 接收者角色交叉：独立源种子确认结果与下一步

## 研究问题

第一批角色交叉训练把 A、B、C 的替换位置放到同一父代策略、初始化和随机流下，发现三个位置都能从 live 包中获得 Q 增益，而角色差异区间跨零。本轮使用独立源种子 66709–66716 完整重做同一设计，检验这个任务性结论及其机制是否稳定。

每个角色臂都从同一已审计的 `altpair_001` 源 checkpoint 插入同一规则生成的新三模块学习者；另外六个模块逐参数冻结。`live` 与 `silent` 共享初始化、世界、消息和训练随机流，只更新被替换角色的 `sender1`、`sender2` 和 `action` 模块。

本轮测量的是当前任务协议下新主体利用既有跨主体包的适应，不测量词素、公共词典、组合语法或人类语言起源。

## 冻结设计与审计

- 8 个独立源种子（66709–66716）× 3 个被替换角色（A/B/C）× `static/rematched` × `live/silent`，共 96 次训练。
- 每次训练 6,000 步、batch 256，保存 0/100/500/1500/3000/6000 六个 checkpoint；终点使用六个留出布局，主要读数为按种子统计的 `live−silent` 团队 Q 率和 Q 中心化时间 AUC。
- 独立审计重放 576 个 checkpoint 评价和 96 个终点评价，共 10,782,720 个监测世界、5,391,360 个终点世界和 145,566,720 次模块前向；配对流、冻结角色、跨角色流和源 checkpoint 绑定均通过，`max_abs_error=0`。
- 训练预算记录为 576,000 次适应优化更新和 2,654,208,000 次训练模块前向；审计没有调用外部模型、LLM 或视觉模型。

## 主要结果

单位为百分点；区间为 8 个独立新源种子的 t(7) 区间，static/rematched 分开报告。

| 被替换角色 | static Q AUC | rematched Q AUC | static 终点 Q | rematched 终点 Q |
|---|---:|---:|---:|---:|
| A | **+16.341** [+6.007, +26.675] | **+21.198** [+14.536, +27.859] | **+24.782** [+16.866, +32.698] | **+24.060** [+17.813, +30.307] |
| B | **+19.718** [+12.192, +27.244] | **+15.171** [+5.687, +24.655] | **+28.430** [+20.362, +36.499] | **+26.178** [+20.497, +31.860] |
| C | **+18.139** [+10.853, +25.425] | **+13.726** [+10.221, +17.231] | **+19.669** [+11.530, +27.808] | **+17.029** [+9.140, +24.918] |

六个角色×日程单元的 Q AUC 区间均高于零。每个 seed 先平均两个日程后，B−A 的 Q AUC 为 **−1.325 pp**（[−10.752, +8.102]），C−A 为 **−2.837 pp**（[−9.306, +3.632]）；终点 Q 差分别为 **+2.883 pp**（[−8.435, +14.201]）和 **−6.072 pp**（[−17.198, +5.053]）。角色差异区间均跨零，独立批次没有给出稳定的角色特异性 Q 优势。

## 机制分解

与第一批一致，live−silent 的 Q 增益主要伴随物理执行率上升，而不是执行之后的条件 Q 稳定上升。Q AUC 与物理执行 AUC（pp）如下：

| 角色 | static Q / physical | rematched Q / physical |
|---|---:|---:|
| A | +16.341 / +46.012 | +21.198 / +62.456 |
| B | +19.718 / +52.530 | +15.171 / +44.028 |
| C | +18.139 / +48.216 | +13.726 / +48.117 |

static 条件 Q AUC 为 A/B/C 的 +6.291/−6.600/+17.365 pp，rematched 为 +2.076/−15.624/−11.871 pp。终点目标搭档合法率变化在六个角色×日程单元均为负，A/B/C 的 static 变化为 −13.995/−13.264/−11.848 pp，rematched 为 −14.610/−15.417/−11.002 pp。因此未条件化 Q 的正增益不能解释为新学习者已经恢复了目标搭档或源端方案内容。

## 解释边界

独立源种子确认了“既有包能帮助新主体学到更多可执行行为”的任务性现象，但没有确认角色位置本身会产生稳定的 Q 适应优势。当前 `live−silent` 仍是通道收益，不能作为语言能力量尺；目标搭档率下降也说明不能用团队 Q 代替内容选择读数。

这个批次与第一批共享架构、任务协议和源实验族，因而适合做独立源种子复现，不应表述成跨架构或跨环境泛化。角色分层的 aligned/placebo 内容探针已在本批终点上完成，独立确认报告见下一份记录。

## 下一步

1. 把两批角色交叉训练结果并列汇总，保留源种子区块和机制读数，不把跨区块汇总当作新的预注册推断。
2. 继续分析本批的 aligned/placebo、单槽替换、符号双射和 closed-channel 对照；优先检验内容转移而非 Q 增益是否在重编码后保持。
3. 只有内容转移在角色、重编码和通道对照下都稳定，才进入带持久库存与代际传递的形成实验。
