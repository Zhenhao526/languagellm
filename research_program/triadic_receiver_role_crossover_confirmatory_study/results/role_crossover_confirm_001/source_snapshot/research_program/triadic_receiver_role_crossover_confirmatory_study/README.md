# Receiver-role crossover confirmatory study

This confirmation uses the independent source-seed block 66709–66716. It
replaces A, B, or C in the same audited full-combination policy with the same
fresh three-module learner; the other six modules remain frozen. Each role arm
uses the same source checkpoint, fresh initialization, world streams, message
streams, and rematching assignments, paired across live and silent channels.
The result tests whether the role-stratified content-transfer difference
survives a new source-seed block; it does not claim lexical meaning or
language origin.
