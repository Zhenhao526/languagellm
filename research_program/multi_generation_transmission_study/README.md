# Two-generation protocol transmission

This study follows a staged `dual2` protocol through two sequential replacement events. It keeps the nine parent seeds that passed the earlier compositionality rule and compares `worker_then_sender` with `sender_then_worker`, each with paired live and silent branches. The second event starts from the first event's final parameters, so the design measures path-dependent transmission rather than independent retraining.

The compact archive reports held-out natural return, silent and scrambled controls, slot recombination, sender codebook fidelity and stage-to-stage transitions. It contains no raw training logs or checkpoints; those files were temporary inputs to the independent replay audit.
