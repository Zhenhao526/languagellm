# Factorized neutral aligned/placebo transfer probe

This is a post-hoc probe over the audited frozen policies in
`triadic_factorized_neutral_altpartner_study/results/altpair_001`. Each probe
case changes one sender's private need to a same-context kind, length, or
destination neighbor. The aligned condition inserts the sender's first-window
packet from the changed need into the receiver world. The placebo condition
uses a cyclic donor packet from another case with the same sender, changed
axis, and physical background, preserving the message marginal while breaking
source-need alignment.

The receiver's legal two-plan set is held fixed for settlement and the aligned
donor's legal two-plan set defines donor-only versus receiver-only plan mass.
This gives an aligned-minus-placebo content-transfer readout, separate from
physical execution and neutral/engage selection. Static/rematched and
live/silent policies are evaluated for all 16 seeds. No training or optimizer
updates occur.

The primary statistic is the rematched-by-communication interaction on
aligned-minus-placebo signed plan transfer:

```text
[(rematched live − rematched silent)
 − (static live − static silent)]
```

The claim boundary is causal task sensitivity in a frozen strategy, not word
meaning, compositional syntax, intergenerational transmission, or human
language origin.
