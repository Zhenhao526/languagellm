# 因子化中性行动 aligned/placebo 消息转移

## 研究问题与设计

因素留出任务中的 aligned−placebo 读数接近零，一个可能原因是唯一合作动作和整包搭档约束把执行变化与内容变化混在一起。本轮把同一读数放到已经冻结的“两个可替代搭档 × 显式 neutral/engage”策略上：每个世界有两个不同搭档对的合法完整方案，行动内容和是否参与由不同头输出。数据来自 `altpair_001` 的 16 个种子、static/rematched × live/silent 四格，共 64 个冻结策略，没有重新训练。

每条案例保持公共布局、私有站点所有者和接收者需求不变，只把一个发送者的个人需求替换为同上下文的 kind、length 或 destination 邻居。aligned 使用该邻居需求在相同背景下产生的源端首窗消息；placebo 在相同发送者×变化轴×背景层内循环错配另一条源消息，因此保持消息边际和案例难度而破坏源端需求对应。每个策略有 76,032 条有向案例（2,112 个需求—发送者—轴边 × 36 个背景）。

内容读数是相对于目标自然行动的带符号合法方案质量转移：源端需求独有方案的概率质量减去接收端需求独有方案的概率质量，再减自然值。aligned−placebo 是主要对照。另存物理执行率、团队 Q、执行后条件 Q、行动改变率和搭档转移；搭档转移在单轴邻居中理论上应为零，因为合法搭档集合保持不变。

## 结果

下面的均值先在 kind、length、destination 三个轴内等权，再对 16 个种子汇总；区间是种子层描述性 t(15) 区间，单位为百分点。

| 训练安排 | 通道 | aligned plan transfer | placebo plan transfer | aligned−placebo |
|---|---|---:|---:|---:|
| static | live | +22.2152 | +10.8697 | **+11.3456** [+8.1997, +14.4914] |
| rematched | live | +19.4944 | +10.0071 | **+9.4873** [+6.5693, +12.4054] |
| static | silent | 0.0000 | 0.0000 | 0.0000 |
| rematched | silent | 0.0000 | 0.0000 | 0.0000 |

aligned 消息因此比同边际 placebo 更频繁地把行动概率推向源端独有方案。该效应在三个轴都为正：static 的 kind、length、destination 分别为 +9.2586、+12.1185、+12.6596 pp；rematched 分别为 +9.5692、+8.4712、+10.4215 pp。它不是搭档边响应，因为单轴变化没有改变合法搭档集合。

预先规定的重配×通信交互为

```text
[(rematched live − rematched silent)
 − (static live − static silent)]
```

对 aligned−placebo plan transfer 为 **−1.8582 pp**，t(15) 区间 **[−4.1845, +0.4680]**。同一交互的物理执行率为 −2.1960 pp（[−4.5991, +0.2070]），团队 Q 为 +0.4699 pp（[−0.9820, +1.9217]），执行后条件 Q 为 +1.8221 pp（[−0.5065, +4.1508]），行动改变率为 +0.4017 pp（[−1.6638, +2.4673]）。因此随机重配没有可靠地增强消息的方向性内容响应。

## 审计与边界

独立审计没有导入 `probe.py`，重新载入 64 个最终 checkpoint，构造自然消息库，重算 aligned/placebo 的 W2、因子化行动、合法计划质量、严格结算和每个 sender×轴组的统计。审计重放 4,866,048 条案例、2,433,024 条 live 干预，核对 64 个 checkpoint 和 76,032 个 placebo 映射，`max_abs_error=0`。三名发送者的自然消息 sham 在每个 live 策略上动作和概率逐项相等。

这项结果比单纯的执行率更接近内容可识别性：同一背景中，源端需求变化携带的首窗消息使接收者向源端独有方案移动，而同层错配消息的转移较小。但它仍是对既有策略的后验干预，消息、动作空间和奖励由研究者预设，邻居需求来自训练支持集合，且每个世界只有两个合法方案。它没有证明单符号词义、可组合语法、跨搭档公共词典、代际传递或人类语言起源。

## 下一步

1. 在新独立种子上预注册同样的 aligned/placebo 计划转移，并把 source message 改为单发送者单槽位，检验方向性是否由整包替换驱动。
2. 加入 full-information、closed-channel 和固定符号重编码对照，区分接收者利用源端信息、整包编码扰动和可见性本身。
3. 在训练中随机化需求和搭档，使 aligned−placebo 读数不依赖冻结策略的后验邻居；只有在新群体上复现且跨未见组合保持正向，才进入新主体或代际传递。
