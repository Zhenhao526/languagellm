# 因子化中性行动 aligned/placebo 消息转移

在已审计的 `altpair_001` 冻结策略上，对同背景的个人需求邻居做源端首窗消息移植，并与同发送者×变化轴×背景层内循环错配的 placebo 比较。64 个策略块、4,866,048 条案例经独立复算通过；static/rematched 的 aligned−placebo 计划转移分别为 **+11.3456 pp** 和 **+9.4873 pp**，重配×通信交互为 **−1.8582 pp**（t(15) CI [−4.1845,+0.4680]）。

该结果表明多合法行动生态中可以测到方向性内容响应，但不支持随机重配增强这一响应，也不等于词义、组合语法或语言起源。完整记录见[`结果与下一步.md`](结果与下一步.md)，机器结果见[`results/summary_semantic_transfer_002/汇总表.md`](results/summary_semantic_transfer_002/汇总表.md)。
