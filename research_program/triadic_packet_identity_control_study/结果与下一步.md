# 包身份控制：端点置换产生了稳定的响应选择性

这轮实验检验上一轮四选一内容探针中的一个关键混淆：实时响应是否真的跟随供体端点，还是只对某个包的位置或字符串产生反应。实验复用已经完成的64条形成策略，不新增训练；每个实时控制只替换首窗中指定发送者的对外包，然后重算W2和三个人的行动头。静默条件继续使用自然行动概率作为不可见别名。

静态案例沿用 `new_needs_and_layouts` 的48组、36个背景、4个端点和16个宿主—供体格。端点循环控制（`endpoint_cycle`）把供体端点 `d` 的包换成同一组、同一背景的 `d+1` 包。跨组控制（`cross_group_cycle`）把包换成同一发送者—接收者×种类／长短层中下一个组的同端点包；它改变第三人需求和接收者锚点，保留发送者、接收者及大类层。两种映射均在读取策略前静态确定，所有17个行动概率都保留。

边际仍定义为

`M = p_receiver(a_d | host e, packet d) − max_{v≠d} p_receiver(a_v | host e, packet d)`，

先在每个组—背景的12个非对角格内平均，再对12个层等权。主要选择性量是每个种子、每条执行规则的自然同组实时基线 `M` 减去控制 `M`，最后平均strict和reciprocal。正值表示替换包后目标候选边际下降；它是包端点特异性的行为指标，不等于词义或语言。

运行覆盖16个配对初始化、4个策略条件、2个控制和6个检查点，共768条策略—时间记录；384个实时探针文件包含10,616,832行，另有384个静默别名。实时前向只来自控制探针，共63,700,992个模块样本；没有训练更新。

主要结果是端点循环选择性。strict为 **+25.5776 个百分点**（近似t15区间 **[+20.5624,+30.5928]**），reciprocal为 **+20.6793 个百分点**（**[+14.7840,+26.5745]**）；把两条规则在每个种子内平均后为 **+23.1284 个百分点**，区间 **[+18.7495,+27.5073]**。16个种子全部为正。端点循环和跨组循环的差值为 **+23.3344 个百分点**，区间 **[+19.0203,+27.6484]**，也是16个种子全部为正。

跨组循环的同组基线减控制值接近零：strict为 **−0.3866 个百分点**（区间 **[−1.3277,+0.5544]**），reciprocal为 **−0.0253 个百分点**（**[−0.4940,+0.4434]**）；两条规则平均为 **−0.2059 个百分点**（**[−0.7434,+0.3315]**）。这说明在本任务和本层定义下，响应的显著变化主要发生在同组四端点之间的置换，而不是来自把包移到相邻内容组。端点循环时目标动作概率和全17动作命中率也同步下降；因此这轮比上一轮的M交互更接近“包端点特异的因果响应”，但仍不能排除离散包查表或固定位置触发。

这轮结果支持一个有限结论：形成后的策略在首窗包被换成同组另一端点时，接收者的四候选反事实响应会系统性下降，而跨到同层另一内容组基本保持原有响应水平。它尚未证明包内符号具有可组合的公共意义，也没有证明形成了语言；此前的M交互仍然不能被改写成词义证据。

下一步按区分力排序：

1. 在同一冻结案例上做全局符号置换、逐位置置换和包内顺序置换，区分“端点身份”与“特定离散字符串／槽位”。
2. 对每个新初始化预注册目标动作概率、四候选命中率、全17动作命中率，以及未见过的端点—属性组合泛化；把端点循环和跨组循环作为固定阴性／结构对照。
3. 在新的任务生态中重复控制，逐步改变端点数、属性交叉和行动依赖；只有当响应能跨背景、跨组合保持，并且对符号重编码具有预期不变性时，才讨论词典或组合性。
