# 贪心覆盖 U 的解释边界与连续概率参照

2026-09-15，策略增益实验训练期间新增的讨论。以下是后续纯数值诊断建议，**不属于本轮预登记指标**，没有应用于当前已保存 logits，没有产生任何新的测量结果，也不修改当前 J／U／N、早期 AUC 或停止规则。应先完成 64 组既定读数，再决定是否另行冻结、完整执行这个补充分析。

## U 的收缩说明什么

固定一个接收者、检查点及空库存／历史上下文，令地图为 \(x=(f,w)\)，其中食物、水位于不同地点；完整消息集 \(\mathcal M=\{0,\ldots,6\}^2\)，共 49 个码。接收者对目标 \(g\in\{F,W\}\) 的六地点 logits 为 \(\ell_{m,g,s}\)。当前量是

\[
U(x)=\mathbf1\{\exists m\in\mathcal M:
\arg\max_s\ell_{m,F,s}=f\ \land\ \arg\max_s\ell_{m,W,s}=w\}.
\]

本轮要求两类目标的最大值唯一。U 衡量当前**贪心决策规则**的完整码覆盖；它不衡量概率有多集中，也不是符号信道的固有容量。某目标的第一、第二名仅差很小时，微小变化也可改变码的对应地点。地图是否有至少一个码是离散判定，最后一个正确码消失会使 U 从 1 跳到 0。

所以随机起点较高的 U、随后 U 收缩，既可能包含实际贪心可用映射的改变，也可能包含接近并列的排名翻转。两者并不互斥。仅从 U 曲线不能判定变化是否伴随相应概率质量的大幅流失；当前实际 logits 的边距及连续概率变化尚未在本文计算，不能直接宣称已经发现阈值伪影。低 N 同样不能单独定位接收者、发送者或视觉识别的内部原因。

## 一个固定完整码的连续成功概率

首先固定温度 1，与原 `draw` 的 softmax 意图一致：

\[
p_g(s\mid m)=\frac{\exp\ell_{m,g,s}}{\sum_{r=0}^{5}\exp\ell_{m,g,r}},\qquad
c_m(x)=p_F(f\mid m)\,p_W(w\mid m),
\]
\[
C(x)=\max_{m\in\mathcal M}c_m(x).
\]

这里两目标必须使用**同一完整码**。不能改为 \(\max_m p_F(f\mid m)\times\max_m p_W(w\mid m)\)，后者允许为两个目标选不同的码，会高估共同消息的能力。C 是可针对真实地图选择最优完整码时的接收概率上界，不保证冻结发送者能识别该地图、会产生这个码，或训练曾使用过它。最大化可以选择不同地图的不同码，但不能根据接收者本次私有目标或菜单临时换码。

最大化有限个连续函数使 C 关于 logits 连续，但在最优码切换处未必可微。它仍依赖 softmax 的尺度：所有 logits 同乘正数不改变理想精确计算下的 U，却会改变 C。因而它应作为概率质量参照，与 U 并列；不能更名为“真正的覆盖率”或经校准的真实成功概率。

## 两个概率何时可以相乘

相乘要求：给定同一实际消息、固定权重／上下文及两个目标，接收者两次行动采用条件独立的抽样；第二次不读取第一次动作或反馈，也不更新库存、记忆或地图。当前 [rollout](../../redesign_v0.8/run_experiment.py) 复用同一消息，两个查询连续消费不同随机数且无反馈；[receive](../../redesign_v0.8/camp.py) 的菜单仅在最终 logits 做 gather，因此在精确概率计算下，置换菜单不改变物理地点概率，即使分数并列也如此。

这个结论是对策略声明的独立 categorical 抽样分布而言。实际程序由有限精度伪随机数实现；未来分析必须明确数值精度与一致性容差，不能把解析期望声称为逐字节重现一次随机抽样结果。

若未来加入轮间记忆、看得到的首次动作、反馈或共同隐含随机变量，不能直接乘两个无条件边缘概率，应使用链式条件概率。例如先取食物时，联合成功为 \(P(A_F=f\mid m)P(A_W=w\mid m,A_F=f)\)。若菜单进入接收者内部而非只做末端重排，还应明确菜单分布，以及最优码在菜单揭示前还是后选取；不能先逐私有菜单最大化再称其为同一个可用消息。

## 与自然消息、U 和 stochastic 模式的区别

设照片对为 z，\(m_G(x,z)\) 是冻结发送者按当前逐符号贪心方式生成的一条实际码。它是贪心解码输出，不应未经核对称为整条消息概率的全局最大值。连续的自然使用参照为

\[
E_G(x,z)=c_{m_G(x,z)}(x)\le C(x).
\]

E_G 固定发送者的实际贪心码，只对接收者两次独立抽样求期望。当前 N 则对这同一码的两次**贪心**行动给 0／1 成功判断。平均 E_G 与平均 C 可使用同一固定地图／照片分布，但地图 C 不应因重复 16 张照片而获得 16 份独立样本。

原 `stochastic` 模式同时随机发送和随机接收，因而相应期望是

\[
E_S(x,z)=\sum_{m\in\mathcal M}\pi_S(m\mid x,z)c_m(x)\le C(x).
\]

发送者是自回归的两符号生成器，\(\pi_S(m_1,m_2\mid x,z)=\pi_S(m_1\mid x,z)\pi_S(m_2\mid m_1,x,z)\)。已保存的贪心消息及接收 logits 足以计算 E_G 和 C，却不足以重建完整的 \(\pi_S\)；一条被抽到的消息也不是该分布。stochastic 的实际 J 是这类期望的抽样实现，评价照片又与固定 16 对探针不同，因此不能把 stochastic J 直接等同 E_G，或把其与 C 的差全部解释为发送者选码问题。\(E_G\) 和 \(E_S\) 之间也没有一般大小关系。

如实际通道封锁为 00，合法码集合必须改为 \(\{00\}\)，相应参照只有 \(c_{00}(x)\)。49 码 C 此时只能另列为未封锁的反事实；随机重排消息则还需按真实投递分布计算，不能直接套用自身原始发送分布。

## 几个有用但有限的数学界

在六地点、唯一最大值和精确实数 softmax 下：

- \(U(x)=1\Rightarrow C(x)>1/36\)：同一码下，每个目标的唯一最大概率都大于 1/6。
- \(C(x)>1/2\Rightarrow U(x)=1\)：乘积大于 1/2 时，两个概率分别都大于 1/2，故各自必为唯一最大。
- \(U(x)=0\) 时 \(C(x)<1/2\)，但可以接近 1/2：一个目标概率略低于另一个竞争地点、接近 1/2，另一个目标概率接近 1。由此可见，U 为 0 不代表抽样联合成功接近 0。
- U 为 1 时，两目标概率仍可仅略大于 1/6，C 接近 1/36。高 U 不意味着已形成高置信的接收约定。

有限 logits 的精确 softmax 各项均正，所以 C 不会严格等于 0；数值下溢产生的 0 不能当作结构上的不可能。若所有 logits 差缩向 0，C 趋向 1/36，而非证明某地图语义已经可达。若放大 logits，唯一最大决定的贪心结果会逐渐主导概率；这些尺度性质进一步说明 U 与 C 回答不同的问题。

这些数学关系已由另一代理独立检查，未使用新结果或运行指标。它们不提供本批曲线的实证结论。

## 后续如何检查而不改当前结论标准

如完整既定结果使这一问题值得追查，可先单独冻结：温度 1、固定浮点精度、稳定 log-softmax、原 64×8×2 全部记录和同一照片集合，完整计算 C／E_G，不以 U 跌幅挑种子、检查点或地图。利用已保存 logits 和每照片码即可纯数值完成，不需要新增模型前向。建议同时保存获选完整码及差距 C−E_G；该差是给定接收者、已知真地图的最优码与实际贪心码之间的概率差，不是独立估计的因果中介。

如需要检查小边距，还应先规定其定义和汇总，避免见到曲线后挑温度或边距阈值使某种解释成立。若 C 变化小而 U 大幅变化，可支持“贪心读数对排序敏感”的描述；若二者均下降，可说明该下降同时涉及概率质量。两种结果都不能单独排除信号使用、优化器、探索或表征变化。当前注册的 U 仍保留原义和原始数值，连续参照应明确标为补充诊断。
