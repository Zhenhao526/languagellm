# 共享物资信息与三人需求表达：固定实验方案

本轮在新模型初始化和成绩读取前固定任务、主要量、拆分、训练预算与评价。上一轮合法答案数量不等及各内容轴成绩已知，故新任务受开发发现启发；新初始化和新留出不等于独立实验室确认。本方案不以“环境影响语言”或更换采集任务宣称方法首创。

## 问题与干预

检验：个人需求保持私有时，公开完整物资布局是否改变新符号对需求内容的适切表达及其形成轨迹。所有条件面对完全相同的需求、布局、正确共同方案、17个动作、原R和外生随机流，只改变可见信息和是否收到他人消息。

- `LL_silent / LL_live`：旧局部物资观察，每人见公共S0及自己的私有地点，个人需求私有。
- `PL_silent / PL_live`：每人见全部四处物资，个人需求仍私有。
- `FI_silent / FI_live`：物资与所有个人需求均可见，作为能力和协调参照。

公开物资信息既增加共同知识，也减少必须经消息传递的观察信息；这不是同时固定信息量和推理难度的“纯依赖效应”。任务真值、每个完整世界的17³联合动作收益和目标角色在六组完全相同。不同内容轴虽都只有1个正确动作，也未被证明计算难度相同。

## 环境与表达需求

保留三主体A/B/C、四物资位置、木／纤维×长／短四种物资各一件、左右目的地。行动仍是等待，或选择位置、目的地与搭档的16种运输动作；必须两人互指、同位置／目的地、第三人等待。满足一人的R=0.5、满足两人的R=1，其余为0。失败行动保留完整菜单，不在部署中删除或按正确性重新排序。

资源需求从木、纤维、短、长四种接受谓词扩为八种，新增木短、木长、纤维短、纤维长的联合要求；目的地仍为L、R或均可，共24种个人需求。只使用全部24³表中恰有一个满分共同方案的5,376种需求关系，不按模型成绩筛选。它们在所有24布局和6种私有观察归属下都有唯一满分共同动作，共774,144世界。全信息见证只供环境核查，不给学习者。

旧规则下，保持搭档的单项需求变化使对象／长短／目的地的正确听者行动数必为1／1／2，单靠布局或需求重加权不能消除。新增联合谓词后，预定内容案例三轴两端均为1。没有把所有需求都替换为精确物资，否则会消除某些单属性内容对比。

54维输入来自官方逐主体观察：每人的需求为known位＋2个种类接受位＋2个长短接受位＋2个目的地接受位，共21维；地点物资20维、归属9维、自身身份3维和FI控制位1维。未知需求／物资的字段全零。没有全局need ID、场景ID、目标方案、正确动作、伙伴答案或组别奖励表进入观察。该接受集编码提供显式属性结构，是所有本轮条件共有的表示偏置，不能叫无任何先验的语言起源。

## 留出、抽样与形成轨迹

需求表按主体置换、种类值翻转、长短值翻转、种类／长短因素互换和L／R互换的96种变换形成轨道。以轨道canonical最小表和固定字符串`action_dependency_need_split_v1`计算SHA排序，前ceil(轨道数/4)个轨道留出，其余训练。全部个体24需求须在两部分各主体中出现，主体／属性对称性须保留。

这留出的是三人的需求关系结构，不是某个个体的木×短×R值组合从未出现；不将新需求表答对直接称组合语法。24布局用固定字符串`action_dependency_layout_split_v1`的SHA排序，前6留出、其余18训练，六种观察归属全保留。得到train、new_needs、new_layouts、new_needs_and_layouts四分区，全部关系／布局笛卡尔积保留。训练均匀独立抽取训练需求、布局、归属，六条件逐批完全配对。

0/100/500/1500/3000/6000六检查点保存参数、优化器和随机状态。形成监测为各分区全部需求×两种固定背景：按字符串`action_dependency_monitor_background_v1`对布局／归属排序，取前两个不同布局的背景。这样所有预定内容对子在监测中都有两端；曲线只代表这两背景，不能当全域轨迹或精确起源时刻。此前1024个散点监测构想在冻结前撤换，因为不能保留充分的成对端点，没有执行旧构想。6000步另评全部774,144世界。

## 主要量与辅助量

**唯一主要量：**6000步、`new_needs_and_layouts`中，内容两端均适切的三轴宏均值，比较`PL_live − LL_live`，报告四个配对种子与等权均值。内容对子只有一个发送者的一项需求变化，听者自身观察（PL/LL）、参与身份与所需搭档不变，两个端点唯一正确行动不同。两个需求端点都必须属于指定分区，所有背景与失败保留。

对象、长短、目的地先各占1/3；每轴再对六有序发送／听者组合等权，组内案例均匀，背景均匀。参与↔等待案例单独按它们实际覆盖的轴配平，不混入内容主量。正确动作须按实际布局重算，不能把规范布局位置当实际答案，不能按已学固定伙伴筛选分母。监测用相同案例和两个固定背景计算，完整终点用全部背景。

PL/LL静默在听者自身观察不变且两端正确动作不同的内容对中，greedy两端均适切结构为0。因此不把它写成额外独立实验发现，也不把以该零构造的内容差中差另算效应。全域均匀任务上无通信正确角色最优在[1/3,31/84]，公开／私有物资条件相同；前者为固定pair可达下界，后者为仅凭own_need预测角色的单主体Bayes上界，尚未求精确最优。训练／留出需用各自need支持另算界；角色界不是完整物资行动或R最优。

辅助量全部保留：原生平均R、满分率、实际角色（含等待和具体搭档）、位置与目的地的分项和联合适切；三轴分项；四分区；FI参照；全部六检查点。全任务满分率的通信效应差`(PL_live−PL_silent)−(LL_live−LL_silent)`属于辅助读数，不取代主内容差。

每个live政策在所有保存评价点另从第一窗关闭他人通道，保留本人消息，重新生成两窗和行动。silent引用自然结果并明确标记，不重复计前向。关闭的分布变化不能直接证明词义。此批不追加逐字符筛选或新的远背景供体干预，成分复用与因果迁移需另行固定检验。

## 固定学习与执行

新初始化51101–51104；每个初始化运行FI_silent/FI_live/PL_silent/PL_live/LL_silent/LL_live六条件，共24次。九个独立MLP，无参数共享，保持原64×64隐藏层；每人两窗、每窗4位、8种符号。消息生成、两条轨迹的发送者估计、原生期望的log目标、Adam、学习率、熵日程与梯度裁剪全复用已有SHA绑定实现，不改变旧文件。

每次6000更新×256状态，共144,000更新、36,864,000训练世界抽样、73,728,000完整消息轨迹、1,769,472,000个离散符号抽样。4个spawn worker各串行六条件，CPU／BLAS1；初始化、逐批世界与12路消息随机流跨六条件相同。使用本地主Python3.12.14／NumPy2.5.3，不加载Qwen或DINO。

共144检查点、576自然监测文件、288实际关闭监测文件、96完整自然末点和48实际关闭末点。完整末点合计27,869,184世界、250,822,656网络样本前向；监测实际数量按固定spec另列prepared.json，不与训练或独立社会重复混计。完整消息、动作、概率、结算、状态索引和失败保存。角色或内容未提高不追加预算或替换初始化。

准备阶段只构造静态支持并绑定源码，不初始化模型。正式执行只启动一次，已存在execution目录拒绝覆盖或恢复；异常保留，等待超时不触发重启。数据／收益／编码／执行接口与测量先做纯测试，执行后独立核对训练抽样、参数SHA和完整末点前向、全部监测结算及主要统计。独立重算的预算另列，不声称重放优化器。报告与图表须保留负结果、结构零及适用范围，持续论文目标不因单次正结果自动完成。
