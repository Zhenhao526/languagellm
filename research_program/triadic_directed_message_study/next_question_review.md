# 候选后续问题：任务需要哪条通信路径，约定何时变得相互匹配

**状态：仅静态设计复核，未执行、未训练、未读取本轮新政策输出。** 本文件不进入本轮主实验冻结源，不改变已冻结的 L、案例、预算或报告顺序。依据为本目录的 `plan.md`、`design_review.md`、`cases.py`、`intervention.py`，以及已知的互选执行与两轮同步路由定义。这是 runner／干预模块作者另行完成的科学推理，不是独立作者对程序正确性的验证。

## L 与任务必要条件之间的距离

L 要求同一发送者的两种首窗包，在两个相反接收情境中，使两位接收者的“提议与发送者合作”概率分别朝兼容方向变化；每组、每背景的四个差取最小值。这个条件有明确用途：它限制某些固定身份指令、普遍抑制所能解释的结果。它也要求了任务并不必需的行为。

一个具体反例是：A 的需求在“短木材、送 L”和“短纤维、送 L”之间变化；B、C 分别需要这两种物资，另一个情境交换 B、C 的需求。B、C 始终提议与 A 合作，各自选择满足自己需求的公开物资地点和目的地。A 从 B、C 发来的消息获知其需求，选择兼容者及相应地点。互选的一对执行，第三人的未匹配提议被忽略。在这个四世界组中，策略可以全部成功，而 B、C 提议 A 的概率始终为 1；A 向外的首窗包可以完全没有作用，四个差和 L 都为 0。这里说的是一种允许的策略反例，不是对任何已训政策的描述，也不是声称它解决整个世界支持。

这说明至少有三种需要区分的情况：

- 私人需求经 B/C→A 传递，由 A 决定合作对象；A→B/C 的接收选择性不是必要路径。
- A 的包改变地点或目的地选择，却不改变“伙伴为 A”的总概率。L 把这八个行动加在一起，可能看不到这种内容协调。
- W1 的变化被 W2 补偿、覆盖，或只在原公开布局中有效。本轮同时限定了首窗路径与跨布局供体迁移，不能把其中一处不成立推广为所有通信无效。

因此，非正 L 只能限制冻结方案所问的较强选择性；正 L 也仍只是这条路径的证据。不能把 D、奖励变化或初始差值提升为替代主量，也不应为寻找正数而删去接收者、情境或背景。下面两个候选问题应先各自冻结，再观察其新干预结果。

## 候选一：同背景下对入向、出向首窗路径做交叉替换

**问题：合作主要依靠谁收到需求信息、谁据此选择搭档？** 使用现有四世界组、四个政策及完整原分区，先仅取最终检查点。对每个原受体世界固定三人观察、自身消息、可见性和公开背景，设置两个二元因素，形成四格：

1. 入向替换：把另外两人送给焦点 A 的 W1，换成“交换这两人需求”的同背景世界中的各自 W1；不改其自身消息或彼此之间的投递。
2. 出向替换：把 A 送给另外两人的 W1，换成 A 的另一需求端点的同背景 W1；A 看到自己的 W1 不变。

四格为原样、仅入向、仅出向、两者同时；全部同步重算 W2 和行动。供体均由原四世界组确定，不按成功、符号距离或消息是否变化选例。W1 对他人私人需求不敏感，因此两个因素的包来源可以明确分开；这里不移植带有他人首窗上下文的 W2。

预先保留完整响应向量：A 向哪位伙伴提议的概率、两位其他主体向 A 提议的概率、地点／目的地概率变化，以及互选执行和原生收益。入向因素的定向比较按“交换他人需求后 A 应选择的伙伴”标记，两种相反情境均保留；出向因素继续报告冻结方案中同类的兼容方向，不能只挑有利方向。原样格必须复现原生轨迹。四格的差与交互是这些具体消息替换的效应，不能直接叫作任务机制的因果分解。

若主要是入向替换改变 A 的搭档选择，而出向替换对其他人的伙伴提议影响很小，这与“由 A 汇总需求后选择”的机制相容。若伙伴总概率不变而地点／目的地改变，则提示当前 L 的聚合层次遗漏了内容协调。若两方向都明显依赖对方，则支持更分布式的协调。每一种模式都应包含反向案例、零作用和四种子的差异，不能只报告平均收益下降。

**仍然不能排除什么：** 替换可制造不一致消息；不同方向的符号扰动幅度不一定相同；W2 仍可能修复错误；仅有两个候选搭档时，泛化的扰动也可能产生貌似定向的转移。同背景对照消除了“供体跨布局”这一附加变化，却不能证明词义或语法。这个实验定位的是已形成政策中的功能路径，本身不展示约定怎样形成。它的价值在于避免把本来不必工作的方向当作形成失败。

## 候选二：已有检查点之间的发送包—接收计算交叉配对

**问题：首窗包和接收计算是否在学习期间逐渐形成相互匹配的对应关系？** 使用现成的 0、100、500、1500、3000、6000 检查点，不新增训练，不根据本轮 L 挑时点。对同一社会构造发送时点 `t_s` 与接收时点 `t_r` 的完整交叉矩阵。

每个受体使用 `t_r` 的原观察、自己的自然 W1、三个 W2 头和三个行动头；仅把跨人收到的 W1 改为相同世界下对应发送者在 `t_s` 生成的 W1。随后正常重算 `t_r` 的 W2 与行动。自身 W1 始终属于 `t_r`，以免把自己的符号计算格式变化混入跨人协议配对。`t_s=t_r` 的对角格必须复现各自原生政策。全部社会、时点和原四分区保留；新前向预算在执行前另算。

用事先固定的原生任务指标作兼容性读数，例如给定贪心消息的精确满分概率 `S(t_s,t_r)`，同时保留行动分布；不将其取代当前主量 L。固定接收时点比较不同发送时点，可以观察接收器是否依赖特定时期的消息；固定发送时点则观察这种消息是否逐渐可用。对预定的相邻时点 `t,u` 可报告配对对应项：

`C(t,u) = [S(t,t) + S(u,u) - S(t,u) - S(u,t)] / 2`。

它在代数上消去可加的发送端与接收端时点效应，但不消除非线性的能力差异。若只是晚期接收器在所有发送时点上普遍变好，更符合接收能力增长；若同期配对逐渐优于异期配对，则支持首窗消息与接收计算共同适配。旧包能够一直被后来的接收器使用，与早期对应逐渐稳定相容；明显跨期失配与对应关系漂移相容。这些都只是可区分的行为模式，不保证在现有政策中出现。

**仍然不能排除什么：** 异期包会改变接收器的输入分布；相配优势可能来自任意整包编码、符号频率变化或一般的网络共同适配，而非人类式约定。不同检查点并非随机分配的学习阶段，不能据矩阵推断哪一种训练事件导致某个符号意义。低任务能力也可能使整个矩阵缺乏辨别力，不能因此只选表现好的时点。

这个候选比单一终点更接近“形成过程”：它检查对应关系在何时出现、是否稳定以及后期接收器能否理解早期包。但它仍没有引入新的学习者，也不展示协商、社会传承或代际变化；这些问题需要另行固定实验设计及预算。

两个候选分别回答功能路径和时间上的相互适配。无论本轮 L 的方向如何，它们的价值都应由问题本身决定；它们目前均未执行，不构成对当前结果的补救或对语言产生的既成证据。
