# 单人需求变化的保存末点诊断

新规则政策确实能对部分局部需求改变作适当伙伴调整，但一致性有限。完整双留出双端均选对搭档的Q均值为18.6019%，背景内精确打乱参照为9.3122%；唯一诊断主量Q超额为+9.2897个百分点，四个既有种子均正。此处两端搭档正确不要求完整内容正确，不能当作满分率。

这项分析在看过总体能力结果后提出；案例定义在读取新Q聚合前固定，属于追加描述，不是独立确认。分析复用全部8个FI无通信政策×4完整分区的保存提议，0新增参数读取、网络前向或训练。两种政策都按共同reciprocal规则结算，另保留strict辅助结算。旧规则政策在共同reciprocal下Q全部为0，符合其固定搭档行为；新政策在strict下零分由第三人持续提议引起，不能误当需求表达失败。

案例仅改变一个人的材料种类、长短或目的地需求，另两人、布局和归属保持相同；两端正确执行搭档必须不同。四域分别有152928/36288/50976/12096对完整背景案例，三个主体×三个轴九层均非空，九层等权。所有未执行保留并计错。大量重叠案例不是独立群体样本；独立政策种子仍只有4个。

新规则Q在训练域、新需求、新布局、双留出分别为19.4248%、20.8547%、17.3297%、18.6019%。双留出不同主体×轴存在差异，例如57103的C长短层只有5.2083%，不能把总体正超额解释为全面一致的需求响应。所有层与失败保留在[完整JSON](results/response_001/result.json)。

打乱在每个固定背景的全部需求世界中无放回置换实际伙伴标签，保留各伙伴频数和不执行率；每边精确期望为n_t0*n_t1/[N(N−1)]。它不控制各人的自身需求条件，不是最优静默政策界或显著性检验。FI直接公开全部需求，故本结果不能说明通信，也不能说明词义、组合性或语言形成。

下一项实验保持reciprocal规则和任务，只比较私人需求下从头训练的开放/静默组；不以本诊断设门槛、挑种子或延训。其唯一主量为完整双留出Q_live−Q_silent。报告的语言能力解释需要随后通过消息内容干预和形成过程参照检验。
