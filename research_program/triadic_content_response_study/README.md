# 四选一内容响应探针

本轮对 `triadic_rule_formation_study` 的64条冻结策略做无训练反事实评价。接收者的PL观察、第三人需求、布局和私有站点在每组内固定；发送者的首窗W1包在四个单值需求端点间替换。实时条件只改指定发送者对外的W1投递，然后重算三人的W2和行动头；静默条件复用自然接收者输出，替换不可见且不做前向。

静态构造包含48组、36个公共背景、每组4个需求端点和全部16个主客体端点组合。12个发送者—接收者×种类／长短层各4组。唯一预注册主量是6000更新末点的四选一内容边际交互；完整17个行动概率、四候选命中率和所有背景／组层级均另行保存。

主结果的独立审计通过，但主量区间跨零，且M在四个条件均为负；因此本轮只支持“实时通信改变了有限候选行动的反事实响应”，不能称为形成了词义、公共词典或人类语言。下一步应加入随机重编码／包身份对照，并在训练时预注册内容可泛化检验。
