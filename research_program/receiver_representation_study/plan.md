# Receiver representation comparison

This study holds the staged dual2 parent sender, world, partner ecology, channel controls and leave-one-goal-out support fixed. It replaces worker 0 and compares two receiver state representations with the same parameter tensor shape:

- `joint_history`: the worker indexes the complete sequence of received slots;
- `slot_local`: at each subtask the worker indexes only the slot delivered for that subtask.

The leave-one-out arm removes one goal combination from child training. The held-out criterion is natural team return at least 0.60. A pass is finite-protocol zero-shot recovery, not open-ended language.
