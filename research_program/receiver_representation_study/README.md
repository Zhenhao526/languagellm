# Receiver representation study

This package tests whether the held-out-combination failure is caused by the receiver representation. It compares a joint message-history lookup with a slot-local lookup while holding the frozen parent sender, task, partner ecology, support mask and live/silent pairing fixed.

The formal archive contains compact metrics, source and dependency hashes, a parent status map, and independent replay audits. Raw execution trees are temporary.

See [the formal result report](receiver_representation_formal_结果与下一步.md) for the parent-stratified zero-shot result.
