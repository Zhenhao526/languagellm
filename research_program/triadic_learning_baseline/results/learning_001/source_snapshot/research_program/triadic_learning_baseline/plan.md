# 三主体完整信息可训练能力基线：固定计划

状态：设计与代码在首次正式训练之前写定；须完成独立奖励、梯度、信息边界和冻结核查后，由根任务启动。当前没有训练成绩，没有为本配置试训挑参数。既有Qwen能力与接口结果已知，本计划不是对那些实验的补写预注册。

## 问题及适用范围

在同一个 `research_program/triadic_task/environment.py` 一步生态中，三套独立随机初始化的小策略能否通过任务收益学会稳定的分工与共同搬运，并泛化到未训练的需求组合和物资布局？该问题首先检验此生态、完整观察和离散动作接口能否成为可靠的可训练能力基线。它不检验语言形成，也不比较哪种模型更擅长语言。

Qwen `interface_001` 两臂各4/12，不能靠继续改措辞来宣布原门槛通过。本轮更换了策略类别、训练方式、输入表示、输出实现与测试范围，因此不能把新旧分数的差异归因于其中一个因素。旧Qwen门槛保持原状。

环境不变：三人A/B/C，四个物资对象，每种kind×length组合各一个，四个位置S0–S3、两个目的地L/R，每人有对象属性与目的地需求。三人各自保留全部17个动作：等待，或4位置×2目的地×2其他搭档的运输。最多两人运输，D1要求两人互选对方且选同一位置和目的地。原生收益是两人需求满足数/2，可能为0、0.5、1。不增加加工、道路事件、唯一正确搭档、固定参与者或合法动作筛选。

使用既定996种有序需求表的开发域：每表至少有两对搭档在某种物资与目的地上可同时满足。布局含全部24种排列；公开的私有地点分配含全部6种排列。这个域不是所有1728种需求表，更不等于开放世界。对象及物资属性采用官方观察中的符号化字段，没有视觉骨干、自然语言理解或长期生存负担。

## 为什么采用精确期望策略梯度

只实施一个固定方法：三独立actor的精确期望策略梯度，加预先固定的熵退火。不实施同时比较的REINFORCE/actor-critic分支，也不根据结果切换算法。

三人策略为

\[
\pi(a_A,a_B,a_C\mid x)=\prod_{i\in\{A,B,C\}}\pi_i(a_i\mid o_i(x)).
\]

每个actor对完整17项做softmax。全联合空间有17³=4913项。D1中只有24种结构配置可能执行：3对搭档×4位置×2目的地，余下一人等待。其余4889种联合动作恒为0分。这里的24项不是按当期需求筛出的成功动作，其中仍可能为0、0.5或1分。

目标是对当前三策略独立采样的联合动作精确计算

\[
J(x)=\sum_{t=1}^{24}R(x,a^t)\prod_i\pi_i(a_i^t\mid o_i(x)).
\]

省去的是恒0项的求和；其动作概率仍留在各17项softmax分母中。均匀策略下物理执行概率仅24/4913≈0.4885%，满分概率通常更低。精确求和免去了此处的奖励采样方差，适合先做能力参照。它不能证明一次只获得原生反馈的学习者也能达到同等表现。

训练器知道全部世界状态、所有24种结构配置的原生反事实收益和三actor的当前概率。这是集中计算学习信号、独立执行actor的富反馈训练。它没有把某个最优共同计划、正确动作编号或一组固定参与者输入actor，也没有以正确动作标签做交叉熵或模仿学习；但不能因此宣称“没有监督信息”或“仅靠一次环境互动”。反事实奖励表本身就是较强的信息资源。

一次更新最大化 `batch_mean(J) + beta * batch_mean(mean_actor_entropy)`。精确梯度对每个actor的logit为“选择该动作的收益概率质量−该动作概率×期望收益”。各参数组在同一更新中使用各自梯度；不共享权重、不共享隐状态、不选一个共同最大联合动作来覆盖三人的选择。没有critic、额外价值目标、成功奖励加权、优势归一化、教师或课程。

## 观察、参数与真实行动

actor仅接收 `env.observe(..., shared_needs=True, full_information=True)` 的官方观察，经固定转换得到54个float64输入：

| 列（从0开始） | 内容 |
| --- | --- |
| 0–20 | A/B/C各7维：需求可见位、wood/fiber/short/long需求类别one-hot、允许L/R两个位 |
| 21–40 | S0–S3各5维：物资可见位、wood/fiber两维、short/long两维 |
| 41–49 | S1–S3各3维：该私有观察地点公开分配给A/B/C谁 |
| 50–52 | 本人A/B/C one-hot |
| 53 | 完整信息控制标记 |

已知位与属性位分开。没有需求表编号、全局场景编号、训练/留出标签、奖励、成功搭档、最优位置、别人的logits或当前动作。S0作为固定公共位置在接口中校验。编码器从观察构建；研究者 `State` 只供奖励计算与离线评分。

每人是独立54→64→64→17的MLP，两个tanh隐层，末层线性logits；每人8785个可训练参数，三人共26355。每层权重独立高斯 `N(0, 2/(fan_in+fan_out))`，偏置0。每个种子中A/B/C分别使用 `SeedSequence([seed, actor_index, 100])` 生成参数；既不复制同一初值，也不将一人的更新应用于其他人。

输出头固定对应各自 `env.all_actions(agent)` 的完整语义顺序，等待为0，所有伙伴/位置/目的地组合保留。它不是Qwen的随机菜单编号输出任务；不训练中文动作原文，也不加入正确编号过滤器。固定语义头更换了策略实现，其影响不能与Qwen数值作单因素解释。

部署时每人仅根据自己的完整信息向量，独立取17项概率的argmax；精确并列取最小原动作索引并计数。三人全部选完再用原 `env.settle(require_match=True)` 结算，没有按伙伴动作或共同得分事后协调。部署不调用反事实奖励表、不取联合最优动作、不使用训练时的其他策略输出。

同时报告随机独立动作政策的精确期望收益、满分概率、物理执行概率。这些是当前分布的解析量，不是额外随机执行次数，更不能替代真实离散argmax的0/0.5/1分布。

## 预先固定的训练与数据预算

4个训练种子固定为43101、43102、43103、43104。初次确定时检查了旧目录699个plan/config/manifest/prepared JSON中的seed字段，均未命中这4个整数；旧代码和Markdown的精确数字边界检索也无命中。范围是当前保存的配置与文本，不声称能恢复未记录的历史调用。

| 参数 | 固定值 |
| --- | --- |
| 每种子更新数／batch | 6000／256；均匀有放回抽训练格世界 |
| Adam | lr=0.001，β₁=0.9，β₂=0.999，ε=1e−8；不设weight decay |
| 梯度裁剪 | 三人全部参数梯度的联合L2范数上限5 |
| 熵 | 三人熵取平均；第u次更新的β=0.001·max(0,1−(u−1)/1000)，u从1开始 |
| 数值与设备 | float64，CPU NumPy，禁止使用Torch/MLX或GPU |
| BLAS线程 | 在导入NumPy前强制OMP/OpenBLAS/MKL/Accelerate相关线程环境变量为1 |
| 抽样RNG | 每种子 `SeedSequence([seed,200])`，与三个初始化流分离 |
| 固定检查点 | 0、100、500、1500、3000、6000 |
| 检查点监测 | 四格各固定1024世界；所有种子复用同一组，只记录，不选模型或早停 |
| 正式终点 | 更新6000；四格所有世界逐项评估，不选最佳检查点 |

总计24000更新、6144000个训练状态抽样、147456000个24项加权贡献。离线奖励预计算覆盖143424×24=3442176个状态–结构动作项。它不是6144000次“只提交一组动作、获得一次反馈”的原生环境互动；随机抽样仅用于训练世界，联合动作的奖励期望由精确求和得到。

正式执行之前可以做纯数组梯度与矩阵速度核查，不能做任务成绩pilot。已做的匿名高斯矩阵计算没有世界输入、政策成绩或参数更新：50次三actor形状的前/反向矩阵运算约0.023秒，线性外推24000次约11秒；它不包含数据编码、reward求和、Adam、JSON日志、原环境逐世界结算、压缩与其他进程竞争，绝不能当成整批耗时。整批预计为数分钟到约15分钟量级，估算峰值内存低于1GB、文件约300MB；实际耗时与文件大小以记录为准。硬预算是4×6000更新，运行报错保留失败，不自行重试或延长。

## 完成判断、报告与停止条件

所有4种子都按固定6000更新完成，即使中间效果不好也不换seed、追加更新或修改阈值。数值非有限、冻结文件变化、结构或计分核验失败属于执行错误：保存failure并停止整批；不自动重跑。普通任务失败不是执行异常，不删除任何失败世界。

每个种子、每一格均完整报告argmax满分/半分/零分、非满分数、等待与运输提议数、实际执行数、满足人数、伙伴配对，以及各种失败类型。保存每世界状态、三人的17项概率、实际动作索引、反馈和收益；可以独立用原环境重放。另列精确随机政策的三个解析量。保存全部6个检查点、Adam状态、抽样RNG状态和每更新batch状态哈希、原生期望、熵、损失、裁剪、耗时。不得用训练期望改善代替部署动作改善。

预先声明的低残余失败候选条件是：4个种子各自在3个留出格的argmax满分率均≥99%。这是12个seed×格逐项筛查，不能用平均值掩盖某格或某种子失败。即使达到也不叫“完全解决任务”，必须保留并检查所有残余失败；它不替代后续有通信任务的独立能力门槛。执行器始终写 `symbolic_phase_unlocked=false`，不会自动启动符号学习。若未达标，本批结论就是固定方法与预算尚未给出低残余失败基线，不根据结果增加训练或降低标准。

目前不提出显著性检验，不把4种子的平均称作普遍收敛保证。四格差异可描述泛化范围，但需求与布局都影响具体任务，不能将它们等同于后续信息结构或通信机会的随机因果操纵。

## 能否延伸到局部信息与互动

同一54列编码器可以表达官方局部观察：未见物资/他人需求的known位与属性位均为0，保留本人需求、公共及本人私有地点和公开分配。改变未见状态不应改变该actor输入，这一点可离线测试。但本轮所有训练都在完整信息下，不能直接遮挡输入后宣称局部信息能力已经通过。

后续可以保留对象、属性、搭档、目的地、17动作及参数独立性，在这个骨架中加入三人各自的离散发信头和历史处理；通信窗口与可见性必须重新明确冻结。集中精确梯度仍是训练信息选择，不自动解决局部信息条件的可达上界、通信负担或可学习性。通信出现后还需要检验伙伴、对象/属性和目的地是否通过新约定得到表达，以及打乱/移植/冻结协议的因果证据，不能把高任务分或动作同步本身称为语言。
