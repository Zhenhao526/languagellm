# FI 消息局部性与重编码探针

本包在已经冻结并审计的 FI `altpair_factorized` 策略上做只读后验干预，检验当前离散通道的行为作用来自哪些路由成分：跨主体消息、符号身份、四槽位置，还是某一个发送者。它不是新的训练批次，也不把结果称为词义或语言形成证据。

探针保留发送者自己的 payload。`natural` 使用训练时的路由；`cross_closed` 清除跨主体 payload 并将可见位归零；`symbol_permutation` 对跨主体 token 应用一个固定八符号双射；`position_rotation` 和 `position_reverse` 只重排跨主体四槽；`mask_sender_A/B/C` 只关闭指定发送者发给另外两人的 payload 与可见位。第一窗干预后的第二窗和行动都重新计算，因此它测量的是完整的因果路径。

静默训练策略的重编码和发送者遮蔽是负对照：它们没有跨主体 payload，按定义应基本不变。所有模式在同一 56,160 个新布局世界上评估，输出只保存汇总读数；独立审计重新加载 checkpoint 并逐模式重放。

本探针是后验探索性机制测量。只有在新的独立训练群体中预先固定局部重编码、未见组合和接收行为读数，才可把它作为确认性论文结果。
