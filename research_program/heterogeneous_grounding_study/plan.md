# 实验计划：群体感知异质性与共同符号形成

## 研究问题

在发送者看不到伙伴身份、只能发送有限离散符号的条件下，工人的感知表面标签采用不同稳定约定，是否会改变共同符号协议的形成速度、可迁移性和结构？这个干预把“群体内部共享的感知约定”从任务压力和模型容量中分离出来。

## 最小环境

- 每个回合有两个阶段，每阶段有两个对象类型；工人每阶段只能选择等待、取表面位置 0 或取表面位置 1。
- 发送者根据目标对象对发送一个 `mono4` 单槽四值消息，或一个 `dual2` 双槽二值消息。
- 消息在第 1、3 个时间步到达；奖励只由是否取到目标语义对象决定。
- 工人看到表面标签，不看到潜在对象类型；发送者看到目标，不看到伙伴身份。伙伴身份由环境轮换，避免发送者为某一伙伴维护独立码本。

## 干预与对照

父代先在完整目标分布上学习发送者和全部工人。均质群体中所有工人使用 identity 表面映射；异质群体中 worker 1、3 使用 swap，worker 0、2 使用 identity。随后冻结发送者和其他工人，只让新 worker 0 学习。新 worker 的映射有 identity 与 swap 两个水平。

`full` 与 `leave_one_out` 区分普通适应和未见目标的组合泛化；`live` 与 `silent` 区分有消息和无消息；`joint_history` 与 `slot_local` 区分是否把两次消息组成一个联合状态。所有配对条件共享语义世界、目标、伙伴、消息随机数和动作随机数。

## 主要指标

1. **主要结果**：leave-one-out、live 条件下，新 worker 在 held-out 目标上的自然回报及其训练增益。
2. **通信因果性**：all-goal 流中的 `natural−permuted`，以及 live 相对于 silent 的差异。排列在每个伙伴的完整四目标块内进行，因而不再是恒等操作。
3. **群体干预**：同一表示、消息形式、映射、支持和信道下的 `heterogeneous−homogeneous`。
4. **协议结构**：发送者确定性码本的 pairwise Hamming 距离，以及 `mono4`、`dual2` 和 `slot_local` 的成对差异。

功能性阈值暂定为 held-out natural team return ≥ 0.60。该阈值只用于描述性计数，不替代连续指标和配对区间。

## 解释边界

这里的“语言”严格指在任务反馈下形成的离散、可复用的发送者—工人符号协议。实验能够检验非语言感知约定、伙伴不透明性、消息容量和记忆结构对协议形成的影响；它不能单独证明出现了人类语言的组合语法、意图共享或文化传承。任何论文结论都应把协议层结果与人类语言起源假说分开表述。
