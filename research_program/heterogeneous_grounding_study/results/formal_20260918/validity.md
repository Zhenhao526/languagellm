# Validity and interpretation

All three independent shard audits passed. Together they replayed 36 parent runs and 432 child runs, including 36,000 parent training-log rows, 432,000 child training-log rows, 48 parent checkpoints, 576 child checkpoints, 216,000 live/silent paired rows, and 216,000 identity/swap paired rows. Maximum absolute replay error was 0. The parent endpoint is evaluated over all four rotating partners; child endpoints are evaluated on the replaced worker 0.

The message control is evaluated on complete four-goal blocks per partner, so `natural−permuted` changes message-to-goal alignment rather than applying a no-op permutation. The population intervention changes stable surface-label conventions for workers 1 and 3 while holding latent semantic worlds and random streams fixed. The leave-one-out endpoint measures local repair and zero-shot combination recovery in a finite tabular task; it does not establish human-like language, syntax, or cultural transmission.

The final aggregation source was corrected after execution to remove a duplicated statistics row in `swap−identity`; this did not change training, checkpoints, or audit code. The pre-correction execution source plan is retained as `execution_plan.json`, and the final analysis source plan is retained as `plan.json`.
