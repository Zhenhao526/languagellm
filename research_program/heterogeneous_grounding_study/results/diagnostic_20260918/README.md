# Diagnostic population heterogeneity run (2026-09-18)

This is a one-seed, 3,000-update diagnostic for the population-level perceptual heterogeneity design. It contains 4 parent and 48 child endpoints and a passed replay audit. It is not a formal estimate: the matched homogeneous/heterogeneous endpoints were effectively identical in this target-worker setup, so the design is retained as a null diagnostic rather than expanded blindly.

The result motivates a redesign in which the evaluated worker actually encounters heterogeneous partner mappings or an incumbent worker is transferred across them. Raw logs and checkpoints were deleted after audit.
