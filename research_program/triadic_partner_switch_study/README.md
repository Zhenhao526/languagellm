# 可替代搭档与全有或全无收益先导

本包沿用已审计的三人离散消息学习器，只把训练中的部分成功效用作为生态变量：`partial` 使用原生 0/.5/1，`all_or_nothing` 把 .5 映射为 0。原生物理结算不变。5,376 个唯一完整计划按 AB/AC/BC 各 1,792 个精确配平；训练 18 个布局，留出 6 个布局；四个配对种子运行八个条件，共 32 次训练。

静态方案和预注册主量见[`plan.md`](plan.md)。当前批次是开发先导，主量为留出布局上全有或全无收益对通信相对部分收益对正确执行搭档率的中心化时间 AUC。只有在先导暴露出稳定的搭档适应后，才冻结新种子确认和因素组合留出；本包不自动宣称语言形成。
