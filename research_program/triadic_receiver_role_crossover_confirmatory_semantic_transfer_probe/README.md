# Receiver-role crossover confirmatory semantic-transfer probe

This post-hoc probe uses the 96 final checkpoints from the independent
`triadic_receiver_role_crossover_confirmatory_study/results/role_crossover_confirm_001`. For each
replaced role, it transfers the same-background first-window packet from a
neighboring source demand and compares it with a cyclic same-stratum placebo.
The cases, messages, action probabilities and strict settlement are replayed
without training updates. The primary quantity is role-stratified
aligned-minus-placebo signed plan transfer; it is a task-content diagnostic,
not evidence for lexical meaning or language origin.
