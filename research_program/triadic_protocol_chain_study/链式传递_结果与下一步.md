# 两代学习者替换链：结果与下一步

## 这轮实验回答什么问题

前一轮已经发现，冻结 A/B 并换入随机初始化 C 后，跨主体路由使 C 的任务收益高于静默自回路，但 C 的最终表现仍低于旧 C。这里继续问一个更接近文化传递的问题：当新学习者进入已有群体、再由下一名学习者进入时，任务协议能否沿短链保留？路由通信是否改变每一代的适应速度和保真度？

这里的“协议”只指当前严格三人任务中，把私人需求映射为地点、目的地、搭档和等待动作的可执行策略。它不是词典、词义或人类语言。实验使用已有审计过的 PL 因子化 neutral/engage 策略和同一物理环境，所有网络都是本地 NumPy `float64` tanh MLP；没有调用 LLM、视觉模型、外部 API 或网络服务。

## 设计

代 1 是 `transmission_002` 中已经完成并审计的 live full-C 终点。每个源种子和日程都从对应 checkpoint 读取。

代 2 替换 A 为新初始化的三模块学习者，冻结 B/C，只更新 A 的 sender1、sender2 和 action 模块。代 2 同时运行 live 与 silent；live 路由所有主体的包，silent 只把包送回发送者自身。

代 3 只从代 2 的 **live** 终点继续：替换 B 为另一个新初始化学习者，冻结代 2 live 的 A/C，只更新 B 的三模块。代 2 silent 是不向后传播的配对反事实；代 3 的 live 和 silent 从同一个代 2 live 父代开始。

两代各包含 static 和 rematched 两种私人需求调度。共有 8 个预先固定的源种子、2 代、2 日程和 2 通道，共 64 个运行；每个运行 6000 次更新、batch 256，在更新 0/100/500/1500/3000/6000 保存监测点，并在六个新布局上做最终评估。live/silent 在每个种子—代际—日程单元内共享父代参数、新学习者初始化、世界均匀数、批索引、消息均匀数和重匹配分配。

主读数是：

1. 每一代最终留出 Q 和监测 Q 中心化时间 AUC 的 `live − silent`；
2. live 子代相对 live 父代的最终 Q 变化，作为短链保真度；
3. 物理执行、执行后目标搭档率、提案合法率和 engagement 作为机制性次量。

统计单位是 8 个独立源初始化；static/rematched 先在种子内等权平均，因此日程不是额外独立社会。区间为双侧 Student-t(7) 近似 95% 区间。

## 结果

### 路由通信对新学习者仍有稳定增益

| 代际（替换角色） | 最终 Q：live−silent | 95% 区间 | 中心化监测 Q AUC | 95% 区间 |
|---|---:|---:|---:|---:|
| 代 2（替换 A） | **+19.54 pp** | [+14.60, +24.49] | **+17.34 pp** | [+11.11, +23.57] |
| 代 3（替换 B） | **+14.06 pp** | [+10.74, +17.39] | **+13.34 pp** | [+9.84, +16.83] |

两个代际的 8/8 种子最终 Q 差均为正。分日程看，代 2 的最终增益为 static **+22.50 pp**、rematched **+16.59 pp**；代 3 为 static **+14.86 pp**、rematched **+13.27 pp**。代 3 的增益仍存在，但相对代 2 减小，说明路由对适应的作用可以沿一代传递，却没有保持相同幅度。

绝对最终 Q 也显示出这一点：代 2 的 live/silent 均值为 static **32.44%/9.94%**、rematched **26.74%/10.14%**；代 3 为 static **24.07%/9.21%**、rematched **21.76%/8.49%**。silent 子代几乎没有获得可用的跨主体信息，live 子代则明显提高，但第二次替换后整体水平下降。

### 代际保真度出现衰减，尤其是第二次替换

live 子代相对 live 父代的最终 Q 变化如下：

| 代际 | static | rematched | 两日程按种子平均 |
|---|---:|---:|---:|
| 代 2 ← 代 1 | −0.98 pp（CI [−3.81, +1.86]） | −2.65 pp（CI [−7.27, +1.97]） | **−1.81 pp**（CI [−5.39, +1.76]） |
| 代 3 ← 代 2 | −8.37 pp（CI [−14.17, −2.58]） | −4.98 pp（CI [−13.89, +3.94]） | **−6.67 pp**（CI [−13.09, −0.25]） |

代 2 的下降区间跨过 0；代 3 的总体下降区间略低于 0，且 8 个种子中 7 个为负。因而在这个短链中，第一名新学习者大致能接近父代的 live 任务水平，第二名替换 B 后出现更明显的保真度损失。该结果是任务策略的父代—子代保持度，不能解释为自然语言的代际传承。

### 增益主要来自“发生执行”，不是执行后的内容选择

按两日程、两代在种子内平均的最终 `live − silent` 次量：

| 次量 | 代 2 | 代 3 |
|---|---:|---:|
| 物理执行率 | +50.47 pp | +36.30 pp |
| 执行后目标搭档率 | −11.22 pp | −6.80 pp |
| 提案合法率 | +12.23 pp | +9.93 pp |
| engagement 率 | 0.00 pp | 0.00 pp |

路由包让新主体更常做出可执行的动作，且提案合法率提高；但已经发生执行后，选择目标搭档的正确率没有提高，反而在两代都下降。Q 的正差因此主要是物理执行率的增加与行动头适应，而不是已经识别出一个可稳定复用的搭档—内容符号。它延续了前一轮模块消融的结论：action 适应是主要入口，sender 适应提供额外帮助，但当前协议仍是整包、任务绑定的行为策略。

## 解释边界

这轮增加了“短链代际保真度”这一可检验维度，但仍没有得到“语言诞生”的证据。原因有三点：

1. 新主体接收的是研究者定义的四元八符号包，并且动作、奖励、网络结构和信息路由都已预设；实验没有从无语言感知中让符号自然出现。
2. 代 2/3 的正效应主要落在物理执行，执行后目标搭档率没有改善，因此不能把 Q 增益称为词义或组合语法。
3. 代 3 只替换 B，且始终从代 2 live 传播；角色不对称、短训练预算、固定整包消息和共享任务接口都可能造成衰减，不能据此推断一般文化演化规律。

这轮最窄的结论是：在当前因子化三人任务中，路由通信能让连续替换的新学习者获得一部分父代协议的任务收益，但每次替换都会损失一定保真度，第二次替换更明显；这一作用主要体现为完成物理执行，而不是执行后的内容选择。

## 下一步

下一轮不应只增加代数或训练步数。优先做三个识别：

1. 在同一链式框架增加多合法行动、随机搭档和新布局留出，把执行、搭档选择和方案内容分开作为预注册目标；
2. 对每一代加入全信息和 closed-channel 对照，以及保持等式模式的局部符号重编码，判断“传递”依赖跨主体信息、绝对符号身份还是固定位置触发；
3. 用方向可识别的单发送者接收指标和未见对象×属性组合，检查新主体是否复用功能成分，而不只是在既有整包接口上恢复行动概率。

只有在这些控制下仍出现跨搭档、跨组合且可由行为干预验证的稳定复用，才值得把后续实验推进到更长的代际链和更接近原始社会的资源分工环境。
