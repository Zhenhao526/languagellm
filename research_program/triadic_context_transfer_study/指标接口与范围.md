# 固定政策的完整消息包跨背景诊断

本模块只读既有终点和本轮保存的干预数组。没有训练、参数加载、神经前向或按结果挑选案例。主量为双留出分区、两端目标材料均换位的供体支持上，`remote_opposite target_apt − remote_same target_apt` 的 PL_live − LL_live；保留四个逐种子配对值及等权均值。

## 调用接口

1. 对每个原终点 NPZ 调用一次 `build_pool_context(pool, information)`。它缓存原环境的唯一正确动作，并按实际布局把材料变为位置，核对自然行动概率、贪心动作和结算。`information` 为 PL 或 LL。
2. 对每个同案例、供体 shift、方向下的 same/opposite 记录，分块调用 `cell_values(spec, context, data, mode=..., shift=..., direction=..., live=..., rows=slice(start,end))`。`data` 是完整新 NPZ 的数组映射，静默别名为 None。无需额外载入模型或执行前向。`rows` 同时索引 spec 的 N 轴和新 NPZ。
3. `contrast_values(same, opposite)` 返回逐行配对差。主要键为 `target_apt_gain`；保守诊断为 `conservative_target_apt_gain`。
4. `support_weights(spec, shift, layer, rows)` 的 layer 为 `eligible`、`all_other`，或 shift=-1 时的 `control`。权重已经包含方向的 1/2。对所有预定 shift 和两个方向调用 `WeightedAccumulator.update(values, axis, weights)`，然后 `finish()`；每轴总权重必须为 1，否则拒绝。三轴 macro 等权。不能按 gate、view、答对情况筛行后重新归一化。
5. `primary_comparison(records16)` 要求全部 16 政策和四分区。每条记录为 `seed,condition,partitions`；其中 `partitions[part][eligible/all_other]['contrast']` 是配对差累加器的 `finish()`。返回主要双留出结果及所有分区、支持、种子和静默参照。

同生态共 16 个既有政策，四种子为独立训练初始化单位。案例、布局、归属、两个方向和各供体是同一政策上的重复测量，不是新增训练种子。

## 保存指标

每条 cell 的向量包括 current/target 适切率及其概率、相对原自然行动的 current 变化、listener 行动变化、任意自生消息变化和 listener 本人第二窗消息变化。实际消息指主体自己生成的消息；供体替换包另由原始 NPZ 保存，不能把供体文本当主体自生文本。

团队读数分别为 native_reward/native_team_full 和 counterfactual_reward/counterfactual_team_full。后者在接收方布局及反事实需求世界中结算同一组干预行动；不会更改接收方输入或重新执行反事实政策。

供体辅助读数包括供体两个自然端点在自身世界中的正确率、把各供体 listener 实际动作直接复制到接收方时的 current/target 正确率，以及实际干预行动是否等于这些供体动作。完整输入相等标记按固定 endpoint 0/1 保存，指标按 direction 转成 same/opposite。静默别名根据官方可见材料和本人两窗自然消息精确推导完整输入相等，无需新的前向。

保守条件 `G = target != donor_same_actual AND target != donor_opposite_actual` 在两臂相同。`conservative_target_apt = G * target_apt` 始终保留原分母；另报告 G 的覆盖率。这个差不是原始差的数学下界，且 G 可以随政策改变，因此不能把其 PL−LL 差解释为固定共同案例子集上的单独机制效应。

两端目标材料均换位，排除的是将对应语义端点的供体正确动作直接照搬后仍对应正确。它不能排除错误供体动作碰巧等于接收方目标，或跨端点的动作巧合；共同 G 专门描述其中的字面实际动作复制情况。

## 解释边界

完整供体消息包的功能性跨背景转移不证明单字符语义、成分复用、组合性或语言起源。静默两种供体干预的效果差结构上为零，不是新训练发现。local-opposite 是确定性图结构下的输入重现检查。

same 在方向 b 的非 sender 完整输入与 opposite 在方向 1-b 的对应输入可能按端点交换精确一致。在本方案对称权重下，same/current 和 opposite/target 的绝对率互为重复读数，不能算两条独立证据。这不自动消去同方向 same/opposite 的干预差。保守 G 根据目标和实际供体动作定义，不能把上述原始绝对率恒等无条件套到所有 gated 指标。
