# 从整包迁移到单成分选择性复用

2026-09-16。这是候选备忘录，未冻结、未执行，也未读取本批迁移成绩。沿用全部4种子、PL/LL既有政策和三类需求，不挑高分社会；研究对象仍是有限任务协议。

**把发现单位与验证单位分开。** 首轮只允许8个候选单位：两窗各4个符号位置，不搜索任意子串、位置组合或不同长度片段。用训练需求×训练布局内预先按哈希选定的平衡小集，复用自然消息，计算每个位置对三轴单因素需求变化的响应。按“目标轴符号变化率减去另两轴平均变化率”排序，每政策×发送者×轴选1个位置，平局按窗、位置顺序决胜。公开全部8个分数；不强迫三轴选不同位置，不因分数低排除政策。这只是候选发现，不能据关联分数宣称词义。

**验证不再选单位。** 主验证只用未参与发现的新需求×新布局；案例、接收背景和供体在加载消息或动作前按静态真值定好。每轴、六个有序发送者/听者层均保留，背景和双向需求权重固定；消息未变、自然失败的行也保留。其他留出分区可作预定辅助，但不能看到成绩后替换主分区。这里的评价隔离只针对本次单位发现；既有政策及其总体表现已经开发过，不能包装成全新政策的独立确认。

**单位置替换保留完整互动。** 对同一接收背景，same与opposite供体共用不同于接收方的布局、归属和其他需求，仍要求两端目标材料都搬位。只换焦点发送者向两名伙伴广播的一个位置，自身存储和事实不覆盖。若替换第一窗，应重算第二窗和行动；若替换第二窗，保留第一窗自然交互。第一窗位置的效应包含后续回应中介，不能叫该字符对最终行动的直接效应。两臂及所有参照使用完全相同的接收行、供体和权重。

**适切与选择性一起检查。** 将为轴q发现的位置分别用于三类轴r的供体，形成3×3作用矩阵：每格均为opposite减same的反事实正确听者动作率。候选主量是对角平均减去非对角平均；同时要求正的对角效应，避免把非目标上的破坏误称为有用选择性。逐轴、逐种子展示绝对适切率，并按实际布局将行动还原为材料种类、长短、目的地及伙伴，检查非目标要求是否保持。全正确动作、原生奖励和反事实团队奖励分列，不能只报告某一分项改善。

参照保留自然输出、已执行的整包same/opposite及sham；另按预定哈希从8个位置均匀指定一个随机位置，跨PL/LL保持配对，移植同一供体的合法符号，比较发现位置是否优于同大小的任意干预。不使用零向量、掩码外符号或把删除字符当作正常消息。**单位置替换产生未见整串仍属合法通信，全部进入主分母**；训练中是否自然出现该整串只作描述，不据此拒绝、判失败或重加权。未见组合若有效有助于复用解释，但异常混合导致的失效仍可能包含分布偏移，不能一概证明无语义。

预算先作静态核算：若每轴×有序S/L取4例、每例2个接收背景、双方向和每背景1个合格供体，则每政策288行。8个live政策中，每行检验3个发现位置及1个随机位置、各same/opposite两臂，最多18,432个新干预世界；按每世界6模块保守计110,592个模块样本。整包、sham及自然参照按相同索引复用，silent只作结构别名。先核各层供体支持；若缺层，在任何新成绩前调整共同抽样方案，不事后补容易案例。这个小集估计的是预定平衡样本，不冒称全域遍历。

若对角效应不正、选择性差不正、优势只来自少数种子或发现集、需要改位置才能跨背景，便不支持稳定单成分复用；不追加片段搜索挽救。若仅整包有效，应保留整体约定结论。即使通过，也只说明一个位置对需求的条件化功能可复用，尚非词素、句法或完整语言；后续还需新政策和独立背景确认。现有政策固定搭档的限制不被这项测量解决，不能把对固定伙伴运输属性的表达推广为灵活协商参与者。
