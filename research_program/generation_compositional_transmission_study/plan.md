# Compositional parent-to-child transmission plan

The parent is the staged dual2 factorized population from `action_dependent_signaling_study`. Each parent checkpoint is frozen by SHA-256. A child replaces worker 0 or the hidden sender and starts from an independent initialization; the complementary parent parameters remain frozen.

Channels are `live` (natural staged tokens), `silent` (NULL tokens with the same reward stream), and `permuted` (partner-permuted tokens). The primary communication contrast is paired `live−silent`; `live−permuted` tests stable pairing. The structural transfer readout is `recombined−natural` plus the child sender sequence and semantic codebook.

This experiment tests recovery of an existing protocol, not emergence from scratch. Parent success strata are retained so transmission is not reported as evidence that every parent learned a compositional code.
