# Open-world grounding transfer study

This study crosses two mechanisms that were previously measured separately: compositional cultural transmission and perceptual surface remapping. Parents learn values `0,1,2`; an expansion child learns only single-new meanings involving value `3` with fresh sender and receiver roles, while `(3,3)` is held out. The expansion checkpoint becomes a frozen incumbent culture.

In the transfer stage a fresh sender, receiver, both, or neither role is replaced. The incumbent receiver sees canonical object labels. A fresh receiver sees either the same labels (`identity`) or a stable reverse permutation `[3,2,1,0]` (`reverse`). Semantic scenes, goals, message streams and action streams are paired across mapping arms; only the fresh receiver's perceptual surface changes. The held-out double-new meaning tests whether atomic coordinates can be culturally transmitted and recombined after grounding has changed.

The architecture intervention is `holistic`, fixed `factorized`, or `tied_routed`. Primary endpoints are new-single recovery, new-double recovery, natural versus donor-recombined double-new messages, surface-remapping contrast, and the zero-update replacement control. The reverse arm is a stable bijection, so it changes the grounding convention without deleting semantic information.

This is a tabular mechanism experiment. It does not claim human language, open vocabulary or visual understanding. Its purpose is to identify whether compositional transfer survives a controlled change in the receiver's perceptual code.
