# Implementation note

This formal batch extends the frozen open-world cultural-transmission study with a child-only object-surface intervention. Incumbent receivers always consume canonical scene meanings. Fresh receivers consume `identity` or the stable bijection `[3,2,1,0]`; semantic goals, sender messages and random streams remain paired. The new `fresh_scene_sha256` field is included in every replay check.

The reverse arm tests re-grounding, not a visual encoder: the environment uses a deterministic attribute-label permutation in a tabular scene. Results therefore support a mechanism claim about stable perceptual relabeling, not visual language understanding.
