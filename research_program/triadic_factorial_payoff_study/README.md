# 收益生态 × 因素语义留出

本包在相同三人 D1 任务上同时操纵训练收益生态和语义组合留出。训练排除资源 5（wood-long）和资源 6（fiber-short）的组合，保留其单个对象、长度和目的地值；`all_or_nothing` 把半成功训练收益置零，`partial` 保留原生半成功。16 个新种子运行八格配对条件，共 128 次训练。

静态方案、主量和解释边界见 [`plan.md`](plan.md)。结果目录中的 `prepared.json`、`plan.json`、`freeze.json` 和 source snapshot 用于复现冻结输入；执行结果应包含完整留出资源轨迹、三类最终分区、配对日志和逐文件评价哈希。该实验用于检验行为语义泛化，不能单独宣称语言形成。
