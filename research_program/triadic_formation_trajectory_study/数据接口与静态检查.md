# 六时点静态索引与检查点接口

本模块仅准备文件身份、原样本索引和去重世界池。没有加载检查点参数，没有读取政策消息／行动数组，没有生成新真值或重新选案例，没有运行神经前向或训练。旧 `result.json` 的运行身份与检查点元数据用于核对；整个旧位置实验结果文件仅做字节哈希，未解析其中成绩。

## 入口与文件

`load_sources(position=POSITION, context=CONTEXT)` 返回先前冻结的静态发现／验证数据、源哈希、原 context prepared、96 条检查点身份记录。

`make_prepared(bundle)` 返回：

```text
schema
discovery: {metadata, arrays}       # 旧完整训练内容对，原序原真值
validation: {metadata, arrays}      # 旧144行，原序原真值
pool: {metadata, arrays}            # 本轮仅新增索引映射与世界池
checkpoints: [96 条]
source_sha256
static_paths
separation_proof                   # 旧发现/验证分离证明原样保留
```

`prepare(out)` 是显式命令，拒绝覆盖已有目录。它逐字节复制原 `discovery.json/.npz`、`validation.json/.npz` 和 `separation_proof.json`，新增 `pool.json/.npz`、`checkpoints.json`、`manifest.json`。清单的 `outputs` 为文件名到 `{path, sha256, bytes}` 的映射。所有读取源在保存完成前再核一次哈希。该入口目前未由本子任务正式调用，根代理冻结方案后负责调用。

```sh
qwen_collect_pilot/.venv/bin/python -m research_program.triadic_formation_trajectory_study.dataset prepare --out <新目录>
```

## 索引与实际计数

| 数组 | 形状 | 含义 |
|---|---|---|
| `train_world_indices` | `[419904]` | 完整训练域原索引升序，不局限于发现对引用的世界 |
| `validation_pool_endpoint_indices` | `[554]` | 原完整 double-held 分区中的索引，升序且唯一 |
| `validation_pool_states` | `[554,10]` | 相应原状态；前三列 need，随后四列物资布局，最后三列 private site 归属 |
| `recipient_pool_rows` | `[144,2]` | 旧144行的两个接收需求端点在554世界池中的行号 |
| `donor_pool_rows` | `[144,2]` | 同行两个供体需求端点在同一池中的行号 |

恒等关系为：`validation_pool_endpoint_indices[recipient_pool_rows] == validation.arrays.endpoint_indices`，供体同理。池内仅合并相同的完整世界 ID；所有原行、方向、权重、sender/listener、旧 source_spec_row、donor_shift_index、correct_actions 和属性真值都不变。

验证接收端点共284个不同世界，供体端点共280个，交集10个，合并池为 **554** 个。576次接收／供体端点引用由映射恢复，不当作576个独立世界。验证仍为144无向行、288方向；每轴48行、六种有序发送者／听者层各8行不变。

完整发现集为209952无向行、419904次端点引用，实际涉及326592个训练世界。训练消息池采用**完整419904个训练世界**，包括未被发现对引用的93312个世界，便于每时点采用相同完整训练域定义消息包集合。训练域和验证域的需求关系轨道、布局仍按先前冻结证明分离；不声称单个需求取值未见。

主 runner 可为池内干预构造局部 spec：将 `endpoint_indices` 替换为 `recipient_pool_rows`，将 `donor_endpoint_indices` 替换为 `donor_pool_rows`；原完整分区索引必须仍作为 provenance 保存。不得把池行号当成原分区索引或重排144行。

## 检查点来源链

固定四种子51101–51104、`PL_silent / PL_live / LL_silent / LL_live`，全部保留0、100、500、1500、3000、6000，共96个实际文件。每条记录包含：

```text
seed, condition, update, path, sha256, bytes
source_run_record, source_main_result, source_audit
array_parameters_loaded=false, neural_forward_calls=0
```

96份文件均存在，并逐一满足 `文件SHA == 原run.monitor对应SHA == 原独立audit的artifact SHA`；每政策六个 update 的顺序与完整性同时核对，原 run 记录必须与原整批 results 对应条目完全一致。检查点只流式读取字节做 SHA256，不用 `np.load` 反序列化参数。

固定来源锚为原位置实验 plan SHA `87bf3b412c10fc7a27539b90542e2ec67165e1b2ad4b19476748f2cac2a81eaa` 与 context 原独立审计 SHA `7c0eab86edff602ec6def4e54e92cacf3403cb495e39b195594b0185caeb250a`。原任务环境／数据源码也对照旧 freeze 核验。原位置实验 freeze 绑定的静态 manifest、五份静态文件均按历史哈希核验，不重新执行旧样本抽样。

6000条目还保存 `saved_natural_6000` 的 train/double-held 原输出路径与旧冻结哈希，以及 `prior_policy_tag`、`source_position_result`、`source_position_policy_directory`、`source_position_selection` 与相应哈希。这里不读取这些消息／行动数组；runner 在实际复用时仍须核查输出字节并验证索引来源。位置实验结果文件的当前字节哈希已加入新来源清单。

## 自然消息预算

训练域每世界仅需要三位主体的第一窗和第二窗发送网络，共6个模块样本，不计算三份行动头。验证554世界池需要两窗发送加行动，共9个模块样本。silent 仍计算自身消息，不因跨人不可见而跳过其形成轨迹。

| 自然评估范围 | 政策×时点 | 训练世界样本 | 训练模块样本 | 验证自然世界样本 | 验证自然模块样本 |
|---|---:|---:|---:|---:|---:|
| 全六时点参考账 | 96 | 40310784 | 241864704 | 53184 | 478656 |
| 根代理确定的新计算：前五时点；6000复用旧输出 | 80 | 33592320 | 201553920 | 44320 | 398880 |

这张表只计自然消息／行动，不含跨时点整包替换、单位置替换、sham或独立审计。跨时点干预预算由主 runner 另行固定；此数据模块的实际前向和训练数始终为0。
