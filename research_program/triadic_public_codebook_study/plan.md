# 公共与私有符号码本的训练期对照

本实验把前一轮“固定策略对符号双射敏感”的后验结果改写成训练期操纵。任务仍是已审计的 PL reciprocal 三人协作生态；对象、属性、搭档、目的地、两轮同步消息、每窗四个 base-8 token 和 17 个离散动作均不变。

每个新种子从相同参数和相同世界／消息随机流开始，运行四臂：

- `silent`：从训练开始屏蔽跨人消息，作为无通信参照；
- `identity_live`：恒等 wire；
- `public_live`：所有发送者共享同一个固定八符号双射；
- `private_live`：三个发送者分别使用三个固定双射。

双射只在消息离开发送模块、进入接收模块前作用于 wire token；发送模块仍输出内部 token。固定 map 全部写入 `prepared.json`，不在读取结果后选择。

主训练读数保留原生 reciprocal Q、物理执行率和完整成功率。后处理探针将使用同一批 checkpoint 做四选一内容移植，并比较跨发送者包替换的目标动作边际；所有四候选概率、命中率、全 17 动作命中率和 silent 别名同时保存。该探针检验公共码本是否让消息内容更容易跨发送者复用，不能把任意正效应称作词义。

训练前冻结 seeds、map、partition、预算、路由、随机流和审计源码。独立审计不导入生产 `wire.py` 或 `runner.py`，重建 wire 映射、消息采样、第二窗、动作和结算。生产和审计都不调用 Qwen、视觉模型或外部网络。
