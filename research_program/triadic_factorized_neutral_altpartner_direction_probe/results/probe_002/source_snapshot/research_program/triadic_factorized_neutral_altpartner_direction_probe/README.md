# 因子化中性行动的单发送者方向探针

本包冻结并读取 `triadic_factorized_neutral_altpartner_study/results/altpair_001` 的64个最终策略，检验同一布局、同一站点所有者下，改变一个发送者的对象／属性／目的地需求时，替换其首窗外发包是否使接收者朝供体合法方案移动。

这是后验机制探针，不是新的训练确认。每个世界有两个使用不同搭档对的合法方案；策略使用独立 neutral/engage 意图头和16类地点—目的地—搭档提案头。方向案例由全部2,112个同上下文单轴邻居需求生成，乘36个背景共76,032行；不按模型行为筛选。live 重新计算第二窗与因子化行动，silent 复用闭通道自然输入；每个发送者前256行做逐项 sham。
