# 新三人一步任务：Qwen 能力控制准备计划

实现见 [qwen_capability.py](qwen_capability.py)。目前已完成代码和无模型假后端审查；真正的源码、场景与提示冻结由根代理在环境和运行器审查通过后调用`prepare`完成。本文件不是已执行结果。

本轮检验完整信息、自然语言下的一步匹配能力。它取消了旧采集任务中的多步拿取、移动、加工和交付规划；通过这里只能满足新任务的能力门槛，不能改写原v3失败记录或门槛，也不意味着语言已形成。

固定3个上下文群体301、302、303，每群体4场，共12场。四个场景由种子20260916011、20260916012、20260916013、20260916014各独立抽取一次，需求支持为已审计的996表，布局为24种排列；三群体共享同四个语义场景，以配对任务难度。选择这些编号前已用`rg`检查该路线相关源码和记录，没有发现旧用例。共有4个独立场景抽取，并非12个独立世界；三群体也不是分别训练的模型。

每场所有人看见四处物资和三人需求，执行D1规则：所有物资均需两人互选、同位置、同目的地，第三人等待。每人的物资需求只限制种类或长短一个因素，另一因素不限；匹配后分别评分，只满足一人可得0.5。动作直接完成本轮取用和运送，没有前置操作。每人17个选项完整保留并独立随机排列；编号不是共享消息或正确动作提示。

每场先有两个同步自然语言广播窗，再同时提交三个动作。每窗3个广播决定，加3个动作决定，共9个决定；每个决定沿用冻结v3 Backend的“私有分析＋正式输出”两阶段，共18调用。12场上限216调用，正常完成必须恰好216调用。108个决定种子彼此不同；同次分析与正式输出沿用相同种子，不能写成216个独立种子。私有分析最多256 token、温度0；自然广播最多96 token、温度0.7；动作温度0，均使用新cache，关闭原生thinking。

群体间历史隔离。每群体内新场景使用新世界，保留自身真实观察、自己提交的动作、自己的`individual_feedback`及公开广播。其他人未执行动作、`settle.researcher`、源state、场景seed、群体编号和见证不进入模型输入或私人历史。场景生成函数不调用研究者见证。首窗输入可在真实历史为空时冻结；后续输入由冻结构造器和本群体的实际经历重建。

门槛为12场全部真实结算R=1。任一中途失败仍执行全部剩余场次，不增加例题、规则、场景或调用；完整记录0、0.5和1分。通过也不会自动启动符号阶段。这个小型配对能力检查不能单独证明稳定泛化，更不能将自然语言能力直接视为新符号约定的形成。

内置假后端审查已覆盖108个决定、216个模拟调用：所有场景故意等待失败，验证不会提前停止；核对两窗屏障、动作同时输入、群体隔离、群内历史长度0/1/2/3、首提示一致和108个种子无碰撞。独立审查另可使用真实`Backend.decide`并替换`infer`，核对完整两阶段提示。所有假审查均不加载权重。

`prepare`要求环境独立审计通过并匹配环境SHA，冻结运行器、环境、旧Backend、相关包初始化文件、审计记录和全部实际模型tokenizer/配置元数据。权重只保留原下载版本与来源清单、检查文件大小，本轮不重新复制或全量计算权重SHA。准备和执行记录Python、mlx、mlx-lm、transformers、tokenizers及numpy版本。

审核后可使用：

```sh

```
