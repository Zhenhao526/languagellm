# Held-out goal-combination recovery

This package replaces worker 0 after a staged `dual2` protocol has formed, then compares full child training support with a leave-one-goal-combination-out support. The frozen parent sender can still emit the missing two-slot message; the child worker must recover its action mapping from the three seen combinations. Live and silent arms are paired on worlds, goals, partners and random streams.

The formal archive keeps the plan, source and dependency snapshots, compact metrics, parent status map, and audit receipt. Raw child logs and checkpoints are temporary execution artifacts.

See [the formal result report](heldout_formal_结果与下一步.md) for the stratified result and its interpretation boundary.
