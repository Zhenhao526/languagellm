# 两条通信轨迹的训练估计审查

本审查固定数学定义和无训练验收要求，不执行训练、不修改旧源码。对应设计为3个独立主体，每主体有三个不共享参数的MLP：sender1为54→64→64→32，sender2为153→64→64→32，action为252→64→64→17。每个sender输出4个位置各8项categorical分布，同一窗口的4位置条件独立，不是自回归；位置没有预先指定语义，但固定位置和顺序本身仍是结构先验。

结论：所述两条完整、条件独立轨迹的leave-one-out基线给出无偏的sender score-function估计。必须停止基线及优势对sender surrogate的梯度，且最小化loss时取负号。receiver熵若进入优化目标，也须进入sender所用的整条轨迹回报。首版不加sender熵合理，可以避免遗漏早期消息对后期熵的影响。

## 1. 轨迹与同步信息

用x表示固定环境状态，o_i(x)为主体i在FI或PI条件下的合法原始观察。用M^(r)表示第r条**完整两窗轨迹**，r=1,2；它不是窗口编号。每条轨迹包含3人×2窗×4位置，共24个8类符号。

设q^(1)_{i,l}(·|o_i;θ_i1)是第一窗第l位置的分布，q^(2)_{i,l}(·|h_i(M_1),o_i;θ_i2)是第二窗的分布，则

`q_θ(M|x) = Π_i Π_l q^(1)_{i,l}(M_(1,i,l)|o_i) × Π_i Π_l q^(2)_{i,l}(M_(2,i,l)|o_i,h_i(M_1))`。

第一窗三人、四位置全部采完后形成统一屏障，第二窗才能看到通过live/silent规则投递的第一窗消息。第二窗不能看到其他人的第二窗消息；action在第二窗完整结束后统一读取两窗历史。第二窗同一位置不能依赖该窗其他位置的抽样，因为当前设计明确为4位置独立分类头。

sender2输入153=54+3×33，action输入252=54+2×3×33。每份消息使用4×8 one-hot加1个独立可见位。live接收本窗结束后各人的消息；silent将**其他主体**的payload置0、可见位置0，自身payload及可见位保留。缺失消息不能用8类中的一个真实符号代替，也不能只清可见位却把原payload留在网络输入中。

两条轨迹必须在给定x与当前参数后独立，不能为了省计算共用第一窗抽样、只重采第二窗；也不能把一个轨迹的消息带入另一个轨迹。两条轨迹和所有主体的最终梯度先完整形成，再统一更新参数。不同实验条件可使用配对外生U流，条件内两轨迹仍须使用独立流；FI/PI、live/silent的配对不能成为轨迹内共享随机数。

## 2. 精确动作目标

action模块的参数记为φ_i，给定合法观察和已投递消息后输出完整17项π_φi(a_i|x,M)。三人仍独立选择动作，不能通过已知同伴当前动作过滤17项。

定义原生收益期望

`J_φ(x,M) = Σ_(a_A,a_B,a_C) R_x(a_A,a_B,a_C) Π_i π_φi(a_i|x,M)`。

可对24个可能执行的结构配置精确求和；其余4889项R恒0，但其动作概率仍保留在17项softmax分母中。令

`H_R(x,M) = (1/3) Σ_i H(π_φi(·|x,M))`，

`F_φ(x,M) = log J_φ(x,M) + β H_R(x,M)`，

则本步共同目标是 `L_target(θ,φ)=E_x E_(M~qθ)[F_φ(x,M)]` 的最大化。β沿既定receiver熵时间表，是当前更新编号决定的常数，不根据样本或消息调节。

它是对通信轨迹平均的logJ，不是`log E_M J`，更不是采一次联合动作后对实际R取log。动作期望由反事实收益表精确给出；只有消息轨迹被采样。PI仍需明确披露集中训练器知道原生反事实奖励及三人策略输出，不能写成学习者只获得一次环境反馈。

正收益支持存在且所有动作logits有限时，数学上J>0。实现用 `logsumexp(log R + Σ_i log π_i)`，R=0的结构项用−∞排除；不取`log(float_J)`，不加epsilon，不以最优联合动作代替求和。float64 J可以下溢为0，而稳定logJ、后验和导数仍可有限。若没有正收益支持或logJ非有限，应保存错误并停止，不能悄悄平滑原生收益。

## 3. 无偏sender估计及符号

完整轨迹的score是

`S_θ(M,x)=∇_θ log q_θ(M|x)=Σ_(w,i,l) ∇_θ log q^(w)_(i,l)(M_(w,i,l)|合法输入)`。

两个独立轨迹的回报记F_1、F_2。一个状态的sender梯度估计为

`g_sender(x) = (1/2)[(F_1−F_2)S_θ(M^(1),x) + (F_2−F_1)S_θ(M^(2),x)]`。

给定x，`E[S_θ(M,x)]=0`。两条轨迹独立，所以交叉项 `E[F_2 S_θ(M^(1),x)]=E[F_2|x]E[S_θ(M^(1),x)|x]=0`，另一项同理。因此 `E[g_sender|x]=∇_θ E_M F_φ(x,M)`。

这个证明允许F_2的数值依赖当前政策，但它必须来自独立轨迹，并在surrogate中detach。不能对baseline求导，不能将两条优势再做数据依赖的标准化、除以样本标准差或裁剪后仍称同一个无偏估计。

对batch大小B，若优化器最小化loss，正确sender surrogate是

`loss_sender = −(1/(2B)) Σ_b [ stop(F_b1−F_b2) log q_θ(M_b1|x_b) + stop(F_b2−F_b1) log q_θ(M_b2|x_b) ]`。

其中logq是每条轨迹全部24个token的log概率**总和**，不再除以agent数、窗口数或位置数。每个sender模块只收到该模块4个位置对应的score贡献；写总logq不等于共享参数。若把基线误改成包含自身的两样本均值而不乘修正因子，梯度会缩为本公式的一半。若直接使用loss值−F作回报，则应一致改为loss差乘score的正号，不能混合两种符号约定。

sender1的score使用完整最终F，因此包含它经第二窗消息影响最终动作的总效果；不需要对离散消息one-hot反传。sender2也使用相同最终F，它的条件分布以本轨迹第一窗历史为输入。不能只给sender1第一窗的局部回报，或把第二窗输入视为可跨sender模块连续反传的隐藏向量。

首窗与次窗的4分类头梯度均为 `one_hot(token)−q(token)`，再乘上述优势、loss负号及1/(2B)。其他主体模块不共享参数；全局团队F是训练信号，不构成执行时读取其他主体私有观察的许可。

“无偏”指裁剪和Adam之前的随机梯度估计。整体梯度裁剪、Adam等后续更新并不是无偏梯度定理的一部分，需要照实际流程记录，不能从估计无偏推得优化收敛或低方差。

## 4. receiver直接梯度与熵

当前三模块参数完全独立，q只依赖θ，给定抽出的离散M后F只直接依赖φ。故receiver梯度为

`g_receiver=(1/(2B))Σ_(b,r) ∇_φ[log J_φ(x_b,M_br)+β H_R(x_b,M_br)]`。

对任一actor的logits，logJ导数仍是“奖励后验的动作边缘分布−该actor当前π”；receiver熵的导数沿原三人平均定义，包含1/3因子。这个1/3属于H_R定义，不能再套在整个logJ或sender score上。最小化时对整个receiver目标取负号。

sender回报必须是同一个F，包含βH_R。否则receiver优化熵、sender只用logJ，便不是上述共同标量目标的无偏分解。由于当前θ与φ不共享且只通过离散消息连接，sender没有额外直接∇F分支，receiver没有额外∇logq分支。后续若共享encoder或连续hidden，这个分解就需重新推导。

首版不添加sender熵。如果以后给sender各步分类熵加奖励，第二窗熵本身依赖第一窗消息：

`∇_θ E_M[C_θ(M)] = E_M[∇_θ C_θ(M) + C_θ(M)S_θ(M)]`。

仅对各窗口熵做直接反传会漏掉早期消息通过第二窗输入改变后期熵的score项。即使silent，第二窗还依赖自己的第一窗消息，此问题仍存在。也可从完整轨迹熵`−E logq`另行推导等价估计，但不能未经推导混用局部熵梯度与整轨迹回报。

## 5. silent解释边界

silent仍采完整消息，保存自身消息历史，sender仍可能通过自己的离散随机码影响sender2与action。它是“屏蔽跨主体投递、保留自用通道”的控制，不是移除发送模块、移除随机性或完全无内部记忆。

自用消息只由已有观察生成，不凭空增加关于其他主体私有状态的信息；但它增加了可训练的中间计算、随机化和表示路径。FI与PI也必须保持相同模块、合法可见位规则和训练预算。任何live优势仍需核查确实来自他人消息，而不是错误投递、模块参数差异或评估时不同的随机性。

训练用采样消息；部署采用采样还是逐位置argmax必须另外明确冻结，两者可能有差距。实际argmax动作R、随机消息下收益分布、训练平均logJ分别报告，不能互相替代。固定4位置没有研究者给定语义槽，但也不能预先宣称已学出词、语法或可组合语言。

## 6. 必须先通过的纯数组／枚举验收

以下均用匿名合成logits、合法状态或缩小的枚举通信空间，不创建正式actor或试训挑参数：

1. **完整轨迹概率**：缩为3人×2窗×1个二值位置，共64条轨迹；第二窗显式依赖第一窗。逐轨迹q求和为1，实际score与logq的有限差分一致。另以4×8头检查形状、独立采样、全部4位置梯度累加以及没有额外÷4/÷3。
2. **LOO无偏**：对64条轨迹两两组合的4096对完整枚举，使用q(M1)q(M2)权重。平均估计须与`∇Σ_M q(M)F(M)`及独立有限差分一致。加入第一窗会改变第二窗分布的例子，避免只测独立单窗。负例确认共享首窗会破坏整轨迹LOO的保证，包含自身的均值基线会造成1/2缩放。
3. **梯度符号与分母**：用同一固定两轨迹和回报检查最小化surrogate负号、batch×2平均、全部24项总score；参数冻结时验证两个优势互为相反数。不能依赖一次随机更新恰好提高收益来验收无偏性。
4. **receiver及熵**：小状态枚举原17³联合动作与24项精确求和；logJ后验导数与有限差分一致。β=0与β>0分别验证sender回报确含receiver熵、receiver直接梯度含原1/3熵平均。
5. **tinyJ**：构造float64 J下溢为0但logJ有限的−1000、−20000级例子，确认F和优势有限、无epsilon或截断，logJ后验导数与独立参考一致；全无正R支持必须拒绝并保存错误。
6. **隔离与同步**：改另一条轨迹的抽样不得改变本轨迹输入；任意同窗消息变化不得进入同窗其他sender。固定PI合法观察时改变隐藏需求／物资，不得改变sender1输入；sender2/action只能通过已许可投递消息取得额外信息。silent改其他人的两窗token不得改变本人的sender2或action输入，自身token仍可改变。
7. **共享参数与更新时点**：三个主体×三个模块共9套参数和optimizer状态相互独立；两条完整轨迹采样及梯度计算之间无参数更新。所有符号one-hot是离散常量，不能通过接收输入把连续sender logits或私有hidden传给另一人。
8. **有限性与记录**：保存每更新样本状态哈希、两轨迹完整token、实际log概率或其可核回执、F/logJ/熵、LOO优势及各模块梯度范数，能区分估计错误与普通失败。任何正式预算、entropy或采样实现变动应在首次训练前另行冻结；不可凭中间成绩加窗口、重试seed或换估计器。

上述保证只涉及所定义目标的梯度估计和输入隔离。它不保证语言形成、不保证PI任务可解，也不把集中反事实收益训练当作原始社会只依靠自然反馈的直接模型。
