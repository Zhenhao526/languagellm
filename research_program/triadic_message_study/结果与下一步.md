# 三人有限符号共同学习：结果与下一步

本轮已完成16次固定训练及全部消息干预。**在这个三人采集任务中，有限符号通信提高了局部信息下的合作成绩，冻结政策也确实依赖跨人消息；但私人事实的行为区分在新布局上明显不足，搭档与表达结构仍有重要缺口。** 当前证据支持任务中有限的功能通信，尚不能宣称形成了稳定、可组合的语言，更不是人类语言起源的验证。

本轮使用随机初始化的小型神经网络，不是新增Qwen推理。三人分别有独立发送与行动参数，观察由人工定义的结构化特征组成。它用于建立可检查的共同学习基线，不代表用户放弃Qwen路线，也不与另一任务的DINO结果合并。

**固定设计与实际执行。** 保留物资种类、长短属性、搭档、目的地及原生搬运规则；没有加工或道路事件。4个新团队种子47101–47104分别运行完整／局部信息×开放／屏蔽跨人消息，初始参数、世界抽样及消息外生随机数配对。每人两窗同步发言，每窗4位，字母表为`@ # $ % & * + ~`，符号无预定含义。静默条件仍生成并保留自己的消息。

每次6000更新、每批256状态、每状态两条完整抽样通信轨迹。行动使用同一原生收益的精确条件期望，发送端使用已核对的leave-one-out估计；这是集中训练、独立执行，不能把反事实奖励计算次数等同原始社会的自然互动次数。16次共96000更新，实际主批211.604秒，唯一启动后退出0；没有按成绩重训、加步或补种子。部署评价固定采用greedy消息与动作，和训练时抽样通信有区别。[执行前方案](plan.md)、[冻结与预审](results/messages_001/root_preflight.json)、[完整原始结果](results/messages_001/execution/results.json)。

**私人事实能否通过消息用于行动。** 训练前固定4320对世界：保持听者的合法观察、所有需求与公共事实相同，交换另外两人看到的私有物资；只保留该听者在两世界可参与满分的动作集合不相交的对子。只有听者在自然两端都选择各自适合的行动，才计“双方适切”；仅动作变化不计成功。这是事先限定的诊断子集，不是整个世界分布的理解率。

双向移植其他人的两窗消息、重生听者自己的第二窗后，69120个供体概率向量精确重现。但同观察、同收到的历史本就应给出同一输入；这是实现恒等检查，不是69120次学会新词。移植针对一个听者，不能当作完整团队的反事实成功。测量、所有种子和双向读数见[完整干预汇总](results/messages_001/endpoint_probes_001/summary_001/汇总.md)。

逐条核查全部全域联合动作频数后，16个团队各自在143424个世界中均为同一对主体始终互选搭档、第三人始终等待。PI_live四种子依次为BC、AB、AB、AC；不同团队或不同条件选不同搭档不等于同一团队会随情境换搭档。位置／目的地行动有变化，但残余失配及固定分工仍限制对伙伴表达的研究。[全部16组提议统计与消息描述](results/messages_001/message_behavior_001/消息与伙伴描述.md)保留完整分母。

**可复核性与边界。** 数学检查通过：发送端两条独立完整轨迹的估计、两窗因果关系、稳定logJ及行动熵项均核对。实际执行独立审计重建96000批世界与消息随机流，核查96个检查点和448份评价文件；末点2294784世界的两窗神经前向独立重现，行动概率最大误差0，条件统计误差不超过6.66e−16。没有重放优化器或中间检查点的神经前向。[执行独立核验](results/messages_001/audit_execution_001/独立核验.md)。

末点探针177.854秒完成；只读汇总核对34560份配对观察与69120个方向。根另用独立结算和观察编码核查6884352个干预世界及全部常量条件实际输入，10.262秒通过；该核查没有重新生成干预的第二窗或加载权重。[独立干预记录核验](results/messages_001/endpoint_probes_001/root_record_audit_001/verification.json)。图表初版脚注重叠，保留原图及仅布局修正版，最终引用第三版；修改没有产生新训练或新指标。

**下一步的科学问题。** 这次四格及消息因果方法是已有工具，正结果尚不是论文创新。最需要改变的是表达压力的可检查定义：让不同情境需要不同伙伴，并检验消息是否因此形成可迁移的关系表达。当前支持允许长期固定伙伴取得相当收益；仅把“搭档”列在动作菜单里，不足以保证语言必须表达搭档。

已另做原需求域与“唯一兼容伙伴”候选的[纯静态枚举](next_ecology_static_001/静态候选评估.md)，检查固定伙伴上界与边际分布变化。它是下一设计的材料，不是已选择、冻结或运行的新训练。直接把多伙伴情境换成唯一伙伴会同时改变成功方案数、需求关联与优化难度；更窄的共同目的地候选虽能配平部分边际，却削弱目的地信息需求，不能直接当作满足四项表达要求的主实验。下一方案须保留对象、属性、搭档、目的地，并明确哪些因素同时变化。

功能通信之后仍须区分整块代码与成分复用：需要完整码重编码参照、成分替换与未见组合的行为测试；若研究互动本身，还需等带宽的互动／非互动参照，不能从两窗的存在推断修复机制。当前不追加近似调参来追求更高分。确认拆分、生态操纵、跨伙伴迁移和论文中心命题尚未完成，持续研究目标保持进行中。
