# 单槽联合组合留出转移探针

本包在 `matched_control_005` 的同一冻结策略、同一留出案例和同一 aligned/placebo 配对上，只改第一窗消息干预的粒度。`slot_0` 到 `slot_3` 分别替换一个 token 位置，`full` 替换完整四槽包；未选中的槽位继续使用接收者自然消息。第二窗和行动头重新前向计算。

这项后验实验回答的是“整体包络的方向性响应是否集中在某个位置”，而不是给符号预先赋予对象、属性、搭档或目的地含义。单槽效应为零不能证明没有语言，单槽效应为正也不能证明槽位就是词素；它只提供下一轮训练干预的识别依据。

正式批次固定 8 个种子、seen/all 两个 A 支持臂、static/rematched 两种安排和 live/silent 两个通道，共 64 个策略块。每个策略对 3,456 个有向留出案例评估五个掩码，aligned 和 placebo 使用相同案例配对。全程无优化更新。
