# 行动前互动、修复与新约定：六篇直接近邻

核查日期：2026-09-15。聚焦原始实验，属于设计前文献核查；不是系统综述、首创性证明或已冻结实验方案。本轮未运行模型、训练或修改旧实验。

**较有根据的研究问题是：在总交流额度相同、物理任务不变时，表达能否针对当前伙伴尚未解决的歧义作出回应，是否改变约定的形成与成分复用。** “多说几轮促进语言”已有大量近邻，也不能排除额外信息、计算和反馈。以下研究并未共同证明澄清、修复、承诺都促进组合结构。

## 必须区分的机制

| 机制 | 本研究中可观察的最低要求 | 单独不足的现象 |
|---|---|---|
| 请求 | 一方的消息引出另一方与当前信息缺口相关的回应 | 系统轮到第二人发言 |
| 澄清／修复 | 已有表达或理解存在歧义，后续互动针对该歧义调整解释或表达 | 第一次询问；增加一条任意消息；试错后奖励上升 |
| 确认 | 收到或理解的信号改变伙伴是否继续表达／何时行动 | 两次相同字符串；双方碰巧选对 |
| 承诺 | 可识别的未来行动表态形成相互预期，并预测后续履行或失配 | 同时选中匹配动作；研究者预置“同意”按钮 |

这是本项目的操作性区分，不是给主体的词典或发言模板。六篇中没有直接建立“行动承诺的形成导致组合表达”的因果结果；这只说明本次证据范围，不说明外部文献不存在。

## 已核实的直接干预

### 1. Kottur et al., 2017，EMNLP

*Natural Language Does Not Emerge ‘Naturally’ in Multi-Agent Dialog*，原文 §§2、4.1–4.3，Table 1。Q-BOT 私有待询问的两个属性，A-BOT 私有对象；固定两轮问答。作者改变词表和 A-BOT 的记忆。大词表支持整体对象编码；缩词表后仍可把属性对整体分区，第二轮缺乏稳定独立意义。进一步限制词表并去除 A-BOT 记忆才得到更稳定的属性／取值对应。[官方原文](https://aclanthology.org/D17-1321.pdf)；[复用本地 PDF](</Users/xia/Documents/ChatGPT/语言/文献调研_2026-09-14/论文/02_神经多智能体/2017_Kottur_Natural Language Does Not Emerge ‘Naturally’ in Multi-Agent Dialog.pdf>)。

**对本设计的约束：** 私有需求与问答轮次本身不排除整块编码。该研究的正结果同时涉及容量和记忆限制，不能归为“澄清的独立作用”。若我们的第二条消息只是整局码的后半段，互动窗口增加了容量，却没有证实局部修复或成分复用。

### 2. Evtimova et al., 2018，ICLR

*Emergent Communication in a Multi-Modal, Multi-Step Referential Game*，原文 §§2–3、6。双方分别得到图像与文字描述，交换二进制向量；接收者决定何时结束，最多十轮。论文分析对话长度、困难度和预测变化，并操纵消息维度。困难类别往往对话更长，域内预测随对话推进更确定；域外趋势较弱。[原文](https://arxiv.org/pdf/1705.10369)；[本地 PDF](</Users/xia/Documents/ChatGPT/语言/research_program/interaction_ecology_study/papers/2018_Evtimova_Emergent Communication in a Multi-Modal Multi-Step Referential Game.pdf>)。

**对本设计的约束：** 这是主动结束和双向新代码的直接近邻，但长度与困难度的相关关系不是随机分配“更多轮次”的效应。本文未建立等总位数的闭环与盲发比较，也未证明可解释的修复语义、搭档关系或组合语法。其文字描述输入还包含已有语言提供的结构。

### 3. Kalinowska et al., 2022，CogSci

*Towards Situated Communication in Multi-Step Interactions: Time is a Key Pressure in Communication Emergence*，原文 pp. 616–619。比较每步自动收到信号与主动索取：后者选择停留，下一步才获得信号，付出放弃移动的机会成本；同时研究局部视野和记忆。部分可见时，成功主体主要在岔路索取信息。报告展示最优超参数下的主体或同配置十次重复，不能视为全部配置的无选择平均。[作者原文](https://olakali.github.io/assets/pdfs/2022CogSciKaDaMaMuPi.pdf)；[正式论文页](https://escholarship.org/uc/item/61k7486v)；[本地 PDF](</Users/xia/Documents/ChatGPT/语言/research_program/interaction_ecology_study/papers/2022_Kalinowska_Towards Situated Communication in Multi-Step Interactions_Time is a Key Pressure in Communication Emergence.pdf>)。

**对本设计的约束：** 环境中的决策岔点与沟通时机可以联系起来，但索取动作由研究者预设，不能算“问句自行出现”。机会成本、可见性和记忆各有作用；不能把结果缩写为增加反馈促进语言。也不需要把迷宫、道路事件或额外行动代价搬入我们的任务。

### 4. Garrod et al., 2007，Cognitive Science

*Foundations of Representation: Where Might Graphical Symbol Systems Come From?*，原文 §§4.1–4.2，尤其 4.2.3。实验一比较反馈与角色轮换；实验二比较作画中反馈和画完后反馈。识别率没有反馈类型的显著主效应；实时条件图形简化较快，但按被试检验相关差异仅达边缘水平。超过最小反馈的试次很少：首块约 7%，之后约 1%。[出版方全文](https://onlinelibrary.wiley.com/doi/full/10.1080/03640210701703659)；[复用旧库记录](</Users/xia/Documents/ChatGPT/语言/文献调研_2026-09-14/数据/human_downloads.json>)。

**对本设计的约束：** 反馈时机已有直接操纵，不能当作新点。其结果还提醒我们：简单确认也可能支持简化，不能把一切改善归于复杂澄清。两条件并非精确等绘图量或等时间预算。图形简化与任务准确率要分开，更不能用前者替代组合结构。旧库 PDF 获取失败，本轮复用出版方可读全文，未重试下载。

### 5. Healey et al., 2007，Cognitive Science

*Graphical Language Games: Interactional Constraints on Representational Form*，原文 §§2–5。实验一在相同任务经验后安排群体内／跨群体配对；实验二将“不能编辑对方区域”与“双方上下区域互换显示”交叉操纵，干扰对对方图形局部的指向、修改和对齐，同时保留编辑自己图形等能力。操作改变抽象／具象图形的使用，早期表现影响随经验减弱。[出版方全文](https://onlinelibrary.wiley.com/doi/full/10.1080/15326900701221363)。

**对本设计的约束：** 最接近“修复能否定位表达的组成部分”的人类干预。作者讨论抽象图形的原始组合性；这与任意离散字符串的语法仍有距离。跨群体差别说明共同历史不能被累计任务经验替代。屏幕位置、编辑权限和可用指示方式一起影响互动，不是单纯保留等比特但关掉语义回应。

### 6. Fay et al., 2018，Cognitive Science

*How to Create Shared Symbols*，接受稿 §§3–9，PDF pp. 29–38 的实验二最直接。第一实验比较真实互动与重放式观察，并打破既有指称先例；第二实验在 60 对参与者中交叉操纵允许模仿伙伴符号与允许即时反馈。沿用符号主要帮助准确率，反馈主要帮助简化。禁反馈不仅禁匹配者画图，还使其不能在导演画完前选择意义并结束试次。[官方机构页](https://eprints.gla.ac.uk/157897/)；[接受稿](https://eprints.gla.ac.uk/157897/7/157897.pdf)；[本地 PDF](</Users/xia/Documents/ChatGPT/语言/research_program/interaction_ecology_study/papers/2018_Fay_How to Create Shared Symbols_Accepted Version.pdf>)。

**对本设计的约束：** 这是把互动组成分开的直接近邻，但“反馈作用”包含提前终止的作用，不能归为澄清内容。准确率和简化并非严格互不影响。也不能把禁止模仿直接移植为禁止主体复用约定；那会人为删除用户真正想研究的形成过程。

以上三项人类工作研究已有语言和社会认知能力的成人建立新实验符号，并非人类语言能力从零诞生。它们和神经实验可比较操作与过程指标，不能合并为同一机制的重复实验。

## 对下一步最有区分力的要求

以下是基于上述局限提出的设计判断，尚未实施。当前三人 Qwen 能力门槛未过；不能把本核查当成已经允许启动符号形成实验。已有 DINO 的目标可见性、课程、双方冻结和新组合适应，也不应包装成新的互动操纵。

**保留一个最小对照：行动前可回应伙伴当前消息，与同额度但发言前看不到伙伴本轮消息。** 同场物资、私有需求、身份分配、动作接口、原生奖励和训练批次保持相同。两条件每人都具有相同发送次数、每次长度上限、计算次数、训练更新与最终可见的本轮消息；盲发条件先独立产生全部消息，再统一交付供行动使用。可回应条件分窗口交付，窗口内仍同步，不泄漏他人尚未提交的动作。使用固定长度和固定交付时点时，可先避免长度／停顿的额外信道；允许变长后则须计入这些信道。这个比较识别的是**表达对本轮伙伴消息的依赖机会**，不是纯粹的“修复”效应；它本身也已有时序近邻，不足以成为论文中心贡献。

不能只报告该对照的总分差。应在同一有限任务内，事先枚举哪些局部观察下存在两个仍合理、却要求不同联合动作的世界；分别记录差别涉及对象、属性、可用搭档还是目的地。再验证当前消息究竟能排除哪种歧义。客观候选集合属于研究者分析，不提供给主体作语法槽位。若环境本来允许各人一次发完全部私有状态、随后用固定选择器完成，必须承认闭环并非信息论上必要；若想研究额外作用，就测形成速度、稳健性或成分复用，不能声称任务迫使主体学会提问。

| 有区分力的预测 | 为什么“更多消息／反馈”本身不够 | 否证或收缩结论的结果 |
|---|---|---|
| 在相同交流额度下，后续表达随伙伴当前未解决的歧义而改变，并补足相应信息 | 必须关联到缺口的具体内容，不能只数轮次 | 只有全局信息量增加；盲发同样解决所有缺口 |
| 交换或屏蔽与缺口有关的伙伴消息，会选择性改变后续回应和联合行动 | 保留数量和时点，改变的是配合关系；但这种探针仍可能产生分布外输入 | 效果只由任意扰动造成，无法区分相关与无关消息；仅学成后敏感，形成过程无差异 |
| 对同一成分的修正方式在不同对象、伙伴或目的地组合中复用，并迁移到预先留出的组合 | 整局码增加和第二轮查表也能提高成功率，不能自动满足迁移预测 | 成功提升但成分替换／跨情境复用失败；只在原整局组合有效 |

形成主张需要从初始参数到终点都记录上述关系，固定检查点和独立训练种子；仅在终点交换消息不能解释约定如何产生。成功率、形成速度、表达压缩、稳定成分复用分别报告，不以单一指标兼任。相关性和探针结果必须与原生未扰动表现配对，不能只挑出看起来像问答的对话。

对象／属性应在同场包含最小对照，搭档和目的地也必须存在会改变正确行动的反事实。私有对象句柄、合法菜单筛选或固定身份不能偷偷透露答案。只存在唯一搭档的场景无法检验搭档选择的表达需求；允许形成固定分工本身可以是结果，不应为强迫出现“伙伴词”而不断加难。共同动作接口可以规定搭档匹配，但不能把这一物理规则宣称为自发形成的承诺机制。先不加入承诺按钮、违约奖惩、加工、道路事件或额外社会层级。

**可保留的候选主张应比“多轮产生语言”窄，但比“多轮提高任务分”更强：行动前针对性互动，是否改变跨情境可复用约定的形成。** 若只得到更多可用信息带来的成绩提高，或主体始终使用整局码，结果仍应如实保留；上述文献不能为预期的组合语言结果提供保证。
