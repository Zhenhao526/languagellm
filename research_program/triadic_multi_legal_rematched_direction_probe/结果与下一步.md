# 随机重配策略方向性消息探针结果

## 结论先行

这次探针没有复现“随机重配会稳定增强方向性计划响应”。预先固定的主量是

```
[(rematched live − rematched silent) − (static live − static silent)]
```

其中每个单元先在三个发送者上取平均，再计算有符号的“供体方案转移 − 接收者方案转移”。16 个独立种子的终点均值为 **−0.3620 个百分点**，近似 t15 区间为 **[−0.8317, +0.1076]**；正向种子 6/16。作为参照，static 条件中 live−silent 的有符号计划转移为 **+3.6725 个百分点**，rematched 条件为 **+3.3104 个百分点**。因此方向性响应在重配后略小，而不是更大，且交互区间跨过零。

自然轨迹中的 `Q` 交互为 **−1.5160 个百分点**，区间 **[−2.8211, −0.2109]**；现场干预的 `Q` 交互为 **−1.3743 个百分点**，区间 **[−2.5011, −0.2474]**。自然轨迹和干预轨迹的条件 `Q` 交互分别为 **−2.7973** 和 **−2.0914 个百分点**，区间均跨过零。搭档转移交互接近零（**−0.0004 个百分点**，区间跨零）。

这批结果支持一个较窄的判断：在已有策略上，消息可使接收者的方案分布相对发送者方向发生小幅改变；随机重配没有把这种变化变成稳定的增强。它仍然没有显示符号层面的词义、组合性、生成传递或语言起源。

## 探针与数据

- 使用多合法行动 × 随机重配确认训练的 16 个新种子（66501–66516）和四个冻结条件：`static/rematched × live/silent`。
- 每个世界恰有两个收益相同的合法完整方案；方向探针把发送者偏向其中一个方案的自然策略，与只保留供体方案或只保留接收者方案的重放策略比较。
- 每个条件使用同一冻结的需求、布局、消息均匀数和主体分配；`live`/`silent` 只在通信可见性上不同。探针本身不再训练参数，因此这是后验策略测量，不是新的形成训练。
- 64 个最终策略、9,704,448 个案例、58,374,144 次模型前向；含 192 个 sham 行。独立审计的 `max_abs_error = 0`，四臂配对和自然／干预分母均通过。

完整冻结规则见 [`plan.md`](plan.md)。原始策略结果保存在 [`probe_004/execution/results.json`](results/probe_004/execution/results.json)，独立审计见 [`audit_002/verification.json`](results/audit_002/verification.json)，图表见 [`figures_001/`](results/figures_001/)。

## 解释边界

主量是训练暴露方式与通信可见性的差中差，不是消息字符串与任务变量之间的互信息，也不是新主体从旧主体处学习约定的指标。由于探针读取的是已训练策略，静态条件中出现的方向性变化可能来自动作先验、执行门控或主体状态的相关性；本轮不能区分这些机制，更不能据此宣称形成了词。

## 下一步

1. 在独立训练中加入一个与发起执行分离的显式中性／取消动作，记录发送、等待、取消和合法方案选择四个出口；这能检验当前的方向效应是否只是执行门控的副产物。
2. 预注册 rematched 条件下的方向探针，在新种子上同时报告供体转移、接收者转移、物理执行和 `Q|physical`，并把无消息 sham 作为固定阴性对照。
3. 只有当方向效应在新的训练批次、显式中性动作和主体重置后仍可重复，才进入形式—任务对应和代际传递实验。
