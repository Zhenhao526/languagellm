# 运行与数据接口

本目录以薄封装复用旧 `triadic_message_study.runner` 的九网络、两同步窗、抽样、训练梯度、Adam 与逐世界评价。准备阶段不初始化网络、不训练；本说明不是执行记录。

从工作区根目录，使用已指定的 Python3.12.14／NumPy2.5.3：

```bash
qwen_collect_pilot/.venv/bin/python -m unittest research_program.triadic_partner_ecology_study.tests.test_runner -v
qwen_collect_pilot/.venv/bin/python -m research_program.triadic_partner_ecology_study.runner prepare --out research_program/triadic_partner_ecology_study/results/partner_001
qwen_collect_pilot/.venv/bin/python -m research_program.triadic_partner_ecology_study.runner verify --out research_program/triadic_partner_ecology_study/results/partner_001
qwen_collect_pilot/.venv/bin/python -m research_program.triadic_partner_ecology_study.runner execute --out research_program/triadic_partner_ecology_study/results/partner_001
```

正式运行须在全部方案、源文件与独立预审冻结后由根任务启动一次。本轮不自动执行额外实验。已有输出目录拒绝 prepare；已有 execution 拒绝恢复或重跑。CPU四个 spawn worker 各负责一个种子，强制 BLAS 单线程；异常只终止本执行器持有的四个进程句柄，保存 failure/status，保留中途材料。

每个 worker 顺序运行 unique 与 multiple，每生态顺序 FI_silent、FI_live、PI_silent、PI_live。每臂重新初始化，同 seed 八臂权重初值相同、世界 U 与消息 U 相同。四列世界 U 分别决定目的地层、该层需求、布局与私有观察归属；跨生态只要求目的地／布局／归属配对，实际需求不同。同生态四臂完整状态也相同。外生 U、层编号、奖励表、全局索引与配平权重均为研究者数据，不进入政策输入。

每种生态两分区分别保留完整数组。每 worker×生态×分区只写一份 `weights_*.npz`，含 `full_weights`、`monitor_weights`、`monitor_indices`；评价记录引用相对 execution 路径、文件 SHA 与实际权重向量 SHA。不同 worker 的权重文件容器元数据无需逐字相同，数值向量必须相同。

单臂 `monitor.jsonl` 记录六检查点，两分区，每分区包含 `natural` 和 `closed`。`final` 也采用 `final[partition][mode]`：

- `uniform`：旧评价函数的全部原始枚举计数及均值，不是目标分布主读数。
- `weighted`：独立 metrics 按冻结目标权重给出兼容角色、物理匹配、满分、R、固定伙伴上界等。额外 exact 概率均明确以贪心消息轨迹为条件，不是全通信抽样期望。
- `raw`：完整联合动作的计数与概率权重、全量世界数。
- `data_file/data_sha256`、`weights_*`：实际数据与权重溯源。

live 的 closed 调用同信息条件的 silent 路由，使用同网络从第一窗起重新计算第二窗与行动，保留自己的消息。silent 的 closed 直接引用同一 natural 文件，`reused_natural=true`，不另算前向或伪造重复样本。672监测样本只用于固定曲线，不替代全量加权终点；监测中的 fixed_pair_oracles 仅是这672个抽样世界的上界，不能画作目标总体严格上界。两个生态的监测分别按局部索引排序，不能按行号配对，应使用 D／布局／归属键。

保存192网络检查点、576真实监测NPZ、96真实全域末点NPZ，另有16权重NPZ。自然末点3041280世界，live闭信额外1520640世界；监测387072世界前向。32×6000×256为49152000训练状态抽样、98304000完整消息轨迹、2359296000个符号分类抽样与同数24结构行动加权项。每worker奖励表190080×24=4561920项，四worker实际18247680项；这些集中反事实反馈不等于同等数量的真实单次物理互动。

测试只覆盖新接口、权重、跨臂配对及失败边界；使用假政策评价和假进程句柄，prepare 测试明确禁止网络初始化、输入数组构建或训练，不做正式 seed 任务成绩 pilot。旧数学核心 SHA 必须与已有审计一致。最终 `execution/results.json` 仅在32臂全部完整、配对核对与源文件复核通过后写出；不根据中间成功率停止或挑种子。
