# 符号频数与形成过程的描述

全部448份自然消息记录已处理：32组×2分区×（6个监测点＋1个完整终点）。另保留320段相邻检查点变化及1920个固定示例；每个监测记录取索引最前5个世界，不按成功或字符串外观挑选。唯一分析会话75203退出0，耗时2.173秒，无训练、神经前向或模型参数读取。

`summary.json`中的`frequency_array_row`对应`message_frequencies.npz`第一轴。`raw_string_counts`为448×2窗×3人×4096完整码的原计数；`weighted_string_mass`为同形状的加权概率质量；`weighted_position_symbol_mass`为448×2×3×4位置×8符号。完整码按8进制、首位置为高位编码。统计包括silent组自己生成但未投递给他人的消息。

完整终点使用21个目的地层等权的目标分布，监测使用固定672个世界的等权分布。两个生态全域大小不同，不能把原始类型数量之差直接解释成语言复杂度差；加权熵也仅描述输出分布，不能确定其语义。浮点累加可能使单一码的熵在零附近出现约1e−12以内尾差，原值保留，不将这些尾差作正负效应解释。

留出布局PI_live，3000→6000更新期间至少一人某窗消息改变的世界数，unique四种子依次为638、672、672、672／672；multiple为672、587、672、590／672。它们是相同固定世界上的表面代码变化，不代表词义改变，更不代表相邻未保存步骤均持续变化。

本描述的范围在整批执行期间固定，不是新增确认性终点。消息种类、熵和变化不能替代听者行为、语义反事实或组合干预。原契约字段`weight_loads=0`指模型参数载入次数；程序确实读取了评价所用的统计权重文件，且核对其SHA与分母。

完整内容见[summary.json](summary.json)、[全部频数](message_frequencies.npz)、[固定示例](fixed_examples.jsonl)。
