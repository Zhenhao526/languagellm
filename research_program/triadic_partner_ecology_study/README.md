# 伙伴可替代性与符号通信

本目录研究三人合作中，需求所允许的搭档关系怎样影响符号通信和参与角色选择。保留对象、属性、搭档、目的地，沿用原物理规则；不加入加工或道路事件。

当前状态：32次预定训练及独立执行核验全部完成。主要角色差中差为0，所有团队维持固定搭档；通信提高局部信息下的采集与物理匹配。完整结论见[结果与下一步](结果与下一步.md)，全部失败和反向差保留。没有补种子、延长或重跑训练。
