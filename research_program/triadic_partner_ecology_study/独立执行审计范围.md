# 独立执行审计范围

本文件登记独立审计准备，不是训练结果。审计器、8项离线测试及来源 SHA 见 `audit_test_preflight_002.json`；第一次测试的元组/JSON列表格式失败保留在001收据。没有查看当前主批成绩或做神经网络前向。

根代理确认32组全部完成后，执行一次：

```text
qwen_collect_pilot/.venv/bin/python -m research_program.triadic_partner_ecology_study.audit_execution --run RUN --out RUN/audit_execution_001
```

审计拒绝覆盖输出；失败留下 `failure.json`，不自动重试。

审计独立构造21个共同目的地层、两生态条件资源支持、18/6布局和6种观察归属，复建完整分层权重与固定672世界监测样本。监测在两生态各自按世界编号排序，配对依据目的地/布局/归属，不按排序后行号强配。完整终点的每个目的地层权重为1/21，各层内条件需求、布局、归属均匀；不把均匀世界比例当目标总体概率。

对每个种子的8个条件核验相同初始化、6000批外生世界随机数和消息随机数。实际世界编号只要求同生态四条件相同；两生态共同目的地、布局与归属相同。核验192000条日志、192个检查点、576份监测数据及96份完整终点。全部4561920个终点世界用独立9网络实现重算两窗消息、行动概率和贪心动作；中间检查点仅核参数、优化器数组、RNG及保存监测记录，不重新前向。

natural、live网络从第一窗关闭跨人通道后的closed分别核对。silent的closed是自然记录的明确引用，共224条引用，不新增数据文件或前向。旧独立消息审计和更早的基础环境/网络辅助代码各自绑定已完成审计收据中的源 SHA。

角色兼容、互选搭档、真正同步搬运、满分和原生回报分别核算。独立指标实现不调用正式 `metrics.summarize` 或 `primary_comparison`。主差中差由每个种子8个留出布局条件率重新构造，再等权平均4个种子；世界数量不能充当独立社会数量。

完整目标分布的固定搭档界为unique的1/3、multiple的31/39；监测界只由该672样本计算，不能称总体严格界。完整PI静默或从第一窗关闭消息的角色上界另有专门证明，不能将总体界直接用于监测样本。

审计不会重放优化器更新，也不重新计算历史梯度或从中间权重重建采样消息；日志中的采样消息哈希因此只核格式与记录绑定。通过代表保存数据、实现及预定统计口径相符，不证明已经形成组合语言。
