# 因子化中性动作的 full-information 能力对照 pilot

## 目的

前两轮 PL（只看自己需求）方向探针显示：整包首窗可改变部分联合行动质量，但对合法搭档边没有稳定响应。本 pilot 在独立新种子上把同一两个可替代搭档任务的需求观察改为 FI：每个主体直接看到三人的需求描述。它回答一个能力诊断问题：如果私有需求不再需要通过通信获得，行动头是否能表达和执行搭档选择；由此区分观察权限瓶颈与消息／行动机制瓶颈。

该 pilot 不是新的语言形成主实验。训练仍使用同一 strict 互选规则、两个同步四符号窗口、显式 neutral/engage 与16类提案；`live/silent`和`static/rematched`四臂保持配对。

## 冻结方案

- 独立种子66721–66728，共32次训练（8种子×2 schedule×live/silent），每次6,000步，保存0、100、500、1500、3000、6000六个检查点。
- 需求、布局、站点所有者和两个不同搭档对的合法方案完全沿用已审计的`altpair_001`生态；只把输入特征从PL替换为FI，并核对第54维full-information标记为1。
- `static`使用恒等需求分配，`rematched`使用同一独立六排列流随机重分配；每个schedule的live/silent共享世界、批索引、消息均匀数和重配排列。
- 预注册主诊断是条件`Q|physical`的重配×通信差中差时间AUC；同时记录物理执行、团队Q、engage、提案合法率、目标搭档率和搭档计数。

## 解释边界

FI 若提高目标搭档率，只能说明PL的私有信息结构限制了当前任务的行动选择；FI 若仍没有提高，则更支持消息路径、整包编码、信用分配或提案头饱和是瓶颈。两种结果都不能证明字符词义、组合语法、公共词典、代际传递或人类语言起源。pilot 的八个独立种子用于容量筛查，不能替代正式的16种子确认。
