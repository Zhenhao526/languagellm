# 显式中性／取消动作 pilot 结果

## 结论先行

本 pilot 没有形成可用的全员 `cancel` 协议。预先规定的主量是取消收益 0.10 相对于 0.00 对通信—条件 `Q` 作用的差异：

```
[(cancel=0.10 live − cancel=0.10 silent)
 − (cancel=0.00 live − cancel=0.00 silent)]
```

在 static/rematched 两种训练暴露上等权、四个配对种子（66701–66704）的条件 `Q` 中心化时间 AUC 为 **+0.1448 个百分点**，近似 t3 区间为 **[−0.4516, +0.7412]**；终点交互为 **−0.1240 个百分点**，区间 **[−1.5055, +1.2576]**。因此 pilot 没有给出中性收益会稳定分离方案选择的证据。

`cancel=0.10` 的全员取消率在所有最终新布局中均为 0；初始随机策略的少量 `cancel` 在第一次更新后消失，之后也没有混合取消。作为参照，两个取消收益格的通信作用仍主要落在物理执行：平均 live−silent 条件 `Q` AUC 为 **−18.9758**（cancel=0.00）和 **−18.8310 个百分点**（cancel=0.10），物理执行 AUC 为 **+54.3879** 和 **+54.5946 个百分点**。这与此前“通信提高是否执行，但不提高执行后的方案选择”的边界一致。

## 设计和审计

- 四个新种子 66701–66704；每种子八格 `static/rematched × cancel{00,10} × live/silent`，每格 6,000 步、batch 256，共 32 个训练运行。
- 任务保留对象、属性、搭档和目的地需求；每个世界恰有两个使用同一搭档对、不同地点的合法完整方案。动作 0 是被动 `wait`，1–16 是原有运输提议，17 是显式 `cancel`。
- 只有三人同时选择 `cancel` 才得到 0.10 的安全收益；混合取消阻断运输且得零分。训练目标是 24 个原有运输事件与全取消事件的精确 `log expected reward`。
- 保存 192 个检查点和 32 个新布局终点评估。独立审计逐检查点重放 31,781,376 个世界、286,032,384 次模块前向，`max_abs_error = 0`；动作维度、两种取消收益和 24,576,000 次重配分配均通过。
- 取消事件的 `log expected reward` 梯度另做有限差分预检，18 个动作、25 个事件的最大绝对误差为 `1.53e-9`（[`preflight_gradient.json`](results/pilot_001/preflight_gradient.json)）。
- JSON 汇总只读取 per-run 结果，没有新增前向或优化更新；图表已人工检查。

冻结方案见 [`plan.md`](plan.md)，原始训练结果见 [`pilot_001/execution/results.json`](results/pilot_001/execution/results.json)，独立审计见 [`pilot_001/audit_002/verification.json`](results/pilot_001/audit_002/verification.json)，汇总见 [`pilot_001/aggregation_001/results.json`](results/pilot_001/aggregation_001/results.json)，图表见 [`pilot_001/figures_001/`](results/pilot_001/figures_001/)。

## 解释边界

这是四种子 pilot，且全员取消协议在终点不可达。结果不能说明中性动作一般无效，也不能称词义、组合语法、公共词典、代际传递或语言起源。它只否证了当前“需要三名主体同时选择同一个新动作、但安全收益较低”的具体实现。

## 下一步

1. 不把本 pilot 的零取消率当作形成失败；先改用独立的 neutral/engage 意图头，让中性选择不与 16 类运输提议共享同一个动作 softmax。
2. 在同一改造中使用两个不同搭档对的合法方案，使参与者选择与方案内容可分别测量；继续保留 static/rematched、live/silent、物理执行和 `Q|physical` 分解。
3. 新批次必须使用全新种子并预注册中性率、参与者提案合法率和执行后方案选择；只有这些指标在独立主体上重复后，才推进符号形式—任务对应和代际传递。
