# 显式中性／取消动作试验

本包在两合法运输方案的任务上增加一个第 18 个动作 `cancel`。`wait` 仍是允许严格互选的被动第三人动作；只有三名主体同时选择 `cancel` 才形成对称的安全中性结果，混合取消会阻止运输且得零分。`cancel` 的收益在 0.00 与 0.10 两格之间配对操纵。

这是一个四种子探索性 pilot，用来判断显式中性结果能否把“是否发生物理执行”和“已执行后选择哪一个合法方案”分开。它不是词义或语言形成实验；只有在新的 16 种子确认中重复，并通过独立主体与形式干预，才进入代际传递。

设计和冻结规则见 [`plan.md`](plan.md)，结果生成后写入 `结果与下一步.md`。训练使用 18 维动作头，消息仍为两个四符号窗口、每符号八类无意义符号，观察仍是 PL 的对象、属性、搭档和目的地需求。
