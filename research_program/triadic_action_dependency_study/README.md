# 共享物资信息与三人需求表达

本实验比较共同可见的物资布局与分散的局部物资观察，检验它们怎样改变需求表达的形成。三人的个人需求在两组中都私有；每组各有开放／静默消息对照，并另设全部信息可见的能力参照。主体是随机初始化的小型独立神经网络。

新任务保留对象、长短属性、搭档、目的地及原17动作，新增联合资源要求，使预定三个内容轴的两端正确行动数均为1。所有条件共享同一批世界和原生收益，不屏蔽失败动作。

- **已完成：**[结果与下一步](结果与下一步.md)。24组训练及独立核验完成；双留出内容两端均正确率PL开放13.4190%、LL开放7.2879%，四配对差全正但两组不足1个百分点。24组仍固定伙伴，辅助满分率通信差中差两正两负，尚未证明组合语言。

`runner.py prepare`只做静态准备；`execute`拒绝覆盖已有执行目录。训练、末点评价与独立审计的前向分别计数，不把检查点、反事实端点或背景世界算作独立社会。

新需求留出检验的是未训练的三人需求关系，所有个体需求值在训练中都出现。任务中显式提供对象属性表示；自然内容适切和通道关闭效应尚不足以证明组合语言或人类语言起源。
