# 共享物资信息怎样影响需求约定：本轮结果

记录日期：2026-09-16（北京时间）。24组正式训练、完整评价、汇总和独立执行核验已完成。


**主要结果：**在未见需求关系和物资布局中，公开布局组的内容两端均正确率为13.4190%，局部观察组为7.2879%，四个配对差均为正，等权差+6.1312个百分点；其中两个差不足1个百分点。全部24个团队仍固定搭档，尚未出现灵活分工或组合语言的证据。

## 这轮实际研究什么

比较两种信息环境：PL中每人看得到四处物资，LL中每人只看到公共地点和自己的私有地点；两组都不知道其他人的需求。每组分别训练开放消息和静默政策，再以需求与布局全部可见的FI组作参照。六条件中的需求、布局、正确共同方案、动作菜单、收益、初始化和逐批外生随机数完全配对。[固定方案](plan.md)在本批初始化和成绩读取前冻结。

保留对象、长短属性、搭档和目的地，没有加工或道路事件。上一任务的对象／长短／目的地内容案例分别有1／1／2个正确听者动作；本轮增加“短木”等联合资源要求，并保留原单属性要求，使用全部5,376种恰有一个满分方案的需求关系。新任务三个内容轴的每个端点均只有一个正确动作；全部17种行动始终可选，失败照常结算。

这排除了一个明确的答案数量差异，却没有证明三轴同样容易。公开布局也减少了必须经消息传递的物资信息，因此本轮比较的是这一具体信息环境的整体效应。新旧任务还改变了需求支持和编码，不能把两轮成绩之差归因于单一因素。

主体是随机初始化的小型独立神经网络，三人各有两个消息模块和一个行动模块，九模块不共享参数。每人两窗交流，每窗4位、8种符号，没有预设符号词义；输入提供显式对象属性和需求接受集。这不是新增Qwen推理或DINO实验，也不是没有表征先验的语言起源模型。

## 主要结果与完整任务表现

唯一主要量是6000步完整双留出中的**内容两端均正确率**：只改变发送者的一项需求，保持听者自身观察、参与身份和所需搭档不变，要求听者在变化前后都选中唯一正确行动。对象、长短、目的地三轴等权，每轴再配平六种发送／听者组合和所有背景；全部失败保留。它测的是这一固定案例集中的内容区分能力，不是总体理解率。

PL／LL静默或关闭后的内容两端均正确率均为0：听者观察相同而两端正确动作不同，这个零是结构结果，不另算一次实验发现。开放政策关闭消息后的满分下降说明行动依赖通道，但关闭还改变输入分布，不能单独赋予字符词义。FI静默／开放的内容主量为22.3118%／19.6177%；FI直接看得到需求变化，不能把其正确率当成通信理解。FI仍固定伙伴且满分率不高，表明行动能力也限制本轮测量。

位置与目的地另行评分时，PL开放的正确率为22.3692%／31.2500%，LL开放为13.3774%／31.8548%；要求真实目标参与者行动并给对相应值，未按已学伙伴过滤。两者与角色共同正确才是完整满分；位置分项更弱并不能独自证明消息编码了哪个属性。

## 尚未形成按需求调整的角色分配

对全部96张自然终点动作频数表作[单独核对](role_pattern_description_001/说明.md)：24个政策在各自全部774,144个世界中，均始终由同一对主体互选搭档，第三人始终等待。完整联合动作仍有11–56种，变化发生在位置与目的地，不能把整套行动称为常量。不同种子采用不同伙伴，也不代表某一个团队能随需求换伙伴。固定分工本身可能是一种约定；本轮未见的是按需求调整的角色分配，不能笼统说没有任何角色约定。

所有自然终点的正确角色率因此均为1/3。PL/LL没有通信时，仅凭自己的需求决定角色的联合最优值尚未求出；固定伙伴可达1/3，独立枚举给出的上界在训练需求中为185/486≈38.07%，在留出需求中为23/62≈37.10%。这些是角色决策的界，不是完整采集任务的最优值；FI可见他人需求，不适用该无通信上界。[分区界的完整计数](train_heldout_role_bounds.json)保留。

需求内容主量对六个有序发送／听者组合等权，不按实际学得的搭档筛样。内容案例要求听者在两端都与发送者搭档；对于本批这种两人固定互选、第三人等待的政策，只有其中两个组合可能在内容两端都选对，因此该主量的上界为1/3。保留全体分母，不以仅选活跃伙伴后的高正确率替代主结果。

## 信息障碍确实存在，但不等于语义证据

[静态证书](context_certificates_001/说明.md)在四分区中均找到这样的两个世界：需求和归属不变，交换听者看不到的两处物资，听者的LL观察完全相同，唯一正确运输地点却不同；PL能看见这个差别。双留出实例中，C需要由S1改到S2运输，搭档A和目的地L保持不变，两端都不能靠等待取得满分。

这证明LL确实存在需要获得他方信息才能同时解决的局部歧义。它没有证明已学消息表达的是物资、位置还是整体方案；有重叠的证书计数也不能当作总体无通信失败率。

固定4个配对初始化51101–51104，每个初始化6条件，共24次训练；每次6000更新、批量256。正式执行仅启动一次，原会话95679退出0，耗时511.645秒。累计144,000更新、36,864,000次训练世界抽样和73,728,000条完整消息轨迹，没有追加种子、训练步数或修改冻结源。

四分区完整终点分别包含419,904／160,704／139,968／53,568个世界。新需求留出是未训练的三人需求关系，所有个体需求都在训练中出现，不是未见个体属性组合。形成监测在0／100／500／1500／3000／6000步覆盖每分区全部需求及两个固定背景；监测6000步与完整终点是不同评价，不能混入同一条全域曲线。

## 对论文方向的含义与下一步

现有证据仍不能支持“产生了组合语言”或已经有足够创新性投稿ICLR。任务使用消息、两个需求端点都选对、消息关闭后退步，分别限制了无用通道与部分行为解释；它们不能确定某个字符、片段或组合规则有可复用含义。当前通道容量也允许整体编码，消息较长本身不构成语言证据。

下一项工作应先冻结已有政策，检验同一需求消息换到另一物资布局后，听者是否依据当前布局作出正确行动。比较同需求供体与相反需求供体，保持两种供体背景一致，目标按接收世界重新计算；保留全部预定案例、失败和种子，不照抄供体动作。不先增加训练或只挑表现最好的团队。

整条消息跨背景有效之后，仍需把片段的发现和检验分开：在发现部分提出候选片段，在未参与选择的需求与背景中替换该片段，测其对预定属性的影响及其他行动成分是否保持。搭档表达另需解决全体政策固定角色的问题，不能把运输内容的局部进展写成分工约定已经形成。上述是下一实验方向，尚未冻结具体供体映射、片段选择或执行新干预。

[五篇原始工作的有界核查](先行工作与主张范围.md)说明，任务用途、属性区分压力和情境依赖已经有直接先行研究。本轮四篇PDF复用并核对，Choi等的官方全文在线阅读，但两次本地PDF取得失败，保留失败记录；没有新增取得的PDF。候选贡献仍需落在明确定义的信息环境、协议形成过程和跨背景内容作用的联合证据上，不能把更换任务或总体成功率提高称为首创。
