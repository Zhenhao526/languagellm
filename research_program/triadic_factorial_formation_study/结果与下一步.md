# 因素组合留出形成实验：校正后的结果与下一步

## 研究问题和设计

问题是：通信是否会使主体把训练中分别见过的对象因素和长度因素组合起来，响应从未出现过的对象×长度资源谓词。`factorial_holdout` 训练臂完全排除 resource 5（wood-long）和 resource 6（fiber-short），但保留 wood-any、fiber-any、short-any、long-any 以及相反的单属性组合；`saturated` 训练臂包含全部 5,376 个支持需求三元组。两臂都在 18 个布局上训练，并在训练需求、未见资源、未见布局和双留出四个分区评估。

每个配对初始化同时运行 strict/reciprocal × PL-live/PL-silent 四个条件，16 个配对初始化（62101–62116），每次 6,000 次更新，共 128 次训练。消息为两个同步窗口、每窗四个 base-8 符号；静默条件从始至终阻断跨人投递而保留同一离散网络。对象、属性、搭档和目的地保留，没有加工前置步骤和道路事件。`heldout_changed_actor` 是评价后按端点需求标注的九个主体×轴分层，标签不进入输入、奖励或训练。

预注册主量是未见资源分区的原生响应 Q：

```text
[(factorial live − silent) − (saturated live − silent)]
```

每个种子和规则先减去第 0 步，再在 0/100/500/1500/3000/6000 六个检查点按真实更新间距作梯形积分并除以 6,000，最后等权平均 strict 与 reciprocal 及 16 个配对初始化。Q 是两个端点都匹配研究者真值的行为指标，不是语言分数。

## 解释边界

这批数据支持三个有限结论：

1. 在当前动作依赖、固定主体和学习器中，跨人消息能提高部分协作任务的执行率。
2. 在 reciprocal 条件中，饱和训练臂的未见资源 Q 通信增益高于因素留出臂；因素留出没有产生额外的对象×长度泛化信号。
3. 端点响应 Q 对两端同时正确很严格，且只测行为对应，不等于词义、组合语法、公共词典、代际传承或人类语言起源。

因此，本轮结果不能写成“通信产生了组合语言”。更准确的论文表述是：**在固定三人协作生态中，通信增益依赖训练覆盖，简单的因素留出没有自动产生可迁移的对象×属性响应；这为区分协调码和可组合语义提供了一个可反驳的负边界。**

固定伙伴、整包查表、绝对符号绑定、位置触发和行动规则仍可能解释一部分 Q。之前的端点循环、随机符号双射和局部结构控制已经显示策略依赖整包编码，但尚未证明成分复用；本批的负交互也不能把这些控制自动升级为词义证据。

## 下一步

下一轮不应继续只扫描训练步数或符号排列。优先设计一个保留对象、属性、搭档和目的地、但让成功行动集合具有多个等价方案的任务：

- 在训练中随机化可替代搭档和目的地，避免固定伙伴查表成为最优解；
- 将发送者的对象、属性、搭档和目的地因素分别改变，并保证每个候选都有至少两个合法行动，另设全信息和无通信上界；
- 用新搭档和新布局同时测试“已见包在新主体上能否被使用”和“未见因素组合能否被响应”，把接收端行为、完整团队收益和消息形式分开；
- 继续保留六个形成检查点、silent/live、随机重编码和跨组包控制，不按中途结果加种子。

该设计才有机会把当前的负结果转化为机制论文：若新生态仍只得到整包依赖，则说明固定行动生态是关键限制；若出现对新搭档和新组合的稳定行为泛化，才可进一步讨论约定的内容结构。无论方向，必须先通过静态支持、无通信可解性和独立群体确认，再开启下一次训练。
