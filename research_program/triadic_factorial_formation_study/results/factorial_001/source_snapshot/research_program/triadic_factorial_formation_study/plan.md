# 因素组合留出形成实验（训练前固定）

## 问题

在三人协作任务中，通信是否能让主体把已经见过的对象和属性因素组合起来，响应训练中从未出现过的资源谓词？该问题把“通信有用”与“通信支持新组合”分开：同一套测试世界由一个饱和训练臂和一个因素留出训练臂共同评估，四个训练臂内再比较 live 与 silent 通道及 strict 与 reciprocal 结算规则。

## 任务与观察

每个世界有三人的私人需求、四个公共材料位置和三种私有位置所有权。需求由资源接受集合与目的地接受集合给出；主体只观察自己的需求、公共布局及官方可见的材料，其他人的需求块和 FI 标志为零。两个同步消息窗各四个 base-8 符号；第二窗接收第一窗的路由包；动作头从完整观察和两窗路由包中选择17个动作。训练目标、网络结构、采样和结算核沿用已冻结并独立审计的离散学习器。

## 语义因素留出

资源谓词编号5（wood-long）和6（fiber-short）在 factorial_holdout 的训练世界中完全缺席。训练仍包含宽谓词 wood-any、fiber-any、short-any、long-any 以及相反的两个单属性角 wood-short 和 fiber-long；因此 kind、length 和 destination 的边际都出现，测试的两种资源是对象×长度的未见组合。三人需求三元组只保留原生任务中恰好一个完整成功方案的支持世界。saturated 训练臂使用全部5376个支持需求三元组；两臂都只在18个训练布局训练，并在相同的6个留出布局上报告辅助结果。

四个完整评估分区为：训练需求×训练布局、未见资源需求×训练布局、训练需求×未见布局、未见资源需求×未见布局。每个分区包含全部6种私有站点所有权排列。`heldout_changed_actor` 边组只在评估后按研究者标签选取：需求响应边中改变的主体在前或后端点使用资源5或6；该标签不进入输入、奖励或训练采样。其九个改变主体×轴层都必须非空；`seen_changed_actor` 是同一测试分区内的对照。

## 预注册统计

唯一主量是未见资源分区 `heldout_changed_actor` 的原生 Q。对每个种子和结算规则计算 `(factorial live−silent)−(saturated live−silent)`，减去第0步，再在0、100、500、1500、3000、6000六个检查点按真实更新间距作梯形积分并除以6000；先对 strict 与 reciprocal 等权，再对16个配对初始化等权。报告近似 t15 区间；世界和边只构成分母，不当作独立社会样本。四个条件的原始 Q、Q-excess、共同 reciprocal 评分、完整成功率、行动和消息面板均作为辅助结果。

## 解释边界

若因素留出臂的 live−silent 响应高于饱和臂，结果支持“通信在新语义组合上提供额外行为泛化”。它仍不能单独证明组合语法、词义、跨代传承或人类语言起源；固定包查表、绝对符号绑定、行动规则和优化差异都需后续消融。所有结果在训练前固定种子、运行数量、检查点、边组和主要还原算法；不早停、不按结果增种子。
