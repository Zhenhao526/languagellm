# 接收者角色 C−A：单槽、符号重编码与闭通道结果

## 研究问题

角色分层 pooled 分析显示，C 相对 A 的整包 aligned−placebo 计划转移在 16 个源种子上仍低于零。本轮在独立确认批次的 A/C 终点上，把整包移植拆成四个单槽，并加入两个固定八符号双射，检验这个角色差异是否依赖整包、特定槽位或绝对 token 身份。

每个源端需求变化都沿 `kind`、`length`、`destination` 三轴构造同背景邻居；aligned 使用邻居源包，placebo 在相同发送者×轴×背景层内循环错配。`full` 替换四槽，`slot_i` 只替换第 i 槽，`recode_add1` 和 `recode_xor4` 对供体四槽先做固定双射再整包替换。`silent` 行是闭通道逐行对照，`live` 行重新计算第二窗消息和动作。

本轮仍是冻结策略上的后验机制探针，没有训练更新；它检验接口的因果敏感性，不能直接测量词义、组合语法或语言起源。

## 规模与审计

- 独立源种子 66709–66716 × A/C × `static/rematched` × `live/silent`，共 64 个策略块。
- 每块 76,032 条案例、56,160 个自然世界；7 个包变体共 238,786,560 次新模块前向；无优化更新。
- 生产结果通过不导入生产探针的独立重放：4,866,048 条案例（live 2,433,024）、64 个 checkpoint 哈希、76,032 个 placebo 映射，`max_abs_error=0`。sham 路由、静默别名和严格结算均通过。

## 解释

单槽结果保留了小幅正的 aligned−placebo 转移，但约为整包效应的一个较小部分；没有一个槽位单独复现 full 的幅度。C−A 在 slot_2 和 slot_3 仍略低于零，slot_0 和 slot_1 的区间跨零，说明角色差异在单槽干预下明显收窄而不是由某个单一槽位完整承载。

两种固定双射使 A、C 的 aligned−placebo 点估计都转为负，C−A 则变为约 +0.81 pp，区间跨零。这说明当前冻结策略对供体包的绝对 token 身份很敏感；它不支持“把符号任意重命名后仍保持同一内容”的强解释。由于双射只作用于分布外供体包，这个结果是接口鲁棒性边界，不能单独证明符号没有可复用意义。

物理执行和 Q 的 C−A 方向在不同变体中与计划转移不一致，`Q|physical` 大多跨零；因此这些变体没有把团队得分提供成内容语义的替代量。闭通道 silent 行逐行不变，说明上述变化来自跨主体 packet 干预而不是审计或自然路由差异。

## 下一步

1. 把 `recode_add1/xor4` 扩展为预先固定的全符号双射集合，并加入“发送者和接收者同时共享双射”的训练或评估臂，区分分布外破坏与真正的可重编码约定。
2. 在新主体训练阶段加入显式内容选择损失和持久符号库存；用单槽效应作为局部识别读数，用 full 与 recode 作为整包和 token 身份对照。
3. 只有在新主体能够在闭通道、单槽和重编码对照下保持跨情境内容转移，才进入代际传递；当前结果仍不足以称语言形成。
