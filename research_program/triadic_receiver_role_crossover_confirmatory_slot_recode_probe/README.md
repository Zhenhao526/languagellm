# Receiver-role crossover slot/recode probe

This post-hoc probe uses the independent `role_crossover_confirm_001` final
checkpoints for roles A and C. It compares full-packet transfer, four
single-slot transfers, and two fixed eight-symbol token bijections against the
same cyclic sender×axis×background placebo. `silent` is a closed-channel
alias; `live` recomputes the second window and actions. No training updates
are made. The primary quantity is the C-minus-A contrast in
aligned-minus-placebo signed plan transfer; it is a frozen task diagnostic,
not evidence for lexical meaning or language origin.
