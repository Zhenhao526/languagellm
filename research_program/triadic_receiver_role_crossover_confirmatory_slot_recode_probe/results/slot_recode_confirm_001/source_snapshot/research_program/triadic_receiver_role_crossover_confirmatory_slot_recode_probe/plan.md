# 接收者角色交叉确认终点的单槽、重编码与闭通道探针

在独立源种子 66709–66716 的 A/C 角色交叉终点上，不再训练模型。对同一背景内的
`kind`、`length`、`destination` 三条需求轴，把源端改变者第一窗的包按同一
发送者×轴×背景层内循环错配的 source packet 构造 aligned/placebo 对照。

本批只分析 A 与 C 两个位置，因为 pooled 结果预先给出了 C−A 方向；B 的整包
参照沿用上一批和确认批次的全角色结果。每个包变体都在三名发送者和三条轴内
先等权，8 个种子作为统计单位：

- `full`：四槽整包替换；
- `slot_0`–`slot_3`：只替换一个首窗槽位；
- `recode_add1`、`recode_xor4`：对供体四槽施加固定八符号双射后整包替换。

`silent` 是闭通道逐行对照；`live` 行实时重算第二窗和行动。首要读数是各变体
的 C−A aligned−placebo 带符号合法方案转移，同时报告物理执行、团队 Q、执行后
条件 Q、搭档转移和行动改变率。整个探针无优化更新，独立审计不导入生产实现。
