# 组合信号预实验结果与下一步（2026-09-17）

## 研究问题

本实验比较同等名义容量下的两种表达形式：`mono4` 用一个四值 token 表达两个二元因素，`dual2` 用两个二值 token 顺序表达两个因素。环境包含两个连续资源子任务；发送者知道两个私有目标，工作者只能看到局部资源状态。两种形式都能表达 4 种完整序列，但只有 `dual2` 提供了可检验的槽位结构。

实验矩阵包含 8 个 seed、10 个条件，交叉固定/轮换搭档、搭档身份隐藏/可见、live/silent 通道以及 factorized/entangled 任务。live 条件做闭合消息、整段置换和 dual2 槽位重组。先进行了 300-update 筛查，随后在同一冻结设计下完成 3000-update 完整批次。

## 完整批次结果

完整批次的独立审计包含 80 runs、240,000 条训练日志、80 个终点检查点、120,000 对 live/silent 轨迹，最大回放误差为 0。轮换隐藏 factorized 条件下，`mono4` 与 `dual2` 的通道必要性几乎相同；消息长度增加没有提高行为收益。`dual2` 的槽位重组在所有有定义的条件中均值为负，且轮换隐藏 factorized、entangled 和 visible 条件的区间均排除零。

终点码本揭示了原因：轮换隐藏 factorized 条件下，`dual2` 的 sender 在 8 个 seed 中平均只使用约 2.38 个完整序列（4 个目标组合），而跨 worker 的序列一致率为 1.0。部分 seed 学到了两个槽位各携带一个因素，另一些 seed 则把同一个因素复制到两个槽位，或只使用两个完整码字。因而当前任务确实能形成跨 worker 的公共离散协议，却没有稳定地选择可重组编码。

## 解释边界

这批结果把“训练不足”与“任务机制不支持组合性”区分开了：延长到 3000 updates 后，公共码本的通道因果效应稳定出现，但组合重组仍然失败。natural−silent 与 natural−permuted 接近，说明主要收益来自发送者和接收者共享一个具体码本；它不需要槽位具有独立语义。`dual2` 与 `mono4` 的行为收益近似相等，也说明单纯增加字符数不能推出语言结构。

这仍不是自然语言或人类语言起源模型。当前协议没有强制发送者在不同阶段承担独立的信息责任，worker 在第一个行动前即可看到整个消息，因此任意四码字协议都能完成任务。下一组实验的关键不是再增加字符，而是改变信息的行动依赖：让第一个 token 只影响第一个子任务，第二个 token 只在第二个子任务前可用，并加入未见的属性组合和新搭档迁移。只有在这种干预下，槽位重组仍保持成功，才有理由把结果称为组合机制。
