# 随机重配搭档确认实验

本包检验一个比“固定搭档留出”更直接的机制：训练时仍排除一个由需求定义的 AB、AC 或 BC 搭档组合，但在 `rematched` 臂中把每个训练世界的三份私人需求随机分配给物理主体；`static` 臂保持原始主体分配。这样可以区分固定物理搭档局部策略与对社会关系的可迁移响应。

本批固定 `partial + strict`，只比较 `live/silent` 通信和 `static/rematched` 暴露方式，使用 16 个新种子。主量是未见搭档两名主体精确行动率的“重配×通信”差中差中心化时间 AUC。它仍是任务行为指标，不是词义、组合语法或语言起源证据。完整冻结方案见 [`plan.md`](plan.md)。
