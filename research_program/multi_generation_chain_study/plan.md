# Multi-generation chain plan

Use the same staged, factorized, dual2 parent protocol as the action-dependent and receiver-representation studies. Leave one target combination out of child training for every seed. Replace worker 0 at generation 1, replace the hidden sender at generation 2, then replace worker 0 again at generation 3. `joint_history` indexes the complete received message history; `slot_local` indexes only the current staged slot for worker 0. Live and silent branches share all random streams at every event, and each event's final parameters are passed to the next event.

Primary outcomes are held-out live natural return, live−silent, recombined−natural, composability pass rate by generation, pass transitions across generations, and parent-stratum interaction. The experiment measures sequential protocol stability and finite-task compositional generalization; it does not by itself establish open-ended language or cultural semantics.
