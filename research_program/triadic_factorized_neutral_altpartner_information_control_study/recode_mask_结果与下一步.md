# FI 多符号重编码与字段遮蔽探针：结果与下一步

## 研究问题和范围

全信息（FI）正式批次已经表明，实时消息主要改变严格互选是否发生，未稳定改变执行后的搭档选择。本探针进一步问：这种作用是否依赖消息 token 的绝对身份、四槽顺序，或者只是依赖“有消息”这一可见位。它是固定策略上的后验机制测量，不是新的训练，也不测量词义、组合性或语言起源。

来源是 `fi_001` 的 64 个最终 checkpoint（16 个种子 × `static/rematched` × FI-live/FI-silent）。每个策略在 56,160 个新布局世界上评估。对每个选定发送者，第一窗对外包做以下十种变换，并重新贪心计算第二窗和行动：六个固定的八符号双射、四槽循环、四槽反转、跨人 payload 全置零、跨人 visibility 全置零。自身看到的包保持自然值。共有 1,920 条行（960 条 live 干预，960 条 FI-silent 别名对照），覆盖 107,827,200 个世界；执行只调用本地网络做前向重放，不进行优化更新，也不调用外部模型或 API。

所有效应均为“自然 − 干预”，单位为百分点；正值表示干预降低了指标。表中的区间是在 16 个配对种子上计算的近似 Student-t15 区间。

## 结果

FI-live 的家族均值如下。`symbol ensemble` 对六个双射等权，`position` 对循环和反转等权，`payload zero` 与 `visibility zero` 是单独的字段控制。

| schedule | 干预 | 团队 Q 损失 | 物理执行损失 | 执行后目标搭档率变化 |
|---|---:|---:|---:|---:|
| static | 6 个符号双射 | **+3.81** [3.05, 4.57] | **+7.17** [5.60, 8.74] | −0.75 [−1.00, −0.50] |
| static | 2 个槽位重排 | **+3.31** [2.51, 4.12] | **+6.47** [5.12, 7.81] | −0.74 [−0.98, −0.49] |
| static | payload 全置零 | +2.78 [1.99, 3.57] | +5.87 [4.48, 7.27] | −0.76 [−1.04, −0.49] |
| static | visibility 全置零 | +0.05 [−0.01, 0.11] | +0.30 [0.11, 0.49] | −0.03 [−0.08, 0.02] |
| rematched | 6 个符号双射 | **+4.21** [3.25, 5.16] | **+6.99** [5.43, 8.55] | −0.52 [−0.74, −0.29] |
| rematched | 2 个槽位重排 | **+4.00** [2.93, 5.06] | **+7.02** [5.49, 8.55] | −0.45 [−0.68, −0.21] |
| rematched | payload 全置零 | +3.47 [2.63, 4.31] | +6.57 [5.15, 7.99] | −0.58 [−0.82, −0.34] |
| rematched | visibility 全置零 | +0.02 [−0.06, 0.11] | +0.13 [−0.07, 0.34] | −0.02 [−0.07, 0.04] |

六个双射分别造成的团队 Q 损失在 static 为 **3.35–4.50 pp**，在 rematched 为 **3.08–5.46 pp**；每个双射的 16/16 种子均为正。槽位循环和反转也分别为 16/16 种子正。相反，visibility 控制的 Q 损失接近零（static 10/16、rematched 9/16 种子为正），而且区间跨零。FI-silent 的所有符号、位置和发送者变换都逐行等于自然别名，Q 和物理执行变化为零。

在同一组 live 策略上，六个双射的 `Q|physical` 变化接近零：static **+0.04 pp**（[−0.83,+0.91]），rematched **+0.53 pp**（[−0.30,+1.37]）；proposal 合法率分别下降 **2.33 pp**（[1.78,2.88]）和 **2.70 pp**（[2.01,3.40]）。两种槽位重排的 `Q|physical` 为 **−0.09/+0.27 pp**，proposal 合法率下降 **2.01/2.52 pp**；payload 全置零的 proposal 合法率下降 **1.67/2.14 pp**。visibility 置零的 Q 和 proposal 变化都接近零。也就是说，重编码的主要代价出现在“能否形成可执行提案”，而不是已执行样本的 Q。

选定发送者的六个双射平均 Q 损失（16 个种子区间）为：static 的 A/B/C 分别 **3.37 [1.45, 5.30]、3.79 [1.39, 6.18]、4.27 [2.21, 6.32] pp**；rematched 分别 **5.01 [2.96, 7.05]、3.82 [1.61, 6.02]、3.80 [1.80, 5.79] pp**。三名发送者都受到影响，但区间重叠，不能据此宣称已经形成固定的发送者分工。

## 解释边界

在这组固定 FI 策略中，改变跨人 payload 的 token 身份或槽位顺序会稳定降低提案和物理执行；只清除 visibility 位则影响很小，FI-silent 负对照也不变。这支持“策略使用了跨人整包编码及其槽位结构”这一任务机制描述。它不能区分查表、绝对符号绑定、槽位触发和组合规则，也不能说明 token 已获得公共词义。干预包属于训练分布外输入，损失本身不是语义理解的量尺；目标搭档率的轻微负值还受到物理执行分母选择的影响。

## 下一步

1. 在新的独立初始化中预注册单槽替换、局部 payload/visibility 遮蔽，并把目标搭档、对象、属性、目的地和 `Q|physical` 分开作为主要读数。
2. 让接收者面对训练中未出现的对象×属性组合，测量局部片段是否在新组合中产生可选择的行为；保留同整包重编码作为零假设参照。
3. 同时保留 PL、FI 和真正闭通道三层信息权限，区分消息通道的训练作用与后验干预作用。
4. 只有跨需求、跨搭档的接收响应在新群体中重复，才进入新主体或代际传递；在此之前不把整包编码敏感性写成语言形成。
