# 全信息观察与通信通道对照：结果与下一步

## 本轮目的

上一轮在部分信息（PL）条件中发现，live 通信显著提高了严格互选的物理执行率，却没有稳定提高已经执行后的搭档选择。这里把三人的需求全部放入每个主体的输入，比较 `static/rematched × FI_live/FI_silent` 四格。FI silent 是“事实已知、跨人路由关闭但保留自消息”的任务参照，FI live 用来检验在事实已经可见时，实时通道是否仍有额外作用。

这一步仍然是任务协调实验。它没有词汇、语义标签、教师动作或跨代传递，因此不能把结果称为语言形成。

工作区曾有一批 66721–66728 的 FI pilot；其 rematched 重配误用了 PL 版需求块变换，已标记为 `invalid_by_information_remap`，不进入本报告统计。当前结果只使用下面冻结的 66701–66716 正式批次。

## 冻结设置

- 16 个独立种子 66701–66716；每个种子有 static/rematched 和 FI live/silent 四条训练，共 64 条，每条 6,000 更新。
- 每个世界包含 3 个需求、4 个地点材料和 3 个私有地点所有者；需求集合含 1,560 个组合。每个世界恰有两个 full-success 方案，并且两个方案使用不同的搭档对；AB+AC、AB+BC、AC+BC 各 520 个需求。
- 行动由两个头给出：`neutral/engage` 意图头和 16 类地点—目的地—搭档 proposal 头。第三人需要保持 neutral，结算要求双方严格互选。
- FI 观察含三人的全部需求、公共布局、地点所有者和自身身份；live/silent 只决定两段四符号消息是否通过真实路由传递。rematched 每个训练世界从六种需求—主体置换中独立抽样，static 使用恒等置换。
- 四条运行在同一种子内共享初始参数、世界均匀数、批索引和消息均匀数；live/silent 在同一 schedule 内共享重配流。FI 与 PL 是分别训练的两个人口，跨信息层比较只作描述性分析。

## 预注册读数

主量是目标搭档率（已发生物理配对后，实际搭档是否属于该世界两个合法搭档对）的重配×通信交互：

`[(rematched FI_live − rematched FI_silent) − (static FI_live − static FI_silent)]`

每个种子先在六个检查点上计算中心化时间 AUC，再在 16 个种子上给出近似 Student-t 区间。次量包括团队 Q、`Q|physical`、物理执行率、proposal 合法率、engage/neutral 和第三人 neutral。FI 与已审计 PL `altpair_001` 的同种子差异在独立 JSON 文件中计算，并标明为跨训练群体的探索性对照。

## FI 结果

主量均值为 **−0.0079 个百分点**，近似 t15 区间 **[−0.1756, +0.1599]**；终点交互为 **+0.0029 个百分点**，区间 **[−0.2023, +0.2080]**，6/16 个 AUC 为正。也就是说，在三人需求全部可见时，live 相对 silent 没有给重配条件下的执行后搭档选择带来稳定额外增益。

主量的次量交互（中心化时间 AUC）为：团队 Q **+0.4172 pp**（[−1.2032, +2.0376]），`Q|physical` **+0.3437 pp**（[−1.1881, +1.8754]），物理执行率 **+0.1817 pp**（[−0.3017, +0.6650]），proposal 合法率 **+0.3968 pp**（[−1.1796, +1.9732]）。engage 率和第三人 neutral 率在四格间的交互为 0；最终贪心策略在每个世界保持两人 engage、一人 neutral 的结构。

新布局终点的 16 种子均值如下，目标搭档率的分母是已经形成严格物理配对的世界：

| 条件 | 团队 Q | `Q\|physical` | 物理执行率 | 目标搭档率 |
|---|---:|---:|---:|---:|
| static silent | 37.17% | 42.52% | 87.35% | 67.72% |
| static live | 47.11% | 51.53% | 91.43% | 67.60% |
| rematched silent | 36.58% | 41.98% | 87.01% | 67.68% |
| rematched live | 47.72% | 52.45% | 90.96% | 67.44% |

FI live 相对 FI silent 的主要变化是团队 Q 约增加 10–11 个百分点、`Q|physical` 约增加 9–10 个百分点；目标搭档率基本不动。这把“形成一对可执行行动”和“在两种合法搭档中选对哪一对”分成了两个不同读数。

## FI 与 PL 的探索性对照

PL 采用同一任务和行动头，但每个主体只看到自己的需求和公共布局。把两个已完成的 16 种子训练群体按 seed 对齐后，终点 FI−PL 差异为：

| 条件 | Q 差异 | `Q\|physical` 差异 | 物理执行率差异 | 目标搭档率差异 |
|---|---:|---:|---:|---:|
| static silent | +18.46 pp | −6.61 pp | +48.88 pp | −14.06 pp |
| static live | +1.95 pp | +1.38 pp | +1.70 pp | +0.46 pp |
| rematched silent | +18.09 pp | −8.03 pp | +49.48 pp | −14.27 pp |
| rematched live | +3.91 pp | +3.11 pp | +2.43 pp | +0.14 pp |

PL silent 的物理执行率较低，但一旦形成配对，目标搭档率较高；FI silent 更容易形成配对，目标搭档率接近两合法搭档的对称基线。PL live 把执行率提高到 FI live 的相近水平，而两者的目标搭档率也接近。这些是两个独立训练人口的描述性差异，不能单独归因于“看见其他需求”这一因果效应；同种子配对只减少了报告噪声，不改变训练群体不同这一事实。

## 同一策略的关闭通道探针

在 64 个最终 FI 策略上做只读后验干预：保留第一窗 token，把两窗的跨主体消息 payload 和 visibility bits 全部置零；live 策略的自然条件保留全路由，silent 策略的自然条件保留自身消息。对每个策略分别重放自然与 closed 两种路由，共 128 个评估、7,188,480 个世界和 64,696,320 次模块前向。

live 训练策略的自然减 closed 差异为：

| 训练 schedule | 团队 Q | `Q\|physical` | 物理执行率 | 目标搭档率\|physical | 提案合法率 |
|---|---:|---:|---:|---:|---:|
| static / FI live | +14.83 pp | +2.48 pp | +25.46 pp | −1.81 pp | +9.38 pp |
| rematched / FI live | +15.14 pp | +2.35 pp | +25.64 pp | −1.77 pp | +9.56 pp |

live 两行的目标搭档率点估计为负且区间不跨零，但这是在物理执行分母显著减少后对保留下来样本的条件比例变化；它不能被解释为搭档词义。通信关闭主要损伤执行发生率和提案合法率，没有显示稳定的正向搭档选择增益。对 silent 训练策略，保留自身消息相对完全 closed 的 Q 增益较小（static +6.27 pp、rematched +5.64 pp），目标搭档率区间跨零。独立关闭通道审计检查 64 个 checkpoint hash、128 行和两种自然路由，`max_abs_error=0`；因此这项后验探针支持把消息路径作用定位为“是否形成可执行配对”，不能把它写成公共搭档词义。

## 多重重编码与逐字段遮蔽

在相同的64个最终策略上继续做更细的局部干预：每个选定发送者分别使用六个固定八符号双射、四槽循环、四槽反转、跨人 payload 全置零或跨人 visibility 全置零；自身消息保留，第一窗改变后重新计算第二窗和行动。三名发送者、十种变换和四种策略条件共1,920行，live干预和FI-silent自然别名各960行。完整表格和解释边界见[重编码遮蔽探针报告](recode_mask_结果与下一步.md)。

FI-live的自然−干预团队Q损失，static/rematched分别为：六个双射 **3.81/4.21 pp**，两种槽位重排 **3.31/4.00 pp**，payload全置零 **2.78/3.47 pp**；对应物理执行损失为 **7.17/6.99、6.47/7.02、5.87/6.57 pp**。visibility全置零只造成 **0.05/0.02 pp** 的Q变化，区间跨零。六个双射和两种槽位重排在每个schedule均为16/16种子Q损失为正；FI-silent的符号、位置和发送者变换逐行等于自然别名。执行后的目标搭档率没有同步下降，反而因保留下来的物理执行样本选择性而小幅上升。

这组结果把作用定位到跨人payload的绝对token和槽位结构，而不是visibility位本身；它仍然只说明固定任务策略对分布外整包干预敏感，不能区分查表、槽位触发、符号身份绑定和组合规则。修正后的独立审计重放1,920行、107,827,200个世界和328,872,960次模块前向，`max_abs_error=0`；一次发现own路由辅助函数问题的审计保留在`audit_recode_mask_fi_invalid_001/`，不进入统计。完整逐指标汇总见[summary_002](results/recode_mask_fi_001/summary_002/summary.json)，图表见`results/figures_recode_mask_fi_001/`；早期两图版本保留在`results/recode_mask_fi_001/figures_001/`。

## 单槽位 payload 与符号探针

为区分“整包损坏”与局部位置作用，在同一64个最终策略上又对A/B/C发送者的四个槽位逐一做 payload 清零、`(t+1) mod 8` 和 `t xor 4`，共2,304行、129,392,640个世界。单槽Q损失小于整包清零：static/rematched 的 payload 清零为 **+0.25/+0.22 pp**，符号加一为 **+0.55/+0.47 pp**，XOR4为 **+0.44/+0.52 pp**；四个槽位均有小幅正效应，跨 schedule 没有稳定的单一“语义槽”。FI-silent 行逐行等于自然别名。

这一步仍是固定策略的后验敏感性测量。它支持跨人代码的分布式整包依赖，但不能区分查表、位置触发、符号绑定和组合规则，也没有证明词义或语言形成。执行和独立审计分别覆盖393,569,280次模块前向，`max_abs_error=0`；详细表格见[单槽位报告](single_slot_结果与下一步.md)，汇总见[summary_001](results/single_slot_fi_001/summary_001/summary.json)，图表见[figures_single_slot_fi_002](results/figures_single_slot_fi_002/)。

## 解释边界

本轮支持的最窄说法是：在当前因子化行动、严格互选和整包四符号通道中，知道三人的需求足以显著改善任务执行，但并没有让 live 通道稳定改变两种合法搭档之间的选择。它没有证明主体形成了公共符号，也没有测量词义、组合性、可重编码接收、跨新需求泛化或代际传递。

FI silent 不是一般意义上的能力上界：它仍受网络容量、策略梯度和固定行动接口限制。FI live 与 FI silent 的小差异也可能来自整包消息的策略扰动、信用分配或随机优化历史。PL–FI 的终点差异尤其不能视为同一群体内的处理效应。

## 下一步

下一轮应把“知道事实”和“必须借助公共符号表达事实”分开，并增加能区分内容选择的检验：

1. 把本轮后验重编码转为新独立群体的预注册实验：使用单槽替换和逐字段遮蔽，同时测量目标搭档、地点、目的地、长度和 `Q|physical`；只有在去除绝对位置、身份和整包键后仍按需求改变行为，才有理由讨论接收内容。
2. 在新的独立种子群体中同时训练 FI、PL 和真正的 closed-channel，保持任务与奖励一致，并把训练期通道依赖与后验通道依赖分开报告。
3. 让新需求改变合法搭档集合，检验 live 策略是否能跨需求、跨搭档迁移，而不是只在既有两个搭档对中提高执行率。
4. 只有上述行为指标稳定后，再引入新主体或代际传递；届时比较人工语言实验中的共同使用、替代和传承，而不是先把整包 token 的一致性称为语言。
