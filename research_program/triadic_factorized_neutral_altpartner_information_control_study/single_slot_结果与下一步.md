# FI 单槽 payload 与符号探针：结果与下一步

## 研究问题和范围

上一轮整包重编码显示，FI-live 策略依赖跨人 token 身份和四槽顺序。本轮把干预缩小到一个槽位，检验损失是否集中在某个固定位置，或是否所有槽位都承担类似的协调作用。这仍是固定策略上的后验机制测量，不是新的训练，也不测量词义、组合性或语言起源。

来源为 `fi_001` 的 64 个最终 checkpoint（16 个种子 × `static/rematched` × FI-live/FI-silent）。每个策略在 56,160 个新布局世界上，对 A/B/C 三名发送者的第一窗跨人包分别干预四个槽位。三类预先固定的变换是：该槽 payload 清零、该槽 token 做 `(t+1) mod 8`、该槽 token 做 `t xor 4`；自身看到的包保持自然值，随后重新计算第二窗和行动。共有 2,304 条记录（1,152 条 live 干预，1,152 条 FI-silent 解析别名），覆盖 129,392,640 个世界；只做本地前向重放，不进行优化更新，也不调用外部模型或 API。

所有效应均为“自然 − 单槽干预”，单位为百分点；正值表示干预降低了指标。区间是在 16 个配对种子上计算的近似 Student-t15 区间，并先在同一条件的三名发送者上取均值。

## 结果

| schedule | 单槽变换 | 团队 Q 损失 | 物理执行损失 | 目标搭档率变化\|physical |
|---|---|---:|---:|---:|
| static | payload 清零（四槽均值） | +0.25 [0.14, 0.36] | +0.75 [0.59, 0.92] | −0.14 |
| static | token +1（四槽均值） | +0.55 [0.35, 0.75] | +1.34 [0.97, 1.72] | −0.18 |
| static | token XOR 4（四槽均值） | +0.44 [0.27, 0.61] | +1.16 [0.91, 1.41] | −0.19 |
| rematched | payload 清零（四槽均值） | +0.22 [0.10, 0.34] | +0.55 [0.35, 0.76] | −0.10 |
| rematched | token +1（四槽均值） | +0.47 [0.30, 0.64] | +0.98 [0.60, 1.37] | −0.13 |
| rematched | token XOR 4（四槽均值） | +0.52 [0.33, 0.71] | +1.01 [0.80, 1.22] | −0.12 |

单槽效应明显小于上一轮整包 payload 清零的 Q 损失（static/rematched +2.78/+3.47 pp），说明当前策略的跨人信息不是由单个槽位独占。静态条件下 payload 清零的四槽 Q 损失为 slot0/1/2/3 **0.255/0.154/0.186/0.407 pp**；slot3 相对其余三槽平均的差为 **+0.21 pp**（[+0.01,+0.41]）。随机重配下对应为 **0.162/0.321/0.120/0.268 pp**，差异区间跨零。两类符号替换在四槽间没有稳定的单槽优势，slot0–3 的区间大多重叠。

FI-silent 的所有单槽变换逐行等于自然别名，Q 和物理执行变化为零。这是因为干预只作用于跨人块，而 silent 路由本来就没有跨人 payload。目标搭档率的轻微负值来自物理执行分母变化，不能解释为搭档内容的传递。

## 解释边界

在当前任务中，单槽 payload 清零和单槽 token 重编码都能稳定但幅度较小地降低 live 策略的执行质量；影响分散在四个槽位，没有得到一个跨 schedule 都稳定的“语义槽”。这支持跨人代码具有分布式整包依赖，同时不能区分查表、位置触发、符号绑定和组合规则。单槽干预仍是训练分布外输入，损失不是语义理解的量尺；它没有证明公共词典或可组合语言。

## 下一步

1. 在新的独立训练群体中预注册单槽替换和逐字段遮蔽，并以对象、长度、目的地、伙伴和 `Q|physical` 的接收反应为主要读数。
2. 让训练中未出现的需求轴组合进入测试，比较自然包、整包重编码和单槽重组；只有局部替换能在新组合中选择性改变相应行为，才可讨论功能成分。
3. 同时保留 PL、FI 和真正 closed-channel 三层信息权限，区分训练期通道作用与后验干预作用；在跨需求结果重复前不进入代际传递。
