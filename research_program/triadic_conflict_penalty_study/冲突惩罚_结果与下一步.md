# 第三人冲突惩罚梯度实验：结果与下一步

## 结论先行

本轮把第三个主体的约束从二元 strict/reciprocal 规则改成五个连续成本水平：`c0/c25/c50/c75/c100`。在这些条件下，匹配的一对主体仍然可以物理执行；如果第三主体 engaged，native reward 乘以 `1−c`。strict 作为硬约束锚点单独报告，不纳入连续斜率。

实验包含 8 个独立种子、6 个约束水平、PL/FI、static/rematched、live/silent，共 **384 次训练运行**。预注册主量是每个种子在五个成本水平上的 `live−silent` 目标搭档率斜率，日程先在种子内平均；目标搭档率只在已经发生物理执行的世界中计算。

PL 中目标搭档率的中心化时间 AUC 斜率为 **−12.94 个百分点 / penalty**（近似 t(7) 95% CI **[−14.02, −11.87]**），8/8 个种子为负；终点斜率为 **−12.74 pp / penalty**（**[−14.99, −10.49]**）。从 `c0` 到 `c100` 的目标搭档率 AUC 差为 **−11.31 pp**（**[−12.51, −10.12]**）。FI 中相同斜率为 **−0.49 pp / penalty**（**[−1.45, +0.47]**），区间跨零。

因此，第三人冲突成本在 PL 中确实产生了稳定的剂量反应，但方向是：成本升高把通信后的执行搭档选择推向 strict 的负向模式，而不是恢复一个更好的公共搭档选择。成本上升同时使第三人更少 engaged，物理执行率和惩罚后团队 reward 增加。这个结果把“约束改变主体参与结构”和“消息携带了可迁移的搭档内容”区分开来。

## 冻结设计

- **世界**：三名主体、四个地点、四种材料、六种站点所有者排列；1,560 个三人需求组合。每个组合恰有两个 full-success 方案，而且两个方案使用不同搭档对；AB+AC、AB+BC、AC+BC 各 520 个。
- **信息**：PL 只观察自身需求及公共布局；FI 观察三人的需求及同一公共布局。两者使用相同的 54 维特征接口。
- **通信**：两个同步窗口，每窗四个位置，每位置八类无意义符号；live 将消息路由给其他主体，silent 保持发送者私有。
- **行动**：neutral/engage 二分类意图头，加 16 类地点—目的地—搭档 proposal 头。
- **连续成本**：`c0=0`、`c25=.25`、`c50=.5`、`c75=.75`、`c100=1`。c 水平采用 reciprocal 物理执行；第三人 engaged 时只改变 reward，不改变匹配 pair 的物理执行。strict 要求匹配 pair 之外第三人 neutral。
- **训练**：8 个新种子 `66901–66908`，每个 run 3,000 次更新、batch 256；检查点 `0/100/500/1500/3000`。同种子内共享初始参数、世界均匀数、批索引、消息均匀数和重配排列。
- **模型**：本地 CPU NumPy float64 tanh MLP；无 LLM、视觉模型、外部 API、教师标签或语言预训练。

冻结方案见 [plan.md](plan.md)，准备快照见 [prepared.json](results/conflict_001/prepared.json)。

## 主要剂量反应

数值为百分点；斜率的单位是“live−silent 增益每增加 1.0 penalty 的变化”。区间为跨 8 个独立种子的近似 t(7) 95% 区间。

| 信息 | 目标搭档率 AUC 斜率 | 目标搭档率终点斜率 | c100−c0 AUC | c100−c0 终点 |
|---|---:|---:|---:|---:|
| PL | −12.94 [−14.02, −11.87] | −12.74 [−14.99, −10.49] | −11.31 [−12.51, −10.12] | −10.83 [−12.60, −9.05] |
| FI | −0.49 [−1.45, +0.47] | −1.34 [−3.09, +0.41] | −0.52 [−1.29, +0.26] | −1.21 [−2.79, +0.36] |

PL 五档终点的 `live−silent` 目标搭档率均值依次为：`c0 −3.44 pp`、`c25 −3.51 pp`、`c50 −6.33 pp`、`c75 −13.70 pp`、`c100 −14.26 pp`。strict 硬约束锚点为 **−14.18 pp**。线性斜率在 8/8 个种子上为负，但五档终点逐档严格非增的种子只有 3/8；主要变化集中在 c50 到 c75，不能把曲线描述成精确的线性或逐档单调函数。

FI 五档终点的目标搭档率增益接近零：`c0 +0.69 pp`、`c25 +0.39 pp`、`c50 +0.40 pp`、`c75 −0.53 pp`、`c100 −0.52 pp`。这与 FI 已经公开全部需求后，通信对搭档选择的额外作用很小相一致。

## 解释边界

本轮证明的是：在研究者定义的三人协调任务中，连续的第三人冲突成本会改变主体的参与结构，并在 PL 条件下系统性改变 live 通信对执行后搭档选择的影响。它没有证明主体形成了词义、公共词典、组合语法或人类语言。

限制包括：

1. 消息字母表、窗口长度、行动类别和奖励结构均由研究者给定；不存在从连续感知中分割符号的过程。
2. 需求仍是工程化的 54 维状态，主体没有视觉世界模型、身体运动或自然资源库存。
3. 五档成本改变训练目标，并非自然生态中独立出现的变量；c100 与 strict 的物理结算仍不同，只能作为锚点而非同一个条件。
4. 每回合只有两次消息窗口，回合之间没有持久历史、社会记忆、新主体学习或代际传递。
5. 目标搭档率是任务内方案读数，尚未通过跨需求消息移植、未见组合重组或跨主体传递检验内容可迁移性。

## 下一步

1. **第三人成本的独立确认**：使用全新初始化和更少的训练网格，重复 PL 的 c0/c50/c75/c100，并加入无通信 reward-matched 对照，排除成本导致的单纯 reward 标度变化。
2. **持续社会生态**：引入持久库存、稀缺资源、私有采集结果、伙伴切换和多回合信用分配；把消息成本、资源收益、执行和选择同时记录。
3. **内容可识别性**：在形成训练中加入跨需求局部消息替换、同层 placebo、未见对象×属性组合留出，检验消息是否携带可迁移的需求内容，而不只改变参与率。
4. **主体能力比较**：保留当前 MLP 作为无语言控制，再加入冻结视觉编码器或本地开源视觉—语言模型的无语言接口；比较世界状态理解、行动能力、短期记忆和符号学习各自的贡献。
5. **新主体与代际传递**：只有当持续生态中的局部消息干预和未见组合读数稳定，才替换一个主体并测试其从任务后果恢复公共约定；随后再评估代际保真度。

这轮结果适合作为 ICLR 论文中的机制剂量反应和负边界实验；距离完整论文仍缺少自然感知、持久社会后果、独立新主体形成和可迁移内容证据。
