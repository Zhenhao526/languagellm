# 八意义类容量压力正式结果（2026-09-18）

正式矩阵包含 9 个 seed、3 个任务、3 种消息形式、3 种适应方式和 3 个噪声水平，共 81 个 parent 与 729 个 child。三片执行的独立审计均通过，合并后的 parent/child 训练日志为 243,000/2,187,000 行，配对噪声轨迹为 1,458,000 行，最大回放误差为 0。紧凑结果、冻结方案和收据位于 `results/formal_20260918/`。

`shared8` 的候选端点在 `triple2` 中为 78/81，在 `quad2` 中为 75/81，而 `atomic16` 为 0/81。`coadapt` 的 `shared8`/`triple2` 自然回报在 p=0、0.10、0.25 时分别为 0.800、0.770、0.645；对应的 `quad2−atomic16` 配对差值在 p=0.10 和 0.25 时为 +0.149 [0.132,0.167] 与 +0.203 [0.178,0.228]。这说明在等原始容量下，多个二值坐标可以在重复后果压力下形成受噪声保护的协议，而原子 token 没有同样的 codebook 几何。

更高意义熵的控制没有达到候选标准：`unique8` 与 `repeat4` 均为 0/81。`repeat4−unique8` 的平均配对效应在三种噪声下为 +0.048、+0.032、+0.019，而 `shared8−unique8` 为 +0.261、+0.225、+0.159；局部重复的增益小且不稳定，全局重复的增益更大但随噪声减弱。`shared8` 仍然只包含两个 parity 类，因此这项结果加强了“重复后果可诱导冗余”的机制证据，却没有跨过开放词汇、组合语法或高熵意义映射的门槛。

下一项关键实验应把高熵目标留出和行动依赖同时加入，检查已形成的重复码是否能被新对象和新组合重新解释；随后再将该干预移植到能力匹配的视觉或本地模型主体。
