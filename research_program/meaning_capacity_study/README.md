# Meaning-capacity repetition study

This study tests whether the repetition effect survives when the meaning space expands from four to eight goal states. `unique8` uses eight distinct balanced Boolean meanings once each, `repeat4` repeats four independent meanings twice each, and `shared8` repeats one three-bit parity across all eight stages.

`triple2` has eight raw message states. `quad2` and `atomic16` both have sixteen raw states, providing a capacity-matched comparison between four binary coordinates and one atomic token. Messages arrive simultaneously before action, and hidden partners rotate. Noise, scratch/worker-only/coadapt adaptation, paired streams and codebook geometry follow the lower-entropy repetition study.

The candidate rule is natural return ≥ 0.60, minimum relevant code distance ≥ 2, and for `shared8` identical codewords within each parity class. The formal matrix is planned as 81 parent and 729 child runs. This is a mechanism test of discrete protocols, not a claim that the agents have acquired human language.
