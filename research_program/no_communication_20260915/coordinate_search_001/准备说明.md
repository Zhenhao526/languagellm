# I1–D1 有限最佳回应搜索：已准备，尚未执行

本包的目的仅是提高合法无通信策略的可达下界。研究者用已知的完整分布评价决策表；实际策略每人只读本人需求、公共物资和自己的私人物资，不能按完整世界临时选择动作。这不是主体通过互动形成语言，也不声称求出了全局最优。

已冻结 [代码](coordinate_search.py)、[计划](plan.json)、[初始策略](initial_policies.json) 与11份来源文件的快照和摘要。准备阶段没有评价收益、进行坐标更新或启动模型。

- 分布：996张需求表与24布局均匀独立，完整遍历23,904个规范状态；公开位置重命名代表另外6种观察分配。
- 策略：每人144种合法局部观察，每种观察始终保留原17个动作；观察编号和每人动作字段均随策略保存。
- 起点：已验证的固定AB公共位置L策略，以及种子2026091501–2026091507生成的7个均匀随机动作表，共8个。随机表在收益评价之前固定。
- 搜索：每个起点最多20整轮，每轮依次更新A、B、C。固定另两人的表，对一人的每个观察计算17种动作的完整状态期望，选择最佳回应；平局优先保持原动作。
- 停止：一整轮没有严格收益改善时停止该起点，仍继续其他预定起点。不会因结果追加起点、轮数或重试。
- 核验：以整数成功单位比较收益，每次坐标更新及整轮均不得下降；始终不得超过43,200/47,808＝75/83。保存每次坐标更新、每轮结果、所有8个最终策略与局部一致性检查。

最多480次主体坐标更新、195,056,640次候选动作的状态结算，另有实际策略评价与一致性核验。这些都是纯NumPy数学运算，不是模型调用或主体训练步数。

审核后运行入口为：

```sh
qwen_collect_pilot/.venv/bin/python research_program/no_communication_20260915/coordinate_search_001/coordinate_search.py verify
qwen_collect_pilot/.venv/bin/python research_program/no_communication_20260915/coordinate_search_001/coordinate_search.py execute
```

`execute`会再次验证冻结来源，并排他创建`execution`目录。任一检查失败时保存失败记录，不覆盖已有结果。最大值只是这8个起点内找到的可达收益；即使坐标搜索收敛，也不构成全局最优证明。
