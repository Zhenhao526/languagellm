# 表达需求与设计取舍

**独立设计审查；没有启动训练，也不修改[原草案](../下一轮生态操纵草案.md)。** 本文对需求表做纯组合枚举。结果描述在充分信息下存在哪些满分行动，不是分散无通信策略的上界；后者由根代理另行验证。

当前任务确实让物资类别、目的地和人员配合影响结果，但**不要求每条消息显式表达“对象＋属性＋搭档＋目的地”，也不能排除四类物资的整体代码**。这不是继续增加场景复杂度的充分理由。应先明确研究的是必要区别怎样被通信与共同情境共同承担，还是要证明主体形成了可迁移的成分结构。

## 对象和长短并非每次都必须组合

枚举方法：每人需求为“约束种类或长短、所需二值、可接受目的地集合”，共12种；枚举12³=1728张表及每张表的3种搭档×4种物资×2个目的地，保存同时满足两人的方案。使用相同语义判断即可逐项复核以下计数。这里不使用图像、策略或权重。

| D1充分信息方案性质 | 原996表：至少两组可行搭档 | 追加的612表：唯一搭档 | 合并1608表 |
| --- | ---: | ---: | ---: |
| 有一个只约束物资种类的满分搭档方案 | 270 | 162 | 432 |
| 有一个只约束长短的满分搭档方案 | 270 | 162 | 432 |
| 所有满分搭档方案都同时约束种类与长短 | 456 | 288 | 744 |
| 有一组满分搭档接受L/R任一目的地 | 316 | 36 | 352 |
| 所有满分方案都只能去L | 232 | 288 | 520 |
| 所有满分方案都只能去R | 232 | 288 | 520 |

前三行互斥并穷尽各列；后面三行不是穷尽分类。原996表中，540张存在可以省掉一个对象因素的满分方案。例如两人都只要木材且目的地兼容，长木材和短木材都有效；没有必要为本次行动区分长短。另456张的每个满分方案都结合了一人的种类要求与另一人的长短要求，确实要求选对相应的类别组合。这些情形应分开评估，不能把全部996表都当作同样强的组合需求。

D0中，每人的需求本来只约束一个对象因素，每次独立交付不要求种类与长短同时满足两人的联合条件。D0仍可能需要群体掌握两类区别，但其单次动作与D1的联合条件不同。这正是结算开关增加的要求之一，不能隐去后再把差异全部解释成抽象的“合作强度”。

更弱的固定值策略也覆盖相当一部分状态：原996表中，D1固定只用某一种类仍有735张可满分，固定只用短物资也有735张可满分；D0相应各849张。它们不能覆盖全部状态，但未经分层的平均收益可能掩盖对某个因素的省略。这些都是充分信息、允许按状态选择其他行动的计数，不是可执行无通信策略的得分。

## 四类整体代码仍是完整解，不能用加长消息排除

四种物资始终构成完整的种类×长短对照，能防止“目标从缺少某个干扰项或类别频数直接推断”。它并不防止主体把四类分别当作四个整体类别，学习四个互不相关的符号。

一个理论上的整体协议已经足以说明这一点：第一窗口，每人广播“自己的私人位置是哪一类物资”和“自己的12类需求是哪一类”的组合代码；公共位置和观察归属已知，所有人即可恢复完整地图与需求，按同一确定规则选择一个满分联合行动。以已知公共类别为条件，每人的私人组合至多3×12=36种；I0连私人需求都不用再传。这只是证明整体编码可行的研究者构造，不能作为主体示范或训练词典。它也不是推荐两个字符作为实验语言。

若要证明功能上的成分复用，必须对**同一已形成协议**检验种类、长短的最小改变和未见用途组合，并与容量匹配的整体代码及行为等价整体重编码比较。需要观察哪些消息成分能在控制语境后被替换、保留或重新组合。增加更多有限物资类别只会扩大整体查表，不会逻辑上迫出词法。仅成功选择“短木材”不能证明消息由“短”和“木材”两个单位构成。

## 搭档选择与固定分工是不同问题

| D1充分信息下的限制 | 原996表中仍可满分 | 612张唯一搭档表中仍可满分 | 合并1608表中仍可满分 |
| --- | ---: | ---: | ---: |
| 固定由A/B配对 | 804 | 204 | 1008 |
| 固定C必须参与，另一人可按状态选择 | 996 | 408 | 1404 |

原支持中每张兼容图至少两条边，所以每个人总有一个兼容伙伴。这使固定C参与、另外一人随需求变化成为合法的满分组织方式；固定C不等于固定搭档。D0更允许固定A/B分别完成各自需求，始终不服务C。

如果这种不对称角色由对称初始化、相同接口和环境机会下的互动形成，它可以是研究结果：例如谁成为常驻协调者、角色如何稳定、角色改变时约定是否保持。不能因为它不符合“每人轮流做所有事”的期待就判为失败。只有论文主张要求**伙伴身份和参与者构成必须随需求调整**时，永久固定参与者才是该主张的缺口。

即便参与者确实变化，也不要求消息里出现独立的人名或“伙伴词”。广播自带发送者身份，主体可以只表达自己的需求，伙伴根据发送者标签和公开约定推导谁参与。I0中，所有需求原本共享，参与者甚至可按共享需求表确定，通信仅解决物资在哪里。身份标签、共同规则和语境都在承担指称功能；不能把动作中的伙伴字段直接认定为新语言中的关系成分。

## 目的地会改变正确行动，但也可能被语境省略

固定总去L在原996表中仍有764张D1满分方案，固定总去R同样764张；它们都会漏掉另一边独占的232张表。两种目的地因此在整个任务支持上都有实际作用。

但这不表示每次都需要发一个目的地符号。316张表存在同一搭档可任选L/R的方案；其他状态中，某人的私人需求、被选择的搭档或I0共享表也可能已经唯一确定地点。主体采用稳定默认目的地，仅在默认不适用时发消息，是可以成立的约定。应在“换目的地会改变成功与否”的状态上检验功能，不能用省略率本身否定表达能力。

同理，消息是否承载对象、长短、搭档或目的地，必须在其余可见情境相同或受到明确控制时判断。全局消息与某因素相关，可能只是它们共同依赖需求或发送者角色；全局不相关也可能是信息被语境吸收。

## 最小建议：先不改物理规则，按主张决定是否扩展需求支持

**当前无需为强迫出现四类显式词项而改环境。** 先完成996表上的实际无通信边界验证，保留原收益、动作、观察与运力规则。后续报告至少分开：540张有单因素替代方案与456张联合条件不可省略的表；目的地独占与可省略状态；固定参与者与实际换人行为。该分层不增加训练条件，也不把参与者的自发分工排除在研究之外。

如果下一轮的中心主张确实需要检验“任何人都能因需求变化而退出/参与”，最小可选修订是**只把已可解的612张唯一搭档需求表纳入支持**，不增加对象、属性、动作步、加工或道路，不改奖励。支持将由996变为1608张，语义状态由143424变为231552个。唯一搭档分别为AB/AC/BC各204张，因此任何固定人物都应在204张表中退出，才能维持满分；同时保留原996张的多方案选择。

这项修改只在上述角色适应主张下有必要，也不解决整体四类编码。612张唯一搭档表测试的是被需求约束的参与选择，原996张才保留多方案协商；必须分层报告。扩大支持还会改变需求相关性和无通信策略价值，不能沿用996表的边界当作1608表的证明。本轮不自动采用该修订，更不追加一整套训练矩阵。

新增物理能力、顺序任务、更多属性或奖励项都不是当前必要修复。先区分有限整体约定、语境化省略、自发分工与跨情境成分复用。自然收益N、冻结函数可达性U和固定输入下的消息干预需要配对记录；随机接收映射也可能有较高U，任何单项都不足以命名“语言形成”。

以上结论既不证明通信已经必要，也不预测增加匹配约束会改善表达结构。它们限定本轮无通信验证和未来主张的含义，避免让场景复杂度代替证据。
