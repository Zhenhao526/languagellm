**建议下一次实际训练先做“部分完成效用0.5与0.1”的配对对照。** 保留原世界、观察、网络、训练目标形式和数据流，使用新初始化，并包含FI静默、PL静默、PL开放。它首先检验现有角色固定是否受局部合作收益影响。当前“冻结发送者＋新人接收者”可以形成有用的离线解码诊断，但不宜直接解释成约定形成机制或新人习得；伙伴可用性任务更贴近后续表达需求，仍需静态证明固定搭档和观察泄漏不能成功。

## 一、目前确有的证据和未决解释

上轮在同四个开发初始化的500步观察到：PL的完整双窗包有正向需求作用，但按训练响应选出的单位置对应作用为零；八位置平均作用不全为零。这个观察至少容许三种解释：原包的可迁移内容不足；原行动头未能利用已有内容；关联式选位未找到已有局部作用。三者可以同时存在。任务自然全队成功率仍低，最终角色也未实现随任务变化，因此不能先假定主要瓶颈是词义结构。

消息响应、可解码、原政策使用和团队改进是四个不同判断。Lowe等的原始矩阵实验已显示发送关联可以不伴随对听者的作用；其按世界干预消息的CIC对应行为影响，而非特定词义正确性。[Lowe等，AAMAS2019，正文§3–4](https://ifaamas.org/Proceedings/aamas2019/pdfs/p693.pdf) 因而此次任何新探针均须和原生通信干预并列，不能替换原生证据。

## 二、“冻结发送者、新接收者”须先明确冻结对象

当前推理图按顺序为：

`各自观察 x → 三人的第一窗 m1 → 路由 m1 → 三人的第二窗 m2 → 路由 m2 → 三人的行动 a`。

第二窗输入包括自己的第一窗和其他人的第一窗；最终行动同时使用本地观察、两窗路由消息。动作发生在交流结束后，没有同轮动作返回发送模块的边。

|实现|结构是否自洽|能够测量什么|
|---|---|---|
|固定六个发送模块及原始双窗轨迹，仅另训最终三个行动解码头|是；行动头不会改变本轮消息生成|旧互动产生的完整转录在给定观察下，能否被额外训练的行动解码器利用|
|重置一个人的全部模块，其他两人发送模块冻结，在线生成新转录|是；但消息样本不再是旧的冻结转录|新人改变第一窗后，固定伙伴如何回应，以及新人能否适应整个交互过程|
|重置整个接收者，却同时强制使用旧供体的第一、第二窗包|并非自然在线互动|一个带外部转录回放的混合系统；旧第二窗含旧伙伴输入，不能称冻结发言人对新人的回应|

因此，原建议里存在的不是时间图本身有环，而是**把“固定原消息”与“让新完整主体参与互动”同时当成一个处理**。两者不可同时保持。选择第一种时，应使用“行动解码探针”名称，明确它没有学会发送和互动，也没有进行代际替换。

Rita等已有冻结发送者、另训探测听者的直接先例；其信息／共适应分解基于重构Lewis游戏的后验和似然。我们可以借用诊断逻辑，但不能直接将三人行动损失差称为该文的KL共适应项。[Rita等，NeurIPS2022，§2–3](https://papers.nips.cc/paper_files/paper/2022/file/093b08a7ad6e6dd8d34b9cc86bb5f07c-Paper-Conference.pdf) 此处复用前轮全文笔记及本地文本，未重复下载。

### 最小可解释探针对照

1. 固定同一世界集合与同一批自然转录，训练观察独用、观察＋完整外来转录、观察＋预先所选位置三类行动解码器；结构容量、更新数、训练种子和留出划分匹配。输入遮罩保持通道维度一致，报告每类实际信息。自己的第二窗可能已经汇总他人第一窗，不能在所谓“没有外来消息”条件里保留这一中介而称观察独用。
2. 标签可以使用环境唯一完整合作计划的动作，但须写明这是研究者监督探针。它估计任务相关信息的可提取性，不能与原奖励训练的学习难度直接等同。亦须有完整可见状态的同预算解码器，以识别网络或训练能力不足。
3. 所选位置失败而完整转录成功，仍不能断言“没有局部结构”。要另测全部八位置，或用独立训练／验证集选择另一位置后在最终留出测试；不能在测试集选最佳位置。每个发送者、属性、窗口和伙伴保留独立结果。
4. 原始行动头的自然和单位置干预仍需报告。完整探针成功、原头失败最多支持“在此监督、模型和预算下存在额外可提取信息”；其差可以来自规划、损失函数或训练预算，而不只来自接收词义。
5. 有限预算探针失败不证明消息没有信息。有限离散域可另按`(合法接收观察, 可见消息)`分组，计算真实标签冲突及理想分类上界。该值是明确域和分布上的静态可辨识上界，不是新agent的泛化表现，也不能用测试标签选探针。

这套诊断能缩小三种解释，但不可能仅用一次新接收者训练彻底排除所有“信息存在但难解码”的情形。原头未使用与新头可提取也不互斥。

## 三、完整双射重命名的有效范围

符号的八类编号在one-hot表示里应当是坐标。固定、与世界无关的双射保留完整消息的信息量和等值关系。它有两个不同用途：

- **离线探针的坐标对照。** 对保存转录的全部可见符号一致重命名，再训练新行动解码器。若初始化的相关输入权重也按同一置换配对，则理论上应得到等价的前向与优化轨迹，可作实现检查；若只用相同随机种子而不置换输入权重，有限预算的不同结果包含随机初始化坐标差异。不能据此定义词义漂移。
- **在线协议的等价性检查。** 第一窗发送输出、所有第二窗接收输入、第二窗发送输出、最终接收输入及自身历史均须一致处理。可在所有接收入口解码回原编号，或严格置换相应one-hot输入与输出通道。只改向他人的符号、却保留原sender2的编号解释，会改变第二窗行为和分布；那是协议破坏干预，已不是纯命名。

每世界随机置换会销毁跨样本约定；只置换一个位置会改变该位置与其他位置的关系；保留自路由原编号而改变他人编号则引入不同词典。这些可以成为独立干预，但都不能标成“完整命名等价控制”。

## 四、部分完成效用对照为何更适合作为下一轮训练

根任务当前候选为4个新配对初始化 × 2个部分完成效用 × 3个条件，共24次训练。训练效用定义为未满足0、仅满足一人`c∈{0.5,0.1}`、两人满足1；原生物理结算、满足人数和旧0／0.5／1分数继续单列。不要把0.1称为原环境的一半需求被满足程度，它是研究者设定的优化效用。

**解析判断，不是新实验结果。** 固定世界及已采样双窗消息，令F是独立行动分布下完全成功概率，P是恰好满足一人的概率，则：

`J_c = F + c P`。

原目标是各世界`log J_c`的均值，加原熵项；它不是先取全域均值再取对数。给定唯一满分联合动作`a*`，奖励加权行动分布中满分动作的权重为：

`ρ_c = F / (F + c P)`。

行动logit的梯度是奖励加权边缘分布减当前行动分布；它可分成权重`ρ_c`的唯一满分动作项和权重`1−ρ_c`的部分成功动作项。c从0.5降至0.1，固定当前政策时会增加满分动作项的相对权重。因此它同时改变局部合作的相对价值与学习梯度；这属于对该训练机制的明确定义，不能包装成信息量改变。

若c=0且满分联合动作唯一，则`log J_0 = Σ_i log π_i(a_i* | history_i)`。在固定消息下，行动更新除原熵项外等同唯一计划的监督对数似然。用0.1保留部分成功支持可避免完全退化到这一极限；但仍在连续地接近这个极限。应记录F、P、J和ρ，而不只记录平均训练效用。ρ须逐世界计算再平均，不可用平均F与平均J的商代替。

**局部均衡判断。** 原子匹配规则要求两个主动者地点、目的地和彼此身份相符，第三人等待；三人同时运输使本轮失败。对一个已匹配且获得正效用的部分成功联合动作，任意单个人改变其唯一动作都会破坏匹配、让配对消失或造成过载，所得效用为0。故在固定状态、共同效用的一步行动博弈里，这类部分成功计划仍是严格单边协调均衡。c保持正数时，下调c不会消除这些均衡；它只改变收益差和学习的相对吸引力。该静态判断不是神经政策跨状态学习必然锁定的证明。

### 预先固定的解释标准

|新结果模式|可支持的解释|仍不能支持|
|FI静默和PL开放都提高满分和任务对应伙伴选择|部分效用／协调训练影响角色固定，信息充分时也存在该影响|信息不足是唯一瓶颈；已产生语言结构|
|FI静默提高，PL开放仍受限|原优化已能利用完备信息，私有需求条件还有额外瓶颈|自动把剩余瓶颈全归因于通信；PL规划仍可能困难|
|PL开放相对PL静默的增益随c改变，且关闭通道显著损害新政策|通信参与了收益操纵引起的适应|收益改动直接产生词义、组合性或伙伴词|
|只有平均效用变动，满分／角色正确率不提高|目标改变主要重排部分成功或概率质量|角色锁定已被解决|
|三组均未改善|所选效用差和预算未解决当前瓶颈|部分成功收益与角色固定完全无关|

唯一主量宜固定为留出域**完整成功率的收益×通信交互**：`[PL_live(0.1)−PL_silent(0.1)]−[PL_live(0.5)−PL_silent(0.5)]`，种子内配对后完整报告。伙伴正确率和完整三角色正确率作为关键机制读数；还需按任务真值AB／AC／BC分层报告，防止原先固定一对改为另一固定一对被当成进步。FI静默的c效应是能力／协调参照。若根计划把“角色是否解锁”设为唯一主量，也可行，但须冻结前选定一个主量，不能事后挑较好者。

新种子应独立于旧四开发种子；同一新种子各处理保持初始网络、训练世界流、消息采样随机数和预算一致。配对不增加独立群体数，24政策只有4个初始化区组。训练期间监控仅用于计划内记录，不能看结果后追加种子、改c或择优延长。跨世界的密集评估也不能替代更多独立初始化。

### 与已有协调研究的距离

Sunehag等已有共同奖励下的lazy-agent问题：一人学到可用策略后，另一人的探索可能降低团队收益，导致后者停止有效学习；他们以价值分解缓解，并把角色信息、共享权重、通信作为增强项研究。[AAMAS2018正式扩展摘要，2085–2086页](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p2085.pdf) 我们的三人任意两人配对、全行动期望和离散消息梯度不同，不能直接借其名称宣称同一机制；也不能以修复角色固定本身声称新的语言形成理论。本次只核对正式3页版本，没有冒称复现其完整预印本。

Peysakhovich与Lerer在广义Stag Hunt中改变代理的亲社会效用，考察是否更容易协调到较优均衡。[AAMAS2018正式扩展摘要，2043–2044页](https://ifaamas.org/Proceedings/aamas2018/pdfs/p2043.pdf) 本任务所有人已有相同团队奖励，0.5→0.1不是把自利者改成亲社会者；原匹配也没有保证单人可获正收益的安全行动。较准确的归类是共同收益下的多均衡协调，不应直接等同标准Stag Hunt。本次只核对正式2页版本，未核其完整预印本的证明与全部实验。

这些近邻支持“收益／训练会改变协调结果”已有广泛基础。若本轮有价值，其具体贡献需要来自：保持信息和物理世界不变，展示可重复的伙伴适应变化，并继续检验这些变化是否带来伙伴相关表达和可复用结构。眼下仍是待检验的路线，没有文献缺口证明。

## 五、为何伙伴可用性操纵暂列下一阶段

在相同物理世界上，让两人的可用性公开或仅各自知道，确实能把伙伴身份变为需要恢复的信息；但必须先证明以下条件。其一，伙伴真值不能被个人需求、物资布局、菜单排序或筛选可行世界的过程泄漏。其二，固定搭档在每个划分都有严格低于最优的上界。其三，可用性、材料、长短、目的地的相关性与训练／留出支持明确，三对伙伴覆盖平衡。其四，不可用者仍按同样时序发送固定长度消息，避免无消息、时间或可见动作泄漏角色。其五，公私条件改变的是同一世界的观察，而不是重新筛出不同世界。

若恰好两人可用且已公开，角色真值直接由外部标志确定；私有条件主要考察伙伴身份信息传播。这可以研究角色表达，但不是三人自主协商分工。若同时更换谁可用、重新限制动作菜单、改变奖励和重建需求世界，则无法把效果归因于可用性公开程度。

Kobrock等已在指称游戏中控制说者能否看见上下文，并分别保留概念／上下文变化，观察信息映射如何随上下文改变。[LREC-COLING2024，§2.3–2.5、§4–5](https://aclanthology.org/2024.lrec-main.339.pdf) 该任务是目标／干扰对象分类，不是伙伴行动协调；其做法说明观察操纵和内容结构应分开定义，不能支持“公开布局必然产生更抽象语言”。本次核对正式18页中的正文方法、主要结果与讨论，未复现代码或附录统计。

因此实施顺序建议为：先执行不改世界的效用对照，明确角色固定是否主要属于当前学习机制；再依据静态信息界构造伙伴表达环境；把冻结转录探针留作针对明确失败模式的有限诊断。无论哪一步出现正结果，都仍需独立初始化、预设留出及原生通信作用检验，方能逐渐形成关于语言形成条件的论文命题。

## 审查边界

以上梯度和一步博弈性质是由现有目标与规则推导的设计判断，不是24次候选训练的结果；新实验尚未由本审查执行。关于三种方案的优先顺序属于研究建议。没有声称首创，也没有把未搜到同一任务等同文献空白。未读取或改动`paper_program`、`redesign_*`分支分析，未改动任何旧冻结文件。
