# Formal archive: binary object-surface remapping

This archive contains the frozen design, merged per-run results, compact aggregate statistics, and independent replay audits for the 9-seed binary object-surface remapping study. The source code is identified by `source_commit.txt`; source hashes and runtime versions are recorded in `plan.json`.

The raw execution trees (training JSONL and compressed checkpoints) remain in temporary storage until the archive manifest and audit bundle are verified, then are removed to conserve local disk space.
