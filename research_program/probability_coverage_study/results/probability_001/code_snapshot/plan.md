# 贪心覆盖与连续成功概率：补充分析固定方案

2026-09-15。状态：在本补充量首次计算之前写定。此前policy_gain_study的64组训练、J/U/N全量结果、形成曲线与两次实现修正已经可见，因此本分析是**看到既有结果后提出的诊断**，不是独立确认或训练前注册的主要效应。不修改前轮的指标、停止条件、源码或原始记录。

## 问题及范围

贪心接收覆盖U只记录某个完整码是否让两个目标的最大概率动作都正确。排名改变会改变U，却不必使成功概率同幅改变。本轮问：在相同检查点、地图及原自然消息下，U的变化伴随怎样的连续成功概率变化？检验的是测量解释，不能单独定位训练机制或证明语言诞生。

唯一数据源为`policy_gain_study/results/gain_001/probe`已经保存的全部64运行×8检查点×2方向，共1024份记录。种子28101–28104；加性／联合收益与策略权重1／3；三个留出划分与全图参照。检查点固定0、100、300、600、1200、1800、2100、2400，不按下降幅度选择来源。

每份记录有49条完整码×2目标×6地点的原float32 logits，以及30地图×16固定验证照片配对的原贪心消息。读取JSON、恢复数值和计算概率，不加载权重、运行网络、重训或获取新图片。全量为100352个六地点概率向量、602112个地点概率、30720个地图C值和491520个照片消息E_G值。

## 两个连续量

设地图x的食物、水正确地点分别为f、w；同一完整消息为m。使用温度1、float64稳定log-softmax恢复：

`p_g(s|m)=exp(logit[m,g,s]−logsumexp(logit[m,g,:]))`。

每码的联合成功概率为`c_m(x)=p_F(f|m)×p_W(w|m)`；两个量定义为：

- `C(x)=max_m c_m(x)`：实验者根据真实地图选择最佳完整码时，当前接收策略的双目标成功概率上界。
- `E_G(x,z)=c_{m_G(x,z)}(x)`：使用该地图／照片对原有的贪心发送消息，只让接收者按其概率分布独立行动的期望成功率。

两目标必须使用同一完整码。不能分别选各目标最优消息再相乘。固定所有49码的顺序00、01……66，保存全部数值上严格相等的最大码以及其中第一个；不设“接近最优”的阈值。首码仅便于复核，不把数值并列当作词义等价证据。

相乘依赖当前任务的条件独立：固定权重、消息、目标和零库存／历史后，两次行动没有反馈或状态更新，菜单只在最终输出重排。计算的是策略分布的解析参照；有限精度伪随机抽样的某次实际结果不必等于期望。

E_G始终不大于C。C可使用训练未出现的完整码，也让实验者知道真实地图，因此是乐观上界；C−E_G不是纯发送能力的因果量，还可能包括视觉识别与历史训练造成的差别。C不随照片改变，照片重复不增加它的独立样本数。

原stochastic评价同时随机发送与接收，相应期望还要对完整发送分布求和。现有贪心消息没有提供该分布，所以本轮不计算E_S，也不把E_G等同原stochastic J。C/E_G温度固定为1，不扫描温度或更名为经过校准的真实概率。

## 数值与原量核对

所有原logits必须有限且精确回转float32；本轮概率运算统一float64，不延续上轮margin运算的隐式dtype问题。原U/N从实际最大值与消息重算，动作、并列和整数计数须与已保存结果一致。原最大值并列0继续核对，不允许挑选无并列子集。

概率通过稳定log-softmax得到，再以同码两概率相乘。每个概率向量归一化，所有结果应有限、处于[0,1]并满足E_G≤C；若出现概率或乘积下溢为0，保存全批失败，先检查数值问题，不将其当作结构上的不可能，也不临时调温度或自动重算。本轮不以结果高低设置成功门槛。

独立实现采用与浮点运算相称的明确容差核验连续值；原离散动作、码、最大码集合及整数计数不靠放松容差通过。测试包括均匀策略、明确唯一最大码、最佳码并列、不能分别为目标选码、实际自然码不足最优码、温度尺度的影响、非有限／下溢拒绝，以及完整四格和固定时间积分。

先对每个方向的地图C与地图／照片E_G等权平均。每种子内，再平均两个方向及三个split；split的未见地图是重点解释范围，split训练地图与全图训练范围分列。独立训练起点仍为4个，1024记录或照片不另算独立种子。

完整输出每个种子的8点C/E_G/U/N及C−E_G曲线、2400步终点、0–1200步归一化梯形面积。曲线面积使用固定0、100、300、600、1200五点，不能看到新量后挑时窗。保存同格时间差0→300、300→600、600→1200、0→2400的逐种子值与均值；这些时段根据已经可见的U曲线提出，属于补充描述。

四格对比沿用：两个α下的联合−加性、两个收益下的α3−α1、交互`(联合3−联合1)−(加性3−加性1)`及联合3−加性1辅助对角差。完整报告四种子向量和均值，不按统计显著性增补来源。原J不重新计算成新独立证据；上轮J与固定同照片N/E_G的抽样分母保持不同。

## 解释与反例

若U下降而相同范围的C没有相应下降，说明贪心可用码数与最佳消息下的成功概率有不同轨迹；不能继续把U收缩笼统写成“通信能力整体减少”。若二者均下降，可表述为同时涉及概率质量，不单凭该相关变化定位哪个优化组件。

平均C可能由不同地图改善与退步抵消，所以保存完整逐地图结果；不将均值上升解释为每张失去贪心正确码的地图都改善。若E_G低而C较高，说明存在乐观最优码与实际自然码的差距，不证明只改发送者就能学会达到上界。若新结果削弱此前的广义解释，改写后续报告的主张，保留旧U定义、旧事实及时间记录，不删负结果。

本轮不增加片段替换、人工拼接或新的结构指标，不从连续概率得出词类、句法或自然语言起源结论。下一轮新图库从头形成的设计另外审议；仅换冻结模型的测试照片不能独立检验U形成。
