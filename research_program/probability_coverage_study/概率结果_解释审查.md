# 概率补充结果：解释审查

本次补充结果要求收窄“覆盖收缩”的含义：**U 下降不能概括为最佳完整码的联合成功概率下降；但本批也确实存在自然消息对应的期望成功概率下降，不能把全部退化归为贪心排名的表象。** C 与 E_G 提供了不同于 U 的过程证据，仍不直接给出语言结构或训练内部机制。

本文件于 2026-09-15 读取完整[汇总](results/probability_001/execution/results.json)及[独立数学核验](results/probability_001/audit_probability_001/独立核验.md)后撰写。审查覆盖四条件、四种子、八点曲线、预定早期面积及四段时间差；未重新计算新的指标、读取权重、调用模型、下载照片或修改主分析。独立核验已从原 JSON 重算全部 1024 份记录、30,720 个地图 C、491,520 个 E_G；本次是解释审阅，不冒充另一轮逐图重算。

## 1. 留出地图：四格和固定时间段

C 是针对真实地图选择最佳完整码时，两目标独立抽样均正确的概率；E_G 固定原贪心发送码，只对接收行动求期望。U／N 则分别是贪心规则下的存在正确码／实际自然码正确。四者均可写成百分数，但并非同一个量，不能把 U 的百分点直接解释为损失了多少概率质量。

下表全为留出地图。每格先平均三个划分及两个方向，再取四种子均值。数值是既定时间差，单位为百分点；括号依次给出种子 28101、28102、28103、28104 的方向，`0` 表示精确未变。它保留种子方向，不能说明每个种子内所有地图同向。

三个事实尤其约束此前解释。

第一，0→300 的 U 在四格四种子都下降；但加性×1、加性×3、联合×3 的 C 在各自四种子都上升。联合×1 是反例：C 四种子都小幅下降，均值 −0.36 个百分点，同时 E_G 四种子均上升。不能说所有早期 C 都上升，也不能说 U 的大幅下降总伴随自然概率退化。

第二，联合×1 的 300→600 是最清楚的三者分离：U 四种子均下降，C 四种子均上升，而 E_G 四种子均下降。其 C 变化依次为 +2.13、+0.43、+0.61、+2.22 个百分点；E_G 为 −1.54、−0.62、−1.05、−1.02。最佳可选码的概率提高，并没有阻止实际自然消息对应的联合成功概率变低。

第三，从起点到终点，四格每个种子的 C 都上升；U 均下降，只有加性×1 的第一个种子不变。E_G 却依条件而异：加性×3 的四种子都下降，联合×3 的四种子都上升，正常权重两格各有一个种子下降。故“终点 U 比随机起点低”不能单独构成整体通信能力退化的证据；“所有使用失败都是指标伪象”同样不成立。

## 2. 早期面积改变了对策略增益的具体判断

以下为留出图 0–1200 的既定梯形面积／1200，表示由保存点近似的时间平均水平，不是收缩幅度或形成时刻。

| 条件 | C | E_G | C−E_G | U | N |
|---|---:|---:|---:|---:|---:|
| 加性×1 | 14.83% | 3.05% | 11.79% | 28.04% | 3.19% |
| 加性×3 | 14.35% | 2.19% | 12.16% | 26.22% | 2.12% |
| 联合×1 | 9.75% | 3.96% | 5.79% | 24.25% | 4.06% |
| 联合×3 | 13.24% | 3.08% | 10.16% | 24.74% | 2.62% |

联合条件提高到三倍策略权重后，C 的早期面积在四种子均提高，差值为 **+1.26、+1.88、+1.97、+8.85** 个百分点，均值 **+3.49**。这是一项实际的连续概率改善，不能用旧 U 面积“仅提高 0.49、且只有一个种子提高”的结论将其抹去。

与此同时，E_G 面积变化为 **+0.47、+0.74、−3.36、−1.38**，均值 **−0.88** 个百分点；C−E_G 的面积在四种子都增加，均值 **+4.37**。因此应说“最佳完整码的早期概率潜力提高，但自然使用没有同步改善”，而不是笼统说“三倍策略权重没有任何早期改善”。这个差值仍不是发送者的独立因果缺陷，可能涉及视觉、发送选择与双方共同训练的历史。

早期 C 面积的四格交互均值为 **+3.97** 个百分点；E_G 为 **−0.03**，四种子异号。不能把后者接近零当等效性证据，也不能把前者直接对应到旧主 J 的 +1.94 个百分点交互。它们的读数和时间范围不同。

## 3. 终点缺口与地图范围仍然存在

| 条件 | 留出 C | 留出 E_G | 留出 C−E_G | 已见 C | 已见 E_G |
|---|---:|---:|---:|---:|---:|
| 加性×1 | 24.95% | 3.88% | 21.06% | 80.39% | 77.31% |
| 加性×3 | 19.82% | 1.06% | 18.76% | 61.92% | 56.16% |
| 联合×1 | 28.10% | 7.14% | 20.96% | 94.55% | 93.49% |
| 联合×3 | 25.94% | 6.46% | 19.47% | 88.39% | 87.40% |

这里“已见”是三个 split 的训练地图，仍使用同一批固定验证照片。完整地图训练参照另列，终点 C／E_G 四格依次为 **77.23／74.19、64.14／58.67、93.06／92.82、94.24／93.24%**。这些范围差异支持继续研究训练地图支持与自然选码的关系，但没有将哪一个内部模块识别为唯一原因。

贪心 U 的早期下降也不是留出图专有现象：已见和 full 范围的加性条件在 0→300 也出现平均 U 下降，而 C／E_G 四种子均上升。联合×1 在已见和 full 的 300→600 平均 U 下降，C／E_G 又均为四种子上升。因此，把任何 U 谷值直接命名为“组合泛化崩塌”尤其不妥。

终点留出 C 的三倍增益效应在加性／联合下分别为 −5.13／−2.16 个百分点；E_G 为 −2.82／−0.68。其平均正交互仍来自不同下降幅度，且种子方向不一。旧报告“三倍增益没有稳定修复未见自然使用”的有限判断继续成立，不能扩展为对所有连续接收性质都无改善。

## 4. 我们是否只发现了 greedy argmax 伪象

**不是一个纯粹的计算伪象，也不是足以解释所有过程变化的单一机制。** 原 U／N 是指定贪心策略下的有效读数，实际正常模式也执行贪心决策。新增分析精确重现了旧 U／N，原 margin 的 dtype 修正没有改变动作或指标。这里需要修正的是用 U 代表全部概率能力的解释。

数据确实表明存在明显的指标分离：例如联合×3 的留出 U 从 50.00% 降到 14.58%，而 C 从 4.47% 升到 4.91%。这与“许多相对排名变化不对应同方向的最佳联合概率变化”相容。但仅凭聚合 C 上升，不能断言每张失去贪心正确码的地图都保留了概率质量，也不能量化多少 U 变化由接近并列的翻转造成。本轮未登记并计算这类逐地图条件化归因，不应从均值倒推出它们。

自然消息的连续参照也记录到下降：加性×3 的 E_G 在 0→300 和 0→2400 均为四种子下降，联合×1 的 300→600 亦然。这是在固定温度、当前模型概率分布和实际自然码下的期望变化，不能归咎于接收贪心阈值一个环节。但 E_G 跨时间同时受发送码与接收分布变化影响，不能直接命名为“发送者退化”。

C 的最大化使用研究者知道的真地图及全部 49 码；E_G 固定旧贪心发送输出。二者不是原随机发送／随机接收模式的完整期望，也不等于现实中已校准的成功概率。不同 logits 尺度可以在 U 不变时改变 C／E_G，这进一步限制了把某一种轨迹叫作唯一真实能力的做法。

## 5. 中心主张应怎样收窄

建议保留的主张是：**在这个固定的双目标视觉通信任务中，任务效用与策略损失权重会影响贪心完整码覆盖、最优码的联合成功概率及自然码的实际使用；这些性质具有不同的形成轨迹，对训练地图范围也有明显依赖。** 它描述已完成干预及可观察结果，不预先宣称独有机制或语言诞生。

应收回或避免的宽表述包括：“随机起点有较高通信能力，训练令其整体坍缩”“三倍增益没有改善任何早期形成性质”“既有结果已证明缺口完全在接收覆盖／完全在发送者”“U 谷值就是约定形成的拐点”。新的连续参照对这些概括提供反例。

可以更具体地说：本批联合条件的三倍增益在四个种子都提高了早期最优码概率面积，却没有带来一致的自然码概率改善；到终点，留出图在乐观最优码与自然码之间仍有明显差距。C 上升与 U 下降的并存要求同时报告决策规则和概率分布，不能只选其中更有利于某一叙事的指标。

这仍是看到旧 J／U／N 后设计的同数据补充分析，使用四个训练种子和旧开发照片。它澄清了测量含义，尚未完成新视觉／新生态确认，也没有新增句法、组合结构或人类语言起源的证据。后续主线应围绕预先固定的形成假设做独立确认，而不是将这次解释修正本身包装成完整论文贡献。
