# 单人需求变化与执行搭档：保存末点的追加诊断

本分析在已知总体能力结果后提出，是既有政策的追加描述，不是新的独立确认。分析定义、案例和代码在读取按这些案例聚合的结果前固定。不新增网络前向、参数加载或训练，不以本诊断分数筛选下一轮种子或更改任务。

来源为 `triadic_reciprocal_execution_study/results/rules_001` 的全部四个种子、两执行规则、四个完整末点分区，共32份保存输出。保留对象/材料、长短、搭档、目的地，任务与原分布完全不变。

对每个分区，枚举仅改变一个人的原有单轴需求翻转、另两人需求及布局/归属相同、两端均在分区支持内且唯一正确执行搭档不同的无向边。每边只计一次，不按政策行为或成功筛选。保存紧凑需求边和全部布局×归属背景。完整分区索引及逐行状态必须与冻结的原始笛卡尔顺序一致。

令两端真值为不同搭档 t0、t1，实际执行搭档为 e0、e1；未执行用−1且计错。Q为两端均选中各自正确执行搭档的概率。每个变化主体×轴内背景等权、边等权，随后三主体和三轴等权；九层如有结构空层，整体主量记null并明确披露，不能删除空层后重加权。静态案例支持在运行前核验。

唯一诊断主量：reciprocal训练政策在reciprocal结算下，完整双留出Q减去背景内输出精确置换期望，再对四个既有种子等权。固定背景有N个需求世界，其中输出搭档t的数量为n_t，则每边置换期望为 n_t0*n_t1/[N*(N−1)]，不抽样置换。该参照保持搭档频数与不执行率，不代表最优静默政策，也不是通信因果对照。

辅助保留原始Q、置换期望、所有主体×轴层、两端都对/只一端对/都错、输出改变率（含执行与不执行切换）及两端均执行且实际搭档改变率。两种训练政策均主要按reciprocal结算；strict结算作为辅助，不能因新政策第三人不等待而误解零分。报告所有四分区和种子。

运行前冻结本方案、新分析源文件、纯测试及静态支持记录，绑定旧plan/result/独立audit和32份NPZ的既有摘要；读取时再次验证文件摘要。独立实现重枚举案例、结算保存提议并重算主辅统计。失败保留，不覆盖输出目录。

结果仅描述对局部需求改变的行为响应范围和一致性。不能从Q、伙伴多样性、满分或相对置换超额声称语言、词义或组合性。下一轮私人信息开放/静默实验的指标和预算另行事先固定，不设本诊断的能力通过线。
