# New-receiver joint-combination holdout

This package adds a compositional generalization test to the frozen-pair
transmission line.  It trains a fresh A on 1248 semantic-orbit combinations
and evaluates 312 unseen combinations, while using the existing audited
generation-2 all-needs run as a matched control.  Run `runner.py prepare`,
`runner.py execute`, `audit.py`, `summarize.py` and `plot_results.py` in order.
