# 无加工、无道路事件的三主体实验

**最近结果（2026-09-15）：** 两场完整信息能力检查已结束，分别为12步0/2件、5步3/3件。门槛未全部通过，后续阶段按预设规则未启动。见[结果与下一步](/Users/xia/Documents/ChatGPT/语言/qwen_language_v3/results/20260915_152343/summary/结果与下一步.md)和[逐步回放](/Users/xia/Documents/ChatGPT/语言/qwen_language_v3/results/20260915_152343/replays/capability_full_information/replay.html)。

本版落实2026-09-15确认的简化：8件资源从开始就可搬运，移除加工及斧具，道路永久双向开放。长木材仍须两人选择同一物体、互为搭档、匹配动作与目的地；短木材和纤维可单人搬运。资源的种类、长短、干湿、数量和交付地点仍须完全匹配。旧v2代码与全部结果保留。

三个主体使用同一本地Qwen3.5-9B-8bit权重，各自接收局部观察、私有物品句柄和经历历史。模型参数固定，每次推理使用新缓存。即时通信采用每步四个同步广播窗口；8种符号，每条最多32字符、每人每步最多64字符。没有提供共享词典或通信角色。当前仍只保留原始经历，不增加跨决定的自写私有笔记。

**执行顺序与门槛。** 先完成两个独立的完整信息能力场景，两场都在12步内完成全部交付，才进入两个独立的局部自然语言能力场景。同阶段第一场失败仍完成第二场；任何阶段未通过，就结束本轮后续阶段并报告全部结果。每个能力场景均从三人的空白历史开始。两个场景都要求双人搬运长木材，并变化属性、目的地与最初读板者；它们同时改变多个参数，不是单因素比较。

只有四场能力检查全部通过，才运行一个即时通信群体的连续三段符号任务：第一段建立互动经历，第二段改变需求，第三段恢复第一段的需求类型并更换资源地点、主体起点与私有句柄。符号三段保留同一群体各自的原始经历；这提供候选约定及反例的过程记录，不单凭成功或字符串复现认定共同语言。

预选第1、3段第2步进行原消息／本步文字置空重放。保留原历史、观察、发送者、窗口和种子，先检查原动作是否重现；该干预检查本步文字的行为影响，不是整段无通信基线或组合性检验。第2步可能尚无交付，分数不变不等于行动不受影响。

配置、候选场景选择依据和条件预算在首次模型调用前保存在[锁定配置](experiment_locked.json)。最多4场能力检查、3段符号任务及2个冻结状态，共2544次模型调用；能力门槛未过时不会启动后续阶段，任务成功则提前结束该段。各次运行保存自身源码快照与配置，不依据符号结果增减重复。
